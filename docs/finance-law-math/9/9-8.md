### 前節（9-7）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（時系列解析とボラティリティ）の導入になります。

1. **プロスペクト理論の価値関数による選択の計算：**

    価値関数 $v(x) = \sqrt{x}$（$x \ge 0$）、$v(x) = -2.25\sqrt{-x}$（$x < 0$）を用いて評価します。

    * **(a) 利得領域の選択：**

        * 確実な $+400$ 万円：$v(400) = \sqrt{400} = \mathbf{20.0}$
        * 賭け（$50\%$ で $+900$ 万円、$50\%$ で $0$ 円）：$0.5 \times \sqrt{900} = 0.5 \times 30 = \mathbf{15.0}$

        $20.0 > 15.0$ より、投資家は**確実な $+400$ 万円**を選びます（リスク回避）。

    * **(b) 損失領域の選択：**

        * 確実な $-400$ 万円：$v(-400) = -2.25 \times \sqrt{400} = \mathbf{-45.0}$
        * 賭け（$50\%$ で $-900$ 万円、$50\%$ で $0$ 円）：$0.5 \times (-2.25 \times 30) = \mathbf{-33.75}$

        $-33.75 > -45.0$ より、投資家は**賭け（$50\%$ で $-900$ 万円、$50\%$ で $0$ 円）**を選びます（リスク愛好）。

2. **効率的市場仮説と裁定の限界：**

    * **(a) 公開情報が即座に価格へ織り込まれる仮説：**

        **セミストロング型**の効率的市場仮説と呼びます。

    * **(b) ノイズ・トレーダー・リスクによる裁定の限界：**

        割高な株を空売りしても、非合理な買い手の参入で一時的に価格がさらに高騰する恐れがあり、プロの機関投資家であっても顧客解約や証拠金不足に耐え切れず損失確定（撤退）を迫られるためです。

3. **株価の「水準」は予測できなくても、「変動の激しさ」は予測できるのか（本節への接続）：**

    金融市場の価格水準はランダムウォーク（単位根過程）に近く、明日の上昇・下落を予測することは困難です。しかし、リターンの変動幅（**ボラティリティ**）には「荒れた時期は荒れた日が続き、穏やかな時期は穏やかな日が続く」という強い持続性があります。こうした時間依存の構造を扱う統計モデルが、**ARMA モデル**と **ARCH・GARCH モデル**です。

## 9-8. 時系列解析とボラティリティ（ARMA・GARCH）

### 1. 動機（Why）：なぜ通常の回帰分析を時系列データへそのまま当てはめると失敗するのか

第0部（0-8節）で学んだ通常の線形回帰分析は、各観測データが「互いに独立」であり、「誤差の分散が常に一定（等分散）」であることを前提にしています。

ところが、株価・為替レート・金利・GDP といった時間の順に並ぶ**時系列データ**には、通常の回帰分析の前提を壊す2つの固有の性質があります。

1. **時間を通じた依存関係と「見せかけの回帰」：**

    今日の株価は昨日の株価に強く引きずられています。互いにまったく無関係な2つのトレンド付き時系列（たとえば「日本の株価」と「ブラジルの気温の累積和」）をそのまま回帰分析したとします。すると、たまたま両方とも右上がりだというだけで決定係数 $R^2$ が $0.9$ を超え、統計的に有意に見えてしまう**見せかけの回帰（Spurious Regression）**が起きます。

2. **時間とともに変化するボラティリティ（ボラティリティ・クラスタリング）：**

    株式リターン（日次変化率）をグラフにすると、普段は1日 $\pm 1\%$ 以内の静かな値動きが続く一方、金融危機やショックが起きると数週間にわたって毎日 $\pm 4\% \sim 6\%$ の乱高下が塊（クラスター）になって続きます。分散 $\sigma^2$ が一定ではなく**時間 $t$ に応じて変化する（条件付不均一分散）**ため、固定の標準偏差だけでは危機時のリスクを即座に捉えられません。

本節では、時系列データの基本条件である**弱定常性**と **ARMA モデル**から出発し、金融価格のランダムウォークを表す**単位根過程と共和分**、そして時間変動するボラティリティを記述する **ARCH・GARCH モデル**を順に整理します。

### 2. 具体例と計算イメージ（Toy Model）

一般的な定義に入る前に、①自己回帰係数 $\phi$ の違いがショックの残り方をどう変えるか（定常 vs 単位根）、②GARCH(1,1) モデルで1日の暴落が翌日以降のボラティリティをどう押し上げるか、の2つを手計算で確認します。

#### 実験A：AR(1) モデルにおける「定常（$\phi = 0.5$）」と「ランダムウォーク（$\phi = 1.0$）」

ある時系列 $y_t$ が、1期前の値 $y_{t-1}$ と平均 $0$・分散 $\sigma_\varepsilon^2 = 1$ の独立なノイズ $\varepsilon_t$ から次式で決まるとします（$y_0 = 0$）。

$$y_t = \phi\, y_{t-1} + \varepsilon_t$$

ここで $t = 1$ に大きさ $\varepsilon_1 = +10$ の一時的なショックが1回だけ起きた後、$t \ge 2$ はノイズが $0$ だったとして、ショックの残り方を比べます。

* **$\phi = 0.5$（定常過程）：**

    $y_1 = 10 \to y_2 = 5 \to y_3 = 2.5 \to y_4 = 1.25 \to y_5 = 0.625 \to \dots \to \mathbf{0}$

    ショックは毎期半分ずつ減衰し、やがて平均 $0$ へ戻ります（**平均回帰性**）。また、長期的な分散は一定の有限値 $V[y_t] = \dfrac{1}{1 - 0.5^2} = \mathbf{1.333}$ に収まります。

* **$\phi = 1.0$（単位根過程＝ランダムウォーク）：**

    $y_1 = 10 \to y_2 = 10 \to y_3 = 10 \to \dots$（永久に $10$ のまま消えない）

    過去のショックがすべて蓄積され、分散は $V[y_t] = t \cdot \sigma_\varepsilon^2 = \mathbf{t}$ と時間とともに無限大へ広がり続けます。株価の「水準（対数価格）」はこの $\phi = 1$ に近く、1期前の差をとった「リターン（$\Delta y_t = y_t - y_{t-1} = \varepsilon_t$）」へ変換して初めて定常データになります。

#### 実験B：GARCH(1,1) モデルによるボラティリティの急上昇と減衰

日次株式リターン $\varepsilon_t$（単位：%）の条件付分散 $\sigma_t^2$（前日までの情報に基づく当日の予測分散）が、次の **GARCH(1,1) モデル** に従うとします。

$$\sigma_t^2 = 0.2 + 0.1\,\varepsilon_{t-1}^2 + 0.8\,\sigma_{t-1}^2$$

1. **平常時の長期水準（無条件分散）：**

    後述の公式（3(3)で導出）より、$\alpha + \beta = 0.1 + 0.8 = 0.9 < 1$ のとき、長期的な平均分散は

    $$\bar{\sigma}^2 = \frac{\omega}{1 - \alpha - \beta} = \frac{0.2}{1 - 0.9} = \mathbf{2.0} \qquad (\text{長期標準偏差 } \bar{\sigma} = \sqrt{2.0} \approx \mathbf{1.41\%})$$

2. **暴落ショックが起きた翌日の予測分散：**

    平常時（$\sigma_0^2 = 2.0$）の日に、突然 **$\varepsilon_0 = -5\%$** の大きな暴落（$\varepsilon_0^2 = 25$）が起きたとします。すると、翌日（$t = 1$）の予測分散は一気に跳ね上がります。

    $$\sigma_1^2 = 0.2 + 0.1(25) + 0.8(2.0) = 0.2 + 2.5 + 1.6 = \mathbf{4.3} \qquad (\text{標準偏差 } \sqrt{4.3} \approx \mathbf{2.07\%})$$

3. **その後の緩やかな回帰（持続性 $\alpha + \beta = 0.9$）：**

    時点 $0$ までに得られたすべての情報の集合を $\mathcal{F}_0$ と書くと、$E[\varepsilon_1^2 \mid \mathcal{F}_0] = \sigma_1^2 = 4.3$ であるため $\alpha$ と $\beta$ がまとまり、2日目の予測分散の条件付期待値は $E[\sigma_2^2 \mid \mathcal{F}_0] = 0.2 + (0.1 + 0.8) \times 4.3 = \mathbf{4.07}$（標準偏差約 $2.02\%$）となります。一般に $h$ 日後の予測分散は

    $$E[\sigma_h^2 \mid \mathcal{F}_0] = \bar{\sigma}^2 + (\alpha + \beta)^{h-1}\bigl(\sigma_1^2 - \bar{\sigma}^2\bigr) = 2.0 + 0.9^{h-1}(2.3)$$

    と、1日ごとに差の $90\%$ を残しながらゆっくり長期水準 $2.0$ へ戻っていきます（図9-8-1右）。これが現実の市場で観測される**ボラティリティ・クラスタリング**の数理表現です。

### 3. 定義・導出・構造（What）

#### (1) 弱定常性・自己相関関数と ARMA($p, q$) モデル

時系列データ $\{y_t\}$ を統計的に分析するための基本条件が**弱定常性（Weak Stationarity）**です。すべての時点 $t$ について、①平均 $E[y_t] = \mu$ が一定、②分散 $V[y_t] = \gamma_0$ が一定、③$k$ 期離れた2時点の自己共分散 $\gamma_k := \operatorname{Cov}(y_t, y_{t-k})$ が時点 $t$ によらず**ラグ（時間差）$k$ のみに依存する**とき、弱定常であると言います。自己共分散を分散で割った $\rho_k := \gamma_k / \gamma_0$ を**自己相関係数（ACF）**と呼びます。

定常な時系列を記述する標準モデルが、ホワイトノイズ $\varepsilon_t$（平均 $0$、分散 $\sigma_\varepsilon^2$、異なる時点間で無相関）を用いた **ARMA($p, q$) モデル**です。

1. **AR($p$) モデル（自己回帰モデル）：** 現在の値を過去 $p$ 期分の自身の値で説明するモデルです。特に AR(1) モデル $y_t = c + \phi y_{t-1} + \varepsilon_t$ が弱定常であるための必要十分条件は **$\vert \phi \vert < 1$** であり、このとき無条件平均・分散・自己相関係数は次で与えられます。

    $$\mu = \frac{c}{1 - \phi}, \qquad \gamma_0 = \frac{\sigma_\varepsilon^2}{1 - \phi^2}, \qquad \rho_k = \phi^k \quad (k = 0, 1, 2, \dots)$$

2. **MA($q$) モデル（移動平均モデル）：** 現在の値を現在と過去 $q$ 期分のショック $\varepsilon_t$ の加重和 $y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \dots + \theta_q \varepsilon_{t-q}$ で説明するモデルです（ラグ $q$ を超えると自己相関がちょうど $0$ になります）。
3. **ARMA($p, q$) モデル：** 両者を組み合わせた一般形であり、原系列を $d$ 回差分（$\Delta y_t = y_t - y_{t-1}$）とって定常化してから ARMA($p, q$) を当てはめるモデルを **ARIMA($p, d, q$) モデル**と呼びます。

#### (2) 単位根過程・見せかけの回帰・共和分

AR(1) モデルで $\phi = 1$ となる非定常過程 $y_t = y_{t-1} + \varepsilon_t$（**ランダムウォーク**）を**単位根過程（Unit Root Process）**と呼びます。AR(1) の定常性を判定するために作る方程式 $1 - \phi z = 0$（**特性方程式**）の解（根）がちょうど $z = 1$（単位 $= 1$）になることが名称の由来です。

* **単位根検定（ADF 検定）：** データが定常か単位根かを統計的に判定する標準手法が**拡張ディッキー＝フラー（ADF）検定**です（帰無仮説：「単位根がある［非定常］」）。
* **見せかけの回帰（グレンジャー＝ニューボールド、1974年）：** 互いに独立な2つの単位根過程 $x_t, y_t$ をそのまま回帰すると、通常の $t$ 検定が破綻し、無関係なのに有意と誤判定します。したがって原則として、**1階差分（リターン）をとって定常化してから回帰分析**を行います。
* **共和分（Cointegration：エングル＝グレンジャー、1987年）：** 2つの価格系列 $y_t, x_t$（たとえば同じ企業の現物株価と先物価格、あるいは同業種の大手2社の株価）が、それぞれ単独では単位根（非定常）を持つ場合があります。例外的に、ある線形結合 $y_t - \beta x_t$ だけは**定常（一定の均衡関係へ引き戻される）**になることがあり、この関係を**共和分**と呼びます。共和分は、両者の乖離が広がったときに売って縮まったときに買い戻す**ペア・トレード（統計的裁定）**の数理的基盤になります。

#### (3) ARCH($q$) モデルと GARCH(1,1) モデル

金融リターンの平均はほぼ $0$（あるいは定数 $\mu$）であっても、分散が時間とともに変動します。1982年にロバート・エングルが **ARCH モデル**を提案し、1986年にティム・ボレルスレフがそれを **GARCH モデル**（一般化自己回帰条件付不均一分散モデル）へ一般化しました。これらのモデルでは、当日のショックを $\varepsilon_t = \sigma_t z_t$（$z_t$ は平均 $0$・分散 $1$ で互いに独立かつ同じ分布に従う**独立同一分布［i.i.d.］**の標準化誤差）と表し、前日 $t - 1$ までの情報集合 $\mathcal{F}_{t-1}$ のもとでの条件付分散 $\sigma_t^2 = V[\varepsilon_t \mid \mathcal{F}_{t-1}]$ の時間発展を記述します。

実務で最も広く使われる **GARCH(1,1) モデル** は次の1本の式で定義されます（$\omega > 0,\; \alpha \ge 0,\; \beta \ge 0$）。

$$\sigma_t^2 = \omega + \alpha\,\varepsilon_{t-1}^2 + \beta\,\sigma_{t-1}^2$$

* **$\alpha$（ARCH 項）：** 前日のサプライズ（大きな値動き $\varepsilon_{t-1}^2$）に対して、翌日のボラティリティがどれだけ敏感に跳ね上がるかを表します。
* **$\beta$（GARCH 項）：** 前日のボラティリティ水準 $\sigma_{t-1}^2$ を翌日へどれだけ引き継ぐかを表します。
* **弱定常条件と長期（無条件）分散：** 両辺の無条件期待値 $\bar{\sigma}^2 = E[\sigma_t^2] = E[\varepsilon_{t-1}^2]$ をとると $\bar{\sigma}^2 = \omega + (\alpha + \beta)\bar{\sigma}^2$ となるため、**$\alpha + \beta < 1$** が分散の定常条件であり、長期分散は次式で求まります。

    $$\bar{\sigma}^2 = \frac{\omega}{1 - \alpha - \beta}$$

実際の株式市場データへ GARCH(1,1) を最尤推定すると、多くの場合 $\alpha \approx 0.05 \sim 0.15$、$\beta \approx 0.80 \sim 0.90$、合計 **$\alpha + \beta \approx 0.95 \sim 0.99$** となり、一度高まったボラティリティが長く持続する性質がよく捉えられます。

> **【コラム：株価の下落は上昇よりボラティリティを強く押し上げる「レバレッジ効果」】**
>
> 標準的な GARCH(1,1) モデルでは、前日のリターンが2乗された $\varepsilon_{t-1}^2$ の形で入るため、「$+5\%$ の急騰」と「$-5\%$ の急落」が翌日のボラティリティへ与える影響はまったく同じになります。
>
> しかし実際の株式市場では、**株価が大きく下落した直後の方が、同じ幅だけ上昇した直後よりもボラティリティがはるかに大きく跳ね上がる**という非対称性が強く観測されます。これを**レバレッジ効果（Leverage Effect）**と呼びます（株価が下落すると企業の株式時価総額 $E$ が減って負債比率 $D/E$ が上昇し、9-4節の MM 第2命題の通り株式のリスクが高まるため、また投資家の恐怖によるパニック売りが連鎖するためです）。
>
> この非対称性を組み込むため、実務では下落時（$\varepsilon_{t-1} < 0$）に $1$、それ以外で $0$ をとる指示関数 $\mathbf{1}_{\{\varepsilon_{t-1}<0\}}$ を用いて追加の係数 $\gamma > 0$ を足す **GJR-GARCH モデル**（$\sigma_t^2 = \omega + (\alpha + \gamma \mathbf{1}_{\{\varepsilon_{t-1}<0\}})\varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2$）や、対数分散 $\ln \sigma_t^2$ をモデル化する **EGARCH モデル** が広く用いられています。

### 4. 限界と補正（Critique & Adaptation）

ARMA モデルと GARCH モデルは金融時系列解析の標準ツールですが、実務の予測とリスク管理へ適用する際には次の2つの限界を補う必要があります。

#### (1) 「構造変化（レジーム・スイッチング）」と長期予測の限界

ARMA・GARCH モデルは、パラメータ $(\omega, \alpha, \beta)$ が過去から将来までずっと一定であると仮定しています。しかし、中央銀行の金融政策の大転換、戦争・パンデミック、あるいは市場制度の変更といった**構造変化**が起きると、過去のパラメータが突然通用しなくなります。

* **実務上の補正：** モデルの次数 $(p, q)$ を過剰に増やすと過学習を起こすため、**AIC・BIC（情報量規準）**で簡潔なモデル（実務では GARCH(1,1) が最有力）を選びます。さらに、平常レジームと危機レジームがマルコフ連鎖で切り替わる**マルコフ・スイッチングモデル**や、指数加重移動平均（**EWMA**：$\sigma_t^2 = \lambda \sigma_{t-1}^2 + (1 - \lambda)\varepsilon_{t-1}^2$ として、減衰係数 $\lambda$［日次データの標準設定 $\lambda = 0.94$ など］により直近データに重い重みを置くリスクメトリクス法）が併用されます。なお、EWMA は $\omega = 0,\; \alpha + \beta = 1$（IGARCH）に相当するため、GARCH(1,1) の定常条件 $\alpha + \beta < 1$ を満たさず長期分散への平均回帰を持たない点に留意し、主に短期（翌日〜数日）のリスク予測に用いられます。

#### (2) 標準化誤差の「正規分布仮定」の限界と高頻度データ（実現ボラティリティ）

1. **裾の重さへの補正（t-GARCH）：** GARCH モデルでボラティリティ変動を取り除いた後の標準化誤差 $z_t = \varepsilon_t / \sigma_t$ でも、実際の金融データには正規分布より重い裾（8-8節）が残ることがほとんどです。そのため、$z_t$ に正規分布ではなく **$t$ 分布**や一般化誤差分布を仮定する **t-GARCH モデル** を用いて、VaR や TVaR の過小評価を防ぎます。
2. **日次データの情報不足への補正（実現ボラティリティ）：** 通常の GARCH は1日1個の終値リターン $\varepsilon_t^2$ しか使わないため、日中に大きく荒れて終値だけ元に戻った日のボラティリティを見落とします。現代の実務では、5分刻みなどの高頻度データ（日中リターン）の2乗和として計算する**実現ボラティリティ（Realized Volatility：RV）**を用いることで、当日のボラティリティ計測精度を大幅に高めています。

### 5. 接続と展望（Bridge）：本節の内容が後半のどの部に繋がるか

1. **次節（9-9節：デリバティブの基礎［先物・フォワード・スワップ・オプション］）：**

    本節で「金融資産のボラティリティ（変動の激しさ）」を時系列データから計測する手法が揃いました。次節からは、この価格変動リスクをヘッジ（あるいは取引）するための金融派生商品である**デリバティブ（先物・フォワード・スワップ・オプション）**の契約構造と無裁定価格の基礎へ進みます。

2. **第9部（9-11節：ブラック＝ショールズ方程式とグリークス）：**

    9-11節で学ぶブラック＝ショールズモデルでは、計算の単純化のため「ボラティリティ $\sigma$ は一定」と仮定します。しかし現実の市場では本節で見た通りボラティリティが時間変動するため、オプション市場の価格から逆算される**インプライド・ボラティリティ（ボラティリティ・スマイル）**や確率的ボラティリティモデルへの補正が必要になります。
