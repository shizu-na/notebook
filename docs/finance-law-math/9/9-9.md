### 前節（9-8）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（デリバティブの基礎）の導入になります。

1. **AR(1) モデルの定常性とモーメントの計算：**

    AR(1) モデル $y_t = 2.0 + 0.6\, y_{t-1} + \varepsilon_t$（$\sigma_\varepsilon^2 = 1.6$）について計算します。

    * **(a) 弱定常の理由と無条件平均 $\mu$・無条件分散 $\gamma_0$：**

        自己回帰係数が $\vert \phi \vert = 0.6 < 1$ を満たすため、この過程は弱定常です。

        $$\mu = \frac{c}{1 - \phi} = \frac{2.0}{1 - 0.6} = \mathbf{5.0}, \qquad \gamma_0 = \frac{\sigma_\varepsilon^2}{1 - \phi^2} = \frac{1.6}{1 - 0.36} = \frac{1.6}{0.64} = \mathbf{2.5}$$

    * **(b) 自己相関係数 $\rho_1,\; \rho_2$：**

        $$\rho_1 = \phi = \mathbf{0.6}, \qquad \rho_2 = \phi^2 = \mathbf{0.36}$$

2. **GARCH(1,1) モデルの長期分散と翌期予測の計算：**

    $\sigma_t^2 = 0.3 + 0.15\,\varepsilon_{t-1}^2 + 0.75\,\sigma_{t-1}^2$ について計算します。

    * **(a) 定常条件と長期（無条件）分散 $\bar{\sigma}^2$：**

        $\alpha + \beta = 0.15 + 0.75 = 0.90 < 1$ であるため定常条件を満たします。長期分散は

        $$\bar{\sigma}^2 = \frac{\omega}{1 - \alpha - \beta} = \frac{0.3}{1 - 0.90} = \mathbf{3.0}$$

    * **(b) 翌日の条件付分散 $\sigma_t^2$（$\sigma_{t-1}^2 = 3.0,\; \varepsilon_{t-1} = -4.0$）：**

        $$\sigma_t^2 = 0.3 + 0.15 \times (-4.0)^2 + 0.75 \times 3.0 = 0.3 + 2.4 + 2.25 = \mathbf{4.95}$$

3. **価格変動リスクを「契約」で移転・固定化するデリバティブ（本節への接続）：**

    将来の為替レート・金利・株価の変動リスクを、あらかじめ決めた価格で固定化する契約が**先物・フォワード**、固定金利と変動金利のキャッシュ・フローを交換する契約が**スワップ**、不利なときだけ権利を放棄して損失を限定できる契約が**オプション**です。これらを総称して**デリバティブ（金融派生商品）**と呼び、その理論価格は**無裁定条件**から導かれます。

## 9-9. デリバティブの基礎（先物・フォワード・スワップ・オプション）

### 1. 動機（Why）：なぜ「将来の価格を今約束する契約」の値段は、将来の予想ではなく無裁定で決まるのか

9-1節〜9-8節では、債券・株式といった現物資産の価格評価と、そのボラティリティ（変動の激しさ）の性質を学びました。

ここで、3か月後に米国から部品を $100$ 万ドルで輸入する日本の製造業を想像します。現在 $1$ ドル $= 150$ 円（$1.5$ 億円）ですが、もし3か月後に $1$ ドル $= 170$ 円へ円安が進めば、支払額が $2{,}000$ 万円も増えて本業の利益が大きく損なわれてしまいます。このように、本業とは無関係な価格変動リスク（為替・金利・原油・株価）を切り離して他者へ移転する（**ヘッジ**する）ために生まれた契約が**デリバティブ（金融派生商品）**です。

デリバティブの価格理論には、初学者が意外に感じやすい重要な原則があります。それは、**「将来の価格を約束するフォワード（先渡）契約の公正な価格を決めるのに、『将来株価が上がるか下がるか』という予想は一切不要である」**という事実です。もし理論価格から少しでもずれた値段がつけば、現物と借入れを組み合わせるだけで元手ゼロから確実に儲かる**裁定機会（アービトラージ）**が生まれてしまうからです。

本節では、デリバティブの4大基本商品（**フォワード・先物・スワップ・オプション**）の契約構造と損益（ペイオフ）を整理したうえで、**無裁定条件**からフォワード理論価格、公正なスワップレート、そしてオプションの基本関係式である**プット・コール・パリティ**を導出します。

### 2. 具体例と計算イメージ（Toy Model）

一般的な定義に入る前に、無配当の株式を用いた①**フォワードの無裁定価格**と②**プット・コール・パリティ**の2つを手計算で確認します。

#### 実験A：現在株価 $1{,}000$ 円・年利 $5\%$ におけるフォワード価格と裁定取引

現在株価が **$S_0 = 1{,}000$ 円**（1年間配当なし）、無リスク金利が年 **$r = 5\%$**（年1回複利）である市場を考えます。このとき、「1年後にこの株を売買するフォワード（先渡）契約」の公正な価格 $F_0$ はいくらになるでしょうか。

結論は **$F_0 = 1{,}000 \times 1.05 = 1{,}050 \text{ 円}$** です。もし市場で $F_0 = 1{,}080$ 円という割高な値段がついていた場合、次の手順（**キャッシュ・アンド・キャリー裁定**）で、将来の株価が $500$ 円になっても $2{,}000$ 円になっても確実に $+30$ 円儲かります。

1. **現在（$t = 0$）：** 銀行から $1{,}000$ 円を年利 $5\%$ で借り、その $1{,}000$ 円で現物株を1株買います（手元の自己資金は $0$ 円です）。同時に、「1年後に $1{,}080$ 円で売る」フォワード売り契約を結びます。
2. **1年後（$t = 1$）：** 手元の株をフォワード契約に従って $1{,}080$ 円で引き渡し、銀行へ元利合計 $1{,}050$ 円を返済します。
3. **結果：** 1年後の株価水準によらず、手元に **$1{,}080 - 1{,}050 = +30 \text{ 円}$** の無リスク利益が確実に残ります。

逆に市場価格が $1{,}020$ 円と割安なら、現物株を空売りして $1{,}000$ 円を年利 $5\%$ で運用しつつフォワード買い契約を結べば、確実に $+30$ 円儲かります。この裁定取引が瞬時に働くため、市場のフォワード価格は必ず **$F_0 = 1{,}050$ 円** へ一致します。

#### 実験B：同じ条件におけるプット・コール・パリティの検証

実験Aと同じ株（$S_0 = 1{,}000$ 円、年利 $5\%$、満期 $1$ 年）に対し、権利行使価格 **$K = 1{,}050$ 円** のヨーロピアン・コール（買う権利：価格 $C$）と、同じ条件のヨーロピアン・プット（売る権利：価格 $P$）を考えます。

「コールを1単位買い、プットを1単位売る（初期コスト $C - P$）」ポートフォリオの1年後の**満期ペイオフ**（契約時のプレミアム収支を除いた満期時点の受取・支払額であり、プレミアムを含めた純損益とは区別します）を、満期株価 $S_1$ で場合分けします。

* $S_1 \ge 1{,}050$ 円のとき：コールを行使して $(S_1 - 1{,}050)$ 円を受け取り、プットは権利放棄で $0$ 円となるため、満期ペイオフの合計は **$S_1 - 1{,}050$** です。
* $S_1 < 1{,}050$ 円のとき：コールは権利放棄で $0$ 円となり、プットが行使されて $-(1{,}050 - S_1)$ 円を支払うため、満期ペイオフの合計は **$S_1 - 1{,}050$** です。

どちらの場合も、満期ペイオフは**「現物株を1株保有し（$S_1$）、満期に額面 $1{,}050$ 円の借入れを返す（$-1{,}050$）」**ポートフォリオと完全に一致します。したがって契約時点の現在価値も一致しなければならず（**プット・コール・パリティ**）、

$$C - P = S_0 - \frac{K}{1.05} = 1{,}000 - \frac{1{,}050}{1.05} = \mathbf{0} \implies C = P$$

となります。もしコール価格が $80$ 円であれば、プット価格も必ず $80$ 円です（図9-9-1左・右）。

### 3. 定義・導出・構造（What）

#### (1) フォワード（先渡）と先物（フューチャーズ）

**フォワード（先渡）契約**とは、将来の特定時点 $T$ に、あらかじめ定めた価格 $F_0$ で原資産（株式・為替・商品など）を売買する**義務**を負う契約です。連続複利の無リスク金利を $r$ とすると、無裁定条件から理論価格は次のように決まります（**保有コストモデル**）。

* **配当・保管コストなし：** $F_0 = S_0 e^{rT}$
* **連続配当利回り $q$ あり（株価指数等）：** $F_0 = S_0 e^{(r - q)T}$
* **外国為替フォワード（邦貨建て［外貨1単位あたりの自国通貨額、例：$1$ ドル $= 150$ 円］、自国金利 $r_d$、外国金利 $r_f$）：** $F_0 = S_0 e^{(r_d - r_f)T}$（第1部 1-4節の**カバー付き金利平価式**そのものです）

フォワード契約と経済的機能は同じですが、取引の安全性を高めるために制度化されたものが**先物（フューチャーズ）取引**です。

| 比較項目 | フォワード（先渡）取引 | 先物（フューチャーズ）取引 |
| --- | :--- | :--- |
| **取引の場** | 店頭取引（OTC：銀行等との相対契約） | 取引所取引（大阪取引所・CME 等） |
| **契約条件** | 金額・満期を自由にカスタマイズ可能 | 取引単位・満期日が標準化 |
| **決済のタイミング** | 満期日に一括決済 | 毎日**清算値段（settlement price）**で損益を精算する**値洗い（マーク・トゥ・マーケット）** |
| **信用リスク** | 相手先が破綻するリスクあり | 清算機関（CCP）と**証拠金制度**によりほぼ排除 |

#### (2) スワップ（金利スワップ）と公正なスワップレート

**スワップ取引**とは、将来の複数時点にわたるキャッシュ・フローを当事者間で交換する契約です。最も取引量が多い**プレイン・バニラ金利スワップ**では、想定元本 $N$ に対して「固定金利 $s$ の支払い」と「市場の変動金利（円金利の TONA・TIBOR やドル金利の SOFR 等）の受け取り」を一定期間（例：5年間）交換します。

金利の交換日を $0 = t_0 < t_1 < \dots < t_n$、各計算期間の長さを $\Delta t_i := t_i - t_{i-1}$（年換算、たとえば半年払いなら $\Delta t_i \approx 0.5$）、最終満期を $t_n$ とします。9-2節で学んだディスカウント・ファクター $P(0, t_i)$（時点 $t_i$ の $1$ 円の現在価値）を使うと、契約開始時点で双方の現在価値がちょうど等しくなる公正な固定金利（**スワップレート** $s^*$）が簡潔に導けます。

変動金利側のキャッシュ・フローの現在価値は、元本 $N$ の受け渡しを仮定した変動利付債が常に額面 $N$（パー）で評価される性質から、$N\bigl(1 - P(0, t_n)\bigr)$ に一致します。一方、固定金利 $s^*$ 側の現在価値合計は $N s^* \sum_{i=1}^n \Delta t_i\, P(0, t_i)$ です。両者を等置すると想定元本 $N$ が両辺で打ち消し合い、公正なスワップレートは元本規模によらず次式で求まります。

$$s^* = \frac{1 - P(0, t_n)}{\sum_{i=1}^n \Delta t_i\, P(0, t_i)}$$

企業は変動金利の銀行借入に「固定払・変動受の金利スワップ」を組み合わせることで、変動金利のキャッシュ・フローを相殺し、借入金利を実質的に固定金利 $s^*$ へ変換して金利上昇リスクをヘッジできます（図9-9-2）。

#### (3) オプションの基本構造とプット・コール・パリティ

**オプション契約**とは、将来の特定日（またはそれまで）に、あらかじめ定めた価格（**権利行使価格 $K$**）で原資産を買う、または売る**権利**（義務ではない）を売買する契約です。権利を買う側（買い手）は、対価として契約時に**プレミアム（オプション料）**を支払います。

* **コール・オプション（買う権利）：** 満期 $T$ のペイオフは $\max(S_T - K, 0) = (S_T - K)_+$ です。
* **プット・オプション（売る権利）：** 満期 $T$ のペイオフは $\max(K - S_T, 0) = (K - S_T)_+$ です。
* **行使時期による区分：** 満期日 $T$ のみ行使できるものを**ヨーロピアン・オプション**、満期日以前ならいつでも行使できるものを**アメリカン・オプション**と呼びます。

実験Bで示した通り、無配当株式に対する同じ満期 $T$・同じ権利行使価格 $K$ のヨーロピアン・コール価格 $C$ とプット価格 $P$ のあいだには、モデルやボラティリティの仮定を一切置かずに無裁定条件だけから次の**プット・コール・パリティ**が常に成り立ちます（図9-9-1右）。

$$C - P = S_0 - K e^{-rT}$$

> **【コラム：オプションの「非対称なペイオフ」と、第8部の損害保険契約の同型性】**
>
> プット・オプションの満期ペイオフ $(K - S_T)_+$ やコール・オプションのペイオフ $(S_T - K)_+$ を見比べると、第8部（8-3節・8-7節）で繰り返し登場した**損害保険のエクセス免責・超過損害額再保険（XL）**の支払式 $(X - d)_+$ と数学的にまったく同じ形をしていることに気づきます。
>
> たとえば、株式ポートフォリオを保有する投資家が、現在の株価水準付近のプット・オプションを購入する戦略（**プロテクティブ・プット**）は、「株価が $K$ 円を下回って暴落したときだけ、その下回り分 $(K - S_T)$ を補填してもらい、株価が上がったときの利益はそのまま享受する」という仕組みです。契約時に支払う**オプション・プレミアム $P$** は、まさに**掛け捨ての保険料**そのものです。
>
> 金融市場のデリバティブ（オプション）と保険市場の契約（免責・再保険）は、歴史的には別の業界で発展しましたが、数理的には「非線形（折れ線型）のキャッシュ・フローを対価と引き換えに売買する」という1つの共通構造で結ばれています。

### 4. 限界と補正（Critique & Adaptation）

デリバティブはリスク管理の強力な道具ですが、実務で用いる際には次の2つのリスクと制度的な補正を押さえておく必要があります。

#### (1) 店頭デリバティブ（OTC）のカウンターパーティリスクと清算機関（CCP）

フォワードや金利スワップなどの店頭（OTC）取引は、契約条件を柔軟に設定できる反面、**「含み益が大きく膨らんだタイミングで取引相手の金融機関が破綻し、約束のお金を回収できなくなる」**という**カウンターパーティリスク（相手先信用リスク）**を抱えています。2008年のリーマン・ショックでは、巨大なスワップ取引の連鎖が金融システム全体の危機を引き起こしました。

* **制度上の補正：** リーマン・ショック後の国際金融規制改革により、標準的な金利スワップ等は**中央清算機関（CCP）**を通じた清算が義務化され、CCP を通さない相対取引でも日々の時価変動に応じた**証拠金（担保）の授受**が義務づけられました。さらに現代の金融機関では、相手先のデフォルト確率を織り込んでデリバティブの時価を割り引く **CVA（信用評価調整）** を価格評価へ組み込んでいます。

#### (2) 先物ヘッジにおける「ベーシス・リスク」とレバレッジの危険性

1. **ベーシス・リスク（Basis Risk）：** 現実のヘッジでは、「保有している個別株や航空燃料」とまったく同じ原資産の先物が取引所に上場されていないことが多く、代わりに日経平均先物や原油先物で代用（クロス・ヘッジ）します。このとき、現物価格と先物価格の差（**ベーシス**）が予想外に動くと、ヘッジが完全には機能しないリスクが残ります。
2. **レバレッジによる損失拡大：** 先物やオプションの売り（ショート）は、少額の証拠金で元本の何倍もの取引ができる（高いレバレッジが効く）ため、相場が逆行すると元本を大きく超える損失が発生します。デリバティブは「ヘッジ（リスク低減）」にも「投機（リスク増幅）」にも使える両刃の剣であり、明確なリスク限度枠（8-8節の VaR 等）のもとで運用することが不可欠です。
