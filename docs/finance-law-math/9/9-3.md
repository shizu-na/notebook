### 前節（9-2）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（株式価値評価）の導入になります。

1. **スポットレートからのフォワードレート算出と利付債の理論価格：**

    1年スポットレート $s_1 = 1.0\%$、2年スポットレート $s_2 = 2.0\%$ について計算します。

    * **(a) 1年後スタート・1年満期のフォワードレート $f_{1, 2}$：**

        無裁定条件 $(1 + s_2)^2 = (1 + s_1)(1 + f_{1, 2})$ より、

        $$1 + f_{1, 2} = \frac{1.02^2}{1.01} = \frac{1.0404}{1.01} \approx 1.0301 \implies f_{1, 2} \approx \mathbf{3.01\%}$$

    * **(b) 額面 $100$ 万円・表面利率 $2.0\%$・残存 $2$ 年の利付債の理論価格：**

        1年後の $2$ 万円を $s_1 = 1.0\%$ で、2年後の $102$ 万円を $s_2 = 2.0\%$ で割り引きます。

        $$P = \frac{2}{1.01} + \frac{102}{1.02^2} \approx 1.9802 + 98.0392 = \mathbf{100.02 \text{ 万円}}$$

2. **イールドカーブの形状と3つの理論：**

    * **(a) 順イールドにおける3つの金利の大小関係（大きい順）：**

        **フォワードレート ＞ スポットレート ＞ パー・イールド** の順になります。

    * **(b) 長期債の上乗せ利回りで順イールドを説明する理論：**

        **流動性プレミアム仮説**と呼びます。

3. **「元本と利息が決まっている債券」から「将来の配当が不確実な株式」へ（本節への接続）：**

    株式には満期がなく、将来の配当や利益も業績次第で変動します。それでも本質は債券と同じく「将来生み出すキャッシュ・フローの割引現在価値」であり、配当に着目する**配当割引モデル（DDM）**、事業全体のキャッシュ・フローに着目する **DCF 法**、そして市場の相場観で比較する**マルチプル（PER・PBR・EV/EBITDA）**の3つを組み合わせて理論株価を評価します。

## 9-3. 株式価値評価（DDM・DCF・マルチプル）

### 1. 動機（Why）：なぜ「PER 15倍は割安か」を判断するために理論式が必要なのか

[9-1節](9-1.md)・[9-2節](9-2.md)では、将来の利息と元本が契約で決まっている債券の価格を評価しました。本節からは、企業への出資持分である**株式**の価値評価（バリュエーション）へ進みます。

ニュースや投資の現場では、「この会社の株価は PER（株価収益率）が $15$ 倍だから割安だ」「PBR（株価純資産倍率）が $1$ 倍を割っている」といった表現がよく使われます。しかし、**「なぜある会社は PER $10$ 倍で妥当とされ、別の会社は PER $30$ 倍でも割高ではないのか」**という疑問に、経験則だけで答えることはできません。

その答えを与えるのが、[第0部](../index.md#part-0)（[0-1節](../0/0-1.md)）で学んだ割引現在価値の考え方です。株式の価値も債券と同じく、**「その企業が将来にわたって生み出すキャッシュ・フローを、リスクに見合う割引率（資本コスト）で現在価値へ割り引いた合計」**として決まります。

本節では、最もシンプルな**配当割引モデル（DDM・ゴードン成長モデル）**から出発し、そこから **PER・PBR と ROE・成長率・資本コストの厳密な関係式** を導出します。さらに、無配企業や M&A の実務で標準的に使われる **DCF 法（FCFF・FCFE）** と **EV/EBITDA 倍率** の構造を整理します。

---

### 2. 具体例と計算イメージ（Toy Model）

一般的な定義に入る前に、利益と配当が同じ **$2$ 社の企業** を比べて、「ROE（自己資本利益率）の違いが理論株価・PER・PBR をどれほど変えるか」を手計算で確認します。

#### 実験A：同じ利益・同じ配当の2社における ROE と理論株価・PER・PBR

来期の1株あたり利益がどちらも **$\mathrm{EPS}_1 = 200$ 円**、配当性向（利益のうち配当に回す割合）がどちらも **$50\%$**（来期配当 **$D_1 = 100$ 円**、社内へ残す内部留保率 **$b = 50\%$**）、株主が要求する利回り（株主資本コスト）がどちらも **$r_E = 10\%$** である A社 と B社 を考えます。

違うのは、期首の1株あたり純資産（$\mathrm{BPS}_0$）に対して来期利益を稼ぐ力（**$\mathrm{ROE} = \mathrm{EPS}_1 / \mathrm{BPS}_0$**）だけです。

* **A社（標準収益）：** $\mathrm{ROE} = 10\%$（株主資本コスト $10\%$ と同じです。期首 $\mathrm{BPS}_0 = 200 \div 0.10 = 2{,}000$ 円）
* **B社（高収益）：** $\mathrm{ROE} = 15\%$（株主資本コスト $10\%$ を大きく上回ります。期首 $\mathrm{BPS}_0 = 200 \div 0.15 \approx 1{,}333$ 円）

利益の $50\%$（内部留保率 $b$）を毎年再投資すると、企業の自己資本と利益・配当は毎年 **$g = b \times \mathrm{ROE}$** のペースで成長します（**持続可能成長率**）。

1. **A社（$\mathrm{ROE} = 10\%$）の評価：**

    * 成長率：$g_A = 0.50 \times 10\% = \mathbf{5.0\%}$
    * 理論株価（後述のゴードン成長モデル $P_0 = \frac{D_1}{r_E - g}$）：

        $$P_A = \frac{100}{0.10 - 0.05} = \mathbf{2{,}000 \text{ 円}}$$

    * 理論 PER：$2{,}000 \div 200 = \mathbf{10.0 \text{ 倍}}$
    * 理論 PBR（$\mathrm{PBR} = P_A / \mathrm{BPS}_0 = \mathrm{PER} \times \mathrm{ROE}$）：$10.0 \times 10\% = \mathbf{1.0 \text{ 倍}}$

2. **B社（$\mathrm{ROE} = 15\%$）の評価：**

    * 成長率：$g_B = 0.50 \times 15\% = \mathbf{7.5\%}$
    * 理論株価：

        $$P_B = \frac{100}{0.10 - 0.075} = \mathbf{4{,}000 \text{ 円}}$$

    * 理論 PER：$4{,}000 \div 200 = \mathbf{20.0 \text{ 倍}}$
    * 理論 PBR（$\mathrm{PBR} = P_B / \mathrm{BPS}_0 = \mathrm{PER} \times \mathrm{ROE}$）：$20.0 \times 15\% = \mathbf{3.0 \text{ 倍}}$

来期の利益（$200$ 円）も配当（$100$ 円）もまったく同じなのに、**ROE が株主資本コスト（$10\%$）を上回る B社 の理論株価は A社 の2倍（$4{,}000$ 円）、PBR は $3.0$ 倍**になります。逆に A社 のように $\mathrm{ROE} = r_E$（資本コストちょうどしか稼げない）企業では、内部留保をどれだけ増やしても PBR は常に **$1.0$ 倍** に張り付いたままです（図9-3-1左）。

### 3. 定義・導出・構造（What）

#### (1) 配当割引モデル（DDM）とゴードン成長モデル

株式を永遠に保有し続けるとき、株主が手にするキャッシュ・フローは毎期の予想配当 $D_1, D_2, D_3, \dots$ です。これを株主資本コスト（株主の要求収益率）$r_E$ で割り引いたものが**配当割引モデル（DDM：Dividend Discount Model）**です。

$$P_0 = \sum_{t=1}^\infty \frac{D_t}{(1 + r_E)^t}$$

ここで、配当が毎年一定の成長率 $g$（ただし $g < r_E$）で成長する（$D_t = D_1 (1 + g)^{t-1}$）と仮定すると、[0-1節](../0/0-1.md)の無限等比級数の和の公式から、**ゴードン成長モデル（定率成長 DDM）**が導かれます。

$$P_0 = \frac{D_1}{r_E - g}$$

さらに、成長率 $g$ は「1株あたり利益のうち再投資に回す割合（内部留保率 $b = 1 - \text{配当性向}$）」と「再投資の収益率（ROE）」の積 **$g = b \cdot \mathrm{ROE}$** で近似されます。

#### (2) DCF 法（FCFF・FCFE）と企業価値（EV）・株式価値の対応

配当を出していない成長企業や、配当政策が恣意的な企業には DDM を直接使いにくいため、実務（M&A や証券アナリスト評価）では企業が生み出す**フリー・キャッシュ・フロー（FCF）**を割り引く **DCF 法** が標準的に用いられます（図9-3-1右）。

ここで、キャッシュ・フローの帰属先（会社全体か、株主だけか）と割引率を必ず対応させることが基本原則です。

1. **事業価値（EV：Enterprise Value）のアプローチ（FCFF ÷ WACC）：**

    債権者と株主の双方へ分配できる本業のキャッシュ・フローを **FCFF（企業フリー・キャッシュ・フロー）** と呼びます。

    $$\mathrm{FCFF} = \mathrm{EBIT}(1 - \tau) + \text{減価償却費} - \text{設備投資（CAPEX）} - \text{運転資本増加額}$$

    （ここで $\mathrm{EBIT}$ は利払前・税引前利益［実務では営業利益で近似］、$\tau$ は実効法人税率であり、$\mathrm{EBIT}(1 - \tau)$ は税引後営業利益［NOPAT］を指します。また、$\mathrm{CAPEX}$ は固定資産の維持・拡大に要する設備投資額です。）FCFF を、債権者と株主の要求収益率を時価比率で加重平均した **WACC（加重平均資本コスト：次節 [9-4節](9-4.md)で詳述）** で割り引くと、本業そのものの価値である**事業価値（EV）**が求まります。

    $$\mathrm{EV} = \sum_{t=1}^{T} \frac{\mathrm{FCFF}_t}{(1 + \mathrm{WACC})^t} + \frac{\mathrm{TV}_T}{(1 + \mathrm{WACC})^T}$$

    （$\mathrm{TV}_T = \frac{\mathrm{FCFF}_{T+1}}{\mathrm{WACC} - g}$ は予測期間 $T$ 年以降の価値をまとめた**ターミナルバリュー［継続価値］**であり、永久成長率 $g$ には **$g < \mathrm{WACC}$** の収束条件が必要です。）

    最後に、非支配株主持分や優先株式がない単純な資本構成を前提とし、事業価値 EV に本業の運転に不要な余剰現預金（実務の簡便計算では貸借対照表上の現預金全額で代用することが多くあります）などの非事業資産を足し、債権者の取り分である有利子負債 $D$ を差し引くことで、**株式価値（時価総額 $E$）**が得られます。

    $$E = \mathrm{EV} + \text{現預金} - D \quad \Longleftrightarrow \quad \mathrm{EV} = E + D - \text{現預金}$$

2. **株式価値（$E$）の直接アプローチ（FCFE ÷ $r_E$）：**

    FCFF から債権者への利払いや借入返済を差し引いた後に残る、株主だけに帰属するキャッシュ・フロー（**FCFE：株主フリー・キャッシュ・フロー**）を、直接 **株主資本コスト $r_E$** で割り引いて株式価値 $E$ を求める方法です。

#### (3) マルチプル法（PER・PBR・EV/EBITDA）の理論的裏付け

類似する上場企業の株価倍率を当てはめて手早く企業価値を見積もる手法を**マルチプル法（類似会社比較法）**と呼びます。代表的な3つの倍率は、ゴードン成長モデルを変形することでその意味が明確になります。

1. **PER（株価収益率 $= P_0 / \mathrm{EPS}_1$）：**

    $P_0 = \frac{D_1}{r_E - g}$ の両辺を $\mathrm{EPS}_1$ で割ると、配当性向 $p = D_1 / \mathrm{EPS}_1$ を用いて次式が得られます。

    $$\mathrm{PER} = \frac{P_0}{\mathrm{EPS}_1} = \frac{p}{r_E - g}$$

    PER が高くなるのは、**①期待成長率 $g$ が高い、②リスクが低く資本コスト $r_E$ が低い、③（同じ成長率なら）配当性向 $p$ が高い** 企業です。

2. **PBR（株価純資産倍率 $= P_0 / \mathrm{BPS}_0$；$\mathrm{BPS}_0$ は期首の1株あたり純資産）：**

    $\mathrm{EPS}_1 = \mathrm{BPS}_0 \cdot \mathrm{ROE}$ および $p = 1 - b$、$g = b \cdot \mathrm{ROE}$ を代入して整理すると、

    $$\mathrm{PBR} = \frac{P_0}{\mathrm{BPS}_0} = \mathrm{PER} \times \mathrm{ROE} = \frac{(1 - b)\,\mathrm{ROE}}{r_E - g} = \frac{\mathrm{ROE} - g}{r_E - g}$$

    となります。この式から、**$\mathrm{ROE} > r_E \iff \mathrm{PBR} > 1$**、**$\mathrm{ROE} < r_E \iff \mathrm{PBR} < 1$** という重要な同値関係が一目で分かります（図9-3-1左）。東京証券取引所が上場企業へ「資本コストや株価を意識した経営（PBR 1倍割れ改善）」を要請している数理的根拠は、まさにこの1行の式にあります。

3. **EV/EBITDA 倍率：**

    EBITDA（利払前・税引前・減価償却・無形資産償却前利益＝営業利益＋減価償却費＋無形固定資産・のれん償却費）に対する事業価値 EV の倍率です。PER は借入金の多寡（資本構成）や各国の法人税率・減価償却方法の違いに影響を受けますが、EV/EBITDA は**借入比率や会計基準・税率の異なる企業同士（クロスボーダー M&A 等）を公平に比較できる**強みがあります。

> **【コラム：残余利益モデル（RIM）が明らかにする「ROE ＞ 株主資本コスト」の価値創造】**
>
> 無配の企業でも純資産と予想利益から直接理論株式価値を導ける手法として、会計学とファイナンスを架橋する**残余利益モデル（RIM：Residual Income Model／エドワーズ＝ベル＝オールソンモデル）**があります。
>
> 企業全体の単位で揃え、各期の当期純利益 $NI_t$ から期首の自己資本（純資産）$B_{t-1}$ に対する株主の要求利益（$r_E B_{t-1}$）を差し引いた超過利益を**残余利益（経済的付加価値）** $\mathrm{RI}_t := NI_t - r_E B_{t-1} = (\mathrm{ROE}_t - r_E) B_{t-1}$ と定義します。クリーン・サープラス関係（$B_t = B_{t-1} + NI_t - D_t$、$D_t$ は配当総額）と無限遠で純資産の現在価値が $0$ へ収束する横断条件（$\lim_{t \to \infty} \frac{B_t}{(1 + r_E)^t} = 0$）のもとで配当割引モデル（DDM）を代数変形すると（具体的には、$D_t = NI_t + B_{t-1} - B_t = (NI_t - r_E B_{t-1}) + (1 + r_E)B_{t-1} - B_t$ を $(1 + r_E)^t$ で割って $t = 1$ から $\infty$ まで足し合わせると、$\frac{B_{t-1}}{(1+r_E)^{t-1}} - \frac{B_t}{(1+r_E)^t}$ が連鎖的に打ち消し合って［望遠鏡和］$B_0$ だけが残るため）、理論株式価値総額 $E_0$ は次の式へ厳密に書き換わります（発行済株式数で割れば1株あたりの理論株価 $P_0$ と $\mathrm{BPS}_0$ の関係になります）。
>
> $$E_0 = B_0 + \sum_{t=1}^\infty \frac{(\mathrm{ROE}_t - r_E)\, B_{t-1}}{(1 + r_E)^t}$$
>
> この式の意味は明快です。企業の株式価値 $E_0$ は、**「現在の純資産（簿価 $B_0$）」＋「将来にわたって株主資本コスト $r_E$ を上回って稼ぎ出す超過利益（残余利益）の現在価値」**の合計に等しくなります。もし将来の ROE がずっと $r_E$ を下回るなら、第2項がマイナスとなって株式価値は純資産 $B_0$ を割り込み（PBR 1倍割れ）、逆に $\mathrm{ROE} > r_E$ の事業を続ける限り、企業は純資産を上回る価値を創造し続けます（※なお実際の会計では、その他有価証券評価差額金などの**その他の包括利益［OCI］**や資本取引によってクリーン・サープラス関係が崩れる場合があるため、実務では包括利益ベースでの調整を行います）。

### 4. 限界と補正（Critique & Adaptation）

DCF 法とマルチプル法は株式評価の両輪ですが、実務上は次の2つの限界を認識して補完し合う必要があります。

#### (1) DCF 法における「ターミナルバリューへの過度な依存」

実務の DCF 法では、通常5年〜10年程度の事業計画（FCFF）を個別に予測し、それ以降の永遠の価値をターミナルバリュー $\mathrm{TV}_T = \frac{\mathrm{FCFF}_{T+1}}{\mathrm{WACC} - g}$ として一括計上します。ところが、多くの企業では**算出された企業価値全体の $60\% \sim 80\%$ 以上がターミナルバリューで占められてしまいます**。

その結果、分母の $(\mathrm{WACC} - g)$ の前提をわずかに $0.5\%$ 変えただけで、企業価値が $20\% \sim 30\%$ も上下する（仮定次第で望む価格をいくらでも作れてしまう）という脆弱性があります。

* **実務上の補正：** 単一の理論株価を「唯一の正解」として提示するのではなく、**WACC と永久成長率 $g$ を縦横に動かした感度分析表（マトリクス）**を作成し、妥当な価格レンジ（幅）として評価します。また、永久成長率 $g$ は長期の名目 GDP 成長率を上回らない保守的な水準に抑えます。

#### (2) 赤字企業・スタートアップへの適用限界と「フットボール・チャート」

設立間もないスタートアップや赤字企業では、当面の利益も FCF もマイナスであるため、PER や単年度の EV/EBITDA が計算できません。また、マルチプル法は「市場全体がバブルで過熱しているとき、類似企業もみな割高なため、バブル価格を適正価格と誤認してしまう」という相対評価固有の盲点もあります。

* **実務上の補正：** 赤字成長企業では、事業価値ベースの **EV/売上高（事業価値÷売上高）** や時価総額ベースの **PSR（株価売上高倍率＝時価総額÷売上高）** を目的に応じて使い分け、さらに顧客1人あたりの生涯利益（LTV）と顧客獲得コスト（CAC）の採算を見る**ユニット・エコノミクス**を併用します。さらに M&A の実務では、DCF 法・類似会社比較法（マルチプル）・類似取引比較法・市場株価平均法の4手法で算出した価格帯を横棒グラフに並べて重ね合わせる**フットボール・チャート**を作成し、複数の視点が重なる妥当レンジを見極めます。

>     * (b) この企業の**理論 PER** と **理論 PBR** をそれぞれ求めてください（小数第2位まで）。
>
> 2. **（EV と株式価値の関係、および DCF 法の実務上の注意点）**
>
>     * (a) ある企業の時価総額（株式価値 $E$）が $500$ 億円、有利子負債 $D$ が $200$ 億円、現預金が $100$ 億円であるとき、この企業の**事業価値（EV）**はいくらになりますか。

> 3. **（次節への伏線：借入金を増やすと「企業価値」や「資本コスト」はどう変わるのか）**
>
