### 前節（0-10）の確認問題の解答

第0部の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（ミクロ経済学の消費者行動）の出発点になります。

1. **逆関数法による乱数生成：**
    $u = F(x) = 1 - \frac{1}{x^2}$（$x \ge 1$）を $x$ について解くと、$\frac{1}{x^2} = 1 - u \implies x = \frac{1}{\sqrt{1 - u}}$ となります。したがって逆関数による乱数生成式は

    $$X = \frac{1}{\sqrt{1 - U}}$$

    であり、$u = 0.75$ のときの乱数値は $x = \frac{1}{\sqrt{1 - 0.75}} = \frac{1}{\sqrt{0.25}} = \frac{1}{0.5} = \mathbf{2.0}$ です。

2. **モンテカルロ法の必要試行回数と収束速度：**
    $\sigma_g = 2.0,\; z_{0.025} = 1.96,\; \varepsilon = 0.04$ を必要試行回数の式に代入すると、

    $$N \ge \left(\frac{1.96 \times 2.0}{0.04}\right)^2 = 98^2 = \mathbf{9{,}604 \text{ 回}}$$

    誤差幅 $\varepsilon$ を半分（$1/2$）にすると、$N$ は $(1/\varepsilon)^2$ に比例するため必要試行回数は **$4$ 倍**（$38{,}416$ 回）になります。

3. **数理最適化から経済学の最適選択へ（本節への接続）：**
    制約 $p_1 x_1 + p_2 x_2 - I = 0$ のもとで $U(x_1, x_2) = x_1^{1/2} x_2^{1/2}$ を最大化するため、ラグランジュ関数 $\mathcal{L} = x_1^{1/2}x_2^{1/2} - \lambda(p_1 x_1 + p_2 x_2 - I)$ の偏微分を $0$ とおきます。

    $$\frac{1}{2} x_1^{-1/2} x_2^{1/2} = \lambda p_1, \qquad \frac{1}{2} x_1^{1/2} x_2^{-1/2} = \lambda p_2$$

    両辺の比をとって $\lambda$ を消去すると $\frac{x_2}{x_1} = \frac{p_1}{p_2} \iff \mathbf{p_1 x_1 = p_2 x_2}$ となり、予算 $I$ 円を財1と財2へちょうど **$1 : 1$（半分ずつ、各 $I/2$ 円）** 配分することが最適だと導かれます。これが本節で扱う消費者行動理論の基本形です。

## 1-1. 消費者行動・生産者行動と市場均衡（ミクロ経済学）

### 1. 動機（Why）：なぜ市場の価格と取引量を「最適化」から導き出すのか

第0部では、時間価値・確率・統計・最適化といった共通の数理道具を整備しました。第1部では、これらの道具を経済と市場の仕組みに適用します。

私たちが普段目にする商品の価格や生産量は、誰か1人の中央司令官が決めているわけではありません。無数の消費者（買い手）が「限られた予算の中で最も満足度が高くなる買い方」を選び、無数の企業（売り手）が「利益（利潤）が最も大きくなる生産量」を選んだ結果として、市場全体で価格と取引量が決まります。この個別の主体の意思決定と市場の調整メカニズムを分析する分野が**ミクロ経済学**です。

本節では、0-9節のラグランジュ乗数法を使って、次の1本の流れを順に導出します。

1. **消費者の選択：** 予算制約のもとで満足度を最大化する行動から、需要曲線と「価格弾力性」を導く。
2. **企業の選択と市場均衡：** 利潤最大化の行動から供給曲線を導き、完全競争市場が社会全体の余剰（利益と満足の総和）を最大化することを確認する。
3. **競争が失われた市場：** 独占や寡占（少数の企業による競争）では何が起き、なぜ社会全体の効率が損なわれるのかをゲーム理論の基礎とあわせて確認する。

### 2. 具体例と計算イメージ（Toy Model）

一般的な理論に入る前に、手計算で最後まで追える1つの市場モデルを使って、「完全競争」と「独占」で価格・取引量・社会全体の利益がどう変わるかを比較します。

#### 実験A：同じ市場における「完全競争」と「独占」の比較

ある財の市場で、買い手全体の需要曲線（価格 $P$ と購入希望量 $Q$ の関係）が $P = 120 - 2Q$ で与えられているとします（価格が $120$ 円なら誰も買わず、価格が $2$ 円下がるごとに購入量が $1$ 単位増える）。

一方、この財を生産するとき、生産量 $Q$ をあと $1$ 単位増やすのにかかる追加費用（**限界費用**：$MC$）が $MC(Q) = 2Q$ であるとします（たくさん作るほど設備や人手の制約で追加コストが高くなる）。

**ケース1：多数の企業が競争する「完全競争市場」**
個々の企業は市場価格 $P$ を自分で変えられないため、「売値 $P$ が追加コスト $MC$ を上回るあいだは生産を増やし、$P = MC$ となる点で止める」のが利潤最大になります。

* 均衡条件 $P = MC$：$120 - 2Q = 2Q \implies 4Q = 120 \implies$ **取引量 $Q_c = 30$、価格 $P_c = 60$ 円**。
* **消費者余剰（買い手の得）：** 買い手が払ってもよいと思っていた上限額（需要曲線の高さ）と実際の支払額（$60$ 円）の差の合計は、底辺 $30$・高さ $(120 - 60) = 60$ の三角形の面積 $\frac{1}{2} \times 60 \times 30 = \mathbf{900}$ 円です。
* **生産者余剰（売り手の得）：** 売上（$60 \times 30 = 1{,}800$ 円）から生産にかかった可変費用の合計（$\int_0^{30} 2q\,dq = 30^2 = 900$ 円）を引いた差は、底辺 $30$・高さ $60$ の三角形の面積 $\mathbf{900}$ 円です。
* **社会全体の総余剰：** $900 + 900 = \mathbf{1{,}800 \text{ 円}}$。

**ケース2：1社が市場を支配する「独占市場」**
同じ需要曲線と費用条件のまま、売り手が1社だけになったとします。独占企業は「生産量 $Q$ を増やすと、市場全体の価格 $P = 120 - 2Q$ 自体が下がってしまう」ことを知っています。総収入は $TR(Q) = P(Q) \cdot Q = 120Q - 2Q^2$ なので、生産量を1単位増やしたときの追加収入（**限界収入**：$MR$）は

$$MR(Q) = \frac{d(TR)}{dQ} = 120 - 4Q$$

となります。独占企業は「追加収入 $MR$ と追加コスト $MC$ が一致する点」で利潤が最大になるため、

* 利潤最大化条件 $MR = MC$：$120 - 4Q = 2Q \implies 6Q = 120 \implies$ **取引量 $Q_m = 20$、価格 $P_m = 120 - 2(20) = 80$ 円**。
* **消費者余剰：** 価格が $80$ 円へ上がり取引量も $20$ に減ったため、三角形の面積は $\frac{1}{2} \times (120 - 80) \times 20 = \mathbf{400}$ 円へ半減以下になります。
* **生産者余剰：** 売上 $80 \times 20 = 1{,}600$ 円から可変費用 $\int_0^{20} 2q\,dq = 20^2 = 400$ 円を引くと **$1{,}200$ 円** へ増えます（独占企業は儲かります）。
* **社会全体の総余剰：** $400 + 1{,}200 = \mathbf{1{,}600 \text{ 円}}$。

注目すべきは、独占によって消費者が失った $500$ 円（$900 \to 400$）のうち、独占企業に移転したのは $300$ 円（$900 \to 1{,}200$）だけで、**残りの $200$ 円は誰の利益にもならず社会全体から消滅している**という事実です。この消えた $200$ 円（本来なら買いたい人の評価額が追加コストを上回っていたのに、価格引き上げのために取引されなかった $Q = 20 \sim 30$ の分の機会損失）を**死重損失（Deadweight Loss）**と呼びます（図1-1-1右）。

### 3. 定義・導出・構造（What）

#### (1) 消費者行動：効用関数・無差別曲線と「限界代替率＝価格比」の導出

消費者が財1（たとえばコーヒー）を $x_1$ 単位、財2（たとえばパン）を $x_2$ 単位消費したときの満足度の大きさを表す関数 $U(x_1, x_2)$ を**効用関数（Utility function）**と呼びます。同じ満足度 $U(x_1, x_2) = \bar{U}$ を与える組み合わせ $(x_1, x_2)$ を平面上に結んだ等高線が**無差別曲線**です。通常は「多いほど嬉しい（$\frac{\partial U}{\partial x_i} > 0$）」かつ「同じものを増やし続けると追加の嬉しさは少しずつ鈍る（限界効用逓減：コーヒーばかり手元にあれば、コーヒーを多めに手放してでもパンを1個欲しくなる）」ため、無差別曲線は右下がりで原点に向かって凸な形になります。

無差別曲線上の接線の傾きの絶対値を**限界代替率（Marginal Rate of Substitution, MRS）**と呼びます。「満足度を一定に保ったまま、財1を1単位増やす代わりに財2を何単位まで手放せるか」という主観的な交換比率です。$x_1, x_2$ をほんの少し動かしたときの効用の変化（全微分）を計算すると、

$$dU = \frac{\partial U}{\partial x_1}dx_1 + \frac{\partial U}{\partial x_2}dx_2 = 0 \implies \mathrm{MRS}_{12} := -\left.\frac{dx_2}{dx_1}\right\vert_{U=\bar{U}} = \frac{\partial U / \partial x_1}{\partial U / \partial x_2} = \frac{MU_1}{MU_2}$$

となります（ここで $MU_i := \partial U / \partial x_i$ を、財 $i$ を1単位増やしたときの追加の満足度＝**限界効用**と呼びます）。

消費者は、所得（予算）$I$ と各財の価格 $p_1, p_2$ のもとで、予算制約 $p_1 x_1 + p_2 x_2 = I$ を満たしながら $U(x_1, x_2)$ を最大化します。0-9節のラグランジュ乗数法を適用し、ラグランジュ関数 $\mathcal{L}(x_1, x_2, \lambda) = U(x_1, x_2) - \lambda(p_1 x_1 + p_2 x_2 - I)$ の偏微分を $0$ とおくと、

$$\frac{\partial U}{\partial x_1} = \lambda p_1, \qquad \frac{\partial U}{\partial x_2} = \lambda p_2$$

が得られます。2式の比をとって $\lambda$ を消去すると、消費者の最適選択条件が導かれます。

$$\mathrm{MRS}_{12} = \frac{MU_1}{MU_2} = \frac{p_1}{p_2} \quad \Longleftrightarrow \quad \frac{MU_1}{p_1} = \frac{MU_2}{p_2} = \lambda$$

左の形は**「自分の主観的な交換比率（無差別曲線の傾き）と、市場での価格比（予算線の傾き）が一致する点を選ぶ」**ことを意味します（図1-1-1左）。右の形は**「最後の1円を財1に使ったときの追加の満足と、財2に使ったときの追加の満足がぴったり等しくなる」**ことを意味します（加重限界効用均等の法則）。また、ラグランジュ乗数 $\lambda$ は0-9節の包絡線定理より、「予算が1円増えたときに満足度がどれだけ増えるか（所得の限界効用）」を表します。

この最適選択 $(x_1^*(p_1, p_2, I),\, x_2^*(p_1, p_2, I))$ において、価格 $p_1$ を変化させたときの購入量 $x_1^*$ の軌跡が、個人の**需要曲線**になります。

#### (2) 需要・供給の価格弾力性

価格が $1\%$ 変化したときに、需要量（または供給量）が何%変化するかという、円や個といった単位に左右されない感応度（無次元の比率）を**価格弾力性（Price elasticity）**と呼びます。

* **需要の価格弾力性：** 通常、価格が上がると需要量は減る（$\frac{dQ}{dP} < 0$）ため、正の値で扱いやすいようマイナスを付けて定義します。

    $$e_d := -\frac{dQ / Q}{dP / P} = -\frac{dQ}{dP} \cdot \frac{P}{Q}$$

    * **$e_d > 1$（弾力的）：** 少しの値上げで需要が大きく減る（代替品が多い嗜好品など）。値上げすると売上 $P \cdot Q$ は減少します。
    * **$e_d < 1$（非弾力的）：** 値上げしても需要があまり減らない（食料・電気・医薬品などの生活必需品）。値上げすると売上 $P \cdot Q$ は増加します。

* **供給の価格弾力性：** $e_s := \frac{dQ}{dP} \cdot \frac{P}{Q}$（通常は正の値）。生産設備の拡張が容易な財ほど大きく、土地や短期間の農産物のように供給を増やしにくい財ほど $0$ に近くなります。

ここで、総収入 $TR = P \cdot Q$ を $Q$ で微分すると、限界収入 $MR$ と需要の価格弾力性 $e_d$ のあいだに重要な関係式が導かれます。

$$MR = \frac{d(PQ)}{dQ} = P + Q\frac{dP}{dQ} = P\left(1 + \frac{Q}{P}\frac{dP}{dQ}\right) = P\left(1 - \frac{1}{e_d}\right)$$

独占企業は $MR = MC$ を満たす点を選ぶため、これを変形すると

$$\frac{P - MC}{P} = \frac{1}{e_d} \qquad \text{（ラーナーの独占度指数）}$$

が得られます。**需要が非弾力的（$e_d$ が小さい、つまり代替品がない）な財ほど、独占企業は限界費用よりはるかに高い価格を設定できる**ことが数式で直接確認できます（実験Aの独占点 $P_m = 80,\; Q_m = 20$ では $e_d = 0.5 \times \frac{80}{20} = 2.0$ なので、$(80 - 40)/80 = 0.5 = 1/2.0$ が厳密に成り立っています）。

#### (3) 生産者行動・余剰分析と「厚生経済学の基本定理」

生産量 $Q$ を作るための総費用を $C(Q) = FC + VC(Q)$（生産量によらずかかる固定費用 $FC$ ＋ 作るほど増える可変費用 $VC(Q)$）とします。市場で決まった価格 $P$ を自分で変えられない完全競争企業（価格を受け入れるだけの企業：プライス・テイカー）の利潤は $\pi(Q) = P \cdot Q - C(Q)$ です。利潤が最大になる点では傾き（微分）が $0$ になるため、

$$\frac{d\pi}{dQ} = P - C'(Q) = 0 \iff P = MC(Q)$$

が成り立ちます（※このとき限界費用曲線が右上がり［$MC'(Q) > 0$］であり、かつ売上 $PQ$ が可変費用 $VC(Q)$ を上回っていることが必要です。固定費用は操業を止めても発生するため、売上が可変費用をカバーできるあいだは操業を続けた方が赤字を抑えられるからです）。したがって、**完全競争企業の限界費用曲線 $MC(Q)$ の右上がり部分が、そのまま企業の供給曲線になります**。

市場全体の需要曲線 $P_d(Q)$（買い手の限界評価額）と供給曲線 $P_s(Q)$（売り手の限界費用）が交わる点（$Q_c, P_c$）において、社会全体の純便益である**総余剰**を書くと、買い手が払う価格 $P$ と売り手が受け取る価格 $P$ は相殺されます。

$$W(Q) := \underbrace{\int_0^Q \bigl(P_d(q) - P\bigr)\,dq}_{\text{消費者余剰 } CS} + \underbrace{\int_0^Q \bigl(P - P_s(q)\bigr)\,dq}_{\text{生産者余剰 } PS} = \int_0^Q \bigl(P_d(q) - P_s(q)\bigr)\,dq$$

これを $Q$ で微分すると、$W'(Q) = P_d(Q) - P_s(Q) = 0$ がちょうど完全競争均衡 $Q_c$ で成り立ちます（$P_d' < 0,\; P_s' > 0$ より確実に最大値です）。

この結果を1つの市場だけでなく、世の中のあらゆる商品とすべての家計・企業を同時に考えたモデル（一般均衡モデル）へ広げたものが**厚生経済学の第一基本定理**です。すなわち、「外部性や情報の非対称性などがなく、すべての市場で完全競争が成り立つならば、市場均衡における資源配分は**パレート効率的**（誰かの満足度を下げずに他の誰かの満足度を上げることがもはや不可能な、無駄のない状態）になる」という定理です。アダム・スミスが「見えざる手」と呼んだ市場の調整機能が、ここで数学的に定式化されます。

ただし、パレート効率性はあくまで社会全体に「無駄がないこと（効率性）」を意味するだけであり、所得や富の分配における**「公平性」を保証するものではありません**。極端な例として、ある1人が社会全体の富をすべて独占し、他の全員が何も持たない状態であっても、その1人の取り分を減らさずに他者の満足度を上げることはできないため、定義上はパレート効率的になります。市場が生み出す配分の「効率性」と、社会が望む分配の「公平性」は切り分けて考える必要があります。

#### (4) 寡占市場とゲーム理論の基礎（囚人のジレンマとナッシュ均衡）

完全競争（無数の売り手）と独占（1社の売り手）の中間にあるのが、少数の大企業が市場を分け合う**寡占（Oligopoly）**です。寡占市場では「自社が値下げしたとき、ライバル企業がどう反応するか」という**戦略的な相互依存関係**が生じるため、**ゲーム理論**を用いて分析します。

最も基本的な例として、市場を2分する企業Aと企業Bが「高価格を維持する（協調）」か「値下げする（裏切り）」かを同時に選ぶ状況を考えます。表の各マスは（企業Aの利潤、企業Bの利潤）を表します。

| 企業A ＼ 企業B | 高価格（協調） | 値下げ（裏切り） |
| --- | :---: | :---: |
| **高価格（協調）** | $(50,\; 50)$ | $(10,\; 70)$ |
| **値下げ（裏切り）** | $(70,\; 10)$ | **$(30,\; 30)$** |

企業Aの立場になって考えます。

* もし相手（企業B）が「高価格」を選ぶなら、自社は高価格（$50$）より**値下げ（$70$）**の方が得です。
* もし相手（企業B）が「値下げ」を選ぶなら、自社は高価格（$10$）より**値下げ（$30$）**の方が得です。

つまり、企業Aにとっては相手がどちらを選んでも「値下げ」が常に最適（**支配戦略**）になります。対称性より企業Bも同様に「値下げ」を選びます。結果として、両社にとって $(50, 50)$ の方が明らかに望ましいにもかかわらず、互いに自分の利潤を最大化した結果 **（値下げ、値下げ）＝ $(30, 30)$** という均衡に落ち着きます。この構造を**囚人のジレンマ（Prisoner's Dilemma）**と呼びます。

一般に、すべてのプレイヤーが「他のプレイヤーの戦略を所与としたとき、自分の戦略を変更しても利得を増やせない状態」を**ナッシュ均衡（Nash Equilibrium）**と呼びます。上の例では（値下げ、値下げ）が唯一のナッシュ均衡です。この例が示す重要な教訓は、**「個々の主体が合理的に自分の利益を追求しても、必ずしも全体にとって最も望ましい結果（パレート効率）にはならない」**という点です。

> **【コラム：サンクトペテルブルクのパラドックスと限界効用逓減】**
>
> 18世紀、数学者ダニエル・ベルヌーイは「人は金額の期待値だけで意思決定しているわけではない」ことを示す有名な思考実験（**サンクトペテルブルクのパラドックス**）を提示しました。
>
> 公正なコインを表が出るまで投げ続け、$k$ 回目に初めて表が出たら **$2^k$ 円** がもらえるゲームを考えます（1回目で表なら2円、2回目なら4円、3回目なら8円、……）。$k$ 回目に初めて表が出る確率は $\frac{1}{2^k}$（0-3節の幾何分布）なので、賞金の期待値は
>
> $$E[W] = \sum_{k=1}^\infty \frac{1}{2^k} \cdot 2^k = 1 + 1 + 1 + \dots = +\infty$$
>
> と無限大に発散します。もし人が期待金額だけで行動するなら、このゲームの参加費が1億円であっても喜んで払うはずです。しかし実際には、ほとんどの人は数円〜数十円程度しか払おうとしません。
>
> ベルヌーイはこの矛盾を解くため、**「お金そのものの金額 $w$ ではなく、お金から得られる満足度（効用）$u(w)$ の期待値を最大化している」**という仮説を立て、さらにお金が増えるほど1円あたりの追加満足が小さくなる**限界効用逓減**（上に凸な関数、たとえば $u(w) = \ln w$）を提唱しました。対数効用のもとでこのゲームの期待効用を計算すると（0-3節の幾何分布の平均 $\sum_{k=1}^\infty k/2^k = 2$ を用いて）、
>
> $$E[\ln W] = \sum_{k=1}^\infty \frac{1}{2^k} \ln(2^k) = (\ln 2) \sum_{k=1}^\infty \frac{k}{2^k} = 2\ln 2 = \ln 4$$
>
> となり、このゲームの効用は**確実に $4$ 円を受け取ることと等価**になります。同じ理屈により、上に凸な効用関数（$u''(w) < 0$）では $-u(w)$ が下に凸となるため0-4節のイェンセンの不等式が逆向きに働き（$E[u(W)] < u(E[W])$）、期待値が同じでも「確実に50万円もらえる」方を「50%で100万円、50%で0円」より好みます。この性質を**リスク回避（Risk aversion）**と呼び、保険に加入する動機や分散投資を行う動機の経済学的基礎になります。

### 4. 限界と補正（Critique & Adaptation）

本節で組み立てたミクロ経済学の標準モデル（完全合理性・完全競争・厚生経済学の基本定理）は有用な基準点ですが、現実の経済社会には次の2つの大きな乖離があります。

#### (1) 「合理的な経済人」の仮定の限界

標準モデルでは、消費者はあらゆる選択肢を完全に把握し、矛盾のない効用関数を瞬時に最大化する**合理的な経済人（ホモ・エコノミクス）**として描かれます。しかし現実の人間は、計算能力や時間・注意に限りがあり（**限定合理性**）、選択肢が多すぎると判断を先送りしたり、同じ金額の得よりも損をずっと重く感じたり（損失回避）、周囲の行動に流されたりします。こうした現実の人間行動と標準モデルのズレを、実際のデータや実験から捉え直したのが後の部で扱う行動経済学・行動ファイナンスです。

#### (2) 完全競争の破綻（独占・カルテル）と競争政策による補正

現実の市場では、規模の経済（大きく作るほど1個あたりのコストが下がる鉄道・電力・通信・巨大ITプラットフォームなど）や特許・ブランドによって、自然と1社や数社に集約されやすくなります（独占や寡占）。実験Aで見た通り、独占は価格を引き上げて供給を絞り、社会全体に**死重損失**をもたらします。また、寡占市場の企業は囚人のジレンマを避けるために、水面下で価格を高止まりさせる協定（**カルテル**）を結ぶ強い動機を持ちます。

こうした市場の歪みを放置せず、競争の仕組みを外部から維持・補正する制度が**競争政策（独占禁止法）**です。具体的には、カルテルや談合の禁止、市場を過度に独占する企業合併の審査、および規模の経済により1社供給が効率的な公益事業（電気・ガス・水道など）に対する料金規制（適正なコストに適正な利潤を上乗せして料金を決める総括原価方式など）によって、独占による死重損失を抑える工夫が行われています。
