### 前節（1-2）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点がそのまま本節（マクロ経済学）の導入になります。

1. **負の外部性とピグー税の計算：**

    * **(a) 市場均衡（介入なし）：** $P = PMC$ より $90 - Q = 10 + Q \implies 2Q = 80$。よって **$Q_m = 40,\; P_m = 50$**。
    * **(b) 社会的最適と死重損失：** 社会的限界費用は $SMC = PMC + EMC = (10 + Q) + 20 = 30 + Q$ です。$P = SMC$ より $90 - Q = 30 + Q \implies 2Q = 60$。よって **$Q^* = 30,\; P^* = 60$**。
        放置した場合の死重損失（DWL）は、過剰生産分 $Q = 30 \sim 40$ における $SMC$ と需要曲線の差の面積なので、$\frac{1}{2} \times 20 \times (40 - 30) = \mathbf{100}$ です。

    * **(c) 必要なピグー税：** 最適点における外部限界費用と等しい **$t = 20$**（1単位あたり）を課せば、企業の限界費用が $PMC + 20 = SMC$ に一致し、最適生産量 $Q^* = 30$ が達成されます。

2. **レモン市場の成立条件：**
    高品質車の割合が $p$ のとき、買い手が市場の車1台に払ってもよい上限価格（期待価値）は $120p + 50(1 - p) = 50 + 70p$（万円）です。高品質車の売り手が撤退せずに残るには、この価格が最低売却価格 $100$ 万円以上である必要があります。

    $$50 + 70p \ge 100 \implies 70p \ge 50 \implies p \ge \mathbf{\frac{5}{7} \approx 71.4\%}$$

    高品質車が7割以上を占めていない限り、市場から高品質車が駆逐されてしまいます。

3. **ミクロ（個別）からマクロ（国全体）へ（本節への接続）：**
    ある1つの家計が将来に備えて節約し貯金を増やすことは、個人にとっては合理的な行動です。しかし、国中のすべての家計が一斉に消費を減らすと、企業の売上が急減し、賃金や雇用が減って結果的に国全体の所得が落ち込み、かえって貯蓄の原資すら失われることがあります（**合成の誤謬／節約のパラドックス**）。このように、ミクロの単純な足し算では捉えきれない一国全体の所得・物価・金利・雇用の連動を扱うのが**マクロ経済学**です。

## 1-3. マクロ経済と金利・物価の決定

### 1. 動機（Why）：なぜ国全体の「所得・金利・物価」を1つの連立系として捉えるのか

前節まで扱ったミクロ経済学では、「ある1つの商品の価格」や「ある1つの取引」に注目しました。そこでは、他の商品の価格や家計の所得は一定（固定）とみなせました。

しかし、一国全体の経済を見渡す**マクロ経済学**では、「誰かの支出は、必ず別の誰かの所得になる」という循環が働きます。消費が増えれば企業の売上が伸び、賃金が増えてさらに消費が増えます。同時に、経済が過熱してお金の需要が高まれば金利が上がり、モノやサービスが不足すれば物価（インフレ率）が上がります。金利や物価が変われば、今度は企業の設備投資や家計の消費がブレーキを踏みます。

このように、一国全体の**総生産（GDP）・金利・物価**は互いに影響を与え合いながら同時に決まります。本節では、以下の1本の流れに沿ってその基本メカニズムを組み立てます。

1. **経済の計測と恒等式：** 国全体の生産・所得・支出が一致する仕組み（GDP三面等価）と、貯蓄・投資・財政赤字の関係。
2. **短期の景気と金利の決定：** 支出の連鎖が生む**乗数効果**と、財市場・貨幣市場の同時均衡（**IS-LM分析**）。
3. **物価と金融政策：** 物価水準を組み込んだ**AD-AS分析**、名目金利と実質金利を結ぶ**フィッシャー方程式**、インフレと失業の関係（**フィリップス曲線**）、および中央銀行の金利ルール（**テイラールール**）。

### 2. 具体例と計算イメージ（Toy Model）

一般的なモデルに入る前に、支出が所得を生み、その所得がさらに次の支出を生む**乗数効果（Multiplier effect）**の仕組みを、手計算で追える単純な数値例で確認します。

#### 実験A：政府が $20$ 兆円を使うと、なぜGDPが $100$ 兆円増えるのか

外国との取引がない閉じた経済（閉鎖経済）で、人々は手取り所得（税引後所得 $Y - T$）が増えると、その **$80\%$ を消費に回し、残り $20\%$ を貯蓄する**（この割合 $c = 0.8$ を**限界消費性向**と呼びます）とします。

いま、政府が公共事業などで政府支出 $G$ を新たに **$20$ 兆円** 増やしたとき、経済全体の所得 $Y$ がどう連鎖的に増えるかを1巡目から追ってみます（金利と物価は一定と仮定します）。

* **第1巡：** 政府が建設会社などに $20$ 兆円を支払う $\implies$ 関係者の所得が **$+20$ 兆円** 増える。
* **第2巡：** 所得を得た人々がその $80\%$ を消費に使う $\implies$ 飲食店や小売店の売上が **$+20 \times 0.8 = +16$ 兆円** 増える。
* **第3巡：** 売上を得た人々がさらにその $80\%$ を消費に使う $\implies$ 別の企業の売上が **$+16 \times 0.8 = +12.8$ 兆円** 増える。
* **第4巡以降：** 同様に $0.8$ 倍ずつ連鎖が続く。

この所得増加の合計 $\Delta Y$ は、0-1節と同じ初項 $20$、公比 $0.8$ の無限等比級数の和になります。

$$\Delta Y = 20 + 20(0.8) + 20(0.8)^2 + 20(0.8)^3 + \dots = \frac{20}{1 - 0.8} = \frac{20}{0.2} = \mathbf{100 \text{ 兆円}}$$

最初の支出 $20$ 兆円の **$5$ 倍**（政府支出乗数 $= \frac{1}{1 - c} = \frac{1}{1 - 0.8} = 5$）だけGDPが増えました。

では、政府が自ら $20$ 兆円を使う代わりに、同額 **$20$ 兆円の減税**（$\Delta T = -20$）を行った場合はどうなるでしょうか。減税された $20$ 兆円のうち、第1巡でいきなり消費に回るのは $80\%$ の **$16$ 兆円** だけです（残り $4$ 兆円は貯蓄されます）。したがって第1巡以降の連鎖は、

$$\Delta Y = 16 + 16(0.8) + 16(0.8)^2 + \dots = \frac{20 \times 0.8}{1 - 0.8} = 20 \times 4 = \mathbf{80 \text{ 兆円}}$$

となります（租税乗数 $= -\frac{c}{1 - c} = -4$）。同じ $20$ 兆円でも、一部が貯蓄に回る分だけ減税の乗数は政府支出よりちょうど $1$ 小さくなります。

ただし現実には、GDPが増えて景気が良くなるとお金の需要が増えて**金利が上昇**し、民間の設備投資が押し出される（後述の**クラウディング・アウト**）ため、実際の乗数はこの単純な $5$ 倍よりも小さくなります。それを組み込むのが次のIS-LM分析です（図1-3-1左）。

### 3. 定義・導出・構造（What）

#### (1) GDP三面等価の原則と貯蓄・投資バランス

一国内で一定期間（通常1年間）に新たに生み出された**付加価値**（売上から原材料費など他社から仕入れた分を差し引いた、新たに付け加えた価値）の合計を**国内総生産（GDP）**と呼びます。GDPは、経済活動のどの断面で測っても必ず同じ金額になるという**三面等価の原則**を満たします。

1. **生産面（付加価値の合計）：** 各産業が生み出した価値の総和です。
2. **分配面（所得の合計）：** 付加価値は必ず誰かの賃金・利潤・地代・利子として分配されます。
3. **支出面（需要の合計）：** 生産された財・サービスは、最終的に誰かが購入するか在庫として残ります。

支出面から見たGDP（$Y$）は、家計の消費 $C$、企業の設備投資（在庫投資含む）$I$（1-1節の予算 $I$ と区別し、マクロ経済では投資 Investment を $I$ と表記します）、政府支出 $G$、および純輸出 $NX := \text{輸出 } EX - \text{輸入 } IM$ の合計として表されます。

$$Y = C + I + G + NX$$

ここで、国民の総所得 $Y$ は、消費 $C$、貯蓄 $S$、および税金 $T$ の3つに振り分けられる（$Y = C + S + T$）ため、上式と組み合わせて $C$ を消去すると、マクロ経済で最も重要な恒等式の1つである**貯蓄・投資（IS）バランス式**が導かれます。

$$(S - I) + (T - G) = NX \quad \Longleftrightarrow \quad S - I = (G - T) + NX$$

この式は、**「民間の貯蓄超過（$S - I$）は、必ず政府の財政赤字（$G - T$）と海外への純輸出（$NX$：貿易・サービス収支の黒字）の和に一致する」**という集計上の必然を表しています（なお、純輸出 $NX$ に海外からの利子・配当等の受取超過［第一次所得収支］を加えたものが次節1-4節で扱う**経常収支**です）。たとえば、民間が投資以上に大きく貯蓄し（$S > I$）、かつ政府が財政赤字を出している（$G > T$）経済では、民間の余剰貯蓄が国債の購入などを通じて政府の赤字を賄う構造になります。

**【資金循環統計（Flow of Funds）：主体別の資金過不足と資産残高】**
上の貯蓄・投資バランス式を、一国経済の主体別（**家計・一般事業法人・一般政府・海外部門・金融機関**）に集計した公的統計が**資金循環統計**（日本では日本銀行が四半期ごとに公表）です。資金循環統計は、川の流れのように一定期間に出入りする各部門の資金の過不足（$S - I$ や $T - G$ に対応する**フロー**）と、ダムの貯水量のように期末時点で積み上がっている金融資産・負債の残高構成（**ストック**）の2面を記録します。

日本の資金循環統計には、欧米主要国と対比して次の2つの構造的特徴が長期にわたり表れています。

* **家計の金融資産における現預金偏重（ストック面）：** 欧米では株式・投資信託などのリスク資産の比率が高いのに対し、日本の家計は金融資産の過半を現金・預金で保有する傾向が続いています。
* **民間全体の資金余剰による国債の国内消化（フロー面）：** 教科書的には企業部門は借入をして設備投資を行う「資金不足主体」として描かれますが、日本の一般事業法人は1990年代末以降、過去の利益を配当に回さず社内へ蓄えた資金（内部留保）の蓄積などにより恒常的な「資金余剰主体（貯蓄超過）」に転じました。その結果、家計と企業を合わせた民間部門の大幅な資金余剰が、銀行・保険会社などの金融機関を通じて一般政府の財政赤字（国債発行）を国内で吸収し、同時に海外への純投資（経常黒字）も支える構図が成り立っています。

#### (2) IS-LM分析（財市場と貨幣市場の同時均衡）

物価 $P$ が短期間ではすぐには動かない（価格が硬直的な）世界において、国民所得 $Y$ と実質金利 $r$ が同時に決まる仕組みを表すのが**IS-LMモデル**です。

* **IS曲線（財市場の均衡：右下がり）：**
    企業の設備投資 $I(r)$ は、借入コストである金利 $r$ が低いほど増える減少関数です（$I'(r) < 0$）。したがって、**金利 $r$ が下がると投資 $I$ が増え、乗数効果を通じて均衡GDP（$Y$）が増える**ため、$(Y, r)$ 平面上でIS曲線は**右下がり**になります。政府支出 $G$ の増加や減税は、同じ金利でも需要を増やすためIS曲線を右へシフトさせます。

* **LM曲線（貨幣市場の均衡：右上がり）：**
    中央銀行が供給するお金の量（物価で割った購買力ベースの実質貨幣供給量 $M/P$）と、人々がお金（現金・預金）を手元に持っておきたい量（実質貨幣需要 $L(Y, r)$）が一致する条件 $M/P = L(Y, r)$ を表します。

    * 取引が増える（$Y$ が増える）ほど、買い物や決済のためのお金が多く必要になります（取引需要：$\partial L / \partial Y > 0$）。
    * 金利 $r$ が高いほど、債券や預金に回していれば得られたはずの利息（機会費用）を逃す損が大きくなるため、利息の付かない現金を手元に置く量は減ります（資産としての貨幣需要、経済学では伝統的に投機的需要と呼びます：$\partial L / \partial r < 0$）。

    したがって、$M/P$ が一定のとき、**$Y$ が増えてお金の需要が高まると、需給を釣り合わせるために金利 $r$ が上昇する**ため、LM曲線は**右上がり**になります。中央銀行が貨幣供給量 $M$ を増やす（金融緩和）と、同じ所得でも金利が下がるためLM曲線は右（下）へシフトします。

**【数値例で確認するクラウディング・アウト】**
具体的な式を当てはめて動きを確かめます。実験Aの消費関数 $C = 100 + 0.8(Y - 100)$ に、金利に反応する投資関数 $I = 150 - 10r$（$r$ は%表記）と $G = 100$ を組み合わせます。

* **IS曲線：** $Y = 100 + 0.8(Y - 100) + (150 - 10r) + 100 \implies 0.2Y = 270 - 10r \implies Y = 1{,}350 - 50r$
* **LM曲線：** $M/P = 400$、貨幣需要 $L = 0.4Y - 20r$ とすると、$400 = 0.4Y - 20r \implies Y = 1{,}000 + 50r$
* **初期均衡：** $1{,}350 - 50r = 1{,}000 + 50r \implies$ **$r = 3.5\%,\; Y = 1{,}175$**。

ここで政府支出を $G = 100 \to 120$（$+20$）へ増やすと、IS曲線は $Y = 1{,}450 - 50r$ へ右に $+100$ シフトします（金利一定なら実験Aと同じ $+100$ の増加）。しかし新均衡を解くと $1{,}450 - 50r = 1{,}000 + 50r \implies$ **$r = 4.5\%,\; Y = 1{,}225$** となります。GDPの増加は $+100$ ではなく **$+50$** に半減しています。財政拡大によって金利が $3.5\% \to 4.5\%$ へ上昇し、民間投資 $I$ が $-10$ 減少（乗数効果込みで $-50$）して押し出されたからです。この現象を**クラウディング・アウト（Crowding-out）**と呼びます。

#### (3) AD-AS分析とフィッシャー方程式（名目金利と実質金利）

IS-LM分析では物価 $P$ を固定していましたが、物価が変わると同じ金額のお金で買える量（実質貨幣供給 $M/P$）が変動します。

* **総需要曲線（AD曲線：右下がり）：** 物価 $P$ が上がると実質貨幣供給 $M/P$ が減ってLM曲線が左へシフトし、金利上昇を通じてGDP（$Y$）が減るため、$(Y, P)$ 平面上で総需要曲線は**右下がり**になります（図1-3-2左）。
* **総供給曲線（AS曲線：短期は右上がり、長期は垂直）：** 短期的には賃金や商品価格の書き換えに時間がかかるため（価格硬直性）、物価が上がると企業は採算が良くなって生産を増やし**右上がり**になります。しかし長期的にはすべての価格と賃金が調整され、生産量は設備・人手・技術水準を標準的に稼働させたときの生産力（**潜在GDP** $Y^*$）に一致するため、長期AS曲線は $Y = Y^*$ で**垂直**になります。つまり長期的には、お金の量を増やすだけでは生産力 $Y^*$ は増えず、物価 $P$ だけが上昇します（**貨幣の中立性**）。

**【フィッシャー方程式（名目金利と実質金利の厳密な関係）】**
インフレ（物価上昇）がある世界では、表面上の金利である**名目金利 $i$** と、モノを買う力（購買力）ベースでの増え方である**実質金利 $r$** を区別する必要があります。

今日 $1$ 個 $100$ 円のリンゴが、1年後の**期待インフレ率 $\pi^e$**（1-1節の企業利潤 $\pi$ と区別し、マクロ経済ではインフレ率を $\pi$ と表記します）によって $100(1 + \pi^e)$ 円に値上がりするとします。今日 $100$ 円を名目金利 $i$ で預金すると1年後には $100(1 + i)$ 円になります。1年後に買えるリンゴの個数の倍率（$1 + r$）は、

$$1 + r = \frac{100(1 + i)}{100(1 + \pi^e)} = \frac{1 + i}{1 + \pi^e} \quad \Longleftrightarrow \quad 1 + i = (1 + r)(1 + \pi^e)$$

展開すると $i = r + \pi^e + r\pi^e$ となります。$r$ と $\pi^e$ が数%程度と小さいときは積 $r\pi^e$ が微小（例：$0.03 \times 0.02 = 0.0006$）なため無視でき、有名な**フィッシャー方程式の近似式**が得られます。

$$r \approx i - \pi^e \quad \Longleftrightarrow \quad i \approx r + \pi^e$$

たとえば名目金利 $5\%$・期待インフレ率 $2\%$ なら、厳密な実質金利は $1.05/1.02 - 1 \approx 2.94\%$、近似値は $3\%$ です。企業の設備投資や個人の借入負担を実質的に左右するのは、名目金利 $i$ ではなく**実質金利 $r$** です。

#### (4) フィリップス曲線と中央銀行の金融政策（テイラールール）

1958年、経済学者フィリップスは英国の長期データから「失業率が低い（景気が良く人手不足の）ときは賃金上昇率・インフレ率が高く、失業率が高いときはインフレ率が低い」という右下がりの関係（**フィリップス曲線**）を見出しました。

中央銀行（日本銀行や米FRBなど）は、**「物価の安定」**と**「景気・雇用の安定」**の2つを目標に、政策金利（短期の名目金利 $i$）を操作します。その標準的な指針を数式化したものが**テイラールール（Taylor Rule）**です。

$$i = r^* + \pi + 0.5(\pi - \pi^*) + 0.5(y - y^*)$$

ここで $r^*$ は景気を過熱も冷却もしない中立実質金利、$\pi$ は現在のインフレ率、$\pi^*$ は目標インフレ率（多くの先進国で $2\%$）、$(y - y^*)$ は実際のGDPが潜在GDPを何%上回っているか（**GDPギャップ**）を表します。

注目すべきは、右辺の $\pi$ の係数が $1 + 0.5 = \mathbf{1.5 > 1}$ になっている点です（**テイラーの原理**）。たとえばインフレ率 $\pi$ が目標 $2\%$ から $3\%$ へ $+1\%$ 上昇したとき、もし中央銀行が名目金利 $i$ を $+0.5\%$ しか上げないと、フィッシャー方程式より実質金利 $r \approx i - \pi$ はかえって **$-0.5\%$ 低下** してしまい、景気とインフレをさらに加速させてしまいます。インフレを抑え込むには、**インフレ率の上昇幅以上に名目金利を引き上げて（この式では $+1.5\%$ 引き上げて実質金利を $+0.5\%$ 押し上げて）**ブレーキを踏む必要があるのです。

> **【コラム：ソロー成長モデルの定常状態と、資本蓄積だけでは成長率が維持できない理由】**
>
> ここまでは短期の景気循環（需要側の変動）を見てきましたが、10年・30年という長期的な経済成長（潜在GDP $Y^*$ の成長）は何で決まるのでしょうか。その基礎となるのが**ソロー成長モデル**です。
>
> 労働者1人あたりの資本（機械や工場）を $k$、1人あたり生産量を $y = f(k) = k^\alpha$（$0 < \alpha < 1$、例：$y = k^{0.5} = \sqrt{k}$）とします。資本を増やすほど生産量は増えますが、増え方は次第に鈍ります（**資本の限界生産力逓減**）。
>
> 1人あたり生産量 $y$ のうち一定割合 $s$（貯蓄率）が新しい設備投資 $s y = s k^\alpha$ に回り、同時に既存の資本は毎年一定率 $\delta$（減価償却率。0-1節の利力 $\delta$ とは別の記号用法です）で古くなって摩耗（$\delta k$）していくとします。すると1人あたり資本の増加ペースは
>
> $$\Delta k = s k^\alpha - \delta k$$
>
> となります。最初は投資 $s k^\alpha$ が摩耗 $\delta k$ を上回って資本が増えますが、資本 $k$ が大きくなるほど追加投資の伸びが鈍り、やがて新規投資と摩耗がちょうど釣り合う点（**定常状態 $k^*$**：$s (k^*)^\alpha = \delta k^*$）に到達します（図1-3-3）。たとえば $y = k^{0.5},\; s = 0.2,\; \delta = 0.05$ なら $0.2\sqrt{k^*} = 0.05 k^* \implies k^* = 16,\; y^* = 4$ で成長が止まります。
>
> もし貯蓄率を $s = 0.2 \to 0.3$ へ引き上げると、定常状態は $k^* = 36,\; y^* = 6$ へと**水準は上がりますが、新しい定常状態に着いたあとは再び成長率ゼロに戻ります**。これがソローモデルの核心的な結論です。すなわち、**「貯蓄や設備投資（資本蓄積）だけでは、長期的な1人あたり経済成長率を持続させることはできず、長期成長の唯一の源泉は技術進歩（機械や人手の量だけでは説明できない技術革新・業務効率の伸び＝全要素生産性の上昇）である」**ということが数式から導かれます。

### 4. 限界と補正（Critique & Adaptation）

本節で扱ったIS-LM分析・フィリップス曲線・政策ルールはマクロ経済学の骨格ですが、1970年代以降や2000年代以降の現実の経済では、以下の3つの大きな限界が明らかになりました。

#### (1) ゼロ金利制約下の「流動性の罠」と非伝統的金融政策

通常、景気が悪化すると中央銀行は政策金利を引き下げて投資や消費を刺激します。しかし、現金の金利は $0\%$ であるため、名目金利を大幅にマイナスにすることは困難です（**ゼロ金利下限：Zero Lower Bound**）。

金利がほぼ $0\%$ に張り付いた状態では、人々は債券を持っても現金を持っても利息が変わらないため、中央銀行がいくら貨幣供給を増やしても人々がそのまま現金として抱え込むだけになり、金利がそれ以上下がらず投資も増えません（図1-3-1右：LM曲線が水平になる**流動性の罠**）。この局面では、金利引き下げという伝統的な金融政策が効力を失う一方、金利上昇（クラウディング・アウト）が起きないため財政政策の効果が相対的に高まります。

この限界に対し、現代の中央銀行は短期金利が $0\%$ に達したあとも、次のような**非伝統的金融政策**を組み合わせて対応しています。

* **量的・質的金融緩和（QE）：** 短期金利を下げられない代わりに、長期国債などの資産を大量に買い入れて長期金利を押し下げる手法です（買い注文が集中して国債の市場価格が上昇すると、満期に受け取る額面は固定されているため利回り［長期金利］が低下します）。
* **フォワードガイダンス：** 「インフレ率が安定的に目標を超えるまで低金利を続ける」と将来の方針をあらかじめ約束し、人々の予想インフレ率 $\pi^e$ を引き上げることで、実質金利 $r \approx i - \pi^e$ をマイナス方向へ押し下げる手法です。

#### (2) スタグフレーションとフィリップス曲線の関係変化

1960年代には「インフレ率と失業率は安定したトレードオフ（右下がりのフィリップス曲線）にあり、政府は少しインフレを容認すれば失業率をずっと低く保てる」と考えられていました。しかし1970年代のオイルショック期に、**高インフレと高失業（景気停滞）が同時に起きる「スタグフレーション」**が発生し、単純なフィリップス曲線は崩れました。

経済学者フリードマンとフェルプスは、人々が将来のインフレを予想して賃金交渉を行うことを組み込んだ**期待修正フィリップス曲線**を提唱しました。

$$\pi_t = \pi_t^e - \beta(u_t - u^*)$$

ここで $u_t$ は失業率、$u^*$ は好景気でも転職や職探しによって構造的に残る**自然失業率**です。政府が金融緩和で一時的に失業率を $u^*$ より下げても（図1-3-2右の $A \to B$）、物価が上がると人々の予想インフレ率 $\pi_t^e$ 自体が切り上がり、フィリップス曲線全体が上へシフトします（$B \to C$）。結果として、長期的なフィリップス曲線は自然失業率 $u^*$ で**垂直**になり、インフレを容認しても長期的に失業率を下げることはできず、高いインフレ率だけが残るという結論に修正されました。

#### (3) ルーカス批判（政策変更が人々の期待と行動ルールを変える）

1976年、ロバート・ルーカスは、過去のデータから統計式を作って政策効果を予測する従来のやり方（マクロ計量モデル）に対して根本的な批判を行いました（**ルーカス批判**）。過去のデータから「減税すると消費が80%増える」「失業率とインフレ率にはこの関係がある」という式を回帰分析で求めても、**政府が政策ルール自体を変えると、家計や企業はその変更を織り込んで行動の仕方（消費の割合や価格の付け方）を変えてしまう**ため、過去の式を使った予測は外れるという指摘です。

たとえば、1年限りの一時的な減税と、将来ずっと続く恒久的な減税では、金額が同じでも家計の消費反応は大きく異なります（一時的な減税の多くは貯蓄に回ります）。この批判を受けて、現代のマクロ経済学では「過去の平均的な関係式をそのまま当てはめる」のではなく、「家計や企業が将来の政策を織り込んでどう最善の選択をするか（合理的期待と個別の最適化行動）」というミクロの土台（ミクロ的基礎）からモデルを組み立て直す方向へ発展しました。
