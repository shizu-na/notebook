### 前節（7-6）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま第7部の最終節である本節（年金数理と財政方式）の導入になります。

1. **生命保険の3利源分析の計算：**

    実験Aの条件（期首運用予定元本 $20{,}000$ 万円、予定利率 $4\%$、予定死亡件数 $10$ 件、危険保険金 $100 - 20 = 80$ 万円、予定事業費 $500$ 万円）に対し、実績（実際事業費 $520$ 万円、実績利回り $3\%$、実際死亡件数 $7$ 件）から各利源を計算します。

    * **死差益：** $(10 - 7) \times (100 - 20) = 3 \times 80 = \mathbf{+240.0 \text{ 万円}}$
    * **利差損益：** $20{,}000 \times (3\% - 4\%) = \mathbf{-200.0 \text{ 万円}}$（利差損）
    * **費差損益：** $(500 - 520) \times 1.03 = -20 \times 1.03 = \mathbf{-20.6 \text{ 万円}}$（費差損）
    * **当期の総剰余：** $240.0 - 200.0 - 20.6 = \mathbf{+19.4 \text{ 万円}}$

    （検算：期首総資産 $18{,}000 + 2{,}500 - 520 = 19{,}980$ 万円を実績 $3\%$ で運用すると期末資産 $20{,}579.4$ 万円、期末支払・積立は $7 \times 100 + 993 \times 20 = 20{,}560.0$ 万円となり、差額 $20{,}579.4 - 20{,}560.0 = +19.4$ 万円と厳密に一致します。）

2. **生命保険の税務と契約変更：**

    * **(a) 死亡保険金の課税区分：**

        契約者（夫）・被保険者（妻）・受取人（子）のように3者がすべて異なる場合は**贈与税**（みなし贈与）が課されます。契約者（夫）・被保険者（夫）・受取人（妻）のように契約者と被保険者が同一の場合は**相続税**（法定相続人には非課税枠あり）が課されます。

    * **(b) 払済保険と延長保険の違い：**

        **払済保険**は「保険期間を維持し、保険金額を小さくする」方法、**延長保険**は「保険金額を維持し、保険期間を短くする（定期保険へ変更する）」方法です。

3. **個人契約の「生命保険」から、集団全体の「年金財政」へ（本節への接続）：**

    毎年新しい加入者が入り定年退職者へ終身年金を支払い続ける年金制度では、定常状態において毎年の給付総額 $B$、掛金総額 $C$、期末積立金 $F$、割引率 $d$ のあいだに**極限方程式 $B = C + dF$** が成り立ちます。積立金を多く持つ財政方式ほど運用益 $dF$ が大きくなるため、毎年の掛金負担 $C$ は軽くなります。

## 7-7. 年金数理と財政方式（公的年金・企業年金）

### 1. 動機（Why）：なぜ企業年金や公的年金では「集団全体の財政方式」を設計する必要があるのか

7-5節・7-6節では、個人1人ひとりの契約ごとに純保険料と責任準備金を計算する生命保険の仕組みを扱いました。これに対し、企業が従業員のために設ける**企業年金**や、国が運営する**公的年金**は、1人の契約ではなく「毎年新しい加入者が入り、定年退職者へ終身年金を支払い続ける**集団全体**」を対象にします。

年金制度を運営するとき、将来の給付額（約束した年金）が同じであっても、「現役時代にどのペースで掛金を積み立てておくか（**財政方式**）」にはいくつもの選択肢があります。

* まったく積み立てず、その年の給付額をそのままその年の掛金で賄う方式（**賦課方式**）
* 退職する瞬間にまとめて一生分の年金原資を積み立てる方式（**退職時年金現価積立方式**）
* 在職期間全体を通じて計画的に積み立てる方式（**加入年齢方式・単位積立方式**など）

積立金のペースが変われば、企業の毎年の掛金負担も、途中で制度を解散したときの保全水準も、さらには財務諸表（貸借対照表・損益計算書）に載る**退職給付債務**の額も大きく変わります。本節では、まず確定給付（DB）と確定拠出（DC）のリスク分担と給付設計の4類型を整理したうえで、年金数理の標準モデルである **Trowbridge（トローブリッジ）モデル** と **極限方程式 $B = C + dF$** を導出し、財政決算・再計算・退職給付会計までを1本の流れで組み立てます。

### 2. 具体例と計算イメージ（Toy Model）

一般的な数式に入る前に、手計算で最後まで追える小さな定常人口の年金制度を使って、**4つの財政方式の掛金 $C$ と積立金 $F$ の違い**、および**極限方程式 $B = C + dF$** がどの方式でも厳密に成り立つことを確かめます。

#### 実験A：在職2年・受給2年の小さな年金制度（Trowbridgeモデルの数値検証）

毎年期首にちょうど **$100$ 人** が新規入社し、**2年間在職**（1年目・2年目の期首に掛金を拠出）した後、定年退職して**2年間（3年目・4年目の期首）に年額 $10$ 万円の年金**を受け取り4年末で終了する定常状態の年金制度を考えます。構造を見やすくするため、途中脱退・死亡はなしとし、割引因子は $v = 0.95$、割引率は $d = 1 - v = \mathbf{0.05}$（対応する予定利率 $i = \frac{0.05}{0.95} \approx 5.26\%$）とします。

定常状態の各期首には、現役が $200$ 人（1年目 $100$ 人・2年目 $100$ 人）、受給者が $200$ 人（退職1年目 $100$ 人・退職2年目 $100$ 人）います。したがって、毎年の年金給付総額はどの財政方式でも共通に

$$B = 200\text{人} \times 10\text{万円} = \mathbf{2{,}000 \text{ 万円}}$$

です。この同じ給付 $B = 2{,}000$ 万円を、4つの代表的な財政方式で賄うときの毎年の掛金総額 $C$ と期末積立金 $F$ を計算します。ここでの期末積立金 $F$ は**「翌期首に給付や掛金の出入りが起きる直前の残高」**として評価するため、翌期首に2回目の $10$ 万円を支払うだけの退職1年目終の残高は割引なしの $10$ 万円になります。

1. **賦課方式（Pay-as-you-go）：**

    積立金を持たないため **$F = 0$ 万円**、毎年の掛金は給付と同額の **$C = 2{,}000$ 万円** です。

2. **退職時年金現価積立方式（Terminal Funding）：**

    退職する $100$ 人のために、退職時点（3年目期首）で2年分の年金現価 $10 \times (1 + v) = 19.5$ 万円を一括拠出します。

    * 掛金総額：$C = 100 \times 19.5 = \mathbf{1{,}950 \text{ 万円}}$
    * 期末積立金：翌期首に2回目の給付 $10$ 万円を受ける退職1年目 $100$ 人分の残高のみなので **$F = 1{,}000$ 万円**。
    * 検算：$C + dF = 1{,}950 + 0.05 \times 1{,}000 = \mathbf{2{,}000} = B$。

3. **単位積立方式（Unit Credit）：**

    在職2年間で年金年額 $10$ 万円を毎年半分（年額 $5$ 万円の2年年金）ずつ獲得するとみなし、その年に新たに発生した給付の現価を掛金とします。

    * 在職1年目 $100$ 人分（2年後開始の年額 $5$ 万円）：$100 \times 5(v^2 + v^3) = 500(0.9025 + 0.857375) = 879.9375$ 万円
    * 在職2年目 $100$ 人分（1年後開始の年額 $5$ 万円）：$100 \times 5(v + v^2) = 500(0.95 + 0.9025) = 926.25$ 万円
    * 掛金総額：$C = 879.9375 + 926.25 = \mathbf{1{,}806.1875 \text{ 万円}}$
    * 期末積立金（退職1年目終 $1{,}000$ ＋ 在職2年目終 $1{,}950$ ＋ 在職1年目終の1年分 $926.25$）：**$F = 3{,}876.25$ 万円**。
    * 検算：$C + dF = 1{,}806.1875 + 0.05 \times 3{,}876.25 = 1{,}806.1875 + 193.8125 = \mathbf{2{,}000} = B$。

4. **加入年齢方式（Entry Age Normal）：**

    1人の加入者が入社時（1年目期首）に持つ給付現価 $10(v^2 + v^3) = 10 v^2(1 + v)$ を、在職2年間の平準掛金現価 $c(1 + v)$ と等しくなるよう平準化します。すると $c = 10 v^2 = \mathbf{9.025 \text{ 万円}}$ となります。

    * 掛金総額（現役 $200$ 人）：$C = 200 \times 9.025 = \mathbf{1{,}805 \text{ 万円}}$
    * 期末積立金（退職1年目終 $1{,}000$ ＋ 在職2年目終 $1{,}950$ ＋ 在職1年目終の将来法残高 $100 \times \{10(v + v^2) - 9.025\} = 950$）：**$F = 3{,}900$ 万円**。
    * 検算：$C + dF = 1{,}805 + 0.05 \times 3{,}900 = 1{,}805 + 195 = \mathbf{2{,}000} = B$。

| 財政方式 | 期末積立金 $F$ | 毎年の掛金総額 $C$ | 運用益の寄与 $dF$ | 合計 $C + dF$（$= B$） |
| --- | :---: | :---: | :---: | :---: |
| **賦課方式** | $0.00$ 万円 | **$2{,}000.00$ 万円** | $0.00$ 万円 | $2{,}000.00$ 万円 |
| **退職時年金現価積立方式** | $1{,}000.00$ 万円 | $1{,}950.00$ 万円 | $50.00$ 万円 | $2{,}000.00$ 万円 |
| **単位積立方式** | $3{,}876.25$ 万円 | $1{,}806.19$ 万円 | $193.81$ 万円 | $2{,}000.00$ 万円 |
| **加入年齢方式** | **$3{,}900.00$ 万円** | **$1{,}805.00$ 万円** | **$195.00$ 万円** | $2{,}000.00$ 万円 |

この表から、**積立金 $F$ の大小関係（賦課 ＜ 退職時 ＜ 単位積立 ＜ 加入年齢）**と、**掛金 $C$ の大小関係（賦課 ＞ 退職時 ＞ 単位積立 ＞ 加入年齢）**が完全に逆向きになる明確な対称性が確認できます（図7-7-1左）。

### 3. 定義・導出・構造（What）

#### (1) 確定給付（DB）と確定拠出（DC・iDeCo）の制度と給付設計の4類型

私的年金（企業年金・個人年金）は、将来の給付額と掛金額のどちらを事前に約束するかによって、大きく2つに分類されます（図7-7-1右）。

* **確定給付企業年金（DB：Defined Benefit）：** 「退職時にいくら年金を支払うか」という**給付額の算定ルール**を企業があらかじめ約束し、年金資産の運用責任も企業が負う制度です。運用成績が悪化して積立不足が生じると、企業が追加で掛金を拠出する必要があります。
* **確定拠出年金（DC：Defined Contribution）：** 「毎月いくら掛金を出すか」という**拠出額**のみを決め、従業員（または個人型 **iDeCo** の加入者）が自ら投資信託や定期預金を選んで運用する制度です。運用成果はそのまま個人の将来の受取額に直結するため、運用リスクは個人側が負います。

確定給付（DB）の退職金・年金額をどのような計算式で決めるかには、次の**給付設計の4類型**があります。

| 給付設計の類型 | 算定方法の概要 | 特徴・リスクの傾向 |
| --- | --- | --- |
| **1. 定額制** | 勤続年数に応じて一定額を支給（例：1年あたり10万円） | 計算が最も単純。物価や賃金水準の上昇が反映されにくい。 |
| **2. 最終給与比例制** | 退職直前の給与 $\times$ 勤続年数に応じた支給率 | 退職直前の生活水準と連動するが、終盤の昇給で債務が急増しやすい。 |
| **3. 累計給与比例制** | 加入期間全体の給与合計（または各年のポイント累計）$\times$ 支給率 | 現役時代の貢献度を均等に反映でき、最終給与制より債務変動が穏やか。 |
| **4. 元利合計制** | 仮想個人口座へ毎年の拠出付与額と利息（再評価率）を積み上げる | 仮想残高が明快。再評価率を国債利回り等に連動させると後述のキャッシュバランスになる。 |

#### (2) Trowbridge モデルと極限方程式 $B = C + dF$ の導出

1952年にアメリカのアクチュアリー、チャールズ・トローブリッジが定式化した **Trowbridge モデル** は、定常状態（毎年一定人数が定年年齢 $r$ より若い加入年齢 $e$ で入社し、同じ脱退率・死亡率・予定利率 $i$ で推移する成熟した年金集団）において、さまざまな財政方式を1本の枠組みで比較する標準理論です。

定常状態にある年金制度の**期末積立金**（＝翌期首の掛金払込・給付支払直前の積立金）を $F$、毎期首に払い込まれる年間掛金総額を $C$、毎期首に支払われる年間年金給付総額を $B$ とします。

期首に掛金 $C$ が流入し給付 $B$ が流出した後の積立金残高 $(F + C - B)$ を、予定利率 $i$ で1年間運用すると、期末の積立金は $(F + C - B)(1 + i)$ になります。制度が定常状態にあるため、期末の積立金は元の $F$ に等しくなります。

$$(F + C - B)(1 + i) = F$$

両辺に割引因子 $v = (1 + i)^{-1}$ を掛けて整理すると、割引率 $d := 1 - v = \frac{i}{1 + i}$ を用いて次の**極限方程式（Equation of Maturity）**が導かれます。

$$F + C - B = v F \quad \Longleftrightarrow \quad \mathbf{B = C + dF}$$

この式は、定常状態では**「毎年の年金給付 $B$ は、毎年の掛金収入 $C$ と、積立金が生み出す割引率ベースの運用益 $dF$ の合計でちょうど賄われる」**という保存則を表します。

Trowbridge モデルで比較される代表的な**5つの財政方式**は次の通りです（一般に、積立金 $F$ は下へ行くほど大きく、掛金 $C$ は下へ行くほど小さくなります）。

1. **賦課方式：** 積立金を持たず、毎年の給付をその年の掛金で賄います（$F = 0,\; C = B$）。
2. **退職時年金現価積立方式：** 定年退職する人の一生分の給付現価を、退職時点で一括拠出します。
3. **単位積立方式（UC）：** 1年間の勤務で新たに発生した給付単位（定額制や累計給与比例制）の現在価値をその年の掛金とします。
4. **予測単位積立方式（PUC：Projected Unit Credit）：** 最終給与比例制のように将来の昇給によって給付額が変わる場合、**退職時までの予想昇給を織り込んだ将来の給付見込額**を全勤続年数で割り、当期1年分に帰属する部分の現在価値を掛金とする方式です（後述の退職給付会計の原則方式）。
5. **加入年齢方式（EAN）：** 加入時の総給付現価を、定年までの在職期間にわたって一定の標準掛金率（または定額）へ平準化して積み立てる方式です（7-5節の平準純保険料式と同じ構造）。

#### (3) 予定脱退率・予定昇給率と未積立債務の償却

生命保険（7-5節）の計算基礎が「予定死亡率・予定利率・予定事業費率」の3つであったのに対し、企業年金の計算基礎には、さらに企業特有の2つの基礎率が加わります。

* **予定脱退率：** 従業員が定年前に自己都合退職・懲戒解雇・死亡などで制度から抜ける確率（中途退職すると退職一時金は減額されるか、一定年数未満は支給されないことが多いため、脱退率が高いほど年金債務は小さくなります）。
* **予定昇給率：** 年齢や勤続年数に応じた給与の伸び率（給与比例制の給付額を予測するために用います）。

**【未積立債務（過去勤務債務：PSL）の償却】**

制度を新しく発足させたとき、すでに勤続10年・20年の従業員に過去の勤務期間もさかのぼって年金受給権を認めたり、あるいは運用悪化で積立金が理論上の必要額（責任準備金）を下回ったりすると、**過去勤務債務（PSL：Past Service Liability）**や**未積立債務**（責任準備金 $-$ 実際の積立金）が発生します。

この不足額を一括で穴埋めすると企業の資金繰りが破綻するため、標準掛金（通常の毎年の掛金）とは別に、一定期間（例：10年〜20年）にわたって元利均等（0-1節の資本回収係数）や定率で分割償却する**特別掛金**を拠出して解消していきます。

#### (4) 財政決算・財政再計算・制度変更計算と退職給付会計

企業年金は長期にわたって健全性を維持するため、次の3つのアクチュアリー実務サイクルで管理されます。

1. **財政決算（毎年）：** 毎事業年度末に、実際の積立金と責任準備金を比較し、7-6節の利源分析と同じように「利差損益（運用利回りのズレ）」「脱退差損益」「昇給差損益」などの**損益要因分析**を行い、積立不足が許容範囲内に収まっているか検証します（継続基準・非継続基準の財政検証）。
2. **財政再計算（原則5年ごと）：** 過去の実績データをもとに、予定利率・予定死亡率・予定脱退率・予定昇給率などの計算基礎を見直し、新しい標準掛金率と特別掛金率を計算し直します。
3. **制度変更計算（随時）：** 給付水準の引下げ・引上げ、定年延長、キャッシュバランスプランへの移行など、年金規約の内容を変更する際に行う再計算です。

**【退職給付会計（企業会計への反映）】**

確定給付（DB）を運営する企業は、第2部（2-5節）で触れた**退職給付会計**に基づき、毎期末に次の2つを算定して財務諸表へ反映します。

* **退職給付債務（PBO：Projected Benefit Obligation）：** 予測単位積立方式（PUC）の考え方に沿って、従業員が期末までの勤務によって獲得した将来の退職金・年金見込額を、期末時点の安全な債券利回り（国債や高格付社債の利回り）で割り引いた現在価値。
* **貸借対照表（BS）の計上：** 連結BSでは、退職給付債務（PBO）から外部へ積み立てた**年金資産**（時価）を差し引いた正味の積立不足を**「退職給付に係る負債」**（積み立て超過なら「退職給付に係る資産」）としてそのまま計上します。
* **損益計算書（PL）の費用：** 毎期の**退職給付費用**は、「勤務費用（当期1年間の勤務で増えたPBO）＋ 利息費用（PBOの割引の巻き戻し） − 期待運用収益（年金資産の期待リターン） ＋ **数理計算上の差異**（予定利率・運用実績・昇給率などの見込みと実績のズレ）および**過去勤務費用**（給付水準の改定に伴う過去勤務分の増減）の償却額」で構成されます。

> **【コラム：賦課方式と積立方式の収益率比較（アーロンの条件）】**
>
> 「公的年金は賦課方式と積立方式のどちらが有利か」という問いに対し、経済学者ポール・サミュエルソン（1958年）とヘンリー・アーロン（1966年）は、簡潔な数理基準（**アーロンの条件：Aaron's Condition**）を導出しました。
>
> 1世代を1期間とし、人口が毎期率 $n$ で成長し、1人あたりの賃金が毎期率 $g$ で成長する経済を考えます。
>
> * **積立方式の収益率：** 現役時代に納めた保険料を金融市場で運用するため、1期後に返ってくる収益率は**市場利子率 $r$**（元利合計 $1 + r$ 倍）です。
> * **賦課方式の収益率：** 現役世代が納めた保険料の総額は「現役人数 $\times$ 平均賃金 $\times$ 保険料率」です。次の期には現役人数が $(1 + n)$ 倍、平均賃金が $(1 + g)$ 倍になるため、保険料率を一定に保ったまま高齢世代へ支払える給付総額は $(1 + n)(1 + g) \approx 1 + n + g$ 倍に増えます。したがって、賦課方式の暗黙の収益率は **人口成長率＋賃金上昇率（$n + g$）**（＝経済全体の賃金総額の成長率）になります。
>
> ゆえに、両方式の有利・不利は次式で判定されます。
>
> $$\begin{cases} n + g > r & \implies \text{賦課方式の方が収益率が高い（高度経済成長・人口増加期）} \\ n + g < r & \implies \text{積立方式の方が収益率が高い（少子高齢化・低成長期）} \end{cases}$$
>
> 戦後の高度成長期には人口も賃金も急拡大していたため（$n + g > r$）、賦課方式は高い収益性を発揮しました。しかし、少子高齢化で $n < 0$ となり $n + g < r$ へ逆転した現代では、賦課方式の収益率が低下します。それでも公的年金を直ちに完全積立方式へ切り替えられないのは、切り替えの過渡期にいる現役世代が「今の高齢者の年金（賦課分）」と「自分自身の老後資金（積立分）」の両方を支払う**二重の負担問題**が生じるためです。

### 4. 限界と補正（Critique & Adaptation）

Trowbridge モデルや伝統的な確定給付企業年金（DB）は、「人口構成が安定し、予定利率が一定に保たれる」という理想的な前提のもとで滑らかに機能します。しかし、現実の経済環境ではこの前提が大きく崩れ、企業年金制度の大きな転換を迫りました。

#### (1) 定常人口・一定予定利率の崩れと「積立不足」の発生

バブル崩壊後の超低金利と株式市場の低迷、さらに退職給付会計の導入（2000年〜）によって、多くの日本企業で次のような問題が一斉に表面化しました。

1. **割引率低下による退職給付債務（PBO）の膨張：** 市場金利が下がると、退職給付債務の計算に使う割引率も引き下げなければなりません。0-1節で確認した通り、割引率が下がると将来の給付の現在価値（PBO）が急激に跳ね上がり、企業のBSに巨額の**積立不足（数理計算上の差異）**が発生しました。
2. **運用利回りの低下と本業の圧迫：** 年金資産の運用利回りが予定利率を下回ると、企業は本業の利益から毎年巨額の特別掛金を追加拠出せざるを得なくなり、企業業績と株価を大きく圧迫しました。

#### (2) DBからDCへの移行と「キャッシュバランスプラン」による折衷補正

この構造的な限界に対応するため、2000年代以降、企業年金の世界では次の2つの方向で制度の補正が進みました（図7-7-1右）。

1. **確定拠出年金（企業型DC）への移行：**

    企業が運用リスクをすべて抱え込むDBを縮小・廃止し、毎月の掛金拠出だけで企業の責任が完了する**確定拠出年金（DC）**へ移行する企業が急増しました。これにより企業のBSから積立不足リスクは切り離され、従業員にとっても転職時に年金資産を持ち運びやすい（ポータビリティ）という利点が生まれました。一方で、金融知識が十分でない個人が元本確保型（低利回りの預金等）ばかりを選び、老後資金が十分に増えないという新たな課題（投資教育の必要性）も生まれています。

2. **キャッシュバランスプラン（折衷設計）の導入：**

    「企業が全リスクを負うDB」と「個人が全リスクを負うDC」の中間をとる補正として導入されたのが**キャッシュバランスプラン（CB）**です。法制度上は確定給付（DB）の一種ですが、従業員ごとに仮想個人口座を設け、毎年の付与額に掛ける利息（再評価率）を固定利率ではなく**「10年国債利回りなどの市場金利指標（下限・上限付き）」に連動**させます。金利が下がって運用が厳しい時期は自動的に再評価率も下がるため、企業と従業員のあいだで金利変動リスクを適切に分担できる設計になっています。

### 5. 接続と展望（Bridge）：第7部の総括と第8部以降への接続

これで第7部「社会保障・生命保険・年金の制度と数理（7-1節〜7-7節）」がすべて完了しました。公的医療・公的年金の制度設計から始まり、生命表と死力、打ち切りデータからのノンパラメトリック生存解析、マルコフ過程と多重状態モデル、生命保険の純保険料・責任準備金（Thieleの微分方程式）・3利源分析・税務、そして企業年金・公的年金の財政数理（Trowbridgeモデル・極限方程式・退職給付会計）まで、「人の生死と長生き」をめぐる制度と数理（アクチュアリー専門数理1）の骨格が一通り揃いました。これらは第8部以降へ次のように繋がります。

1. **次部（第8部 8-1〜8-9節：損害保険・危険理論・リスク管理の数理）：**

    第7部の生命保険では「1人につき死亡は最大1回・給付額は契約時に定額」という構造が基本でした。第8部の損害保険（アクチュアリー専門数理2・リスクマネジメント）では、1年間に事故が「何回起きるか（頻度：ポアソン過程）」も「1回あたりいくらの損害が出るか（強度：重尾分布）」も両方ランダムになる**複合ポアソン分布**や、破産確率・極値理論・コピュラ・ERMの世界へ進みます。

2. **第9部（9-1・9-6節：債券数理・ALMとライフサイクル投資）：**

    本節の退職給付債務（PBO）が市場金利の低下で急膨張する現象は、9-1節で学ぶ債券の**デュレーションと負債イミュナイゼーション（ALM）**そのものです。また、DC・iDeCoで個人が自ら運用リスクを負う構造は、9-6節のライフサイクル投資・取り崩し期の数理へ直結します。
