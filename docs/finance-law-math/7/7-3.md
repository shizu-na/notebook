## 7-3. 生命表・生存関数と死力の数理

### 1. 動機（Why）：なぜ指数分布の「一定の故障率 $\lambda$」では人間の寿命を扱えないのか

第0部（0-4節）では、故障や出来事が起きるまでの待ち時間を表す連続分布として**指数分布 $\mathrm{Exp}(\lambda)$** を学びました。指数分布では、生存確率が $P(T > t) = e^{-\lambda t}$ で表され、「これまで何年経過したかに関係なく、次の瞬間に事象が起きるペースが常に一定の $\lambda$ である（無記憶性）」という性質を持っていました。

しかし、人間の寿命にこの無記憶性をそのまま当てはめることはできません。20歳の人が次の1年間に亡くなる確率と、85歳の人が次の1年間に亡くなる確率は大きく異なるからです。人間の死亡率は年齢とともに上昇し、その上がり方を正確に捉えなければ、生命保険の保険料も公的年金の財政見通しも計算できません。

そこで保険数理（アクチュアリー数理）では、指数分布の定数 $\lambda$ を年齢 $x$ に応じて変化する関数 **$\mu_x$（死力／ハザード関数）** へ拡張し、各年齢における生存者数や死亡率を体系的にまとめた**生命表（せいめいひょう：Life Table）**を土台にします。本節では、小さな生命表の数値例から出発し、生存関数・死力・平均余命・定常人口・古典的死亡法則・経験生命表・連合生命モデルまでを1本の流れで組み立てます。

---

### 2. 具体例と計算イメージ（Toy Model）

一般的な微積分の定義に入る前に、手計算で最後まで追える小さな架空の生命表を使って、生存率・死亡率・平均余命・定常人口の関係を確認します。

#### 実験A：最大年齢 $4$ 歳の小さな生命表（1歳到達者の生存率と平均余命）

出生時（$0$ 歳）に $l_0 = 100$ 人の集団からスタートし、各年齢 $x$ 歳まで生き残る人数 $l_x$ と、$x$ 歳から $x+1$ 歳のあいだに死亡する人数 $d_x = l_x - l_{x+1}$ が次のように観測されたとします（$4$ 歳で全員が寿命を迎えるモデル）。

| 年齢 $x$ | 生存数 $l_x$ | 死亡数 $d_x$ | 1年生存率 $p_x$ | 1年死亡率 $q_x$ | 年央生存数 $L_x$（一様死亡仮定） |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $0$ | $100$ | $20$ | $0.800$ | $0.200$ | $90$ |
| $1$ | $80$ | $30$ | $0.625$ | $0.375$ | $65$ |
| $2$ | $50$ | $30$ | $0.400$ | $0.600$ | $35$ |
| $3$ | $20$ | $20$ | $0.000$ | $1.000$ | $10$ |
| $4$ | $0$ | — | — | — | — |

ここで、**現在 $1$ 歳に到達している $l_1 = 80$ 人** に注目して、4つの基本指標を計算してみます。

1. **生存率と死亡率：**

    * $1$ 年生存率（$2$ 歳まで生きる割合）：$p_1 = \dfrac{l_2}{l_1} = \dfrac{50}{80} = \mathbf{0.625}$
    * $1$ 年死亡率（$1$ 年以内に亡くなる割合）：$q_1 = \dfrac{d_1}{l_1} = \dfrac{30}{80} = \mathbf{0.375} = 1 - p_1$
    * $2$ 年生存率（$3$ 歳まで生きる割合）：${}_2 p_1 = \dfrac{l_3}{l_1} = \dfrac{20}{80} = \mathbf{0.250}$
    * $3$ 年生存率（$4$ 歳まで生きる割合）：${}_3 p_1 = \dfrac{l_4}{l_1} = \mathbf{0}$

2. **略算平均余命 $e_1$（整数年だけで数えた平均残り年数）：**

    $1$ 歳の人が「あと満何年（整数年）生きられるか」の平均です。$80$ 人のうち、$1$ 年後に生きている $50$ 人が $+1$ 年分、$2$ 年後に生きている $20$ 人がさらに $+1$ 年分をカウントするため、

    $$e_1 = \frac{l_2 + l_3 + l_4}{l_1} = p_1 + {}_2 p_1 + {}_3 p_1 = 0.625 + 0.250 + 0 = \mathbf{0.875 \text{ 年}}$$

3. **完全平均余命 $\mathring{e}_1$（死亡した年の端数期間も含めた平均残り年数）：**

    略算平均余命は、たとえば「$1.6$ 歳で亡くなった人」を $0$ 年と切り捨ててしまいます。各年齢の死亡が1年を通じて均等に起きる（平均して年の真ん中で亡くなる）と仮定すると、$x$ 歳から $x+1$ 歳の1年間にこの集団が生きる延べ年数（**年央生存数** $L_x$）は台形の面積 $\frac{l_x + l_{x+1}}{2}$ で近似できます。

    * $L_1 = \dfrac{80 + 50}{2} = 65$、$L_2 = \dfrac{50 + 20}{2} = 35$、$L_3 = \dfrac{20 + 0}{2} = 10$
    * $1$ 歳以降の総生存延べ年数：$T_1 = L_1 + L_2 + L_3 = 65 + 35 + 10 = \mathbf{110 \text{ 人・年}}$
    * $1$ 人あたりの完全平均余命：$\mathring{e}_1 = \dfrac{T_1}{l_1} = \dfrac{110}{80} = \mathbf{1.375 \text{ 年}}$

    ちょうど $\mathring{e}_1 = e_1 + 0.5$（$0.875 + 0.5 = 1.375$ 年）という関係になっています。

4. **中央死亡率 $m_1$ と定常人口：**

    $1$ 歳から $2$ 歳の死亡数 $d_1 = 30$ 人を、期首の人数 $l_1 = 80$ 人ではなく、その1年間の平均的な生存人数 $L_1 = 65$ 人で割った値を**中央死亡率**と呼びます。

    $$m_1 = \frac{d_1}{L_1} = \frac{30}{65} \approx \mathbf{0.4615}$$

    また、毎年ちょうど $l_0 = 100$ 人が生まれ続け、同じ生命表に従って死亡していく社会を想像してみます。このとき各年齢階級の人口は $L_0 = 90,\; L_1 = 65,\; L_2 = 35,\; L_3 = 10$ となり、社会全体の総人口は $T_0 = 90 + 65 + 35 + 10 = \mathbf{200 \text{ 人}}$ で毎年一定に保たれます（毎年 $100$ 人生まれ、$20+30+30+20 = 100$ 人が亡くなります）。この状態を**開集団の定常人口**と呼びます。

### 3. 定義・導出・構造（What）

#### (1) 生存関数 $S(x)$・生存率 ${}_t p_x$・死亡率 ${}_t q_x$ と死力 $\mu_x$

出生から死亡までの寿命を表す連続型確率変数を $X \ge 0$ とします。累積分布関数 $F(x) = P(X \le x)$ に対し、**年齢 $x$ を超えて生存する確率**を**生存関数（Survival Function）**と呼びます。

$$S(x) := P(X > x) = 1 - F(x) \qquad \bigl(S(0) = 1,\;\; \lim_{x \to \infty} S(x) = 0\bigr)$$

次に、現在ちょうど年齢 $x$ 歳まで生存している人（条件 $X > x$）の、そこから先の残り寿命を**将来余命** $T_x := X - x$ と定義します。アクチュアリーの標準記号（国際アクチュアリー記法）では、$x$ 歳の人がさらに $t$ 年生存する確率と $t$ 年以内に死亡する確率を次のように書きます。

$${}_t p_x := P(T_x > t) = P(X > x + t \mid X > x) = \frac{S(x + t)}{S(x)}, \qquad {}_t q_x := P(T_x \le t) = 1 - {}_t p_x$$

（$t = 1$ のときは左下の $1$ を省略して $p_x,\; q_x$ と書きます。また、$x$ 歳の人が $u$ 年間は生存し、その後の $t$ 年間に死亡する確率［据置死亡率］は ${}_{u\vert t} q_x := {}_u p_x \cdot {}_t q_{x+u}$ と書きます。）

**【死力（Force of Mortality／ハザード関数）の定義と積分表現の導出】**

現在 $x$ 歳の人が、次の微小な時間幅 $dx$ のあいだに死亡する条件付確率を時間幅 $dx$ で割った極限（瞬間の死亡の勢い）を**死力（しりょく）**と呼び、$\mu_x$ と書きます。

$$\mu_x := \lim_{dx \to 0^+} \frac{P(x < X \le x + dx \mid X > x)}{dx} = \lim_{dx \to 0^+} \frac{S(x) - S(x + dx)}{S(x)\,dx} = -\frac{S'(x)}{S(x)} = -\frac{d}{dx}\ln S(x)$$

この微分方程式の両辺を $x$ から $x + t$ まで積分します。

$$\int_x^{x+t} \mu_s\,ds = -\Bigl[\ln S(s)\Bigr]_x^{x+t} = -\ln\frac{S(x + t)}{S(x)} = -\ln({}_t p_x)$$

両辺の指数関数をとることで、死力から生存率を復元する基本公式が導かれます。

$${}_t p_x = \exp\!\left(-\int_x^{x+t} \mu_s\,ds\right) = \exp\!\left(-\int_0^t \mu_{x+u}\,du\right)$$

もし死力が年齢によらず定数 $\mu_s \equiv \lambda$ であれば、${}_t p_x = e^{-\lambda t}$ となり、0-4節の**指数分布**に一致します。つまり、生存モデルとは指数分布の定数 $\lambda$ を年齢依存の関数 $\mu_x$ へ一般化した体系です。

さらに、将来余命 $T_x$ の確率密度関数 $f_{T_x}(t)$ は、累積分布関数 ${}_t q_x = 1 - {}_t p_x$ を $t$ で微分することで得られます。

$$f_{T_x}(t) = \frac{d}{dt}(1 - {}_t p_x) = -\frac{d}{dt}\exp\!\left(-\int_0^t \mu_{x+u}\,du\right) = {}_t p_x\, \mu_{x+t}$$

この式には直感的な意味があります。「ちょうど $t$ 年後の微小時間 $dt$ に死亡する確率」は、**「$t$ 年後まで生き延びる確率（${}_t p_x$）」$\times$「$x+t$ 歳の瞬間に死亡する勢い（$\mu_{x+t}\,dt$）」**の積に分解されるのです。

#### (2) 完全平均余命・略算平均余命と開集団の定常人口

1. **完全平均余命（Complete Expectation of Life）$\mathring{e}_x$：**

    将来余命 $T_x$ の期待値です。$t \to \infty$ で $t \cdot {}_t p_x \to 0$ を満たす標準的な寿命分布に対して部分積分を適用すると、密度関数を使わず生存率の積分だけで表せます。

    $$\mathring{e}_x := E[T_x] = \int_0^\infty t\, f_{T_x}(t)\,dt = \Bigl[-t\,{}_t p_x\Bigr]_0^\infty + \int_0^\infty {}_t p_x\,dt = \int_0^\infty {}_t p_x\,dt$$

    つまり幾何学的には、縦軸に生存率 ${}_t p_x$、横軸に経過年数 $t$ をとった**生存曲線の下に広がる面積がそのまま完全平均余命に一致**します。

2. **略算平均余命（Curtate Expectation of Life）$e_x$：**

    $T_x$ の整数部分 $K_x := \lfloor T_x \rfloor$（あと満何年生きられるか）の期待値です。離散版の同じ変形で、

    $$e_x := E[K_x] = \sum_{k=0}^\infty k\, P(K_x = k) = \sum_{k=1}^\infty P(K_x \ge k) = \sum_{k=1}^\infty {}_k p_x$$

    となります（$1\cdot P(K_x=1) + 2\cdot P(K_x=2) + 3\cdot P(K_x=3) + \dots$ を、$P(K_x \ge 1) + P(K_x \ge 2) + P(K_x \ge 3) + \dots$ と縦に並べ替えて足し直す変形です）。各1年間の中で死亡が一様に起きる仮定（**一様死亡仮定：UDD**、${}_t p_x = (1 - t) + t\,p_x$（$0 \le t \le 1$））を置くと、$\int_k^{k+1} {}_t p_x\,dt = \frac{1}{2}({}_k p_x + {}_{k+1} p_x)$ となるため、実験Aで確認した関係

    $$\mathring{e}_x \approx e_x + \frac{1}{2}$$

    が導かれます。

3. **生命表関数と開集団の定常人口：**

    出生時の初期人数 $l_0$（基数：通常 $100{,}000$ 人）に対し、$l_x := l_0 S(x)$ と定義すると、以下の生命表関数が体系的に結び付きます。

    * **死亡数：** $d_x := l_x - l_{x+1} = l_x q_x$
    * **年央生存数（$x$ 歳以上 $x+1$ 歳未満の定常人口）：** $L_x := \int_0^1 l_{x+t}\,dt \approx \frac{1}{2}(l_x + l_{x+1})$
    * **総生存延べ年数（$x$ 歳以上の定常人口総数）：** $T_x^{\mathrm{pop}} := \int_0^\infty l_{x+t}\,dt = \sum_{k=0}^\infty L_{x+k}$（確率変数の将来余命 $T_x$ と区別するため上付き $\mathrm{pop}$ を付けています。これにより $\mathring{e}_x = T_x^{\mathrm{pop}} / l_x$ となります）
    * **中央死亡率：** $d_x = l_x - l_{x+1} = -\int_0^1 l'_{x+t}\,dt = \int_0^1 l_{x+t}\mu_{x+t}\,dt$ より、$m_x := \dfrac{d_x}{L_x} = \dfrac{\int_0^1 l_{x+t}\mu_{x+t}\,dt}{\int_0^1 l_{x+t}\,dt}$（$x$ 歳から $x+1$ 歳における死力の加重平均）

    毎年一定の出生数 $l_0$ が流入し（開集団）、同じ死亡率で退出していくとき、各年齢の人数が $L_x$、総人口が $T_0^{\mathrm{pop}} = l_0 \mathring{e}_0$ で時間変化しない**定常人口**が実現します。

#### (3) 古典的死亡法則（ド・モアブル、ゴムパーツ、メーカム）

生命表の離散データだけでなく、死力 $\mu_x$ を滑らかな数式で表す古典的な3つの法則がアクチュアリー数理でよく用いられます。

| 法則名 | 死力 $\mu_x$ の式 | 生存関数 $S(x)$ と特徴 |
| --- | :---: | :--- |
| **ド・モアブルの法則**（1725年） | $\dfrac{1}{\omega - x}\; (0 \le x < \omega)$ | $S(x) = 1 - \dfrac{x}{\omega}$（区間 $[0, \omega]$ 上の**一様分布**）。$\mathring{e}_x = \dfrac{\omega - x}{2}$ と手計算が容易。 |
| **ゴムパーツの法則**（1825年） | $B c^x\; (B > 0,\; c > 1)$ | $S(x) = \exp\!\left(-\dfrac{B}{\ln c}(c^x - 1)\right)$。老化により死力が年齢とともに指数関数的に増加する性質を捉える。 |
| **メーカムの法則**（1860年） | $A + B c^x\; (A \ge 0,\; B > 0,\; c > 1)$ | $S(x) = \exp\!\left(-Ax - \dfrac{B}{\ln c}(c^x - 1)\right)$。ゴムパーツに年齢無関係な偶発事故死 $A$ を加えた拡張。 |

#### (4) 国民表と経験表（選択表・終局表・総合表・截断表）

生命表は、データの対象集団によって大きく2種類に分かれます。

1. **国民生命表（国民表）：** 国勢調査と人口動態統計に基づき、国全体の人口を対象に作成される表（日本の厚生労働省による完全生命表・簡易生命表など）。
2. **経験生命表（経験表）：** 生命保険会社の実際の契約者集団の死亡データから作成される表（日本アクチュアリー会の標準生命表など）。

保険会社は契約時に健康診断や告知による審査（**危険選択**）を行うため、契約したばかりの人は同年齢の一般国民よりも健康で死亡率が低くなります。この診査の効果は契約後数年（選択期間：例として3〜5年）で薄れ、やがて同じ年齢の既契約者と変わらない水準へ収束します。

* **選択表（Select Table）：** 契約時年齢 $[x]$ と経過年数 $t$ の両方を区別して死亡率 $q_{[x]+t}$ を表した表。
* **終局表（Ultimate Table）：** 選択期間が経過した後の、到達年齢 $x+t$ だけで決まる死亡率 $q_{x+t}$ の表（選択表から選択期間のデータを切り落とした表を**截断表［せつだんひょう］**と呼びます）。
* **総合表（Aggregate Table）：** 経過年数を区別せず、同じ到達年齢の契約者をすべてまとめて算出した表。

#### (5) 連合生命モデル（連生状態と最終生存者状態）

夫婦共同の住宅ローン（連生団信）や、夫婦どちらか一方が生きているあいだ給付が続く連生年金のように、2人（年齢 $x$ 歳と $y$ 歳）の寿命が同時に絡む契約を扱う枠組みが**連合生命モデル**です。2人の将来余命 $T_x, T_y$ が互いに独立であると仮定し、次の2つの状態を定義します（図7-3-1右）。

1. **連生状態（Joint-Life Status：$xy$）：** 「2人とも生存している状態」を指し、どちらか先に1人が亡くなった時点で終了します。残存期間は $T_{xy} := \min(T_x, T_y)$ です。

    * 生存率：${}_t p_{xy} = P\bigl(\min(T_x, T_y) > t\bigr) = P(T_x > t,\; T_y > t) = {}_t p_x \cdot {}_t p_y$
    * 死力：$\mu_{xy}(t) = -\dfrac{d}{dt}\ln({}_t p_x \cdot {}_t p_y) = \mu_{x+t} + \mu_{y+t}$（2人の死力の単純な和になります）

2. **最終生存者状態（Last-Survivor Status：$\overline{xy}$）：** 「少なくとも1人が生存している状態」を指し、2人とも亡くなった時点で終了します。残存期間は $T_{\overline{xy}} := \max(T_x, T_y)$ です。

    * 死亡率：${}_t q_{\overline{xy}} = P\bigl(\max(T_x, T_y) \le t\bigr) = {}_t q_x \cdot {}_t q_y$
    * 生存率：${}_t p_{\overline{xy}} = 1 - {}_t q_x\,{}_t q_y = 1 - (1 - {}_t p_x)(1 - {}_t p_y) = {}_t p_x + {}_t p_y - {}_t p_{xy}$
    * 完全平均余命：常に $\min(a, b) + \max(a, b) = a + b$ が成り立つため、$T_{xy} + T_{\overline{xy}} = T_x + T_y$ の両辺の期待値をとれば直ちに

        $$\mathring{e}_{\overline{xy}} = \mathring{e}_x + \mathring{e}_y - \mathring{e}_{xy}$$

        が得られます。

> **【コラム1：1693年のハレーによる生命表の作成】**
>
> ハレー彗星の軌道計算で知られる天文学者エドモンド・ハレーは、1693年に近代的な意味で最初の生命表を発表しました。当時、英国政府が戦費調達のために終身年金を売り出そうとしていたものの、年齢に応じた適正価格の計算根拠がありませんでした。ハレーは、人口移動が比較的少なく教会に詳細な出生・死亡記録が残っていた現在のポーランド・ヴロツワフ（当時のブレスラウ市）の5年間のデータを分析し、年齢別の生存数表と終身年金の現在価値表を算出したのです。

> **【コラム2：死力と信頼性工学の「バスタブ曲線」】**
>
> 本節で導出した死力 $\mu_x = -S'(x)/S(x)$ は、機械や電子部品の寿命を解析する**信頼性工学**の世界では**故障率関数（ハザード関数）**とまったく同じ数式で定義されます。工業製品の故障率を横軸に時間、縦軸に故障率で描くと、①使い始めの初期不良が多い「初期故障期」、②故障率が低く一定の「偶発故障期」（指数分布の領域）、③劣化が進んで故障率が急上昇する「摩耗故障期」という、浴槽の断面のような**バスタブ曲線**になります。人間の死力 $\mu_x$（図7-3-1左）も、出生直後の乳児死亡率の低下、若年期の低い水準（メーカムの定数 $A$）、そして高齢期の老化による急上昇（ゴムパーツの $B c^x$）という、機械とそっくりのバスタブ曲線を描くことが知られています。

### 4. 限界と補正（Critique & Adaptation）

生命表と古典的死亡法則は保険・年金数理の基礎的な枠組みですが、現実の社会へ適用する際には次の2つの大きな限界に対処する必要があります。

#### (1) 静的生命表の限界と「長寿リスク」の過小評価

通常の生命表（**時点生命表／静的生命表**）は、たとえば「2025年という1年間」に観測された0歳〜100歳の死亡率を横に並べて作ります。しかし、現在30歳の人が80歳になるのは50年後の2075年です。その50年のあいだに医療技術や公衆衛生が進歩すれば、2075年時点の80歳の死亡率は、2025年時点の80歳の死亡率より大幅に下がっている可能性が高くなります。

過去の静的生命表をそのまま使って終身年金や公的年金の将来給付を見積もると、将来の受給者が想定より長生きし、年金支払総額が予算を大きく上回る**長寿リスク（Longevity Risk）**を過小評価してしまいます。

* **補正手法①（コーホート生命表）：** 同じ年に生まれた世代（コーホート）ごとに、将来の死亡率改善トレンドを織り込んで縦に追跡する**コーホート生命表**を作成します。
* **補正手法②（確率的死亡率モデル：Lee-Carterモデル等）：** 死亡率の改善スピード自体も不確実な確率変数とみなすモデルが広く使われています。代表的な **Lee-Carterモデル（1992年）** では、年齢 $x$・暦年 $t$ の中央死亡率 $m_{x,t}$ の対数を次のように分解します。

    $$\ln m_{x,t} = a_x + b_x \kappa_t + \varepsilon_{x,t}$$

    ここで $a_x$ は年齢ごとの平均的な死亡水準、$\kappa_t$ は時間とともに低下する全体的な死亡率トレンド（ランダムウォーク等の時系列モデルで将来を予測）、$b_x$ はそのトレンドに対する各年齢の感応度を表します。これにより、将来の寿命の伸びを確率分布（信頼区間付き）として評価できます（図7-3-2に時点生命表とコーホート生命表の違い［レキシス図］、および3(4)の選択表と終局表の合流構造を示します）。

#### (2) 連合生命モデルにおける「独立仮定」の限界

3(5)の連合生命モデルでは、夫婦の寿命 $T_x, T_y$ が互いに独立であると仮定して ${}_t p_{xy} = {}_t p_x \cdot {}_t p_y$ を導きました。しかし現実の夫婦は、①同じ食生活・居住環境を共有している、②同じ車に乗っている際の交通事故や災害で同時に亡くなる可能性がある（共通ショック）、③配偶者を亡くした強い精神的ストレスで残された側の死亡率が一時的に上昇する（いわゆるブロークンハート現象）、といった要因により**正の従属性**を持っています。

独立性を安易に仮定すると、連生保険や最終生存者年金の価格にズレが生じるため、実務の高度なリスク管理では、共通の事故死リスクをメーカム型の共通ハザードとして組み込んだり、後述する**コピュラ**（周辺分布と従属構造を分離して結合する手法）を用いて2人の寿命の相関をモデル化したりする補正が行われます。

### 5. 接続と展望（Bridge）：本節の内容が後半のどの部に繋がるか

1. **次節（7-4節：ノンパラメトリック生存解析とハザード推定）：**

    本節では生命表や死力 $\mu_x$ がすでに分かっている前提で計算を行いました。次節では、保険の中途解約や観察終了によって死亡時点が最後まで観測できない**打ち切りデータ**から、生存関数 $S(x)$ や累積ハザードを直接推定する**カプラン＝マイヤー推定量・ネルソン＝アーレン推定量・コックス比例ハザードモデル**へ進みます。

2. **第7部（7-5・7-6・7-8節：マルコフ過程・生命保険数理・年金数理）：**

    本節の生存モデル（「生存 $\to$ 死亡」の2状態）を「健康・要介護・死亡」の多状態へ広げたものが7-5節のマルコフ過程です。また、${}_t p_x$ と $\mu_x$ は7-6節の純保険料・Thieleの微分方程式および7-8節の年金数理（Trowbridgeモデル）の直接の部品になります。

3. **第8部（8-8節：コピュラ）および第9部（9-12節：信用リスク誘導型モデル）：**

    4(2)で触れた寿命の従属構造は8-8節のコピュラへ繋がります。また、本節の死力 $\mu_x$ は、9-12節の信用リスク誘導型モデルにおける企業の**デフォルト強度 $\lambda_t$** と数学的にまったく同一のハザード関数です。
