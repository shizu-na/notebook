### 前節（7-2）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（ノンパラメトリック生存解析とハザード推定）の導入になります。

1. **ド・モアブルの法則における生存率・死力・完全平均余命：**

    最大年齢 $\omega = 100$ 歳のド・モアブルの法則 $S(x) = 1 - \frac{x}{100}$ について、$x = 60$ 歳の人を計算します。

    * **(a) $20$ 年生存率 ${}_{20} p_{60}$ と $60$ 歳時点の死力 $\mu_{60}$：**

        $${}_{20} p_{60} = \frac{S(80)}{S(60)} = \frac{1 - 0.80}{1 - 0.60} = \frac{0.20}{0.40} = \mathbf{0.50}$$

        $$\mu_{60} = \frac{1}{\omega - 60} = \frac{1}{100 - 60} = \frac{1}{40} = \mathbf{0.025}$$

    * **(b) $60$ 歳時点の完全平均余命 $\mathring{e}_{60}$：**

        $t$ 年生存率は ${}_t p_{60} = \frac{S(60 + t)}{S(60)} = \frac{40 - t}{40} = 1 - \frac{t}{40}$（$0 \le t \le 40$）なので、

        $$\mathring{e}_{60} = \int_0^{40} \left(1 - \frac{t}{40}\right) dt = \left[t - \frac{t^2}{80}\right]_0^{40} = 40 - \frac{1{,}600}{80} = \mathbf{20 \text{ 年}}$$

2. **連合生命モデルの計算：**

    独立な寿命を持つ2人（${}_{10} p_x = 0.90,\; {}_{10} p_y = 0.80,\; \mu_x = 0.01,\; \mu_y = 0.02$）について計算します。

    * **(a) 連生生存率と最終生存者生存率：**

        $${}_{10} p_{xy} = {}_{10} p_x \cdot {}_{10} p_y = 0.90 \times 0.80 = \mathbf{0.72}$$

        $${}_{10} p_{\overline{xy}} = {}_{10} p_x + {}_{10} p_y - {}_{10} p_{xy} = 0.90 + 0.80 - 0.72 = \mathbf{0.98}$$

    * **(b) 現時点における連生状態の死力：**

        $$\mu_{xy}(0) = \mu_x + \mu_y = 0.01 + 0.02 = \mathbf{0.03}$$

3. **途中で観察が終わるデータから、どうやって生存率を推定するか（本節への接続）：**

    保険の中途解約や調査期間の終了によって死亡時点が最後まで観測できないデータ（**打ち切りデータ**）を含む場合、打ち切りを単純に無視すると生存率を過大評価し、逆に打ち切り者を最初から除外すると生存情報を捨てて過小評価してしまいます。そこで、各イベント時点における「その直前まで観察対象に残っていた人数（リスク集合）」を分母として条件付生存確率を掛け合わせる**カプラン＝マイヤー推定量**などの生存解析手法を用います。

## 7-3. ノンパラメトリック生存解析とハザード推定

### 1. 動機（Why）：なぜ「打ち切りデータ」を扱う専用の推定手法が必要なのか

前節（7-2節）では、生命表やゴムパーツの法則のように、生存関数 $S(x)$ や死力 $\mu_x$ がすでに分かっている前提で計算を行いました。しかし実務の現場では、まず手元の観測データから $S(x)$ や $\mu_x$ を推定しなければなりません。

ここで、通常の統計学（第0部 0-6節）にはない生存データ特有の壁が現れます。それが**打ち切り（センサリング：Censoring）**の存在です。たとえば、生命保険の契約者1,000人を5年間追跡調査するとき、すべての人の死亡時点が分かるわけではありません。

* 2年目に保険を中途解約して追跡できなくなった人（脱落）
* 5年間の調査終了時点で、まだ元気に生きている人（観察終了）

このような「少なくともある時点までは生存していたが、その後にいつ死亡したか（イベントが起きたか）は分からないデータ」を**右側打ち切りデータ（Right-censored data）**と呼びます。

さらに、現実の寿命や損失額の分布が、必ずしも指数分布や正規分布といった特定の数式（パラメトリックな分布）に従うとは限りません。そこで本節では、特定の確率分布を決め打ちせずデータから直接に生存関数やハザードを推定する**ノンパラメトリック生存解析**の2大手法（**カプラン＝マイヤー推定量**・**ネルソン＝アーレン推定量**）から出発します。そのうえで、年齢や喫煙習慣などの要因がハザード率へ与える影響を測る**コックス比例ハザードモデル**、およびヒストグラムを滑らかにする**カーネル密度推定量**を1本の流れで整理します。

---

### 2. 具体例と計算イメージ（Toy Model）

一般的な定義に入る前に、わずか10人の追跡データを使って、「打ち切りの誤った扱い」と「カプラン＝マイヤー推定量」の結果がどう異なるかを手計算で確かめます。

#### 実験A：10人の5年間追跡データ（中途解約を含む生存率の推定）

ある保険契約に同時加入した **$10$ 人** を5年間追跡したところ、次のイベントが観測されたとします。

* **$t = 1$ 年：** $1$ 人が死亡（残りは $9$ 人）
* **$t = 2$ 年：** $1$ 人が中途解約で**打ち切り**（追跡対象は $8$ 人に減少）
* **$t = 3$ 年：** $2$ 人が死亡（残りは $6$ 人）
* **$t = 4$ 年：** $1$ 人が中途解約で**打ち切り**（追跡対象は $5$ 人に減少）
* **$t = 5$ 年：** $1$ 人が死亡（残り $4$ 人は観察期間終了で打ち切り）

このデータから「5年生存率 $S(5)$」を推定したいとします。まず、ありがちな2つの誤った計算を試してみます。

* **誤り①（打ち切り者をずっと生存扱いする）：** 10人中4人が死亡したから $1 - 4/10 = 0.600$。解約した2人がその後も全員生き続けたと決めつけているため、**過大評価**になります。
* **誤り②（打ち切り者2人を最初から除外する）：** 最後まで追えた8人中4人が死亡したから $1 - 4/8 = 0.500$。解約した2人が「2年間・4年間は確実に生きていた」という事実を捨てているため、**過小評価**になります。

そこで、**死亡が発生した時点ごとに「その直前まで観察下に残っていた人数（リスク集合 $r_j$）」を分母にして生存割合を計算し、掛け合わせる**方法をとります（これが**カプラン＝マイヤー推定量**です）。

| 死亡時点 $t_j$ | 直前の観察対象人数 $r_j$ | 死亡数 $d_j$ | その時点の条件付生存率 $1 - d_j/r_j$ | カプラン＝マイヤー $\hat{S}(t_j)$ | ネルソン＝アーレン $\hat{H}(t_j)$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $t_1 = 1$ | $10$ | $1$ | $1 - \dfrac{1}{10} = 0.900$ | **$0.900$** | $0.100$ |
| $t_2 = 3$ | $8$ | $2$ | $1 - \dfrac{2}{8} = 0.750$ | $0.900 \times 0.750 = \mathbf{0.675}$ | $0.100 + 0.250 = 0.350$ |
| $t_3 = 5$ | $5$ | $1$ | $1 - \dfrac{1}{5} = 0.800$ | $0.675 \times 0.800 = \mathbf{0.540}$ | $0.350 + 0.200 = 0.550$ |

カプラン＝マイヤー推定量は **$0.540$** となり、先ほどの過大評価（$0.600$）と過小評価（$0.500$）のちょうど間に入ります。打ち切りが起きた $t = 2,\; 4$ では生存曲線自体は下がらず、**次の死亡時点の分母 $r_j$ が減る**という形で、すべての人の生存期間情報が無駄なく反映されています（図7-3-1左）。

また、右列の**ネルソン＝アーレン推定量** $\hat{H}(t_j) = \sum d_i/r_i$ は累積ハザード関数の推定値であり、7-2節の関係 $S(t) = e^{-H(t)}$ から生存率へ換算すると $\exp(-0.550) \approx 0.577$ となります（小標本では差が出ますが、標本サイズが増えると両者は一致します）。

### 3. 定義・導出・構造（What）

#### (1) 打ち切りデータの構造とカプラン＝マイヤー推定量

対象者 $i = 1, \dots, n$ の真のイベント発生時点（死亡時点など）を $T_i$、打ち切り時点（中途解約や調査終了など）を $C_i$ とします。実際に観測できるのは、先に起きた方の時点 $Y_i := \min(T_i, C_i)$ と、「イベントが起きた（$\delta_i = 1$）」か「打ち切りになった（$\delta_i = 0$）」かを示す指標のペア $(Y_i, \delta_i)$ です。

イベント（$\delta_i = 1$）が観測された互いに異なる時点を小さい順に $t_1 < t_2 < \dots < t_m$ とします。各時点 $t_j$ の直前まで生存かつ未打ち切りで観察対象に残っていた人数（**リスク集合**の大きさ）を $r_j$、ちょうど時点 $t_j$ にイベントが起きた人数を $d_j$ と置きます。

> **【定義：カプラン＝マイヤー推定量（積限界推定量：Product-Limit Estimator）】**
>
> 任意の時点 $t \ge 0$ における生存関数 $S(t)$ のノンパラメトリック推定量を次で定義する。
>
> $$\hat{S}_{\mathrm{KM}}(t) := \prod_{t_j \le t} \left(1 - \frac{d_j}{r_j}\right)$$

* **直感と最尤推定としての意味：** 時点 $t$ まで生き残る確率は、確率の乗法定理（0-2節）より「時点 $t_1$ を生き残る確率 $\times$ 時点 $t_1$ まで生きた条件のもとで時点 $t_2$ を生き残る確率 $\times \dots$」の積で表されます。各時点 $t_j$ の条件付死亡率の最尤推定値が $d_j / r_j$ であるため、それらを掛け合わせた $\hat{S}_{\mathrm{KM}}(t)$ は、打ち切りデータのもとでの生存関数の**ノンパラメトリック最尤推定量**になります。
* **推定量の分散（グリーンウッドの公式）：** $\hat{S}_{\mathrm{KM}}(t)$ の不確実性（信頼区間）を測るため、対数をとって**デルタ法**（関数の微小な変化を微分［1次近似］で分散へ変換する手法）を適用すると、次の**グリーンウッドの公式（Greenwood's Formula）**が導かれます。

    $$\widehat{V}\bigl[\hat{S}_{\mathrm{KM}}(t)\bigr] = \bigl(\hat{S}_{\mathrm{KM}}(t)\bigr)^2 \sum_{t_j \le t} \frac{d_j}{r_j(r_j - d_j)}$$

    時間が進んでリスク集合 $r_j$ が小さくなるほど、右辺の和が急に大きくなり、生存曲線の右端では信頼区間が広く開いて推定精度が落ちることがこの式から読み取れます。

#### (2) ネルソン＝アーレン推定量（累積ハザードの推定）

7-2節で導入した死力（ハザード関数）$\mu(u)$ を $0$ から $t$ まで積分した関数を**累積ハザード関数** $H(t) := \int_0^t \mu(u)\,du$ と呼びます（$S(t) = e^{-H(t)}$ の関係にあります）。

各イベント時点 $t_j$ における瞬間ハザードの増分を $d_j / r_j$ で推定し、それを積み上げたものが**ネルソン＝アーレン推定量（Nelson＝Aalen Estimator）**です。

$$\hat{H}_{\mathrm{NA}}(t) := \sum_{t_j \le t} \frac{d_j}{r_j}$$

推定量の分散は $\widehat{V}[\hat{H}_{\mathrm{NA}}(t)] = \sum_{t_j \le t} \frac{d_j}{r_j^2}$（あるいは有限母集団補正を入れた $\frac{d_j(r_j - d_j)}{r_j^3}$）で評価されます。$x$ が小さいときの近似 $\ln(1 - x) \approx -x$ を使うと、

$$\ln \hat{S}_{\mathrm{KM}}(t) = \sum_{t_j \le t} \ln\!\left(1 - \frac{d_j}{r_j}\right) \approx -\sum_{t_j \le t} \frac{d_j}{r_j} = -\hat{H}_{\mathrm{NA}}(t)$$

となるため、生存率の推定値 $\hat{S}_{\mathrm{NA}}(t) := \exp(-\hat{H}_{\mathrm{NA}}(t))$ は常に $\hat{S}_{\mathrm{KM}}(t)$ よりわずかに大きい値をとりつつ（$\ln(1-x) < -x$ より）、標本サイズが大きく $d_j / r_j$ が小さくなるにつれて両者は漸近的に一致します。

#### (3) コックス比例ハザードモデル（Cox Proportional Hazards Model）

カプラン＝マイヤー推定量は集団全体の生存曲線を描けますが、「年齢が1歳高いと死亡リスクは何倍になるか」「喫煙習慣や企業の負債比率がハザード率にどれだけ影響するか」といった、複数の説明変数（**共変量** $\mathbf{z}_i = (z_{i1}, \dots, z_{ip})^T$）の効果を同時に評価するには回帰モデルが必要です。

1972年にデイヴィッド・コックスが提案した**コックス比例ハザードモデル**は、共変量 $\mathbf{z}_i$ を持つ個人の時点 $t$ におけるハザード関数を次の積の形で表します。

$$\mu(t \mid \mathbf{z}_i) = \mu_0(t) \exp(\mathbf{\beta}^T \mathbf{z}_i) = \mu_0(t) \exp(\beta_1 z_{i1} + \dots + \beta_p z_{ip})$$

* **ベースライン・ハザード $\mu_0(t)$：** すべての共変量が $0$ の基準集団における時間依存のハザード関数。**特定の分布（ゴムパーツやワイブル等）を一切仮定せず、ノンパラメトリックなまま残します**。
* **ハザード比（Hazard Ratio）：** 共変量 $\mathbf{z}_A$ と $\mathbf{z}_B$ を持つ2人のハザード率の比をとると、未知の $\mu_0(t)$ が分子と分母で約分されて消えます。

    $$\frac{\mu(t \mid \mathbf{z}_A)}{\mu(t \mid \mathbf{z}_B)} = \exp\!\bigl(\mathbf{\beta}^T (\mathbf{z}_A - \mathbf{z}_B)\bigr)$$

    つまり、**2人のハザード率の比は時間 $t$ に依存せず常に一定である（比例ハザード性）**と仮定されます。たとえば喫煙ダミー変数（喫煙 $=1$、非喫煙 $=0$）の係数が $\hat{\beta}_1 = 0.693$ であれば、他の条件を同じにしたとき喫煙者のハザード率は非喫煙者の $e^{0.693} \approx \mathbf{2.0 \text{ 倍}}$ と解釈できます。

* **部分尤度（Partial Likelihood）による推定の仕組み：**

    未知の関数 $\mu_0(t)$ を決めることなく係数 $\mathbf{\beta}$ だけを推定できるのがコックスモデルの際立った特徴です。時点 $t_j$ にリスク集合 $R(t_j)$ の中からちょうど1人（個人 $i(j)$）にイベントが起きたとき、「リスク集合の中で、よりによって個人 $i(j)$ が選ばれた条件付確率」は、各人のハザード率の比率

    $$\frac{\mu\bigl(t_j \mid \mathbf{z}_{i(j)}\bigr)}{\sum_{k \in R(t_j)} \mu(t_j \mid \mathbf{z}_k)} = \frac{\exp(\mathbf{\beta}^T \mathbf{z}_{i(j)})}{\sum_{k \in R(t_j)} \exp(\mathbf{\beta}^T \mathbf{z}_k)}$$

    となり、ここでも $\mu_0(t_j)$ が完全に消去されます。これを全イベント時点 $j = 1, \dots, m$ で掛け合わせた**部分尤度**を最大化することで、0-6節の最尤推定法と同様に $\hat{\mathbf{\beta}}$ を求められます。分布の土台となる $\mu_0(t)$ には特定の数式を仮定せず、共変量の影響倍率だけをパラメータで表す折衷型であるため、**セミパラメトリックモデル**と呼ばれます。

#### (4) カーネル密度推定量（Kernel Density Estimation, KDE）

ここまでは累積確率（生存関数・累積ハザード）を扱いましたが、観測データ $x_1, \dots, x_n$（保険の損害額データなど）から特定の分布を仮定せずに**確率密度関数 $f(x)$** そのものを滑らかに推定したい場面もあります。

単純なヒストグラムは、階級幅の取り方や区切り位置（開始点）によって形ががらりと変わってしまいます。そこで、各データ点 $x_i$ の上に面積 $1$ の小さな左右対称の山（**カーネル関数** $K(u)$：代表例は標準正規分布の密度 $K(u) = \frac{1}{\sqrt{2\pi}}e^{-u^2/2}$）を置き、すべて足し合わせて平均をとったものが**カーネル密度推定量**です（図7-3-1右）。

$$\hat{f}_h(x) := \frac{1}{n h} \sum_{i=1}^n K\!\left(\frac{x - x_i}{h}\right) \qquad (h > 0)$$

ここで $h > 0$ は山の広がりを決める**バンド幅（平滑化パラメータ）**です。すべての $i$ で $\int \frac{1}{h}K(\frac{x - x_i}{h})\,dx = 1$ なので、$\hat{f}_h(x)$ の全面積は自動的に $1$ になります。

> **【コラム：医学・保険・金融を貫く「打ち切りデータ付き生存解析」の横断性】**
>
> 本節で扱ったカプラン＝マイヤー推定量やコックス比例ハザードモデルは、もともと医学の臨床試験（新薬を投与した患者群と対照群の5年生存率の比較）で爆発的に普及した手法です。臨床試験では、試験終了時点で生存している患者や途中で転院した患者が必ず発生するため、打ち切りデータの処理が不可欠だったからです。
>
> しかし、数理構造の視点で見れば、「イベント＝死亡」である必要はありません。イベントの定義を置き換えるだけで、まったく同じ数式が金融・保険・ビジネスのさまざまな分野でそのまま機能します。
>
> * **生命保険・年金（第7部）：** イベント＝死亡・要介護発生・契約解約（継続率分析）。
> * **信用リスク・金融工学（第9部 9-12節）：** イベント＝企業のデフォルト（債務不履行）や住宅ローンの期限前償還。財務指標（自己資本比率やインタレスト・カバレッジ・レシオ）を共変量 $\mathbf{z}_i$ に入れたコックス比例ハザードモデルで企業のデフォルト強度を推定します。
> * **賃貸経営・サブスクリプション事業（第5部 5-5節）：** イベント＝入居者の退去やサービス解約（チャーン分析）。
>
> 異なる専門領域の現象が、同じ「生存関数 $S(t)$ とハザード関数 $\mu(t)$」の言葉で統一的に解析できる点は、数理モデルの強力な利点です。

### 4. 限界と補正（Critique & Adaptation）

ノンパラメトリック・セミパラメトリックな生存解析は「特定の分布形を決め打ちしなくてよい」という柔軟さを持つ反面、次の3つの前提やパラメータ選択に固有の限界があります。

#### (1) 「非情報的打ち切り」の仮定が破れる場合のバイアス

カプラン＝マイヤー推定量やコックスモデルは、**「打ち切りになるかどうかは、その人の将来のイベント発生リスク（死亡リスクなど）と独立である（非情報的打ち切り：Non-informative Censoring）」**という重要な前提を置いています。

たとえば、生命保険の継続調査で「健康状態が悪化して死亡リスクが高まった契約者ほど、生前に解約して現金化してしまう（あるいは逆に、健康な人ほど他社の安い保険へ乗り換えて解約する）」という状況では、打ち切りと死亡リスクが強く相関してしまいます（**情報的打ち切り**）。この状態で単純にカプラン＝マイヤー推定を行うと、残ったリスク集合の性質が偏り、生存率が大きく歪みます。

* **補正の方向：** 打ち切り理由を「調査期間終了による事務的打ち切り」と「途中解約・脱落」に分けて点検するほか、解約と死亡を別々のイベントとして同時に扱う**競合リスクモデル（次節 7-4節の多重状態モデル）**や、**逆確率重み付け（IPCW：打ち切り確率の逆数で各観測に重みを付けて偏りを補正する手法）**による補正が行われます。

#### (2) 比例ハザード性の破綻と対処

コックス比例ハザードモデルでは、2群のハザード比 $\exp(\mathbf{\beta}^T(\mathbf{z}_A - \mathbf{z}_B))$ が時間 $t$ を通じて一定であると仮定します。しかし現実には、「手術直後はリスクが高いが、1年を過ぎると逆に低くなる」あるいは「契約直後の効果は数年で薄れる（7-2節の選択表）」のように、時間の経過とともにハザード比が変わる（生存曲線が途中で交差する）現象がよく起きます。

* **検証と補正：** ログ・マイナス・ログプロット（$\ln(-\ln \hat{S}(t))$ の平行性確認）や**シェーンフェルト残差**（イベント時点ごとに共変量の実測値とモデル期待値の差を調べ、比例ハザード仮定が時間で崩れていないか点検する残差）の検定で比例ハザード性を確認します。仮定が崩れている場合は、①比例性が成り立たない変数を共変量から外し、そのグループごとに別のベースライン・ハザード $\mu_{0g}(t)$ を許す**層別コックスモデル**、または ②係数自体が時間に依存する**時間依存共変量モデル**へ拡張して補正します。

#### (3) カーネル密度推定におけるバンド幅 $h$ のバイアス・バリアンス・トレードオフ

カーネル密度推定量 $\hat{f}_h(x)$ の精度は、カーネル関数 $K$ の形よりも**バンド幅 $h$ の選び方**に大きく左右されます（図7-3-1右）。

* **$h$ が小さすぎる場合：** 各データ点の位置に鋭い針のような山が立ち、手元データのノイズを拾いすぎて推定のぶれ（**バリアンス**）が過大になります（過学習）。
* **$h$ が大きすぎる場合：** すべての点が広くぼかされ、分布に本来ある2つの山（二峰性）や尖りが潰れて系統的な偏り（**バイアス**）が過大になります。

これは第0部（0-8節）で導出した**バイアス・バリアンス・トレードオフ**そのものです。実務では、理論的に積分平均二乗誤差（MISE）を最小化する目安（正規分布基準の**シルバーマンの経験則** $h \approx 1.06\,\hat{\sigma}\,n^{-1/5}$）を出発点にします。そのうえで、データを分割して予測対数尤度などを最大化する**交差検証（クロスバリデーション）**によって最適なバンド幅 $h$ を選定します。

### 5. 接続と展望（Bridge）：本節の内容が後半のどの部に繋がるか

1. **次節（7-4節：マルコフ過程と多重状態モデル［健康・要介護・死亡］）：**

    本節では「生存 $\to$ 死亡」の単一イベントを扱いました。次節では、状態が「健康 $\leftrightarrow$ 要介護 $\to$ 死亡」のように複数に分かれ、回復や競合リスクを含む遷移を記述する**マルコフ過程**へ進みます。

2. **第8部（8-2・8-6節：損害保険のクレーム分布と支払備金）：**

    本節のカーネル密度推定や打ち切りデータの扱いは、損害保険における経験損失分布の推定（免責額による左切断・支払限度額による右打ち切りを含むデータ）へそのまま応用されます。

    本節のハザード推定とコックス比例ハザードモデルは、企業の財務データからデフォルト強度 $\lambda_t$ を推定する信用リスク分析の標準的な統計手法として使われます。

>     * $t = 3$：$1$ 人死亡
>     * $t = 4$：$1$ 人打ち切り
>     * $t = 5$：$1$ 人死亡（残り $3$ 人は調査終了で打ち切り）
>
>     各死亡時点 $t = 1,\; 3,\; 5$ におけるリスク集合の人数 $r_j$ を確認し、$t = 5$ 時点の**カプラン＝マイヤー推定量 $\hat{S}_{\mathrm{KM}}(5)$** と**ネルソン＝アーレン推定量 $\hat{H}_{\mathrm{NA}}(5)$** をそれぞれ求めてください（分数および小数第4位まで）。

> 2. **（コックス比例ハザードモデルとカーネル密度推定）**

>     * (b) カーネル密度推定量 $\hat{f}_h(x)$ において、バンド幅 $h$ を極端に小さくした場合と極端に大きくした場合とで、バイアスとバリアンスはどう変化しますか。
>
> 3. **（次節への伏線：「生存・死亡」の2状態から「健康・要介護・死亡」の多重状態へ）**
>
>     7-2節・7-3節では、「生存」から「死亡」へ一方通行で移る2状態モデルを扱いました。しかし現実の医療保険・介護保険・就業不能保険では、「健康 $\to$ 病気・要介護 $\to$ 回復して再び健康に戻る」あるいは「要介護状態から死亡する」といった複数の状態間を行き来します。このように状態が3つ以上あり、時間の経過とともに確率的に状態が切り替わる現象を記述するには、どのような確率過程の枠組みが必要になるでしょうか。
