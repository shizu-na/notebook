## 0-1. お金の時間価値・FP「6つの係数」・住宅ローンの数理

### 1. 動機（Why）：なぜ「今日の100万円」と「10年後の100万円」をそのまま足し引きできないのか

会計や家計の計算では、異なる時点に発生する金額を単純に足し合わせることがあります。たとえば「3,000万円を借りて35年間で総額3,675万円を返したから、差額の675万円がコストである」といった計算です。しかし、ファイナンスやアクチュアリーの数理では、**異なる時点のキャッシュフロー（現金の流出入）をそのまま比較・加算することは原則として行いません**。

理由は主に2つあります。

**理由①：資金には運用機会（機会費用）とリスクが伴うから**
今日手元にある100万円は、国債や預金などで安全に運用すれば、年利 $r > 0$ で1年後には $100(1+r)$ 万円になります。逆に言えば、1年後に受け取る100万円は、今日の価値に換算すると $100/(1+r)$ 万円にとどまります。さらに、将来の受け取りには「物価上昇（インフレ）による購買力の低下」や「相手が支払えなくなる信用リスク」も伴います。このように、時点の違いによって金額の価値が変わる性質を**お金の時間価値（Time Value of Money）**と呼びます。

**理由②：FP・住宅ローン・債券・保険の計算はすべて同じ1つの数式に帰着するから**
ファイナンシャル・プランニング（FP）の学習では、資金計画のための「6つの係数」を個別の表として扱うのが一般的です。また、住宅ローンの返済額計算、不動産投資の採算評価（NPV・IRR）、第7部の生命保険・年金の現価計算、第9部の債券価格評価も、一見すると別々の公式に見えます。しかし、これらはいずれも**「キャッシュフローを共通の基準時点へ割り引いて合計する（等比数列の和）」**という単一の原理の変形です。本節では、その共通基盤を導出します。

### 2. 具体例と計算イメージ（Toy Model）

厳密な定義に入る前に、時間価値の計算が日常の意思決定にどう現れるかを、2つの具体例で確認します。

#### 実験A：住宅ローンの2つの返済方式（元利均等 vs 元金均等）

借入元本 $L = 3{,}000$ 万円、年利 $1.2\%$（月利 $i = 0.012 / 12 = 0.001 = 0.1\%$）、返済期間35年（$n = 420$ 回払い）という条件で、代表的な2つの返済方式を比べます。

1. **元利均等返済（毎月の返済額 $M$ が一定）：**
    毎月支払う金額 $M$ は一定ですが、その内訳（利息と元金の比率）が毎月変化します。当初は借入残高が大きいため返済額の多くが利息に充てられ、後半になるほど元金返済の割合が増えます。後述の資本回収係数の公式から計算すると、以下の通りになります。

    * 毎月返済額：$M = 87{,}511$ 円（1回目〜420回目まで一定）
    * 総返済額：$36{,}754{,}488$ 円（うち利息合計 $6{,}754{,}488$ 円）

2. **元金均等返済（毎月の元金返済額 $L/n$ が一定）：**
    元金を毎回均等に $L/n = 3{,}000\text{万円} / 420 \approx 71{,}429$ 円ずつ返し、それに「その時点の残高 $\times$ 月利 $i$」の利息を上乗せします。第 $k$ 回返済直前の残高は $L \cdot \frac{n - k + 1}{n}$ となるため、総支払利息は等差数列の和として直接求まります。

    $$\sum_{k=1}^n i \cdot L \frac{n - k + 1}{n} = \frac{Li}{n} \sum_{m=1}^n m = \frac{Li}{n} \cdot \frac{n(n + 1)}{2} = \frac{1}{2} L i (n + 1)$$

    これに $L = 3{,}000$ 万円、$i = 0.001$、$n = 420$ を代入すると、以下の数値が得られます。

    * 初回返済額：$101{,}429$ 円（元金 $71{,}429$ 円 ＋ 利息 $30{,}000$ 円）
    * 最終回返済額：$71{,}500$ 円（元金 $71{,}429$ 円 ＋ 利息 $71$ 円）
    * 総返済額：$36{,}315{,}000$ 円（うち利息合計 $6{,}315{,}000$ 円）

元金均等返済の方が元本の減りが早いため、総支払利息は約44万円少なくなります。一方、当初の毎月返済額は元金均等の方が約1.4万円高くなります。この差は「元本をどれだけ早く返すか」という時間軸上のキャッシュフロー配分の違いから生じます。

#### 実験B：変動金利の「5年ルール・125%ルール」と未払利息の発生

日本の多くの銀行の変動金利型住宅ローン（元利均等返済）には、金利が急上昇しても家計が急変しないよう、次の2つのルールが組み込まれています。

* **5年ルール：** 適用金利は半年ごとに見直されるが、毎月の返済額 $M$ は5年間据え置く。
* **125%ルール：** 5年後の返済額見直し時も、新しい返済額は直前の返済額の1.25倍を上限とする。

ここで、借入残高 $3{,}000$ 万円、当初金利 $0.5\%$（35年返済）のケースを考えます。当初の毎月返済額は $M = 77{,}876$ 円です。もし借入直後に適用金利が $4.0\%$（月利 $0.04/12$）まで上昇すると、1か月あたりの発生利息は

$$30{,}000{,}000 \times \frac{0.04}{12} = 100{,}000 \text{ 円}$$

となり、据え置かれた毎月返済額 $77{,}876$ 円を **$22{,}124$ 円上回ります**。この超過分は免除されるわけではなく、**未払利息**として先送りされ、元本がまったく減らない状態が続きます。返済額を一定に抑えるルールは、金利上昇リスクを消すのではなく、将来（最終返済期日の一括精算など）へ繰り延べる仕組みです。

### 3. 定義・定理・導出（What）

#### (1) 単利・複利・連続複利と利力 $\delta$

元本 $1$ を期間 $t$（年）だけ運用したときの元利合計を表す関数を**蓄積関数** $a(t)$ とします（$a(0) = 1$）。年利率を $r > 0$ とするとき、利息の計算方式には以下の3つがあります。

1. **単利（Simple interest）：** 常に当初元本 $1$ に対してのみ利息が付く方式。

    $$a(t) = 1 + rt$$

2. **複利（Compound interest）：** 1期間ごとに生じた利息を元本に組み入れ、次の期間は利息にも利息が付く方式。年 $m$ 回複利（名目年利率 $r^{(m)}$）のとき、1回あたりの利率は $r^{(m)}/m$ なので、$t$ 年後の元利合計は

    $$a(t) = \left(1 + \frac{r^{(m)}}{m}\right)^{mt}$$

    特に年1回複利（$m=1$）のとき $a(t) = (1 + r)^t$ です。名目年利率 $r^{(m)}$ に対し、1年後の実際の増加率 $r_{\mathrm{eff}} := \left(1 + \frac{r^{(m)}}{m}\right)^m - 1$ を**実効年利率**と呼びます。

3. **連続複利（Continuous compounding）：** 複利の回数 $m \to \infty$ の極限をとった方式。ネイピア数 $e = \lim_{x \to \infty} (1 + 1/x)^x$ の定義より、

    $$\lim_{m \to \infty} \left(1 + \frac{\delta}{m}\right)^{mt} = e^{\delta t}$$

    このときの瞬間的な利率 $\delta$ をアクチュアリー数理では**利力（Force of interest）**と呼びます。年1回複利の実効年利率 $i$ と利力 $\delta$ は $1 + i = e^\delta \iff \delta = \ln(1 + i)$ で1対1に対応します。

    より一般に、瞬間金利が時間 $t$ に依存する $\delta(t)$ である場合を考えます。時点 $t$ から微小時間 $\Delta t$ のあいだの増加率は $\frac{a(t+\Delta t) - a(t)}{a(t)} \approx \delta(t)\Delta t$ となるため、両辺を $\Delta t$ で割って $\Delta t \to 0$ の極限をとると、微分方程式

    $$\frac{a'(t)}{a(t)} = \frac{d}{dt}\ln a(t) = \delta(t)$$

    が得られます。初期条件 $a(0) = 1$（すなわち $\ln a(0) = 0$）のもとで $0$ から $t$ まで積分すると、

    $$a(t) = \exp\left(\int_0^t \delta(s)\,ds\right)$$

    となります（$\delta(s) \equiv \delta$ が定数のとき $e^{\delta t}$ に一致します）。

#### (2) 割引現在価値（DCF）と現価率 $v$

実効利率 $i$ のもとで、$t$ 期後に受け取る $1$ 単位のキャッシュフローの現在（時点 $0$）における価値を**現価率（割引因子）**といい、$v := (1 + i)^{-1}$ を用いて $v^t = (1 + i)^{-t} = e^{-\delta t}$ と表します。

時点 $t = 0, 1, \dots, n$ に発生するキャッシュフロー列 $\{CF_0, CF_1, \dots, CF_n\}$ の**割引現在価値（Discounted Cash Flow, DCF）**は、それぞれの金額を時点 $0$ へ割り引いた総和として定義されます。

$$PV = \sum_{t=0}^n \frac{CF_t}{(1 + i)^t} = \sum_{t=0}^n CF_t \, v^t$$

#### (3) 確定年金・累加年金の現価と終価

毎期末に一定額 $1$ を $n$ 回受け取るキャッシュフローを**期末払確定年金**と呼びます。アクチュアリー数理では、その現在価値（時点 $0$ の価値）を $a_{\overline{n}|}$、将来価値（時点 $n$ の価値）を $s_{\overline{n}|}$ と表記します。

初項 $v$、公比 $v$、項数 $n$ の等比数列の和の公式から、

$$a_{\overline{n}|} = v + v^2 + \dots + v^n = \frac{v(1 - v^n)}{1 - v} = \frac{1 - (1 + i)^{-n}}{i}$$

が得られます（ここで $1 - v = 1 - \frac{1}{1+i} = \frac{i}{1+i} = iv$ を用いました）。同様に終価 $s_{\overline{n}|}$ は、$a_{\overline{n}|}$ を $n$ 期間だけ複利運用した値 $(1+i)^n a_{\overline{n}|}$ に一致するため、

$$s_{\overline{n}|} = (1 + i)^n a_{\overline{n}|} = \frac{(1 + i)^n - 1}{i}$$

となります。また、各期の支払額が期首払いの場合はすべて1期間だけ早く受け取るため、$(1+i)$ 倍した $\ddot{a}_{\overline{n}|} = (1+i)a_{\overline{n}|}$ となります。

さらに、1期末に $1$、2期末に $2$、……、$n$ 期末に $n$ を受け取る**累加年金**の現価 $(Ia)_{\overline{n}|} = \sum_{k=1}^n k v^k$ は、両辺に $(1+i)$ を掛けて元の式を引く（等差×等比の和の標準手法）ことで導出できます。

$$(1+i)(Ia)_{\overline{n}|} - (Ia)_{\overline{n}|} = (1 + 2v + 3v^2 + \dots + nv^{n-1}) - (v + 2v^2 + \dots + nv^n) = (1 + v + \dots + v^{n-1}) - n v^n = \ddot{a}_{\overline{n}|} - n v^n$$

よって、

$$(Ia)_{\overline{n}|} = \frac{\ddot{a}_{\overline{n}|} - n v^n}{i}$$

が得られます。なお、$n \to \infty$ とした永久年金の現価は $a_{\overline{\infty}|} = \lim_{n \to \infty} \frac{1 - (1+i)^{-n}}{i} = \frac{1}{i}$ となり、第9部の配当割引モデルや第5部の収益還元法（直接還元法）の原型になります。

#### (4) FP「6つの係数」の導出と相互関係

FP技能検定の資金計画では、利率 $i$・期間 $n$ に対して以下の「6つの係数」が登場します。これらは独立した6つの公式ではなく、上で導出した $(1+i)^n$、$s_{\overline{n}|}$、$a_{\overline{n}|}$ とその逆数（3組のペア）です。

| 係数の名称 | 用途（何を求めるか） | 数式（アクチュアリー記号） | 逆数の関係にある係数 |
| --- | --- | --- | --- |
| **終価係数** | 現在の元本 $1$ を $n$ 年複利運用した将来額 | $(1 + i)^n$ | 現価係数 |
| **現価係数** | $n$ 年後に $1$ を得るために今必要な元本 | $v^n = (1 + i)^{-n}$ | 終価係数 |
| **年金終価係数** | 毎年末 $1$ を $n$ 年積立てたときの $n$ 年後の総額 | $s_{\overline{n}|} = \dfrac{(1 + i)^n - 1}{i}$ | 減債基金係数 |
| **減債基金係数** | $n$ 年後に $1$ を作るために毎年末必要な積立額 | $\dfrac{1}{s_{\overline{n}|}} = \dfrac{i}{(1 + i)^n - 1}$ | 年金終価係数 |
| **年金現価係数** | 毎年末 $1$ を $n$ 年間受け取るために今必要な元本 | $a_{\overline{n}|} = \dfrac{1 - (1 + i)^{-n}}{i}$ | 資本回収係数 |
| **資本回収係数** | 現在の元本 $1$（借入等）を $n$ 年で均等回収・返済する毎年の額 | $\dfrac{1}{a_{\overline{n}|}} = \dfrac{i}{1 - (1 + i)^{-n}}$ | 年金現価係数 |

さらに、減債基金係数と資本回収係数の差をとると、

$$\frac{1}{a_{\overline{n}|}} - \frac{1}{s_{\overline{n}|}} = \frac{i(1+i)^n}{(1+i)^n - 1} - \frac{i}{(1+i)^n - 1} = \frac{i\bigl((1+i)^n - 1\bigr)}{(1+i)^n - 1} = i$$

という恒等式が成り立ちます。これは「借入元本 $1$ を元利均等で返す毎期の返済額（資本回収係数）」が、**「毎期の利息 $i$」と「$n$ 期後に元本 $1$ を返すための積立額（減債基金係数）」の和に等しい**ことを意味します。

#### (5) 住宅ローンの数理（返済式・繰上返済・団体信用生命保険）

1. **元利均等返済の返済額と残債：**
    借入元本 $L$、月利 $i$、返済回数 $n$ のとき、毎月の返済額 $M$ の現在価値の和が $L$ に等しいため、$M \cdot a_{\overline{n}|} = L$ より

    $$M = \frac{L}{a_{\overline{n}|}} = L \cdot \frac{i(1 + i)^n}{(1 + i)^n - 1}$$

    となります（資本回収係数そのものです）。$k$ 回目返済直後の残債 $B_k$ は「残り $n - k$ 回の返済額の現在価値」に等しいため、$B_k = M \cdot a_{\overline{n-k}|}$ と書けます。

2. **繰上返済の2方式（期間短縮型 vs 返済額軽減型）：**
    時点 $k$ で手元資金 $\Delta L$ を元本返済に充てて残債を $B_k' = B_k - \Delta L$ に減らしたとき、2つの調整方法があります。

    * **期間短縮型：** 毎月返済額 $M$ を変えず、残り返済回数 $n - k$ を短くする。
    * **返済額軽減型：** 残り返済回数 $n - k$ を変えず、毎月返済額を $M' = M \cdot (B_k' / B_k)$ に減らす（$B_k' = M' a_{\overline{n-k}|}$ と $B_k = M a_{\overline{n-k}|}$ の比より従います）。

    同じ $\Delta L$ を投入した場合、期間短縮型は毎月の返済額 $M > M'$ を維持するため、時点 $k$ 以降の各期 $t$ における残債 $B_t^{\text{短縮}}$ が返済額軽減型の残債 $B_t^{\text{軽減}}$ より常に小さく推移します。各期の発生利息は直前残債に月利を掛けた $i B_{t-1}$ なので、総支払利息 $\sum i B_{t-1}$ は**期間短縮型の方が常に小さくなります**。一方、返済額軽減型は毎月のキャッシュフロー（資金繰り）の余裕を優先する選択です。

3. **団体信用生命保険（団信）の数理的構造：**
    住宅ローン契約時に付帯される団体信用生命保険は、借入人が死亡・高度障害になったときに「その時点の残債 $B_k$」を保険金として金融機関へ支払い、ローンを完済する仕組みです。時間 $k$ とともに保障額 $B_k$ が減少していくため、数理的には第7部で扱う**残債連動型の逓減定期保険**に該当します。

#### (6) 投資判断の基準：NPV（正味現在価値）とIRR（内部収益率）

初期投資 $CF_0 < 0$ を行い、将来キャッシュフロー $CF_1, \dots, CF_n$ を得るプロジェクトを割引率（資本コスト）$r$ で評価する2つの代表指標を定義します。

* **正味現在価値（Net Present Value, NPV）：**

    $$\mathrm{NPV}(r) := \sum_{t=0}^n \frac{CF_t}{(1 + r)^t} = CF_0 + \sum_{t=1}^n \frac{CF_t}{(1 + r)^t}$$

    $\mathrm{NPV}(r) > 0$ であれば、資金調達コスト $r$ を上回る価値を生むため投資は合理的と判断します。

* **内部収益率（Internal Rate of Return, IRR）：**
    プロジェクトの正味現在価値をちょうど $0$ にする割引率 $r^*$、すなわち方程式

    $$\mathrm{NPV}(r^*) = \sum_{t=0}^n \frac{CF_t}{(1 + r^*)^t} = 0$$

    の解として定義されます。$r^*$ が要求収益率（資本コスト）$r$ を上回っていれば採算が合うと評価します。

> **【コラム：「72の法則」のテイラー展開による導出と誤差評価】**
>
> 複利運用で元本がちょうど2倍になる年数 $n$ を暗算する経験則として、**「$n \approx 72 / (\text{年利}\%)$（72の法則）」**が知られています。この根拠は対数関数のテイラー展開から直接導けます。
>
> 方程式 $(1 + r)^n = 2$ の両辺の自然対数をとると、
>
> $$n = \frac{\ln 2}{\ln(1 + r)}$$
>
> ここで $\ln(1 + r) = r - \frac{r^2}{2} + \frac{r^3}{3} - \dots$ を用いると、$r$ が十分小さいとき
>
> $$n = \frac{\ln 2}{r\left(1 - \frac{r}{2} + O(r^2)\right)} \approx \frac{\ln 2}{r}\left(1 + \frac{r}{2}\right) = \frac{0.6931}{r} + 0.3466$$
>
> となります。連続複利（$e^{rt} = 2$）なら厳密解は $t = \frac{\ln 2}{r} \approx \frac{69.3}{100r}$ です。しかし年1回複利では、上の展開式の第2項（$+0.35$ 年の正の補正）により、$r$ が大きくなるほど $69.3/R$（$R = 100r$）は過小評価になります。たとえば $R = 8\%$ のとき $69.3/8 + 0.35 = 9.01$ 年ですが、分子を $69.3$ から $72$ へ引き上げると $72/8 = 9.00$ 年となり、年利 $5\% \sim 10\%$ 付近で高い近似精度が得られます。さらに $72$ は約数（$2, 3, 4, 6, 8, 9, 12$）が多く暗算に適しているため、実務で定着しました。
>
> | 年利 $r$ | 厳密解 $\ln 2 / \ln(1+r)$ | 72の法則（$72 / 100r$） | 69.3の法則（$69.31 / 100r$） |
> | :---: | :---: | :---: | :---: |
> | $1.0\%$ | $69.66$ 年 | $72.00$ 年 | $69.31$ 年 |
> | $2.0\%$ | $35.00$ 年 | $36.00$ 年 | $34.66$ 年 |
> | $5.0\%$ | $14.21$ 年 | $14.40$ 年 | $13.86$ 年 |
> | $8.0\%$ | $9.01$ 年 | $9.00$ 年 | $8.66$ 年 |
> | $10.0\%$ | $7.27$ 年 | $7.20$ 年 | $6.93$ 年 |
> | $20.0\%$ | $3.80$ 年 | $3.60$ 年 | $3.47$ 年 |
>
> 低金利環境（$1\% \sim 2\%$）では、72の法則よりも「69.3（または70）の法則」の方が厳密解に近いこともこの表から確認できます。

### 4. 限界と補正（Critique & Adaptation）

時間価値とDCF・IRRの枠組みは簡潔ですが、実務にそのまま適用すると以下の2つの構造的な限界に直面します。

#### (1) IRRの複数解・解なしの問題と、NPV・MIRRによる補正

IRRの方程式 $\sum_{t=0}^n CF_t \, x^t = 0$（$x = (1+r^*)^{-1} > 0$）は $n$ 次代数方程式です。ここで実係数多項式に関する**デカルトの符号法則**（多項式の非ゼロ係数を次数順に並べたときの符号変化の回数を $s$ とすると、正の実数根の個数は $s$ 以下であり、$s$ との差は非負の偶数になるという定理。証明は代数学の一般結果として前提にします）を適用すると、正の実数解の個数はキャッシュフロー列 $\{CF_t\}$ の符号が反転する回数以下になります。通常の投資（最初だけマイナス、以後はすべてプラス）なら符号反転は1回なので、正の解は高々1つ（実際には $1 + r^* > 0$ でただ1つ）に定まります。

しかし、不動産の解体費用や鉱山の原状回復費用、大規模修繕などによって**プロジェクトの終盤に再びマイナスのキャッシュフローが発生する（符号反転が2回以上）**場合、IRRは複数存在したり、逆に実数解が存在しなかったりします。

たとえば、$CF_0 = -100,\; CF_1 = +230,\; CF_2 = -132$ というキャッシュフローを考えます。$y = 1 + r^*$ とおくと方程式は

$$-100 + \frac{230}{y} - \frac{132}{y^2} = 0 \iff 100y^2 - 230y + 132 = 0 \iff (10y - 11)(10y - 12) = 0$$

となり、**$r^* = 10\%$ と $r^* = 20\%$ の2つのIRR**が得られます。しかもこのプロジェクトの $\mathrm{NPV}(r)$ は $10\% < r < 20\%$ の範囲でのみ正であり、割引率が $5\%$ のときは逆に $\mathrm{NPV} < 0$ になります（「IRRが資本コストより高ければ投資すべき」という基準が成り立ちません）。

さらに、IRR法には「途中で得たキャッシュフローを再び同じIRRの利回りで再投資できる」という暗黙の仮定が含まれ、規模の異なる排他的プロジェクト（例：100万円投資してIRR 50% と 1億円投資してIRR 20%）の比較も誤ります。そのため、実務・理論では以下の対応を行います。

* **NPV法を最終基準とする：** NPVは加法性（プロジェクトAとBを合わせた価値は $\mathrm{NPV}_A + \mathrm{NPV}_B$）を満たし、金額ベースの富の増加を直接測れるため、IRRと結論が衝突した場合はNPVを優先します。
* **修正内部収益率（MIRR）：** 途中のプラスCFは資本コスト（再投資率）で終点まで複利運用し、マイナスCFは調達金利で時点 $0$ へ割り引いてから1つの利回りを求めることで、複数解と再投資仮定の問題を回避します。

#### (2) 「単一の一定割引率 $r$」という仮定の限界

本節の公式はすべて「1年後も35年後も同じ割引率 $r$ で割り引く」と仮定しています。しかし現実の金融市場では、短期金利と長期金利は異なり、満期ごとに割引率が変化します（金利の期間構造・イールドカーブ）。また、将来のキャッシュフロー自体が確実ではなく確率的に変動する場合、リスクの大きさに応じた調整（リスク・プレミアムやリスク中立評価）が必要になります。これらの拡張は、第7部（確率的な生存率の導入）および第9部（スポットレート・イールドカーブ・CAPM・無裁定評価）で段階的に扱います。

### 5. 接続と展望（Bridge）：本節の道具がこれからの各部にどう繋がるか

1. **第2部（2-3節：新リース会計基準）：** 2027年4月施行予定の新リース会計基準（企業会計基準第34号）では、将来のリース料の支払総額を現在価値（DCF）に割り引いて「リース負債」と「使用権資産」を貸借対照表に計上します。
2. **第5部（5-6節：不動産投資の数理）：** 不動産の収益還元法（DCF法・直接還元法）や、元金返済額が減価償却費を上回る「デッドクロス」の分析は、本節の元利均等返済とNPV/IRRの直接の応用です。
3. **第7部（7-3・7-5節：生命保険と年金の数理）：** 本節の確定年金現価 $a_{\overline{n}|}$ に「各時点で生存している確率 ${}_t p_x$」を掛け合わせることで、生命年金や生命保険の純保険料・責任準備金（Thieleの微分方程式）が構成されます。
4. **第9部（9-1・9-2節：債券と株式の評価）：** 債券の価格式はDCFそのものであり、金利 $i$ に対する感応度（デュレーション）は $PV(i)$ の対数微分から導かれます。また、株式の配当割引モデル（ゴードン・モデル）は永久年金 $a_{\overline{\infty}|} = 1/i$ の拡張です。
