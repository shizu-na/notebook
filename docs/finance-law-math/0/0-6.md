### 前節（0-5）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（数理最適化とモンテカルロ・シミュレーション）の導入になります。

1. **単回帰分析（市場リターンと個別株リターンのベータ推定）：**
    標本平均は $\bar{x} = \frac{-2 + 0 + 2 + 4}{4} = 1$、$\bar{y} = \frac{-3 + 1 + 2 + 8}{4} = 2$ です。平均からの偏差は $x_i - \bar{x} = (-3, -1, 1, 3)$、$y_i - \bar{y} = (-5, -1, 0, 6)$ となるため、

    * $S_{xx} = (-3)^2 + (-1)^2 + 1^2 + 3^2 = 20$
    * $S_{xy} = (-3)(-5) + (-1)(-1) + (1)(0) + (3)(6) = 15 + 1 + 0 + 18 = 34$
    * $S_{yy} = (-5)^2 + (-1)^2 + 0^2 + 6^2 = 62$

    したがって、最小二乗推定量と決定係数（前節で示した単回帰の関係式 $R^2 = r_{xy}^2 = \frac{S_{xy}^2}{S_{xx}S_{yy}}$）は以下の通りになります。

    $$\hat{\beta}_1 = \frac{S_{xy}}{S_{xx}} = \frac{34}{20} = \mathbf{1.70}, \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x} = 2 - 1.70 \times 1 = \mathbf{0.30}$$

    $$R^2 = \frac{S_{xy}^2}{S_{xx} S_{yy}} = \frac{34^2}{20 \times 62} = \frac{1156}{1240} \approx \mathbf{0.9323}$$

2. **主成分分析（2変数の共分散行列と寄与率）：**
    $\Sigma = \begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}$ の固有多項式は $(5 - \lambda)(2 - \lambda) - 4 = \lambda^2 - 7\lambda + 6 = (\lambda - 6)(\lambda - 1) = 0$ なので、固有値は **$\lambda_1 = 6,\; \lambda_2 = 1$** です。

    * **第1主成分の寄与率：** $\frac{\lambda_1}{\lambda_1 + \lambda_2} = \frac{6}{7} \approx \mathbf{85.7\%}$。
    * **第1主成分の単位固有ベクトル $\mathbf{v}_1$：** $(\Sigma - 6I)\mathbf{v} = \begin{pmatrix} -1 & 2 \\ 2 & -4 \end{pmatrix}\begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = \mathbf{0}$ より $v_1 = 2v_2$。長さを $1$ に正規化すると $\mathbf{v}_1 = \mathbf{\frac{1}{\sqrt{5}}\begin{pmatrix} 2 \\ 1 \end{pmatrix}}$（符号反転も可）となります。

3. **不等式制約のある最適化と解析解がない積分（本節への接続）：**
    「空売り禁止（$w_i \ge 0$）」のような不等式制約がある最適化問題では、単純に微分を $0$ とおくだけでは解けず、**線形計画法**や**非線形最適化（ラグランジュ乗数法・KKT条件）**の枠組みが必要になります。また、複雑なデリバティブ価格や保険収支のように期待値の積分が解析的に求まらない場合は、乱数を用いて大量のシナリオを発生させ標本平均で積分を近似する**モンテカルロ・シミュレーション**が用いられます。

## 0-6. 数理最適化とモンテカルロ・シミュレーション

### 1. 動機（Why）：なぜ「最適化」と「シミュレーション」が経済・金融・保険の基礎になるのか

これまでの節で、時間価値・確率分布・推定・回帰の道具が揃いました。しかし、現実の経済・金融・保険の意思決定では、単に現象を記述するだけでなく、「限られた資源のもとで望ましい行動を選ぶこと」と「複雑すぎて手計算できない確率的結果を数値的に見積もること」が求められます。

第0部の締めくくりとして、この2つの数理手法を整備する理由は次の2点です。

**理由①：経済学・ポートフォリオ理論・リスク管理の多くは「制約付き最適化問題」として定式化されるから**
第1部の消費者の効用最大化（予算制約のもとでの消費選択）や企業の費用最小化、第9部の現代ポートフォリオ理論（目標リターンと資金制約のもとでの分散最小化）は、いずれも「制約条件のもとで目的関数を最大・最小化する」という共通の数学構造を持っています。幾何学的なイメージ（等高線と制約面の接点）を掴んでおけば、分野が変わっても同じ手順で解を導けます。

**理由②：解析解が閉じない実務問題では、乱数による数値評価（モンテカルロ法）とリサンプリングが不可欠だから**
第8部の複合ポアソン分布やコピュラを用いたリスク統合、第9部の経路依存型オプションの評価やアセット・アロケーションのシナリオ分析では、期待値の多重積分を初等関数で書き下すことができません。大数の法則を数値計算へ転用するモンテカルロ法と、未知の標本分布をデータ自身から近似するブートストラップ法を押さえておくことで、理論と実務の計算手法が結びつきます。

### 2. 具体例と計算イメージ（Toy Model）

厳密な定義に入る前に、2次形式の制約付き最小化（ポートフォリオ）と、逆関数法による乱数生成の具体的な動きを確認します。

#### 実験A：2資産の最小分散ポートフォリオ（2次形式の制約付き最小化）

資産1（標準偏差 $20\%$、分散 $0.04$）と資産2（標準偏差 $30\%$、分散 $0.09$）の共分散が $0.01$ であるとき、共分散行列は

$$\Sigma = \begin{pmatrix} 0.04 & 0.01 \\ 0.01 & 0.09 \end{pmatrix}$$

となります。資金を全額投資する制約 $w_1 + w_2 = 1$ のもとで、ポートフォリオの分散 $f(w_1, w_2) = \mathbf{w}^T \Sigma \mathbf{w} = 0.04 w_1^2 + 0.02 w_1 w_2 + 0.09 w_2^2$ を最小化する配分 $(w_1, w_2)$ を探します。

幾何学的には、目的関数 $\mathbf{w}^T \Sigma \mathbf{w} = c$ は原点を中心とする同心楕円（等高線）を描きます。制約条件 $w_1 + w_2 = 1$ は傾き $-1$ の直線です。**「楕円を内側から少しずつ膨らませていき、制約直線 $w_1 + w_2 = 1$ に初めて接する点」**が最小分散ポートフォリオです。

接点では、楕円の法線ベクトル（0-5節で導出した2次形式の勾配 $\nabla f = 2\Sigma \mathbf{w}$）と制約直線の法線ベクトル $\mathbf{1} = (1, 1)^T$ が平行になります（$\Sigma \mathbf{w} \propto \mathbf{1}$）。これを解くと、

$$0.04 w_1 + 0.01 w_2 = 0.01 w_1 + 0.09 w_2 \implies 0.03 w_1 = 0.08 w_2 \implies w_1 = \frac{8}{11} \approx 72.7\%,\quad w_2 = \frac{3}{11} \approx 27.3\%$$

となり、最小分散は $0.0318$（標準偏差 $17.84\%$、資産1単独の $20\%$ よりも低い）が得られます。

#### 実験B：一様乱数から任意の分布を作る（逆関数法の視覚化）

コンピュータが基本機能として生成できるのは、区間 $[0, 1]$ の一様乱数 $U \sim U(0, 1)$ です。ここから指数分布や正規分布などの乱数を作る基本的な方法が**逆関数法**です。

たとえば平均待ち時間 $1/\lambda$ の指数分布 $\mathrm{Exp}(\lambda)$ の累積分布関数は $F(x) = 1 - e^{-\lambda x}$ です。縦軸（確率 $0 \sim 1$）上に一様乱数 $u$ を落とし、曲線 $y = F(x)$ にぶつかった位置から横軸へ下ろした値 $x = F^{-1}(u) = -\frac{1}{\lambda}\ln(1 - u)$ をとります。曲線の傾き（確率密度 $f(x)$）が急な場所ほど多くの点が密に落ち、緩やかな裾の部分ほど疎に落ちるため、生成された $X$ は元の分布 $F$ に従います。

### 3. 定義・定理・導出（What）

#### (1) 線形計画法（Linear Programming）の幾何学

目的関数も制約条件もすべて1次式（線形）で表される最適化問題を**線形計画問題**といいます。標準形は次の通りです。

$$\min_{\mathbf{x} \in \mathbb{R}^n} \mathbf{c}^T \mathbf{x} \qquad \text{subject to} \quad A\mathbf{x} \le \mathbf{b},\quad \mathbf{x} \ge \mathbf{0}$$

各1次不等式は $\mathbb{R}^n$ を2つに分ける半空間を定めるため、制約条件をすべて満たす実行可能領域 $P = \{ \mathbf{x} \mid A\mathbf{x} \le \mathbf{b},\; \mathbf{x} \ge \mathbf{0} \}$ は**凸多面体**になります。目的関数 $\mathbf{c}^T \mathbf{x} = k$ は法線ベクトル $\mathbf{c}$ を持つ平行な超平面の族であるため、この超平面を動かしたとき、**最適解が存在するならば必ず凸多面体 $P$ の頂点（端点）の1つに現れます**（線形計画法の基本定理）。

この性質を利用し、頂点から目的関数値が改善する隣接頂点へと辺に沿って移動し続けるアルゴリズムが**単体法（シンプレックス法）**です。

#### (2) 制約付き非線形最適化：ラグランジュの未定乗数法とKKT条件

目的関数 $f(\mathbf{x})$ が非線形（たとえば2次形式）である場合、最適解は頂点とは限らず領域の内部や滑らかな境界上に現れます。

> **【定理1：ラグランジュの未定乗数法（等式制約）】**
> 滑らかな関数 $f: \mathbb{R}^n \to \mathbb{R}$ を、$m$ 個の等式制約 $g_1(\mathbf{x}) = 0, \dots, g_m(\mathbf{x}) = 0$ のもとで最小化（または最大化）する。点 $\mathbf{x}^*$ が極値を与え、かつ制約の勾配ベクトル $\nabla g_1(\mathbf{x}^*), \dots, \nabla g_m(\mathbf{x}^*)$ が線形独立であるとき、ある実数 $\lambda_1, \dots, \lambda_m$（**ラグランジュ乗数**）が存在して、ラグランジュ関数
>
> $$\mathcal{L}(\mathbf{x}, \mathbf{\lambda}) := f(\mathbf{x}) - \sum_{j=1}^m \lambda_j g_j(\mathbf{x})$$
>
> のすべての変数に関する偏微分が $0$ になる（$\nabla_{\mathbf{x}} \mathcal{L} = \mathbf{0},\; \nabla_{\mathbf{\lambda}} \mathcal{L} = \mathbf{0}$）。すなわち、
>
> $$\nabla f(\mathbf{x}^*) = \sum_{j=1}^m \lambda_j \nabla g_j(\mathbf{x}^*), \qquad g_j(\mathbf{x}^*) = 0 \quad (j = 1, \dots, m)$$

**【幾何学的直感と経済学的意味（包絡線定理）】**
制約曲面 $g(\mathbf{x}) = 0$ 上の任意の接線方向 $\mathbf{d}$ に対して、$\nabla g(\mathbf{x}^*) \perp \mathbf{d}$ です。もし $\nabla f(\mathbf{x}^*)$ が接線方向に成分を持っていれば、制約曲面に沿って少し動くだけで $f$ の値をさらに改善できてしまうため、極値では $\nabla f(\mathbf{x}^*)$ も接線方向に直交しなければなりません（$\nabla f = \lambda \nabla g$）。

また、制約の右辺を $g(\mathbf{x}) = c$ として最適解 $\mathbf{x}^*(c)$ が $c$ に関して滑らかに動くとき、最適値 $f^*(c) := f(\mathbf{x}^*(c))$ の変化率を計算してみます。制約恒等式 $g(\mathbf{x}^*(c)) = c$ の両辺を $c$ で微分すると連鎖律より $\nabla g(\mathbf{x}^*(c)) \cdot \frac{d\mathbf{x}^*}{dc} = 1$ です。これと停留条件 $\nabla f(\mathbf{x}^*) = \lambda \nabla g(\mathbf{x}^*)$ を用いると、

$$\frac{df^*}{dc} = \nabla f(\mathbf{x}^*(c)) \cdot \frac{d\mathbf{x}^*}{dc} = \lambda\, \nabla g(\mathbf{x}^*(c)) \cdot \frac{d\mathbf{x}^*}{dc} = \lambda$$

が成り立ちます（**包絡線定理**）。したがって、経済学やファイナンスでは、ラグランジュ乗数 $\lambda$ は**「制約を1単位緩めたときに得られる限界的な価値（シャドウ・プライス／潜在価格）」**という明確な意味を持ちます。

**【2次形式の最小化（ポートフォリオ理論の原型）】**
正定値対称行列 $\Sigma$（共分散行列）に対し、制約 $\mathbf{1}^T \mathbf{w} = 1$ のもとで $\frac{1}{2}\mathbf{w}^T \Sigma \mathbf{w}$ を最小化します。ラグランジュ関数 $\mathcal{L}(\mathbf{w}, \lambda) = \frac{1}{2}\mathbf{w}^T \Sigma \mathbf{w} - \lambda(\mathbf{1}^T \mathbf{w} - 1)$ を $\mathbf{w}$ で微分すると、0-5節で導出した2次形式の勾配 $\nabla_{\mathbf{w}}(\mathbf{w}^T \Sigma \mathbf{w}) = 2\Sigma \mathbf{w}$ より、

$$\nabla_{\mathbf{w}}\mathcal{L} = \Sigma \mathbf{w} - \lambda \mathbf{1} = \mathbf{0} \implies \mathbf{w} = \lambda \Sigma^{-1}\mathbf{1}$$

制約 $\mathbf{1}^T \mathbf{w} = 1$ より $\lambda (\mathbf{1}^T \Sigma^{-1}\mathbf{1}) = 1$ なので、最小分散ウェイトの一般解が得られます。

$$\mathbf{w}^* = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^T \Sigma^{-1}\mathbf{1}}$$

**【不等式制約への拡張（KKT条件）】**
「空売り禁止（$w_i \ge 0$、すなわち $-w_i \le 0$）」のように不等式制約 $h_k(\mathbf{x}) \le 0$（$k = 1, \dots, r$）のもとで $f(\mathbf{x})$ を最小化する場合、ラグランジュ関数 $\mathcal{L}(\mathbf{x}, \mathbf{\mu}) = f(\mathbf{x}) + \sum_{k=1}^r \mu_k h_k(\mathbf{x})$ に対する必要条件が**KKT（カルーシュ・クーン・タッカー）条件**です（適切な制約想定のもとで成立します）。

1. **停留条件：** $\nabla f(\mathbf{x}^*) + \sum_{k=1}^r \mu_k \nabla h_k(\mathbf{x}^*) = \mathbf{0}$
2. **主実行可能性：** $h_k(\mathbf{x}^*) \le 0 \quad (\forall k)$
3. **双対実行可能性（非負制約）：** $\mu_k \ge 0 \quad (\forall k)$
4. **相補性条件：** $\mu_k h_k(\mathbf{x}^*) = 0 \quad (\forall k)$

相補性条件は、各制約について「境界に張り付いて効いている（$h_k(\mathbf{x}^*) = 0$ で $\mu_k \ge 0$）」か「境界の内側に余裕があり効いていない（$h_k(\mathbf{x}^*) < 0$ で $\mu_k = 0$）」のいずれかであることを表します。また、なぜ乗数に非負制約 $\mu_k \ge 0$ が付くのかは停留条件を $-\nabla f(\mathbf{x}^*) = \sum_{k=1}^r \mu_k \nabla h_k(\mathbf{x}^*)$ と書き換えると見通せます。最小化問題で目的関数を減らす方向 $-\nabla f$ が実行可能領域の「外側」（$h_k$ が増える方向 $\nabla h_k$）を向いているからこそ境界で停止して最適になるため、係数は非負（$\mu_k \ge 0$）でなければなりません（もし $\mu_k < 0$ なら領域の内側へ進むことで $f$ をさらに減らせてしまいます）。目的関数 $f$ と制約関数 $h_k$ がともに凸関数であれば、KKT条件は大域的最小解の必要十分条件になります。

#### (3) 逆関数法とモンテカルロ・シミュレーション

確率変数 $X$ の期待値 $\theta = E[g(X)] = \int g(x) f(x)\,dx$ を解析的に計算できないとき、$f$ に従う独立な乱数 $X_1, X_2, \dots, X_N$ を生成し、標本平均

$$\hat{\theta}_N := \frac{1}{N} \sum_{i=1}^N g(X_i)$$

によって $\theta$ を近似する手法を**モンテカルロ法**と呼びます。

1. **逆関数法（Inverse Transform Sampling）：**
    累積分布関数 $F$ が連続かつ狭義単調増加であるとき、一様乱数 $U \sim U(0, 1)$ に対して $X := F^{-1}(U)$ とおくと、任意の $x \in \mathbb{R}$ で

    $$P(X \le x) = P\bigl(F^{-1}(U) \le x\bigr) = P\bigl(U \le F(x)\bigr) = F(x)$$

    が成り立つため、$X$ は厳密に分布 $F$ に従います（離散分布や不連続点がある場合は、一般化逆関数 $F^{-1}(u) := \inf\{x \mid F(x) \ge u\}$ を用います）。なお、正規分布のように $F^{-1}$ が初等関数で書けない場合は、2つの独立な一様乱数から極座標変換で標準正規乱数を生成する**ボックス＝ミュラー法**などが用いられます。

2. **収束速度と必要試行回数：**
    $\sigma_g^2 := V[g(X)] < \infty$ とすると、大数の法則より $\hat{\theta}_N \to \theta$ が保証され、中心極限定理より推定誤差の標準誤差は

    $$\mathrm{SE}(\hat{\theta}_N) = \frac{\sigma_g}{\sqrt{N}} = O\!\left(\frac{1}{\sqrt{N}}\right)$$

    となります。したがって、**推定精度を1桁（10倍）良くするためには、試行回数 $N$ を100倍にする必要があります**。所与の許容誤差 $\varepsilon$ と信頼度 $95\%$（$z_{0.025} \approx 1.96$）を満たすために必要な試行回数は、$1.96 \cdot \frac{\sigma_g}{\sqrt{N}} \le \varepsilon$ より $N \ge \left(\frac{1.96\,\sigma_g}{\varepsilon}\right)^2$ と見積もることができます。

#### (4) ブートストラップ法（Bootstrap Method）

0-4節の区間推定では、標本平均の分布に正規分布や $t$ 分布を仮定しました。しかし、中央値や分位点（VaR）、相関係数などの複雑な統計量 $\hat{\theta} = T(x_1, \dots, x_n)$ の標準誤差や信頼区間を、母集団の分布を仮定せずに求めたい場面が多くあります。

**ブートストラップ法**は、手元の標本 $\{x_1, \dots, x_n\}$ そのものを「母集団の近似（経験分布）」とみなし、そこから**復元抽出（重複を許して引き直す）**でサイズ $n$ の疑似標本を $B$ 回（例：$B = 1{,}000 \sim 10{,}000$ 回）生成する手法です。各疑似標本から計算した統計量 $\hat{\theta}^{*(1)}, \dots, \hat{\theta}^{*(B)}$ のばらつき（標準偏差や $2.5\% \sim 97.5\%$ 分位点）をそのまま $\hat{\theta}$ の標準誤差・信頼区間の推定値として用います。

> **【コラム：高次元積分におけるモンテカルロ法の利点と、疑似乱数の生成原理】**
>
> **1. 高次元積分でモンテカルロ法が有利になる理由：**
> 1次元の定積分を台形公式などの数値積分で計算する場合、区間を $M$ 分割すれば誤差は $O(M^{-2})$ で速く減ります。しかし、100銘柄のバスケット・オプションや多数のリスク要因を統合する $d$ 次元積分では、各軸を $M$ 分割すると格子点の総数が $N = M^d$ 個へ急増します（**次元の呪い**）。総計算点数 $N$ で表すと格子積分の誤差は $O(N^{-2/d})$ となり、$d = 100$ では実用上計算できなくなります。
> 一方、モンテカルロ法の収束速度 $O(N^{-1/2})$ は**次元 $d$ に依存しません**。1次元では遅く見える $1/\sqrt{N}$ ですが、高次元（概ね $d \ge 5$ 以上）では決定論的な格子積分よりはるかに効率的になるため、現代の金融工学・アクチュアリー実務で広く使われています。
>
> **2. コンピュータの「乱数」の仕組み（疑似乱数）：**
> 通常のプログラムが生成する乱数は、物理的なサイコロではなく、初期値（シード）から漸化式によって決定論的に計算される**疑似乱数（PRNG）**です。古典的な線形合同法 $x_{k+1} = (a x_k + c) \bmod m$ は周期が短く高次元で格子状の偏りが出る欠点があるため、現代の科学計算では周期が $2^{19937}-1$ に達する**メルセンヌ・ツイスタ**やPCGなどの高品質な生成器が使われます。決定論的であることは弱点ではなく、「同じシードを指定すればシミュレーション結果を再現・検証できる（再現性）」という実務上の利点になります。

### 4. 限界と補正（Critique & Adaptation）

最適化とシミュレーションは有用な計算手法ですが、入力データの不確実性や計算コストの面で次の2つの限界を持ちます。

#### (1) 最適化の脆弱性（誤差最大化）：入力のわずかなズレが解を大きく変える

数理最適化は「入力パラメータ（期待リターンや共分散）が真の値と完全に一致している」という前提で、目的関数を極値まで押し詰めます。そのため、**入力にわずかな推定誤差が含まれていると、最適化アルゴリズムがその誤差を増幅する方向に極端な解を選んでしまいます**（Error Maximization）。

具体的な数値で確認します。標準偏差がともに $15\%$、相関係数 $\rho = 0.8$（共分散 $0.018$）の2資産について、リスク回避度 $\gamma = 2$ のもとで $w_1 \mu_1 + w_2 \mu_2 - \frac{\gamma}{2}\mathbf{w}^T\Sigma\mathbf{w}$ を最大化します（$w_1 + w_2 = 1$）。

* 期待リターンが $(\mu_1, \mu_2) = (6.0\%,\; 5.5\%)$ のとき：最適配分は **$w_1 = 77.8\%,\; w_2 = 22.2\%$**。
* 推定誤差で期待リターンがわずか $0.5\%$ 入れ替わり $(5.5\%,\; 6.0\%)$ になったとき：最適配分は **$w_1 = 22.2\%,\; w_2 = 77.8\%$** へと逆転します。
* 差が $1.0\%$（$6.0\%$ と $5.0\%$）になると、**$w_1 = 105.6\%,\; w_2 = -5.6\%$**（空売り）まで振れます。

0-4節で見た通り、金融市場の期待リターンは $20 \sim 30$ 年のデータを使っても標準誤差が $2\% \sim 3\%$ 以上残ります。つまり、素朴な最適化はノイズに対して過剰反応する性質を持っています。実務ではこの限界に対し、空売り禁止や上限下限の制約（$0 \le w_i \le 0.3$）、正則化、あるいは第9部（9-3節）で扱う**Black-Littermanモデル**や**リスク・パリティ**などのロバストな手法で対処します。

#### (2) モンテカルロ法の収束の遅さと「分散低減法」

モンテカルロ法の標準誤差 $\sigma_g / \sqrt{N}$ は次元に依らない反面、収束が緩やかです。特に、$1\%$ や $0.1\%$ といった稀な破産事象・テールリスクを正確に評価するには膨大な試行回数が必要になります。そこで、同じ試行回数 $N$ のまま分子の分散 $\sigma_g$ を小さくする**分散低減法（Variance Reduction Techniques）**が広く使われます。

1. **対称変量法（Antithetic Variates）：**
    標準正規乱数 $Z$ を1つ生成したら、必ずその符号反転 $-Z$ もペアで使い、平均 $\frac{1}{2}(g(Z) + g(-Z))$ をとります。$g$ が単調関数であれば $g(Z)$ と $g(-Z)$ は強い負の相関を持つため、ペア平均の分散が大きく減少します。

2. **制御変量法（Control Variates）：**
    解析解 $E[Y] = \mu_Y$ が分かっている類似の確率変数 $Y$（例：複雑なオプションに対する標準的なブラック＝ショールズ・オプション）を同じ乱数で同時にシミュレーションし、$\hat{\theta}_{\mathrm{CV}} = \bar{g} - c(\bar{Y} - \mu_Y)$ と補正します（$E[\hat{\theta}_{\mathrm{CV}}] = E[g(X)]$ なので不偏性を保ちます）。

    この推定量の分散は $c$ の2次関数

    $$V[\hat{\theta}_{\mathrm{CV}}] = \frac{1}{N}\Bigl(V[g(X)] - 2c\operatorname{Cov}\bigl(g(X), Y\bigr) + c^2 V[Y]\Bigr)$$

    となるため、$c$ で微分して $0$ とおくと、分散を最小にする最適な係数 $c^*$ とそのときの最小分散が求まります。

    $$c^* = \frac{\operatorname{Cov}\bigl(g(X), Y\bigr)}{V[Y]}, \qquad V\bigl[\hat{\theta}_{\mathrm{CV}}(c^*)\bigr] = \frac{V[g(X)]}{N}\bigl(1 - \rho^2\bigr)$$

    この最適係数 $c^*$ は **0-5節で導出した単回帰の傾き $\hat{\beta}_1$ とまったく同じ形** です。$g(X)$ と $Y$ の相関係数 $\rho$ が高いほど（たとえば $\rho = 0.9$ なら $1 - \rho^2 = 0.19$ となり）、誤差の大部分が相殺されて分散が大きく縮小します。
