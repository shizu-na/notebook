### 前節（0-3）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（積率母関数と極限定理）の導入になります。

1. **景気レジーム別の資産リターン（繰り返し期待値の法則と全分散の法則）：**

    * **無条件の期待リターン $E[X]$：**
        繰り返し期待値の法則より、条件付期待値の加重平均をとります。

        $$E[X] = E\bigl[E[X \mid Y]\bigr] = 0.6 \times 8 + 0.4 \times (-2) = 4.8 - 0.8 = \mathbf{4.0\%}$$

    * **無条件の分散 $V[X]$ と標準偏差：**
        全分散の法則 $V[X] = E[V[X \mid Y]] + V[E[X \mid Y]]$ を適用します。

        * 条件付分散の平均（群内変動）：

            $$E\bigl[V[X \mid Y]\bigr] = 0.6 \times 10^2 + 0.4 \times 20^2 = 60 + 160 = 220$$

        * 条件付期待値の分散（群間変動）：

            $$V\bigl[E[X \mid Y]\bigr] = 0.6 \times (8 - 4)^2 + 0.4 \times (-2 - 4)^2 = 0.6 \times 16 + 0.4 \times 36 = 9.6 + 14.4 = 24$$

        したがって、無条件の分散は $V[X] = 220 + 24 = \mathbf{244}$、標準偏差は $\sqrt{244} \approx \mathbf{15.62\%}$ となります。

2. **ポアソン分布と指数分布の対応：**

    * **(a) 1年間に故障が0回の確率：** $N \sim \mathrm{Po}(2)$ より、

        $$P(N = 0) = \frac{2^0 e^{-2}}{0!} = e^{-2} \approx \mathbf{0.1353 \quad (13.53\%)}$$

    * **(b) 最初の故障まで半年（$0.5$ 年）超の確率：** $T \sim \mathrm{Exp}(2)$ の生存関数 $P(T > t) = e^{-\lambda t}$ より、

        $$P(T > 0.5) = e^{-2 \times 0.5} = e^{-1} \approx \mathbf{0.3679 \quad (36.79\%)}$$

        なお、「時間 $t$ のあいだ故障が0回である事象」と「最初の故障までの待ち時間 $T$ が $t$ を超える事象」は同一であり、$P(N_t = 0) = e^{-\lambda t} = P(T > t)$ が常に成り立ちます。

3. **独立和の計算と標本平均の収束（本節への接続）：**
    独立な確率変数の和の分布（たたみ込み）を掛け算へ変換する道具が**積率母関数（Moment Generating Function）**です。また、同じ分布に従う独立な標本の平均 $\bar{X}_n$ は、サンプルサイズ $n$ を大きくすると母平均 $\mu$ に収束し（**大数の法則**）、さらにその誤差の分布は元の分布の形によらず正規分布に近づきます（**中心極限定理**）。

## 0-4. 積率母関数・極限定理と統計的推定・仮説検定

### 1. 動機（Why）：「分布が分かっている世界」から「データから分布を推測する世界」へ

前節（0-3節）では、確率分布のパラメータ（たとえば事故率 $\lambda$ や資産の期待リターン $\mu$、標準偏差 $\sigma$）が**あらかじめ分かっている**前提で確率を計算しました。しかし、保険会社や金融機関、研究者が直面する現実の課題は、たいてい逆向きです。

手元にあるのは過去の限られた観測データ $x_1, x_2, \dots, x_n$ だけであり、その背後にある真のパラメータ $\theta$ は分かりません。本節では、確率論とデータ分析を橋渡しする3つの柱を整備します。

**柱①：独立和の分布を代数計算に落とす（積率母関数・キュムラント母関数）**
保険契約 $1{,}000$ 件の損害総額や、$n$ 日間の対数リターン合計のように、実務では「独立な確率変数の和」の分布を頻繁に扱います。積率母関数を使うと、煩雑なたたみ込み積分が単純な掛け算に変わり、分布の再生性や高次モーメント（歪度・尖度）が系統的に計算できます。

**柱②：契約数やデータ数が増えたときの収束を保証する（大数の法則・中心極限定理）**
保険ビジネスが成立する数学的根拠は、「個々の契約者の事故は予測できなくても、独立な契約を多数集めれば1件あたり平均損害額のぶれが $1/\sqrt{n}$ の速度で小さくなる」という大数の法則にあります。さらに中心極限定理によって、誤差の大きさを正規分布で定量化できます。

**柱③：限られたデータから未知の母数を推測し、仮説を検証する（推定・検定）**
標本データから未知のパラメータを推定する方法（最尤推定法）、推定の不確実性を幅で示す方法（信頼区間）、そして「この運用戦略の超過リターンは偶然か否か」を判定する枠組み（仮説検定）を定式化します。

### 2. 具体例と計算イメージ（Toy Model）

厳密な定義に入る前に、大数の法則と中心極限定理が保険の収支安定にどう働くかを具体的な数値で確認します。

#### 実験A：保険契約件数 $n$ と赤字確率の推移

ある損害保険において、1契約あたりの年間損害額 $X_i$ が互いに独立に同一の分布に従い、平均 $\mu = 10$ 万円、標準偏差 $\sigma = 50$ 万円であるとします（ほとんどの契約は損害0円だが、まれに数百万円の損害が発生するため標準偏差が大きい設定です）。

保険会社が1契約あたり純保険料 $10$ 万円に $10\%$ の安全割増を上乗せし、**$11$ 万円**の保険料を徴収するとき、$n$ 件の契約を集めた場合の1件あたり平均損害額 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$ が $11$ 万円を超えて赤字になる確率 $P(\bar{X}_n > 11)$ を、中心極限定理による正規近似 $\bar{X}_n \approx N(\mu, \sigma^2/n)$ で見積もります。

| 契約件数 $n$ | 1件あたり平均損害の標準誤差 $\sigma/\sqrt{n}$ | 標準化スコア $z = (11 - 10) / (\sigma/\sqrt{n})$ | 赤字になる確率 $P(\bar{X}_n > 11)$ |
| :---: | :---: | :---: | :---: |
| $100$ 件 | $5.000$ 万円 | $0.20$ | **$42.07\%$** |
| $1{,}000$ 件 | $1.581$ 万円 | $0.63$ | **$26.35\%$** |
| $10{,}000$ 件 | $0.500$ 万円 | $2.00$ | **$2.28\%$** |
| $50{,}000$ 件 | $0.224$ 万円 | $4.47$ | **$0.0004\%$** |

個々の契約のリスク（$\sigma = 50$ 万円）は変わっていませんが、契約件数 $n$ を増やすことで1件あたり平均のばらつきが $1/\sqrt{n}$ で縮小し、$1$ 万円の安全割増で赤字確率をほぼゼロに抑え込めると分かります。これがリスク・プーリング（大数の法則）の定量的な効果です。

### 3. 定義・定理・導出（What）

#### (1) 積率母関数（MGF）とキュムラント母関数

確率変数 $X$ に対して、実数 $t$ の関数

$$M_X(t) := E\bigl[e^{tX}\bigr]$$

が $t = 0$ を含む開区間 $(-h, h)$ で有限値として存在するとき、$M_X(t)$ を $X$ の**積率母関数（Moment Generating Function）**と呼びます。また、その自然対数 $K_X(t) := \ln M_X(t)$ を**キュムラント母関数**と呼びます。

積率母関数には次の3つの基本性質があります。

1. **微分によるモーメントの生成：** $e^{tX} = \sum_{k=0}^\infty \frac{X^k}{k!} t^k$ の期待値を項別に計算すると $M_X(t) = \sum_{k=0}^\infty \frac{E[X^k]}{k!} t^k$ となるため、$t = 0$ で $k$ 回微分することで $k$ 次モーメントが得られます。

    $$E[X^k] = M_X^{(k)}(0)$$

    キュムラント母関数 $K_X(t) = \ln M_X(t)$ についても、1階微分は平均 $K_X'(0) = E[X]$、2階微分は分散 $K_X''(0) = V[X]$、3階微分は3次中心モーメント $K_X'''(0) = E[(X-\mu)^3]$（歪度の分子）に一致します。

2. **独立和の積公式（たたみ込みを掛け算へ変換）：** $X$ と $Y$ が独立なとき、指数法則より $e^{t(X+Y)} = e^{tX} e^{tY}$ なので、

    $$M_{X+Y}(t) = E\bigl[e^{tX} e^{tY}\bigr] = E\bigl[e^{tX}\bigr] E\bigl[e^{tY}\bigr] = M_X(t) M_Y(t)$$

    キュムラント母関数では単純な和 $K_{X+Y}(t) = K_X(t) + K_Y(t)$ になります。

3. **分布の一意性（前提とする定理）：** 2つの確率変数の積率母関数が $0$ の近傍で一致すれば、両者は同一の確率分布に従います（※この一意性の証明にはラプラス変換・フーリエ解析の理論を要するため、本ノートでは事実として用います）。

**【応用例：ポアソン分布と正規分布の再生性の証明】**

* $X \sim \mathrm{Po}(\lambda)$ の積率母関数は、

    $$M_X(t) = \sum_{k=0}^\infty e^{tk} \frac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda} \sum_{k=0}^\infty \frac{(\lambda e^t)^k}{k!} = \exp\bigl(\lambda(e^t - 1)\bigr)$$

    よって独立な $X_1 \sim \mathrm{Po}(\lambda_1),\; X_2 \sim \mathrm{Po}(\lambda_2)$ の和は $M_{X_1+X_2}(t) = \exp\bigl((\lambda_1 + \lambda_2)(e^t - 1)\bigr)$ となり、一意性より直ちに $X_1 + X_2 \sim \mathrm{Po}(\lambda_1 + \lambda_2)$ が導かれます。

* $X \sim N(\mu, \sigma^2)$ の積率母関数は、前節の対数正規分布の計算と同じ平方完成により $M_X(t) = \exp\left(\mu t + \frac{1}{2}\sigma^2 t^2\right)$ です。独立和をとると指数部が足し合わされるため、独立な正規確率変数の和は再び正規分布 $N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$ に従います。

#### (2) チェビシェフの不等式・大数の法則・中心極限定理

まず、分布の形を一切仮定せずに「平均から大きく外れる確率の上界」を与える不等式を証明します。

> **【定理1：チェビシェフの不等式】**
> 平均 $\mu$、有限分散 $\sigma^2$ を持つ任意の確率変数 $X$ と任意の $\varepsilon > 0$ に対して、次が成り立つ。
>
> $$P\bigl(\vert X - \mu \vert \ge \varepsilon\bigr) \le \frac{\sigma^2}{\varepsilon^2}$$

**【証明（連続型の場合）】**
分散の定義より、積分区間を $\vert x - \mu \vert \ge \varepsilon$ の領域に狭めると値は小さくなります（被積分関数が非負のため）。その領域上では $(x - \mu)^2 \ge \varepsilon^2$ なので、

$$\sigma^2 = \int_{-\infty}^\infty (x - \mu)^2 f(x)\,dx \ge \int_{\vert x - \mu \vert \ge \varepsilon} (x - \mu)^2 f(x)\,dx \ge \varepsilon^2 \int_{\vert x - \mu \vert \ge \varepsilon} f(x)\,dx = \varepsilon^2 P\bigl(\vert X - \mu \vert \ge \varepsilon\bigr)$$

両辺を $\varepsilon^2 > 0$ で割れば求める不等式が得られます。（証明終）

この不等式から、大数の弱法則が直ちに導かれます。

> **【定理2：大数の弱法則（Weak Law of Large Numbers）】**
> $X_1, X_2, \dots$ が互いに独立に同一の分布（i.i.d.）に従い、平均 $\mu$、有限分散 $\sigma^2$ を持つとする。標本平均 $\bar{X}_n := \frac{1}{n}\sum_{i=1}^n X_i$ に対して、任意の $\varepsilon > 0$ で
>
> $$\lim_{n \to \infty} P\bigl(\vert \bar{X}_n - \mu \vert \ge \varepsilon\bigr) = 0$$

**【証明】**
$E[\bar{X}_n] = \mu$、独立性より $V[\bar{X}_n] = \frac{1}{n^2}\sum_{i=1}^n V[X_i] = \frac{\sigma^2}{n}$ です。これをチェビシェフの不等式に適用すると、

$$P\bigl(\vert \bar{X}_n - \mu \vert \ge \varepsilon\bigr) \le \frac{\sigma^2}{n \varepsilon^2} \xrightarrow{\;n \to \infty\;} 0$$

となり、$\bar{X}_n$ は $\mu$ に確率収束します。（証明終）

さらに、$\bar{X}_n - \mu$ を標準偏差 $\sigma/\sqrt{n}$ で割ってスケール調整すると、元の分布の形によらず標準正規分布へ収束します。

> **【定理3：中心極限定理（Central Limit Theorem）】**
> $X_1, X_2, \dots$ が i.i.d. で平均 $\mu$、有限分散 $\sigma^2 > 0$ を持つとき、標準化された標本平均
>
> $$Z_n := \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} = \frac{\sum_{i=1}^n (X_i - \mu)}{\sigma\sqrt{n}}$$
>
> の分布は、$n \to \infty$ で標準正規分布 $N(0, 1)$ に分布収束する。

**【証明の骨格（積率母関数が存在する場合）】**
$Y_i := (X_i - \mu)/\sigma$ とおくと $E[Y_i] = 0,\; V[Y_i] = 1$ であり、$Z_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$ です。$Y_i$ のキュムラント母関数 $K_Y(s)$ を $s = 0$ の周りでテイラー展開すると、$K_Y(0) = 0,\; K_Y'(0) = 0,\; K_Y''(0) = 1$ より $K_Y(s) = \frac{1}{2}s^2 + O(s^3)$ となります。したがって、$Z_n$ のキュムラント母関数は独立和の性質より

$$K_{Z_n}(t) = n \, K_Y\!\left(\frac{t}{\sqrt{n}}\right) = n \left(\frac{t^2}{2n} + O\!\left(\frac{1}{n^{3/2}}\right)\right) = \frac{1}{2}t^2 + O\!\left(\frac{1}{\sqrt{n}}\right) \xrightarrow{\;n \to \infty\;} \frac{1}{2}t^2$$

右辺の $\frac{1}{2}t^2$ は標準正規分布 $N(0, 1)$ のキュムラント母関数に一致します。

（※証明範囲の明示：「積率母関数（一般には特性関数 $\varphi_X(t) = E[e^{itX}]$）の各点収束から確率分布の収束を結論づける」ステップには、フーリエ解析・測度論に属する**レヴィの連続性定理**を用います。本ノートではこの定理を事実として前提にします。なお、積率母関数が存在しない一般の有限分散分布でも、特性関数を用いれば同じテイラー展開で証明できます。）

#### (3) 点推定（不偏性・一致性・最尤推定法）

未知の母数 $\theta$ を持つ分布から得られた無作為標本 $X_1, \dots, X_n$ の関数 $\hat{\theta}_n = g(X_1, \dots, X_n)$ を**推定量（Estimator）**と呼びます。推定量の基本基準として次の2つがあります。

* **不偏性（Unbiasedness）：** $E[\hat{\theta}_n] = \theta$（平均的に真の値から系統的な偏りがない）。
* **一致性（Consistency）：** $n \to \infty$ のとき $\hat{\theta}_n$ が真の値 $\theta$ に確率収束すること。

標本平均 $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ は母平均 $\mu$ の不偏推定量（かつ大数の法則より一致推定量）です。一方、母分散 $\sigma^2$ の推定には $n$ ではなく **$n - 1$ で割った不偏標本分散** $s^2 := \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$ を用います。その理由を直接確認します。

**【導出：不偏標本分散で $n - 1$ で割る理由】**
各偏差を $X_i - \bar{X} = (X_i - \mu) - (\bar{X} - \mu)$ と書き直して2乗和を展開します。$\sum_{i=1}^n (X_i - \mu) = n(\bar{X} - \mu)$ を用いると、

$$\begin{aligned}
\sum_{i=1}^n (X_i - \bar{X})^2
&= \sum_{i=1}^n (X_i - \mu)^2 - 2(\bar{X} - \mu)\sum_{i=1}^n (X_i - \mu) + n(\bar{X} - \mu)^2 \\
&= \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2
\end{aligned}$$

両辺の期待値をとります。$E[(X_i - \mu)^2] = \sigma^2$、および独立性より $E[(\bar{X} - \mu)^2] = V[\bar{X}] = \sigma^2 / n$ なので、

$$E\!\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = n\sigma^2 - n \cdot \frac{\sigma^2}{n} = (n - 1)\sigma^2$$

となります。したがって、$n$ で割ると $\frac{n-1}{n}\sigma^2$ と過小評価が生じ、$n - 1$ で割った $s^2$ がちょうど $E[s^2] = \sigma^2$ を満たす不偏推定量になります（標本平均 $\bar{X}$ をデータから推定した分だけ自由度が1つ減るためです）。

未知パラメータ $\theta$ を系統的に推定する汎用的な手法が**最尤推定法（Maximum Likelihood Estimation, MLE）**です。データ $x_1, \dots, x_n$ が観測されたとき、それを「パラメータ $\theta$ の関数」とみなした同時確率（密度）関数を**尤度関数** $L(\theta) := \prod_{i=1}^n f(x_i; \theta)$ と定義し、対数尤度関数 $\ell(\theta) := \ln L(\theta) = \sum_{i=1}^n \ln f(x_i; \theta)$ を最大化する $\hat{\theta}_{\mathrm{MLE}}$ を求めます。

**【計算例：指数分布 $\mathrm{Exp}(\lambda)$ の最尤推定量】**
故障間隔データ $x_1, \dots, x_n > 0$ の対数尤度は、

$$\ell(\lambda) = \sum_{i=1}^n \ln(\lambda e^{-\lambda x_i}) = n \ln\lambda - \lambda \sum_{i=1}^n x_i$$

これを $\lambda$ で微分して $0$ とおくと、$\frac{d\ell}{d\lambda} = \frac{n}{\lambda} - \sum_{i=1}^n x_i = 0$ より $\hat{\lambda}_{\mathrm{MLE}} = \frac{n}{\sum_{i=1}^n x_i} = \frac{1}{\bar{x}}$ が得られます（2階微分は $-n/\lambda^2 < 0$ なので確実に最大値です）。平均故障間隔 $\bar{x}$ の逆数が事故率 $\lambda$ の最尤推定量になります。

#### (4) 区間推定（信頼区間）と仮説検定

点推定だけでは「推定値がどれくらい不確かか」が分かりません。母集団が正規分布 $N(\mu, \sigma^2)$ に従う無作為標本 $X_1, \dots, X_n$ を考えるとき、次の重要な事実（**正規標本の性質・コクランの定理**）が成り立ちます。

1. $Z := \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$
2. $U := \frac{(n - 1)s^2}{\sigma^2} \sim \chi^2(n - 1)$
3. **$\bar{X}$ と $s^2$ は互いに独立である。**

（※証明範囲の明示：2. と 3. は、$n$ 次元標準正規ベクトルに標本平均方向を1軸目にとる直交行列（ヘルメルト行列）を掛けても独立性と標準正規性が保たれることから証明できますが、多変量正規分布の直交変換とコクランの定理の一般論を要するため、本節では事実として前提にします。）

上の1.〜3.を前節（0-3節）の $t$ 分布の定義 $T = \frac{Z}{\sqrt{U/k}} \sim t(k)$ に当てはめると、未知の母標準偏差 $\sigma$ が分子・分母で相殺され、

$$T := \frac{Z}{\sqrt{U / (n - 1)}} = \frac{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}}{\sqrt{s^2 / \sigma^2}} = \frac{\bar{X} - \mu}{s / \sqrt{n}} \sim t(n - 1)$$

が自由度 $n - 1$ の $t$ 分布に従うことが厳密に導かれます（なお、母集団が非正規であっても $n$ が十分大きければ中心極限定理による近似として用いられます）。

* **$95\%$ 信頼区間：** $t(n-1)$ 分布の上側 $2.5\%$ 点を $t_{n-1,\, 0.025}$ とすると、$P(-t_{n-1,\, 0.025} \le T \le t_{n-1,\, 0.025}) = 0.95$ を $\mu$ について解き直すことで、

    $$\left[\bar{X} - t_{n-1,\, 0.025}\frac{s}{\sqrt{n}}, \quad \bar{X} + t_{n-1,\, 0.025}\frac{s}{\sqrt{n}}\right]$$

    が得られます。厳密な意味は「同じ抽出と区間構成を多数回繰り返したとき、そのうちの $95\%$ の区間が真の定数 $\mu$ を含む」という頻度論的な保証です。

* **仮説検定（Hypothesis Testing）：**

    1. 棄却したい基準仮説として**帰無仮説 $H_0$**（例：ファンドの真の超過リターン $\mu = 0$）、示したい主張として**対立仮説 $H_1$**（例：$\mu \neq 0$）を設定する。
    2. $H_0$ が正しいと仮定したもとで、観測されたデータ以上に極端な統計量が得られる確率を **$p$ 値（$p$-value）** として計算する。
    3. あらかじめ定めた**有意水準 $\alpha$**（通常 $0.05$ や $0.01$）より $p$ 値が小さければ $H_0$ を棄却する。

検定の誤りには2種類があります（図0-4右）。

* **第1種の過誤（偽陽性）：** 本当は $H_0$ が正しいのに誤って棄却してしまう誤り。その確率が有意水準 $\alpha$ です。
* **第2種の過誤（偽陰性）：** 本当は $H_1$ が正しいのに $H_0$ を棄却できない誤り。その確率を $\beta$ とし、$1 - \beta$ を**検出力（Power）**と呼びます。

なお、データが正規分布から大きく外れておりサンプルサイズも小さい場合は、分布の形を仮定せずデータの順位などを用いる**ノンパラメトリック検定**（ウィルコクソンの符号付順位検定やマン・ホイットニーの $U$ 検定など）が用いられます。

> **【コラム：平均値への回帰と、頻度論・ベイズ統計の立場の違い】**
>
> **1. 平均値への回帰（Regression to the mean）：**
> 観測値 $X$ は「真の実力 $\mu$ ＋ ランダムな運（誤差）$\varepsilon$」から成ります。ある年に高いリターンを出したアクティブファンドの上位10%を選び出すと、その中には「実力が高いファンド」だけでなく「たまたま運 $\varepsilon$ が大きくプラスに振れたファンド」が多く含まれます。翌年の運 $\varepsilon'$ は前年と独立に平均 $0$ へ戻るため、翌年の成績は必然的に全体の平均へ近づきます。この統計現象を知らないと、単なる偶然の反動を「ファンドマネジャーの実力が落ちた」「新しい施策が効いた」と誤解してしまいます。
>
> **2. 頻度論（Frequentist）とベイズ統計（Bayesian）の違い：**
> 本節の信頼区間・仮説検定は**頻度論**の枠組みです。頻度論では「真の母数 $\theta$ は未知だが固定された定数」とみなし、確率は「データを何度も取り直したときの長期的な相対頻度」として解釈します。そのため、「真の $\mu$ がこの信頼区間に入る確率は $95\%$」と表現するのは厳密には誤りです（定数 $\mu$ が区間に入るか入らないかは $0$ か $1$ のどちらかだからです）。
>
> 一方、0-2節のベイズの定理をパラメータ推定へ拡張した**ベイズ統計学**では、未知の母数 $\theta$ 自体を確率変数とみなし、事前分布 $p(\theta)$ をデータで更新して事後分布 $p(\theta \mid \text{data})$ を求めます。ベイズ統計学の「$95\%$ 信用区間（Credible interval）」であれば、直接「$\theta$ がこの区間に入る確率は $95\%$」と解釈できます。実務では、客観的な基準が求められる規制・学術検定では頻度論が、過去データと専門家の知見や集団情報を統合する保険料率（第8部）やポートフォリオ運用（第9部）ではベイズ的手法が使い分けられています。

### 4. 限界と補正（Critique & Adaptation）

本節の母関数・極限定理・仮説検定は統計学の標準手法ですが、実務や研究の現場では以下の3つの限界と誤用が繰り返し問題になっています。

#### (1) 積率母関数が存在しない重尾分布の限界

0-3節で見たパレート分布や対数正規分布では、任意の $t > 0$ に対して積分 $E[e^{tX}] = \int e^{tx} f(x)\,dx$ が発散するため、**積率母関数 $M_X(t)$ が $t > 0$ で存在しません**。たとえば第8部で扱う損害保険の破産確率（Lundbergの不等式）は積率母関数の存在を前提とするため、重尾分布にはそのまま適用できなくなります。数学的には、実数 $t$ を純虚数 $it$ に置き換えた**特性関数** $\varphi_X(t) := E[e^{itX}]$ を用いれば、$\vert e^{itX} \vert = 1$ よりすべての確率分布に対して常に存在が保証されます。

#### (2) 「$p < 0.05$」の誤解と、統計的有意性・実務的有意性の乖離

仮説検定の $p$ 値について、実務で多い誤解は「$p = 0.03$ だから、帰無仮説 $H_0$ が正しい確率は $3\%$ である」という解釈です。正しくは「$H_0$ が正しいと仮定したときに、今回以上に極端なデータが出る確率 $P(\text{data} \mid H_0)$ が $3\%$」であり、0-2節で見た通り $P(H_0 \mid \text{data})$ とは別物です。

また、検定統計量 $t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$ は分母に $\sqrt{n}$ を持つため、**サンプルサイズ $n$ が非常に大きければ、実務的には無意味なほど微小な差でも自動的に $p < 0.05$（統計的に有意）になります**。たとえば、ある投資手法の平均月次リターンがわずか $+0.01\%$（標準偏差 $1.0\%$）であっても、取引データが $n = 100{,}000$ 件あれば $t \approx 3.16,\; p \approx 0.0016$ と有意になります。しかし、取引手数料 $0.05\%$ を差し引けば赤字です。

そのため現代の統計実務では、$p$ 値だけで判断せず、**「効果量（差の大きさそのもの）」と「信頼区間（幅の広さ）」を必ず併記して、経済的・実務的な意味があるかを検証する**ことが基本とされています。

#### (3) 多重検定問題と $p$-hacking（データ・スヌーピング）

金融データやクオンツ研究で特に注意が必要なのが**多重検定問題**です。仮にまったく効果のない（すべて $H_0$ が真である）独立な投資指標を $20$ 個用意し、それぞれを有意水準 $\alpha = 5\%$ で検定すると、少なくとも1つが偶然「有意（$p < 0.05$）」と判定される確率は、

$$1 - (1 - 0.05)^{20} \approx \mathbf{64.15\%}$$

まで上昇します。バックテストで数百通りの売買ルールを試し、たまたま $p < 0.05$ になった1つだけを「有効な戦略」として採用する行為（**$p$-hacking** または**データ・スヌーピング**）は、将来データでは再現しにくくなります。

この限界に対する対応として、以下の手法が用いられます。

* **多重比較の補正：** 検定回数 $m$ に応じて有意水準を $\alpha / m$ に厳格化する**ボンフェローニ補正**や、偽発見率（FDR）を制御するベンジャミニ＝ホッホベルグ法を適用する。
* **アウト・オブ・サンプル検証（交差検証）：** 仮説の探索に使うデータと、最終的な検証に使うデータを分離し、未知データでの再現性を確認する。

### 5. 接続と展望（Bridge）：本節の道具がこれからの各部にどう繋がるか

1. **次節（0-5節：回帰分析・因果推論と多変量解析の基礎）：**
    本節の仮説検定（$t$ 検定・$F$ 検定）と最小化・最大化の発想を、「説明変数 $X$ から目的変数 $Y$ を予測するモデル」へ拡張したものが回帰分析です。

2. **第7部（7-2・7-3節：生命表と生命保険の数理）：**
    多重状態モデルにおける推移力の推定には本節の**最尤推定法**がそのまま使われ、保険の収支相等の原則は**大数の法則**を基盤としています。

3. **第8部（8-2・8-5節：複合ポアソン分布と破産確率）：**
    クレーム総額 $S = \sum_{i=1}^N X_i$ の分布解析と再生性の証明には**積率母関数**が中心的な道具として使われ、Lundbergの破産確率の調整係数 $R$ も積率母関数の方程式 $M_X(R) = 1 + (1+\theta)\mu R$ から定義されます。

4. **第9部（9-3・9-8節：ポートフォリオ評価とクオンツ実務）：**
    ファンドの超過リターン（ジェンセンの $\alpha$）が実力か偶然かの判定には $t$ 検定が使われます。また、第9部末尾（9-8節）で扱う「アルファの減衰」や機械学習の過学習リスクは、本節で述べた多重検定・データ・スヌーピングの延長線上にあります。

本節の最尤推定法と仮説検定・信頼区間を、具体的な数値計算で確認します。

> **【確認の問い】**
>
> 1. **（積率母関数によるモーメント計算）**
>     確率変数 $X$ がポアソン分布 $\mathrm{Po}(\lambda)$ に従うとき、積率母関数 $M_X(t) = \exp\bigl(\lambda(e^t - 1)\bigr)$ の対数をとったキュムラント母関数 $K_X(t) = \lambda(e^t - 1)$ を用いて、$K_X'(0)$（平均）と $K_X''(0)$（分散）がともに $\lambda$ になることを直接微分して確かめてください。
>
> 2. **（$t$ 検定と $95\%$ 信頼区間：アクティブファンドの超過リターン検証）**
>     ある投資信託の過去 $n = 25$ か月間の月次超過リターン（ベンチマークとの差）を集計したところ、標本平均 $\bar{x} = +0.60\%$、不偏標準偏差 $s = 1.50\%$ でした。各月の超過リターンが独立に正規分布 $N(\mu, \sigma^2)$ に従うと仮定し、自由度 $24$ の $t$ 分布の上側 $2.5\%$ 点を $t_{24,\, 0.025} = 2.064$ とします。
>
>     * (a) 母平均 $\mu$ の $95\%$ 信頼区間を求めてください。
>     * (b) 帰無仮説 $H_0: \mu = 0$、対立仮説 $H_1: \mu \neq 0$ とする両側 $t$ 検定を有意水準 $5\%$ で行い、統計的に有意な超過リターンがあると言えるか判定してください（また、誤って標準正規分布の $1.96$ を使った場合と結論がどう異なるか確認してください）。
>
> 3. **（次節への伏線：1変数の推定から多変数の関係分析へ）**
>     本節までは「1つの確率変数 $X$ の平均や分散」を中心に扱いました。では、「駅の徒歩分数と築年数からアパートの家賃を予測する」あるいは「市場全体のリターンから個別株のリターンを説明する」といった、複数の変数の関係を数式で捉えるにはどのようなモデルが必要になるでしょうか。また、データ上で強い相関が見つかったとき、それだけで「一方を変えれば他方が変わる（因果関係）」と結論づけてよいでしょうか。
