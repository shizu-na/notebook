### 前節（0-2）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（確率変数と分布の体系）の導入になります。

1. **社債のデフォルトと景気局面（全確率の定理とベイズの定理）：**

    * **(a) 無条件のデフォルト確率 $P(D)$：**
        全確率の定理より、好況 $G$（$0.7$）と不況 $R$（$0.3$）の加重平均をとります。

        $$P(D) = P(G)P(D \mid G) + P(R)P(D \mid R) = 0.7 \times 0.01 + 0.3 \times 0.08 = 0.007 + 0.024 = \mathbf{0.031 \quad (3.1\%)}$$

    * **(b) デフォルト観測後に不況であった事後確率 $P(R \mid D)$：**
        ベイズの定理より、

        $$P(R \mid D) = \frac{P(R)P(D \mid R)}{P(D)} = \frac{0.024}{0.031} \approx \mathbf{0.7742 \quad (77.4\%)}$$

        当初は $30\%$ であった不況の確率が、社債のデフォルトという観測情報によって $77.4\%$ まで更新されます。

2. **排反と独立の区別：**
    **独立にはなり得ません。** $A$ と $B$ が排反であるとは $A \cap B = \emptyset$ なので $P(A \cap B) = 0$ です。一方、仮定より $P(A) > 0$ かつ $P(B) > 0$ であるため $P(A)P(B) > 0$ となります。したがって独立の定義式 $P(A \cap B) = P(A)P(B)$ は成立しません。

3. **事象から数値・分布へ（本節への接続）：**
    標本空間 $\Omega$ の各結果に実数値を対応させる関数を**確率変数（Random variable）**と呼びます。確率変数を導入することで、起こり得るすべての数値に確率を割り当てた**確率分布**が定義でき、その重心（期待値）や広がり（分散）、複数変数間の連動性（共分散・相関係数）を体系的に計算できるようになります。

## 0-3. 確率変数と主要分布の体系

### 1. 動機（Why）：なぜ「分布の暗記」ではなく「相互関係の体系」として学ぶのか

確率統計の学習でつまずきやすいのは、二項分布・ポアソン分布・指数分布・ガンマ分布・正規分布・対数正規分布・$\chi^2$ 分布・$t$ 分布・$F$ 分布といった多数の確率分布が、互いに無関係な公式の羅列として登場するためです。

しかし、アクチュアリー数理や金融工学で使われる主要な確率分布のほとんどは、**「成功か失敗かの試行（ベルヌーイ試行）」**と**「一定ペースで起きる事象の待ち時間（指数分布）」**、そして**「多数の微小な独立要因の和（正規分布）」**という3つの核から派生しています。

本節で確率変数の基本性質と主要分布の全体像を1つの体系としてまとめる理由は2つあります。

**理由①：現象のメカニズムから適切な分布を選べるようになるから**
たとえば「1年間に事故が何回起きるか」はポアソン分布、「次の事故まで何日待つか」は指数分布、「3回目の事故まで何日待つか」はガンマ分布、「株価のように乗法的に変動する資産価格」は対数正規分布というように、確率分布の選択は暗記ではなく「その現象がどのような確率的構造で生成されているか」のモデル化そのものです。

**理由②：平均と分散だけでは捉えきれない「分布の裾（テール）」の違いを把握するため**
ファイナンスや保険の実務では、正規分布のように平均の周りに素直に集まる現象ばかりではありません。大災害の損害額や金融危機時の損失のように、極端な外れ値（重尾分布）が全体の収支を支配する領域があります。主要分布の系譜を押さえておくことで、標準的なモデルの前提がどこで崩れるかを見極められるようになります。

### 2. 具体例と計算イメージ（Toy Model）

厳密な定義に入る前に、複数確率変数の分散（共分散の働き）と、主要分布同士の繋がりを2つの具体例で確認します。

#### 実験A：2資産ポートフォリオの期待値と分散（相関係数 $\rho$ の役割）

2つのリスク資産 $A, B$ の1年リターンを確率変数 $R_A, R_B$ とします。それぞれの期待リターンと標準偏差を次のように置きます。

* 資産 $A$：$E[R_A] = 6\%,\; \sigma_A = 15\%$
* 資産 $B$：$E[R_B] = 4\%,\; \sigma_B = 10\%$

資金を半分ずつ（$w_A = 0.5,\; w_B = 0.5$）配分したポートフォリオ $R_p = 0.5 R_A + 0.5 R_B$ を考えます。期待リターンは相関係数 $\rho$ によらず常に単純平均の $E[R_p] = 0.5 \times 6\% + 0.5 \times 4\% = \mathbf{5.0\%}$ です。

一方、分散は $V[R_p] = w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 + 2 w_A w_B \rho \sigma_A \sigma_B$ となり、2資産の相関係数 $\rho$ によって標準偏差 $\sigma_p = \sqrt{V[R_p]}$ が以下のように変化します。

| 相関係数 $\rho$ | ポートフォリオ期待リターン $E[R_p]$ | ポートフォリオ標準偏差 $\sigma_p$ | 分散投資の効果 |
| :---: | :---: | :---: | :--- |
| $\rho = +1.0$ | $5.0\%$ | **$12.50\%$** | 各標準偏差の単純平均 $(15+10)/2$ と一致（低減効果なし） |
| $\rho = 0.0$（無相関） | $5.0\%$ | **$9.01\%$** | 低い方の資産 $B$（$10\%$）よりもリスクが下がる |
| $\rho = -0.5$ | $5.0\%$ | **$6.61\%$** | 互いの値動きを打ち消し合い、大幅にリスクが低下 |
| $\rho = -1.0$ | $5.0\%$ | **$2.50\%$** | 配分比を $w_A=0.4, w_B=0.6$ にすれば理論上リスク $0\%$ |

期待値には線形性があるため加重平均そのままですが、分散には $2 w_A w_B \operatorname{Cov}(R_A, R_B)$ という交差項が現れます。この交差項が、第9部で扱う現代ポートフォリオ理論の数学的根拠です。

### 3. 定義・定理・導出（What）

#### (1) 確率変数・分布関数・確率（密度）関数

確率空間 $(\Omega, \mathcal{F}, P)$ 上で定義され、各根元事象 $\omega \in \Omega$ に実数を割り当てる関数 $X: \Omega \to \mathbb{R}$（任意の $x \in \mathbb{R}$ に対し $\{\omega \mid X(\omega) \le x\} \in \mathcal{F}$ を満たす可測関数）を**確率変数**と呼びます（※可測性の厳密な検証は測度論の範囲とし、本ノートでは通常の離散・連続確率変数を扱います）。

確率変数 $X$ の挙動を規定するのが**累積分布関数（CDF）** $F_X(x) := P(X \le x)$ です。$F_X$ は単調非減少で、$\lim_{x \to -\infty} F_X(x) = 0,\; \lim_{x \to \infty} F_X(x) = 1$ を満たします。

* **離散型確率変数：** とり得る値が有限個または可算個 $\{x_1, x_2, \dots\}$ である場合。**確率質量関数（PMF）** $p_X(x_k) := P(X = x_k)$ で表され、$\sum_k p_X(x_k) = 1$ を満たします。
* **連続型確率変数：** 非負の関数 $f_X(x) \ge 0$（**確率密度関数：PDF**）が存在し、任意の区間 $[a, b]$ に対して

    $$P(a \le X \le b) = \int_a^b f_X(x)\,dx, \qquad \int_{-\infty}^\infty f_X(x)\,dx = 1$$

    と書ける場合。連続型では1点での確率は $P(X = a) = 0$ であり、$f_X$ が連続な点で $F_X'(x) = f_X(x)$ が成り立ちます。

#### (2) 期待値・分散・共分散・相関係数

確率変数 $X$ の**期待値（平均）** $E[X]$ と**分散** $V[X]$ を次で定義します（和・積分が絶対収束する場合）。

$$E[X] := \begin{cases} \sum_k x_k\, p_X(x_k) & (\text{離散型}) \\ \int_{-\infty}^\infty x\, f_X(x)\,dx & (\text{連続型}) \end{cases}, \qquad V[X] := E\bigl[(X - E[X])^2\bigr] = E[X^2] - (E[X])^2$$

分散の非負の平方根 $\sigma_X := \sqrt{V[X]}$ が**標準偏差**です。期待値は任意の定数 $a, b$ と確率変数 $X, Y$ に対して**線形性** $E[aX + bY] = aE[X] + bE[Y]$ を満たします（$X, Y$ が独立である必要はありません）。

2つの確率変数 $X, Y$ の同時分布が与えられたとき、連動の向きと強さを測る**共分散**と、単位に依存しないよう正規化した**相関係数**を次で定義します。

$$\operatorname{Cov}(X, Y) := E\bigl[(X - E[X])(Y - E[Y])\bigr] = E[XY] - E[X]E[Y], \qquad \rho(X, Y) := \frac{\operatorname{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

任意の確率変数 $U, V$ と任意の実数 $t$ に対して $E[(tU + V)^2] = t^2 E[U^2] + 2t E[UV] + E[V^2] \ge 0$ が成り立つため、2次式の判別式条件から**確率変数のコーシー・シュワルツの不等式**

$$\bigl(E[UV]\bigr)^2 \le E[U^2]\, E[V^2]$$

が得られます。ここに $U = X - E[X],\; V = Y - E[Y]$ を代入すれば $(\operatorname{Cov}(X, Y))^2 \le V[X]V[Y]$、すなわち常に $-1 \le \rho(X, Y) \le 1$ が従います。また、線形結合の分散は

$$V[aX + bY] = a^2 V[X] + b^2 V[Y] + 2ab\operatorname{Cov}(X, Y)$$

となります。$X$ と $Y$ が独立（同時確率が周辺確率の積 $f_{X,Y}(x,y) = f_X(x)f_Y(y)$ に分解できる）ならば $\operatorname{Cov}(X, Y) = 0$ となり、分散も加法性 $V[X + Y] = V[X] + V[Y]$ を満たします。ただし逆は成り立ちません。たとえば $X$ が $0$ に関して対称な分布（例：$P(X = -1) = P(X = 0) = P(X = 1) = 1/3$ や $X \sim N(0, 1)$）に従い $Y = X^2$ とおくと、対称性より $E[X] = 0$ かつ $E[X^3] = 0$ なので

$$\operatorname{Cov}(X, Y) = E[X \cdot X^2] - E[X]E[X^2] = E[X^3] - 0 = 0$$

と無相関になりますが、$Y$ は $X$ の値で一意に決まるため独立ではありません。

#### (3) 条件付期待値と「繰り返し期待値の法則」「全分散の法則」

アクチュアリー数理（複合ポアソン分布・信頼性理論）や金融工学で頻繁に使う2つの恒等式を示します。確率変数 $Y$ の値が $y$ に定まったもとでの $X$ の条件付分布による期待値を $E[X \mid Y = y]$ と書き、これを $Y$ の関数とみなした新しい確率変数を**条件付期待値** $E[X \mid Y]$ と表記します。

> **【定理1：繰り返し期待値の法則（Law of Iterated Expectations）】**
> 期待値が存在する任意の確率変数 $X, Y$ に対して、次が成り立つ。
>
> $$E[X] = E\bigl[E[X \mid Y]\bigr]$$

**【証明（離散型の場合）】**
$E[X \mid Y = y] = \sum_x x\, P(X = x \mid Y = y)$ なので、これを $Y$ の分布で平均すると、

$$E\bigl[E[X \mid Y]\bigr] = \sum_y P(Y = y) \sum_x x\, P(X = x \mid Y = y) = \sum_x x \sum_y P(X = x, Y = y) = \sum_x x\, P(X = x) = E[X]$$

連続型でも、絶対積分可能のもとで重積分の順序交換を保証するフビニの定理（証明は測度論・解析学の範囲外として前提にします）を用いれば同様に示されます。（証明終）

> **【定理2：全分散の法則（Law of Total Variance）】**
> 分散が有限な確率変数 $X, Y$ に対して、全体の分散は「条件付分散の平均（群内変動）」と「条件付期待値の分散（群間変動）」の和に分解される。
>
> $$V[X] = E\bigl[V[X \mid Y]\bigr] + V\bigl[E[X \mid Y]\bigr]$$

**【証明】**
条件付分散の定義 $V[X \mid Y] = E[X^2 \mid Y] - (E[X \mid Y])^2$ の両辺の期待値をとり、定理1（$E[E[X^2 \mid Y]] = E[X^2]$ および $E[E[X \mid Y]] = E[X]$）を適用します。

$$\begin{aligned}
E\bigl[V[X \mid Y]\bigr] + V\bigl[E[X \mid Y]\bigr]
&= \Bigl(E[X^2] - E\bigl[(E[X \mid Y])^2\bigr]\Bigr) + \Bigl(E\bigl[(E[X \mid Y])^2\bigr] - (E[X])^2\Bigr) \\
&= E[X^2] - (E[X])^2 = V[X]
\end{aligned}$$

（証明終）

#### (4) 主要分布の体系と代表分布の導出

図0-3に示した3系統の主要分布について、生成メカニズム・確率（密度）関数・平均・分散を整理します。連続分布の規格化定数として現れる**ガンマ関数**と**ベータ関数**をここで定義しておきます。

$$\Gamma(\alpha) := \int_0^\infty t^{\alpha - 1} e^{-t}\,dt \quad (\alpha > 0), \qquad B(\alpha, \beta) := \int_0^1 t^{\alpha - 1}(1 - t)^{\beta - 1}\,dt = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha + \beta)} \quad (\alpha, \beta > 0)$$

部分積分より $\Gamma(\alpha + 1) = \alpha \Gamma(\alpha)$ が成り立ち、特に正の整数 $n$ に対しては $\Gamma(n) = (n - 1)!$ となります（階乗の連続版です）。

##### ① 離散型分布（ベルヌーイ試行系）

| 分布名と記法 | 生成メカニズム（何を表すか） | 確率質量関数 $P(X = k)$ | 平均 $E[X]$ | 分散 $V[X]$ |
| --- | --- | --- | :---: | :---: |
| **ベルヌーイ** $\mathrm{Ber}(p)$ | 成功確率 $p$ の1回試行（$0$ か $1$） | $p^k(1-p)^{1-k}\;\; (k=0,1)$ | $p$ | $p(1-p)$ |
| **二項** $\mathrm{Bin}(n, p)$ | 独立な $n$ 回試行の成功回数 | $\binom{n}{k} p^k (1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| **幾何** $\mathrm{Geo}(p)$ | 初めて成功するまでの失敗回数 $k$ | $(1-p)^k p\;\; (k=0,1,\dots)$ | $\dfrac{1-p}{p}$ | $\dfrac{1-p}{p^2}$ |
| **負の二項** $\mathrm{NB}(r, p)$ | $r$ 回成功するまでの失敗回数 $k$ | $\binom{k+r-1}{k} p^r (1-p)^k$ | $\dfrac{r(1-p)}{p}$ | $\dfrac{r(1-p)}{p^2}$ |
| **超幾何** $\mathrm{HG}(N, K, n)$ | 全体 $N$（うち当たり $K$）から非復元で $n$ 個抽出 | $\dfrac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$ | $n\dfrac{K}{N}$ | $n\dfrac{K}{N}\left(1-\dfrac{K}{N}\right)\dfrac{N-n}{N-1}$ |
| **ポアソン** $\mathrm{Po}(\lambda)$ | 単位時間あたり平均 $\lambda$ 回の希少事象の発生回数 | $\dfrac{\lambda^k e^{-\lambda}}{k!}\;\; (k=0,1,\dots)$ | $\lambda$ | $\lambda$ |

※幾何分布・負の二項分布には「成功を含めた総試行回数」を確率変数とする定義もあります（その場合、平均は $1/p$、$r/p$ となり、分散は同じです）。なお、二項分布は独立なベルヌーイ確率変数 $X_1, \dots, X_n$ の和 $X = \sum_{i=1}^n X_i$ として表せるため、期待値の線形性と独立和の分散加法性から直ちに $E[X] = np,\; V[X] = np(1-p)$ が得られます（負の二項分布と幾何分布の関係も同様です）。

##### ② 連続型分布（待ち時間系・正規・標本分布系）

| 分布名と記法 | 生成メカニズム・主な用途 | 確率密度関数 $f(x)$ | 平均 $E[X]$ | 分散 $V[X]$ |
| --- | --- | --- | :---: | :---: |
| **一様** $U(a, b)$ | 区間 $[a, b]$ 上で等確率 | $\dfrac{1}{b-a}\;\; (a \le x \le b)$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^2}{12}$ |
| **指数** $\mathrm{Exp}(\lambda)$ | ポアソン到着における1回目の待ち時間 | $\lambda e^{-\lambda x}\;\; (x \ge 0)$ | $\dfrac{1}{\lambda}$ | $\dfrac{1}{\lambda^2}$ |
| **ガンマ** $\mathrm{Ga}(\alpha, \beta)$ | 独立な指数分布 $\alpha$ 個の和（$\alpha$ 回目までの待ち時間） | $\dfrac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}\;\; (x > 0)$ | $\dfrac{\alpha}{\beta}$ | $\dfrac{\alpha}{\beta^2}$ |
| **ベータ** $\mathrm{Beta}(\alpha, \beta)$ | 確率 $p \in (0,1)$ 自体の事前・事後分布（ガンマ比） | $\dfrac{1}{B(\alpha, \beta)} x^{\alpha-1}(1-x)^{\beta-1}\;\; (0 < x < 1)$ | $\dfrac{\alpha}{\alpha+\beta}$ | $\dfrac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ |
| **正規** $N(\mu, \sigma^2)$ | 多数の独立要因の和の極限（中心極限定理） | $\dfrac{1}{\sqrt{2\pi}\sigma} \exp\!\left(-\dfrac{(x-\mu)^2}{2\sigma^2}\right)$ | $\mu$ | $\sigma^2$ |
| **対数正規** $\mathrm{LN}(\mu, \sigma^2)$ | $\ln X \sim N(\mu, \sigma^2)$（株価・損害額等の正の乗法変動） | $\dfrac{1}{\sqrt{2\pi}\sigma x} \exp\!\left(-\dfrac{(\ln x-\mu)^2}{2\sigma^2}\right)\;\; (x > 0)$ | $e^{\mu + \frac{\sigma^2}{2}}$ | $(e^{\sigma^2}-1)e^{2\mu+\sigma^2}$ |

**【代表的な連続分布の導出（指数分布と対数正規分布）】**
表の公式を暗記するだけでなく、積分でどう導かれるかを重要な2分布で確認しておきます（他の分布の平均・分散は次節の積率母関数を使うとさらに系統的に計算できます）。

* **指数分布 $\mathrm{Exp}(\lambda)$ の平均・分散：**
    $t = \lambda x$ と置換してガンマ関数を用いると、$k$ 次モーメントは $E[X^k] = \int_0^\infty x^k \lambda e^{-\lambda x}\,dx = \frac{1}{\lambda^k}\int_0^\infty t^k e^{-t}\,dt = \frac{\Gamma(k+1)}{\lambda^k} = \frac{k!}{\lambda^k}$ です。よって $E[X] = \frac{1}{\lambda}$、$V[X] = E[X^2] - (E[X])^2 = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2}$ となります。

* **対数正規分布 $\mathrm{LN}(\mu, \sigma^2)$ の平均に $+\sigma^2/2$ が付く理由：**
    $Y \sim N(\mu, \sigma^2)$ に対して $X = e^Y$ とおきます。期待値 $E[X] = E[e^Y]$ を正規分布の密度で積分し、指数部を $y$ について平方完成します。

    $$\begin{aligned}
    E[e^Y]
    &= \int_{-\infty}^\infty e^y \frac{1}{\sqrt{2\pi}\sigma} \exp\!\left(-\frac{(y-\mu)^2}{2\sigma^2}\right) dy \\
    &= \exp\!\left(\mu + \frac{\sigma^2}{2}\right) \int_{-\infty}^\infty \frac{1}{\sqrt{2\pi}\sigma} \exp\!\left(-\frac{\bigl(y - (\mu + \sigma^2)\bigr)^2}{2\sigma^2}\right) dy
    = e^{\mu + \frac{\sigma^2}{2}}
    \end{aligned}$$

    （2行目の積分は平均 $\mu + \sigma^2$、分散 $\sigma^2$ の正規分布の全区間積分なので $1$ になります。なお、これは次節で定義する正規分布の積率母関数 $M_Y(t) = E[e^{tY}]$ に $t = 1$ を代入したものと同じです。）同様に $E[X^2] = E[e^{2Y}] = e^{2\mu + 2\sigma^2}$ から $V[X] = e^{2\mu + 2\sigma^2} - e^{2\mu + \sigma^2} = (e^{\sigma^2} - 1)e^{2\mu + \sigma^2}$ が導かれます。

    ここで指数関数 $g(y) = e^y$ は厳密に下に凸（$g''(y) = e^y > 0$）であるため、凸関数に関する**イェンセンの不等式** $E[g(Y)] > g(E[Y])$ より、常に $E[e^Y] = e^{\mu + \sigma^2/2} > e^\mu$（中央値）が成り立ちます。この $+\frac{1}{2}\sigma^2$ のズレは、第9部（9-5節）の幾何ブラウン運動における伊藤の補正項 $-\frac{1}{2}\sigma^2$ と表裏一体の関係にあります。

##### ③ 標本分布系（正規分布から導出される3つの分布）

次節（0-4節）の統計的推定・仮説検定で主役となる3つの分布は、いずれも標準正規分布 $Z_i \sim N(0, 1)$（互いに独立）から構成されます。

* **$\chi^2$（カイ2乗）分布（自由度 $k$）：** $U = Z_1^2 + \dots + Z_k^2 \sim \chi^2(k)$。ガンマ分布の特殊形 $\mathrm{Ga}(k/2, 1/2)$ であり、平均 $k$、分散 $2k$。標本分散の分布に現れます。
* **$t$ 分布（自由度 $k$）：** 独立な $Z \sim N(0, 1)$ と $U \sim \chi^2(k)$ の比 $T = \frac{Z}{\sqrt{U/k}} \sim t(k)$。母分散未知のときの母平均の推定・検定に使われ、$k \to \infty$ で標準正規分布に収束します。正規分布より裾が厚く、特に $k = 1$ は後述のコーシー分布と一致します。
* **$F$ 分布（自由度 $k_1, k_2$）：** 独立な $U_1 \sim \chi^2(k_1)$ と $U_2 \sim \chi^2(k_2)$ の比 $F = \frac{U_1/k_1}{U_2/k_2} \sim F(k_1, k_2)$。2群の分散の比較や回帰分析の有意性検定（分散分析）に使われます。

> **【コラム：指数分布の「無記憶性」とポアソン分布の「少数の法則」】**
>
> **1. 指数分布の無記憶性（Memoryless property）：**
> 待ち時間 $T \sim \mathrm{Exp}(\lambda)$ について、「すでに時間 $s$ だけ事象が起きずに経過した条件のもとで、さらに時間 $t$ 以上起きない確率」を計算すると、
>
> $$P(T > s + t \mid T > s) = \frac{P(T > s + t)}{P(T > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(T > t)$$
>
> となり、過去の経過時間 $s$ に一切依存しません（離散版では幾何分布だけが同じ性質を持ちます）。これは、瞬間発生率（ハザード率）が常に定数 $\lambda$ で老化も学習もしないことを意味します。機械の偶発故障や短期的な事故発生の近似には便利ですが、人間の死亡率（加齢とともに上昇する）には当てはまらないため、第7部ではハザード率を年齢の関数 $\mu_x$ に拡張します。
>
> **2. ポアソン分布の「少数の法則（Law of small numbers）」：**
> 二項分布 $\mathrm{Bin}(n, p)$ において、試行回数 $n \to \infty$、1回あたりの成功確率 $p \to 0$ としつつ、平均発生回数 $\lambda = np$ を一定に保つ極限をとります。$p = \lambda / n$ を代入すると、
>
> $$\binom{n}{k}\left(\frac{\lambda}{n}\right)^k \left(1 - \frac{\lambda}{n}\right)^{n-k} = \frac{\lambda^k}{k!} \cdot \underbrace{\frac{n(n-1)\cdots(n-k+1)}{n^k}}_{\to 1} \cdot \underbrace{\left(1 - \frac{\lambda}{n}\right)^n}_{\to e^{-\lambda}} \cdot \underbrace{\left(1 - \frac{\lambda}{n}\right)^{-k}}_{\to 1} \longrightarrow \frac{\lambda^k e^{-\lambda}}{k!}$$
>
> となり、ポアソン分布が導かれます。19世紀の統計学者ボルトキエヴィッチが、プロイセン軍で20年間に馬に蹴られて死亡した兵士の年間人数（まれな事故の件数）がポアソン分布に非常によく一致することを示した逸話が有名です。多数の契約者がそれぞれ低い確率で事故を起こす損害保険のクレーム件数モデル（第8部）の直接の基礎になっています。

### 4. 限界と補正（Critique & Adaptation）

主要分布の多くは平均 $E[X]$ と分散 $V[X]$ という2つの数値で特徴づけられます。しかし、金融市場のリターンや自然災害の損害額を扱う際、この枠組みには大きな限界が現れます。

#### (1) 「平均と中央値の乖離」：対数正規分布の非対称性

株価や所得、保険の損害額は負にならないため、しばしば対数正規分布 $X = e^Y$（$Y \sim N(\mu, \sigma^2)$）でモデル化されます。3節で導出した通り、中央値（ちょうど半数が下回る値）は $e^\mu$ ですが、平均は $e^{\mu + \sigma^2/2}$ となり、ボラティリティ $\sigma$ が大きいほど平均が中央値から大きく上振れします。

$\mu = 0$（中央値 $= 1.00$）のときの推移を比べると、次の通りです。

* $\sigma = 0.2$：中央値 $1.00$、平均 $1.020$、標準偏差 $0.206$（ほぼ対称）
* $\sigma = 1.0$：中央値 $1.00$、平均 $1.649$、標準偏差 $2.161$
* $\sigma = 1.5$：中央値 $1.00$、平均 $3.080$、標準偏差 $8.974$（平均の値が全体の過半数を大きく上回る）

右に長く裾を引く分布では、「平均値」だけを見て実態を判断すると誤ります。所得分布や不動産価格の分析で平均値と中央値を必ず並べて確認するのは、この非対称性への基本的な対処です。

#### (2) 分散や平均そのものが発散する「重尾分布（Heavy-tailed distributions）」

さらに裾が厚い分布では、平均や分散という基本概念そのものが有限値として存在しなくなります。代表例が、損害保険の巨大クレームや富の分布に現れる**パレート分布**（$f(x) = \alpha x_0^\alpha x^{-\alpha-1},\; x \ge x_0,\; \alpha > 0$）です。

パレート分布の $k$ 次モーメント $\int_{x_0}^\infty x^k \cdot \alpha x_0^\alpha x^{-\alpha-1}\,dx$ が収束する条件は $k < \alpha$ です。したがって、

* **$1 < \alpha \le 2$ のとき：** 平均は有限ですが、**分散は無限大（$V[X] = \infty$）**になります。
* **$\alpha \le 1$ のとき：** **平均すら無限大（$E[X] = \infty$）**になります。

また、自由度 $1$ の $t$ 分布である**コーシー分布**（$f(x) = \frac{1}{\pi(1+x^2)}$）も、左右対称で山が $0$ にあるにもかかわらず、積分 $\int_{-\infty}^\infty \frac{\vert x \vert}{1+x^2}\,dx$ が発散するため期待値が存在しません。

こうした重尾分布では「分散をリスクの尺度とする」標準的な手法が機能しなくなります。実務ではこの限界に対し、以下の対応を用います。

* **分位点・テール指標の併用：** 分散に頼らず、中央値・四分位範囲や、第8部で扱う**VaR（分位点）・TVaR（裾の条件付期待値）**、**極値理論**を用いる。
* **契約設計によるテールの切断：** 損害保険における「支払限度額」や「超過損害額再保険」（第8部 8-5節）は、確率変数を $\min(X, M)$ のように上から打ち切ることで、数学的にモーメントを有限化し破産リスクを制御する実務上の仕組みです。

### 5. 接続と展望（Bridge）：本節の道具がこれからの各部にどう繋がるか

1. **次節（0-4節：積率母関数・極限定理・推定と検定）：**
    本節で整理した独立な確率変数の和（例：ポアソン分布同士の和、指数分布の和＝ガンマ分布）の分布を系統的に計算する道具が**積率母関数**です。また、標本分布系（$\chi^2, t, F$）を使って未知のパラメータを推定・検定する手続きへ進みます。

2. **第5部（5-5節：賃貸管理の実務）：**
    入居者の退去までの期間を指数分布でモデル化することで、アパートの空室率や稼働率の簡易シミュレーションが可能になります。

3. **第7部（7-2・7-3節：生命表と生命保険の数理）：**
    指数分布の一定ハザード率 $\lambda$ を年齢依存の死力 $\mu_x$ へ一般化すると、生命表の生存モデルになります。また、保険金の給付現価を確率変数とみなすことで、純保険料（期待値）とリスク評価（分散）が計算できます。

4. **第8部（8-2・8-3・8-6節：損保数理とリスク管理）：**
    繰り返し期待値の法則と全分散の法則は、クレーム総額 $S = \sum_{i=1}^N X_i$（複合ポアソン分布）の平均・分散の導出、およびベイズ信頼性理論（Bühlmannモデル）の中核公式としてそのまま使われます。

5. **第9部（9-3・9-6節：ポートフォリオとオプション）：**
    実験Aの共分散構造は第9部の効率的フロンティアへ直結し、対数正規分布の性質はブラック＝ショールズ公式における株価モデルの基礎になります。

>
>     * 好況（$Y = G$、確率 $0.6$）：平均 $E[X \mid G] = 8\%$、標準偏差 $10\%$（分散 $100$）
>     * 不況（$Y = R$、確率 $0.4$）：平均 $E[X \mid R] = -2\%$、標準偏差 $20\%$（分散 $400$）
>
>     繰り返し期待値の法則と全分散の法則を用いて、このファンドの無条件の期待リターン $E[X]$ と無条件の分散 $V[X]$（および標準偏差）を計算してください。
>
> 2. **（ポアソン分布と指数分布の対応）**
