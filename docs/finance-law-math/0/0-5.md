### 前節（0-4）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（積率母関数と極限定理）の導入になります。

1. **正規分布の標準化：**
    $X \sim N(500, 10^2)$ より、標準化した確率変数 $Z = \frac{X - 500}{10}$ は標準正規分布 $N(0, 1)$ に従います。

    * **(a) $P(490 \le X \le 510)$：**

        $$P(490 \le X \le 510) = P\!\left(\frac{490 - 500}{10} \le Z \le \frac{510 - 500}{10}\right) = P(-1 \le Z \le 1) \approx \mathbf{0.6827 \quad (68.3\%)}$$

    * **(b) $P(X < 480)$：**
        $480$ は平均から $-2\sigma$ の位置にあるため、$P(X < 480) = P(Z < -2)$ です。標準正規分布は $0$ を中心に左右対称なので、$P(-2 \le Z \le 2) \approx 0.9545$ の外側の面積（$1 - 0.9545 = 0.0455$）を左右半分に分ければ、

        $$P(Z < -2) = \frac{1 - 0.9545}{2} = \mathbf{0.02275 \quad (\text{約 } 2.28\%)}$$

2. **指数分布の無記憶性と対数正規分布：**

    * **(a) 指数分布の無記憶性：** $T \sim \mathrm{Exp}(0.5)$ の無記憶性より、すでに $1$ 時間経過した条件は以後の待ち時間に影響しません。

        $$P(T > 3 \mid T > 1) = P(T > 2) = e^{-0.5 \times 2} = e^{-1} \approx \mathbf{0.3679 \quad (36.8\%)}$$

    * **(b) 対数正規分布の中央値と平均：** $Y \sim N(0, 1)$（$\mu = 0,\; \sigma = 1$）より、$X = e^Y$ の中央値は $e^0 = \mathbf{1}$、平均は $E[X] = e^{0 + 1^2/2} = e^{0.5} \approx \mathbf{1.6487}$ です。

3. **独立和の分布と正規分布が普遍的に現れる理由（本節への接続）：**
    独立な確率変数の和 $X_1 + \dots + X_n$ の分布を直接の足し合わせ（たたみ込み）で計算するのは煩雑ですが、指数関数を通して「和を掛け算に変換する」**積率母関数**を用いると代数的に扱えます。さらにこの道具を使うと、元の分布の形によらず、独立な確率変数の平均が母平均に収束すること（**大数の法則**）と、その誤差が正規分布に近づくこと（**中心極限定理**）を系統的に導くことができます。

## 0-5. 積率母関数と2つの極限定理（大数の法則・中心極限定理）

### 1. 動機（Why）：独立な確率変数の「和」をどう扱い、なぜ正規分布が繰り返し現れるのか

これまでの節では、1つの確率変数 $X$ が従う基本分布（二項・ポアソン・指数・正規など）を個別に調べました。しかし実際の現象では、多数の独立な確率変数を足し合わせた**和 $S_n = X_1 + X_2 + \dots + X_n$** や、その**標本平均 $\bar{X}_n = \frac{1}{n}S_n$** の振る舞いが問題になります。たとえば、100回のコイン投げの表の合計、1,000個の部品の重さの平均、あるいは1年間に発生する多数の小さな誤差の積み重ねなどです。

ここで直面する課題は2つあります。

**課題①：独立な確率変数の和の分布を、手際よく計算したい**
サイコロを2個振って出た目の合計 $Z = X + Y$ の確率を求める場合、「合計が $7$ になる組合せ（$(1,6),(2,5),\dots,(6,1)$）の確率をすべて足し合わせる」という操作（**たたみ込み：Convolution**）を行います。これが連続変数や $n$ 個の和になると、何重もの積分を毎回計算する必要があり、直接の計算は現実的ではありません。そこで、対数表で「掛け算を足し算に翻訳して計算し、元に戻す」のと同じ発想で、「独立な変数の足し算を単純な掛け算へ翻訳する道具」として**積率母関数**を導入します。

**課題②：試行回数 $n$ を増やしたとき、和と平均はどう振る舞うのか**
コインを10回投げただけでは表の割合は $0.3$ や $0.7$ に大きくぶれますが、$10{,}000$ 回投げるとほぼ確実に $0.5$ 付近へ収束します。この直感を厳密に保証するのが**大数の法則**であり、さらに「$0.5$ からどれくらいの幅で、どんな形の分布に従ってぶれるのか」を明らかにするのが**中心極限定理**です。本節では、これらを1本の論理の流れとして導出します。

### 2. 具体例と計算イメージ（Toy Model）

定理の証明に入る前に、最も単純な「公正なコイン投げ」を使って、試行回数 $n$ を増やしたときに**和 $S_n$** と**平均 $\bar{X}_n$** がそれぞれどう変化するかを数値で確認します。

#### 実験A：公正なコインを $n$ 回投げたときの「和 $S_n$」と「平均 $\bar{X}_n$」

表が出れば $1$、裏が出れば $0$ をとる独立なベルヌーイ確率変数 $X_1, \dots, X_n \sim \mathrm{Ber}(0.5)$ を考えます。1回あたりの平均は $\mu = 0.5$、分散は $\sigma^2 = 0.5 \times 0.5 = 0.25$（標準偏差 $\sigma = 0.5$）です。

* **表の合計回数（和）$S_n = \sum_{i=1}^n X_i$：**
    期待値は $E[S_n] = n\mu = 0.5n$、分散は独立和の加法性より $V[S_n] = n\sigma^2 = 0.25n$ です。したがって、**和の標準偏差は $\sqrt{V[S_n]} = \sqrt{n}\,\sigma = 0.5\sqrt{n}$** となり、$n$ の増加とともに広がっていきます。

* **表の割合（標本平均）$\bar{X}_n = \frac{1}{n}S_n$：**
    期待値は $E[\bar{X}_n] = \mu = 0.5$ で一定です。一方、分散は $V[\bar{X}_n] = \frac{1}{n^2}V[S_n] = \frac{\sigma^2}{n} = \frac{0.25}{n}$ となるため、**平均の標準偏差は $\frac{\sigma}{\sqrt{n}} = \frac{0.5}{\sqrt{n}}$** となり、$n$ を増やすほど $0$ に近づきます。

$n = 10, 100, 1{,}000, 10{,}000$ について数値を並べてみます（右列は後述の中心極限定理で計算した「表の割合が $0.45 \sim 0.55$ の範囲に収まる確率」です。なお $n = 10$ で厳密な二項分布を計算しても、表がちょうど $5$ 回となる確率は $\binom{10}{5}/2^{10} \approx 24.61\%$ と近似値に近くなります）。

| 試行回数 $n$ | 和の期待値 $E[S_n]$ | 和の標準偏差 $0.5\sqrt{n}$ | 平均の標準偏差 $0.5/\sqrt{n}$ | $P(0.45 \le \bar{X}_n \le 0.55)$（正規近似） |
| :---: | :---: | :---: | :---: | :---: |
| $10$ 回 | $5.0$ | $1.58$ | $0.1581$ | $24.82\%$ |
| $100$ 回 | $50.0$ | $5.00$ | $0.0500$ | $68.27\%$ |
| $1{,}000$ 回 | $500.0$ | $15.81$ | $0.0158$ | $99.84\%$ |
| $10{,}000$ 回 | $5{,}000.0$ | $50.00$ | $0.0050$ | $99.99999999\%$ 以上 |

この表から、2つの対照的な事実が読み取れます。

1. **平均 $\bar{X}_n$** のばらつきは $1/\sqrt{n}$ で小さくなり、$n = 1{,}000$ 回も投げればほぼ確実に $0.5 \pm 0.05$ の範囲に収まります（大数の法則）。

2. 一方、**和 $S_n$** の期待値 $0.5n$ からのズレは $0.5\sqrt{n}$ で逆に大きくなります。そのため、和のズレ $S_n - n\mu$ をちょうど $\sqrt{n}\,\sigma$ で割ってスケール調整した量 $Z_n = \frac{S_n - n\mu}{\sqrt{n}\,\sigma} = \frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}}$ を作ると、$n$ をどれだけ増やしても平均 $0$・分散 $1$ の一定の幅に保たれ、その形が標準正規分布 $N(0, 1)$ へ収束します（中心極限定理）。

### 3. 定義・導出・構造（What）

#### (1) 積率母関数（MGF）の発想と定義

独立な確率変数の和 $Z = X + Y$ の分布は、定義通りには離散型で $P(Z = z) = \sum_k P(X = k)P(Y = z - k)$、連続型で $f_Z(z) = \int_{-\infty}^\infty f_X(x)f_Y(z - x)\,dx$ という**たたみ込み（Convolution）**で求めます。直接計算するとどれほど手間がかかるかを、最も単純な例で確かめてみます。たとえば $X, Y$ が互いに独立に区間 $[0, 1]$ の一様分布 $U(0, 1)$ に従うとき、$f_X(x) = 1$（$0 \le x \le 1$、それ以外は $0$）かつ $f_Y(z - x) = 1$（$z - 1 \le x \le z$）となるため、たたみ込み積分 $f_Z(z) = \int_{-\infty}^\infty f_X(x)f_Y(z - x)\,dx$ の積分範囲は $z$ の値に応じて場合分けが必要になります。

* $0 \le z \le 1$ のとき：$0 \le x \le z$ の範囲で積分して $f_Z(z) = \int_0^z 1\,dx = z$
* $1 < z \le 2$ のとき：$z - 1 \le x \le 1$ の範囲で積分して $f_Z(z) = \int_{z-1}^1 1\,dx = 2 - z$

こうしてようやく、$z = 1$ に頂点を持つ**三角分布**が求まります。最も単純な一様分布2個の和でさえ場合分けが必要になり、これが3個、10個と増えれば多重積分の直接計算は現実的ではありません。

そこで、独立な確率変数の和 $X + Y$ を扱いやすくするために、「足し算を掛け算に変える関数」を通すことを考えます。数学で足し算を掛け算に変える代表的な関数は**指数関数** $e^{t(X+Y)} = e^{tX}e^{tY}$ です。しかも、指数関数を $t = 0$ の周りでマクローリン展開すると、

$$e^{tX} = 1 + t X + \frac{t^2}{2!}X^2 + \frac{t^3}{3!}X^3 + \dots + \frac{t^k}{k!}X^k + \dots$$

となり、$X$ の1乗・2乗・3乗・……がすべて1本の式に収まります。この両辺の期待値をとったものが**積率母関数（Moment Generating Function, MGF）**です。

> **【定義：積率母関数とキュムラント母関数】**
> 確率変数 $X$ に対して、実数 $t$ の関数
>
> $$M_X(t) := E\bigl[e^{tX}\bigr]$$
>
> が $t = 0$ を含むある開区間 $(-h, h)$（$h > 0$）上で有限値として存在するとき、$M_X(t)$ を $X$ の**積率母関数**と呼ぶ。また、その自然対数
>
> $$K_X(t) := \ln M_X(t)$$
>
> を**キュムラント母関数**と呼ぶ（$M_X(0) = E[1] = 1 > 0$ かつ連続性より、$0$ の近傍で $M_X(t) > 0$ なので対数が定義できる）。

積率母関数とキュムラント母関数は、次の3つの基本性質を持ちます。

1. **微分によるモーメント（積率）の生成：**
    $M_X(t)$ が $0$ の近傍 $(-h, h)$ で有限であることから、期待値と無限和・微分の順序交換が正当化され、$M_X(t) = \sum_{k=0}^\infty \frac{E[X^k]}{k!}t^k$ となります。したがって、$t = 0$ で $k$ 回微分すれば $k$ 次モーメントが得られます。

    $$M_X^{(k)}(0) = E[X^k] \qquad (k = 1, 2, \dots)$$

    さらに、キュムラント母関数 $K_X(t) = \ln M_X(t)$ を微分して $t = 0$ を代入すると、平均と分散が直接現れます。実際、合成関数の微分と商の微分法から、

    $$K_X'(t) = \frac{M_X'(t)}{M_X(t)}, \qquad K_X''(t) = \frac{M_X''(t)M_X(t) - \bigl(M_X'(t)\bigr)^2}{\bigl(M_X(t)\bigr)^2}$$

    ここで $M_X(0) = 1,\; M_X'(0) = E[X],\; M_X''(0) = E[X^2]$ を代入すると、

    $$K_X'(0) = \frac{E[X]}{1} = E[X], \qquad K_X''(0) = \frac{E[X^2] \cdot 1 - (E[X])^2}{1^2} = E[X^2] - (E[X])^2 = V[X]$$

    が得られます（3階微分 $K_X'''(0) = E[(X - \mu)^3]$ は分布の左右の非対称性を表す3次中心モーメントに一致します）。

2. **独立和の積公式（キュムラント母関数では和公式）：**
    $X$ と $Y$ が独立なとき、$e^{tX}$ と $e^{tY}$ も独立なので期待値が積に分かれます。

    $$M_{X+Y}(t) = E\bigl[e^{t(X+Y)}\bigr] = E\bigl[e^{tX}e^{tY}\bigr] = E\bigl[e^{tX}\bigr]E\bigl[e^{tY}\bigr] = M_X(t)\, M_Y(t)$$

    両辺の対数をとれば、キュムラント母関数ではさらに単純な足し算になります。

    $$K_{X+Y}(t) = K_X(t) + K_Y(t)$$

    また、定数倍と平行移動 $aX + b$ に対しては $M_{aX+b}(t) = E[e^{t(aX+b)}] = e^{bt} M_X(at)$、対数をとれば $K_{aX+b}(t) = bt + K_X(at)$ が成り立ちます。

3. **分布の一意性（一意性定理）：**
    2つの確率変数 $X, Y$ の積率母関数が $0$ を含む開区間上で一致すれば、$X$ と $Y$ は同一の確率分布に従います。*（注：この一意性定理の厳密な証明は測度論・フーリエ解析の範囲となるため、本ノートでは事実として用います。）*

#### (2) 応用例：ポアソン分布と正規分布の再生性の証明

積率母関数を使うと、独立な確率変数の和が同じ種類の分布に従う性質（**再生性**）を数行で証明できます。

* **ポアソン分布 $X \sim \mathrm{Po}(\lambda)$：**

    $$M_X(t) = \sum_{k=0}^\infty e^{tk} \frac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda} \sum_{k=0}^\infty \frac{(\lambda e^t)^k}{k!} = e^{-\lambda} e^{\lambda e^t} = \exp\bigl(\lambda(e^t - 1)\bigr)$$

    よって独立な $X_1 \sim \mathrm{Po}(\lambda_1),\; X_2 \sim \mathrm{Po}(\lambda_2)$ の和の積率母関数は

    $$M_{X_1 + X_2}(t) = \exp\bigl(\lambda_1(e^t - 1)\bigr)\exp\bigl(\lambda_2(e^t - 1)\bigr) = \exp\bigl((\lambda_1 + \lambda_2)(e^t - 1)\bigr)$$

    となり、一意性より直ちに **$X_1 + X_2 \sim \mathrm{Po}(\lambda_1 + \lambda_2)$** が従います。

* **正規分布 $X \sim N(\mu, \sigma^2)$：**
    0-4節の対数正規分布の計算で平方完成した積分 $E[e^{kY}] = \exp\bigl(k\mu + \frac{1}{2}k^2\sigma^2\bigr)$ において、$k$ をそのまま実数 $t$ に置き換えれば、直ちに積率母関数とキュムラント母関数が得られます。

    $$M_X(t) = \exp\!\left(\mu t + \frac{1}{2}\sigma^2 t^2\right), \qquad K_X(t) = \mu t + \frac{1}{2}\sigma^2 t^2$$

    したがって、独立な $X_1 \sim N(\mu_1, \sigma_1^2),\; X_2 \sim N(\mu_2, \sigma_2^2)$ の和のキュムラント母関数は

    $$K_{X_1 + X_2}(t) = (\mu_1 + \mu_2)t + \frac{1}{2}(\sigma_1^2 + \sigma_2^2)t^2$$

    となり、一意性より **$X_1 + X_2 \sim N(\mu_1 + \mu_2,\; \sigma_1^2 + \sigma_2^2)$** が導かれます。

#### (3) マルコフの不等式・チェビシェフの不等式と大数の弱法則

次に、確率分布の具体的な形を一切仮定せずに成り立つ2つの不等式から、大数の法則を証明します。

> **【補題：マルコフの不等式】**
> 非負の確率変数 $Y \ge 0$（$E[Y] < \infty$）と任意の $a > 0$ に対して、次が成り立つ。
>
> $$P(Y \ge a) \le \frac{E[Y]}{a}$$

**【証明（連続型の場合）】**
$Y \ge 0$ なので、積分区間を $y \ge a$ に制限すると値は小さくなるか等しくなります。さらに $y \ge a$ の領域では $y \ge a$ を用いて下から抑えられます。

$$E[Y] = \int_0^\infty y\, f_Y(y)\,dy \ge \int_a^\infty y\, f_Y(y)\,dy \ge a \int_a^\infty f_Y(y)\,dy = a\, P(Y \ge a)$$

両辺を $a > 0$ で割れば得られます（離散型も和でまったく同様に証明できます）。（証明終）

この補題に非負の確率変数 $Y = (X - \mu)^2$ と $a = \varepsilon^2$ を代入すると、直ちにチェビシェフの不等式が導かれます。

> **【定理1：チェビシェフの不等式】**
> 平均 $\mu$、有限分散 $\sigma^2$ を持つ任意の確率変数 $X$ と任意の $\varepsilon > 0$ に対して、
>
> $$P\bigl(\vert X - \mu \vert \ge \varepsilon\bigr) = P\bigl((X - \mu)^2 \ge \varepsilon^2\bigr) \le \frac{E\bigl[(X - \mu)^2\bigr]}{\varepsilon^2} = \frac{\sigma^2}{\varepsilon^2}$$

チェビシェフの不等式は「どんな分布であっても、平均から $k\sigma$ 以上離れる確率は高々 $1/k^2$ 以下（例：$2\sigma$ 以上は $25\%$ 以下、$3\sigma$ 以上は $11.1\%$ 以下）」という普遍的な上界を与えます。そして、これを標本平均 $\bar{X}_n$ に適用すると大数の弱法則が1行で証明されます。

> **【定理2：大数の弱法則（Weak Law of Large Numbers）】**
> $X_1, X_2, \dots$ が互いに独立で同一の分布に従い（independent and identically distributed、略して **i.i.d.**）、平均 $\mu$、有限分散 $\sigma^2$ を持つとする。標本平均 $\bar{X}_n := \frac{1}{n}\sum_{i=1}^n X_i$ に対して、任意の $\varepsilon > 0$ で
>
> $$\lim_{n \to \infty} P\bigl(\vert \bar{X}_n - \mu \vert \ge \varepsilon\bigr) = 0$$

**【証明】**
$E[\bar{X}_n] = \mu$、独立性より $V[\bar{X}_n] = \frac{1}{n^2}\sum_{i=1}^n V[X_i] = \frac{\sigma^2}{n}$ です。チェビシェフの不等式より、

$$P\bigl(\vert \bar{X}_n - \mu \vert \ge \varepsilon\bigr) \le \frac{\sigma^2}{n\varepsilon^2} \xrightarrow{\;n \to \infty\;} 0$$

よって $\bar{X}_n$ は、$n$ を増やすほど $\mu$ から少しでも離れる確率が $0$ に近づくという意味で $\mu$ に収束します（**確率収束**）。（証明終）

*（注：より強く「ほとんど確実に $\bar{X}_n \to \mu$ となる」という**大数の強法則**も知られており、そちらは分散の有限性を仮定せず $E[\vert X \vert] < \infty$ だけで成り立ちます。ただし証明には測度論を要するため、本節では有限分散のもとで初等的に示せる大数の弱法則を扱いました。）*

#### (4) 中心極限定理（なぜ $\sqrt{n}$ で割ると正規分布になるのか）

大数の法則は $\bar{X}_n$ が $\mu$ に近づくことを示しますが、誤差 $\bar{X}_n - \mu$ の分布の形までは教えてくれません。実験Aで確認した通り、和の誤差 $S_n - n\mu$ の分散は $n\sigma^2$（標準偏差は $\sqrt{n}\,\sigma$）で大きくなるため、$\sqrt{n}\,\sigma$ で割って分散を常に $1$ に保った標準化統計量 $Z_n$ を考えます。

> **【定理3：中心極限定理（Central Limit Theorem）】**
> $X_1, X_2, \dots$ が i.i.d. で平均 $\mu$、有限分散 $\sigma^2 > 0$ を持つとき、標準化された和（標本平均）
>
> $$Z_n := \frac{S_n - n\mu}{\sigma\sqrt{n}} = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}}$$
>
> の分布は、$n \to \infty$ で標準正規分布 $N(0, 1)$ に収束する（任意の $z \in \mathbb{R}$ に対して累積分布関数が $\lim_{n \to \infty} P(Z_n \le z) = \Phi(z)$ を満たす**分布収束**。ここで $\Phi$ は $N(0, 1)$ の累積分布関数）。

**【証明のスケッチ（積率母関数が存在する場合）】**
各 $X_i$ を標準化した確率変数 $Y_i := \frac{X_i - \mu}{\sigma}$ を定義すると、$Y_1, \dots, Y_n$ は i.i.d. で $E[Y_i] = 0,\; V[Y_i] = 1$ を満たし、$Z_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$ と書けます。

$Y_i$ のキュムラント母関数 $K_Y(s) = \ln M_Y(s)$ は、$K_Y(0) = \ln 1 = 0$、$K_Y'(0) = E[Y_i] = 0$、$K_Y''(0) = V[Y_i] = 1$ を満たすため、$s = 0$ の周りで2次までテイラー展開すると、

$$K_Y(s) = 0 + 0 \cdot s + \frac{1}{2} \cdot 1 \cdot s^2 + o(s^2) = \frac{1}{2}s^2 + o(s^2) \qquad (s \to 0)$$

となります（$o(s^2)$ は $s \to 0$ で $s^2$ より速く $0$ に収束する高次項）。

ここで、3(1)で示した定数倍の公式 $K_{Y_i/\sqrt{n}}(t) = K_Y(t/\sqrt{n})$ と独立和の和公式を使うと、$Z_n = \sum_{i=1}^n \frac{Y_i}{\sqrt{n}}$ のキュムラント母関数は、$s = t/\sqrt{n}$ として $n$ 個分足し合わせたものになります。

$$K_{Z_n}(t) = \sum_{i=1}^n K_Y\!\left(\frac{t}{\sqrt{n}}\right) = n \left(\frac{t^2}{2n} + \frac{\kappa_3}{6}\frac{t^3}{n^{3/2}} + o\!\left(\frac{1}{n^{3/2}}\right)\right) = \frac{1}{2}t^2 + \frac{\kappa_3}{6}\frac{t^3}{\sqrt{n}} + n \cdot o\!\left(\frac{1}{n^{3/2}}\right) \xrightarrow{\;n \to \infty\;} \frac{1}{2}t^2$$

2次の項 $\frac{t^2}{2n}$ に $n$ が掛かってちょうど $\frac{1}{2}t^2$ だけが生き残ります。一方、元の分布の歪み（歪度 $\kappa_3 = E[Y_i^3]$）を表す3次の項は $n \times n^{-3/2} = n^{-1/2} = 1/\sqrt{n}$ の速さで消え、尖り具合（尖度）などの4次以上の項（$O(n^{-1}), \dots$）もすべて $n \to \infty$ で消滅します。極限の $\frac{1}{2}t^2$ はまさに**標準正規分布 $N(0, 1)$ のキュムラント母関数**に一致します。

*（注：母関数の各点収束から確率分布の収束を結論づけるステップには、測度論・解析学の「レヴィの連続性定理」が必要になります。また、積率母関数が存在しない一般の有限分散分布でも、後述の特性関数 $\varphi(t) = E[e^{itX}]$ でまったく同じ2次のテイラー展開を行えば証明できます。本ノートではこの連続性定理を事実として認めます。）*

> **【コラム：標本平均は期待値に収束するのに、和のズレは $\sqrt{n}$ で広がっていく仕組み】**
>
> 大数の法則を初めて学ぶとき、「コインをたくさん投げれば、表と裏の回数の差はやがて0に近づいていく（帳尻が合う）」と誤解されることがあります（いわゆる**ギャンブラーの誤謬**の一種です）。しかし、実験Aの数式が示す事実はまったく逆です。
>
> 公正なコインを $n$ 回投げたとき、表の回数 $S_n$ と期待値 $0.5n$ のズレ $\vert S_n - 0.5n \vert$ の典型的な大きさ（標準偏差）は **$0.5\sqrt{n}$** です。
>
> * $n = 100$ 回ならズレは約 $5$ 回（割合では $5/100 = 5\%$）。
> * $n = 10{,}000$ 回ならズレは約 $50$ 回（割合では $50/10{,}000 = 0.5\%$）。
> * $n = 1{,}000{,}000$ 回ならズレは約 $500$ 回（割合では $500/1{,}000{,}000 = 0.05\%$）。
>
> つまり、**回数の差（絶対的なズレ）は $n$ が増えるほど $\sqrt{n}$ のペースでむしろ大きく広がっていきます**。標本平均 $\bar{X}_n = S_n / n$ が $0.5$ に収束するのは、ズレが打ち消されて小さくなるからではなく、**ズレの拡大ペース（$\sqrt{n}$）よりも分母の試行回数（$n$）が増えるペースの方が速く、比 $\sqrt{n}/n = 1/\sqrt{n}$ が $0$ へ潰れるから**なのです（図0-5-2）。この「和は $\sqrt{n}$ で広がり、平均は $1/\sqrt{n}$ で狭まる」という2つのスケーリングは、時間とともにランダムに変動する現象を解析する際の基本構造になります。

### 4. 限界と補正（Critique & Adaptation）

積率母関数と2つの極限定理は確率論の柱ですが、実務データや複雑な分布へ適用する際には次の2つの限界に注意する必要があります。

#### (1) 積率母関数が存在しない分布と、特性関数による回避

積率母関数 $M_X(t) = E[e^{tX}]$ は、分布の裾が指数関数 $e^{-cx}$ 以上の速さで減衰する場合にしか $t > 0$ で収束しません。前節（0-4節）で扱った**対数正規分布**では、$x \to \infty$ のとき密度の減衰 $e^{-(\ln x)^2/(2\sigma^2)}$ よりも $e^{tx}$ の増加の方がはるかに速いため、**任意の $t > 0$ で $M_X(t) = +\infty$ となり積率母関数が存在しません**（同様にコーシー分布のように裾がべき乗で緩やかに減衰する分布でも存在しません）。

この数学的限界を回避するのが、実数 $t$ を純虚数 $it$（$i = \sqrt{-1}$）に置き換えた**特性関数（Characteristic function）**です。

$$\varphi_X(t) := E\bigl[e^{itX}\bigr] = E\bigl[\cos(tX)\bigr] + i\, E\bigl[\sin(tX)\bigr] \qquad (t \in \mathbb{R})$$

オイラーの公式 $e^{i\theta} = \cos\theta + i\sin\theta$ より任意の実数 $t, x$ に対して $\vert e^{itX} \vert = \sqrt{\cos^2(tX) + \sin^2(tX)} = 1$ が成り立つため、積分 $\int \vert e^{itx} \vert f(x)\,dx = 1$ は**すべての確率分布（期待値が存在しないコーシー分布を含めて）に対して常に有限値として存在**します。独立和の積公式 $\varphi_{X+Y}(t) = \varphi_X(t)\varphi_Y(t)$ や一意性も積率母関数と同様に成り立ちます。

#### (2) 大数の法則・中心極限定理が成り立たない条件と、有限標本での注意

大数の法則と中心極限定理は強力な定理ですが、前提条件（①独立性、②有限の平均・分散、③十分な標本サイズ［データ数］$n$）が破れると機能しません。

1. **分散・平均が無限大の分布：** 0-4節で見たコーシー分布では期待値が存在しないため、大数の法則自体が成り立ちません。実際、独立なコーシー分布の標本平均 $\bar{X}_n$ は何万個足しても元のコーシー分布とまったく同じ分布のままであり、1点に収束しません。

2. **独立性が崩れている場合（共通要因による相関）：** すべての確率変数 $X_1, \dots, X_n$ が共通のショック（たとえば全国的な景気悪化や広域災害）の影響を受けて一定の正の共分散 $\operatorname{Cov}(X_i, X_j) = c > 0$（$i \neq j$）を持つ場合、和の分散に $n(n-1)$ 個の共分散項が加わります。その結果、

    $$V[\bar{X}_n] = \frac{1}{n^2}\bigl(n\sigma^2 + n(n - 1)c\bigr) = \frac{\sigma^2}{n} + \frac{n - 1}{n}c \xrightarrow{\;n \to \infty\;} c > 0$$

    となり、$n$ をどれだけ増やしても標本平均の分散は $0$ に下がらず、共通要因によるばらつき $c$ が残ります。

3. **強い歪みがある分布での有限 $n$ の近似誤差：** 中心極限定理はあくまで $n \to \infty$ の極限の定理です。元の分布が大きく右に歪んでいる場合（まれに大きな値が起きる分布など）、$n = 30$ や $n = 100$ 程度では正規近似の精度がまだ低く、特に分布の裾（確率 $1\%$ や $0.1\%$ の領域）を過小評価しやすくなります。

### 5. 接続と展望（Bridge）：本節の内容が後半のどの部に繋がるか

1. **次節（0-6節：点推定と標本分布［最尤推定・$\chi^2$・$t$・$F$ 分布］、および 0-7節：区間推定と仮説検定）：**
    本節の中心極限定理によって「標本平均 $\bar{X}_n$ が正規分布に近づく」ことが保証されたため、次節以降では手元の限られたデータから未知の母数を推定する仕組み（0-6節）と、その誤差範囲（信頼区間）や仮説の検証（仮説検定、0-7節）を組み立てることができます。

2. **第7部（7-5節：生命保険の収支相等の原則）：**
    多数の独立な契約を集めることで1件あたりの平均支払額が理論上の期待値へ収束する大数の法則が、保険制度の基本原理を支えています。

3. **第8部（8-3・8-7節：複合ポアソン分布と破産確率）：**
    損害保険のクレーム総額 $S = \sum_{i=1}^N X_i$ の分布の解析と再生性の証明には本節の**積率母関数**が使われ、さらにクラメール＝ルンドベリ（Lundberg）モデルの破産確率上界 $\psi(u) \le e^{-Ru}$ における調整係数 $R$ も、積率母関数の方程式から定義されます（そして対数正規分布やパレート分布で積率母関数が存在しないことが、重尾リスクの限界として現れます）。

4. **第9部（9-9節：ランダムウォークからブラウン運動へ）：**
    本節のコラムで確認した「独立なステップの和の標準偏差が $\sqrt{n}$ に比例して広がる」という性質が、時間幅を極限に飛ばしたときの標準ブラウン運動の分散 $V[W_t] = t$（標準偏差 $\sqrt{t}$）へそのまま繋がります。
