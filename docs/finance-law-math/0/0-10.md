### 前節（0-9）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3がそのまま本節（モンテカルロ・シミュレーションとブートストラップ法）の導入になります。

1. **ラグランジュ乗数法と包絡線定理の確認：**
    制約 $g(x, y) = 2x + y - 12 = 0$ のもとで $f(x, y) = xy$ を最大化します。ラグランジュ関数 $\mathcal{L}(x, y, \lambda) = xy - \lambda(2x + y - 12)$ の偏微分を $0$ とおくと、

    $$\frac{\partial \mathcal{L}}{\partial x} = y - 2\lambda = 0, \qquad \frac{\partial \mathcal{L}}{\partial y} = x - \lambda = 0$$

    より $y = 2\lambda,\; x = \lambda$（よって $y = 2x$）が得られます。制約式 $2x + y = 12$ に代入すると $2x + 2x = 12 \implies \mathbf{x^* = 3,\; y^* = 6}$、最大値は $f(3, 6) = \mathbf{18}$、ラグランジュ乗数は $\mathbf{\lambda = 3}$ です。

    また、制約の右辺を一般の定数 $c > 0$（$2x + y = c$）に変えると、同様に $x^* = c/4,\; y^* = c/2$ より最大値は $f^*(c) = \frac{c^2}{8}$ となります。これを $c$ で微分すると $\frac{df^*}{dc} = \frac{c}{4}$ であり、$c = 12$ を代入すると $\frac{df^*}{dc}(12) = \frac{12}{4} = \mathbf{3} = \lambda$ となり、包絡線定理が成り立つことが確かめられます。

2. **KKT条件による不等式制約付き最小化：**
    まず制約を無視して $f(x, y) = (x - 2)^2 + (y - 3)^2$ を最小にする点を調べると $(x, y) = (2, 3)$ です。ところが $2 + 3 = 5 > 3$ となり不等式制約 $h(x, y) = x + y - 3 \le 0$ を満たしません。したがって最適解は境界上（$x + y = 3$、乗数 $\mu \ge 0$）に存在します。
    停留条件 $\nabla f + \mu \nabla h = \mathbf{0}$ より、

    $$\begin{cases} 2(x - 2) + \mu = 0 \\ 2(y - 3) + \mu = 0 \end{cases}$$

    2式から $\mu$ を消去すると $x - 2 = y - 3 \implies y = x + 1$。境界条件 $x + y = 3$ に代入すると $2x + 1 = 3 \implies \mathbf{x^* = 1,\; y^* = 2}$、そのときの乗数は $\mu = -2(1 - 2) = \mathbf{2} \ge 0$（符号条件も満たす）、最小値は $f(1, 2) = (-1)^2 + (-1)^2 = \mathbf{2}$ となります。

3. **解析解が求まらない期待値・積分をどう計算するか（本節への接続）：**
    解析的に積分が計算できない期待値 $E[g(X)]$ に対しては、確率変数 $X$ に従う乱数をコンピュータ上で大量に発生させ、その標本平均 $\frac{1}{N}\sum_{i=1}^N g(X_i)$ によって近似する**モンテカルロ法**を用います。大数の法則によって $N \to \infty$ で真の期待値への収束が保証されます。

## 0-10. モンテカルロ・シミュレーションとブートストラップ法

### 1. 動機（Why）：数式で解けない問題を「乱数」と「繰り返し抽出」で評価する

これまでの節では、等比数列の和、正規分布の積分、最小二乗法の正規方程式、ラグランジュ乗数法など、紙と鉛筆で厳密な数式（解析解）を導出できる問題を扱ってきました。

しかし、実際のデータ分析や複雑な現象の評価では、次の2つの壁に頻繁に突き当たります。

**壁①：期待値の積分が解析的に計算できない**
たとえば「将来の売上や金利・為替が複数絡み合う事業計画で、10年後に赤字になる確率を見積もりたい」「途中で上限・下限に当たったら契約が終了する商品の期待価値を求めたい」といった場面では、期待値 $\theta = E[g(X)] = \int g(x) f(x)\,dx$ に複雑な条件分岐や多数の変数が絡み、初等関数で厳密解を書き下すことはできなくなります。そこで、0-5節の**大数の法則**を逆手にとり、「分布 $f$ に従う乱数を大量に作って平均をとる」ことで積分値を数値的に求めるのが**モンテカルロ法**です。

**壁②：複雑な統計量の標準誤差や信頼区間を、分布の仮定なしで知りたい**
0-7節では「標本平均 $\bar{X}$」の信頼区間を $t$ 分布から求めました。しかし、「アンケートの所要時間の中央値」や「少数データから計算した相関係数」に誤差の幅を添えたいとき、データが正規分布に従うとは限らず、綺麗な公式も存在しません。そこで、「手元のデータ自身を母集団の縮小コピーとみなして何度も引き直す」ことで不確実性を見積もるのが**ブートストラップ法**です。

第0部の最終節として、コンピュータを用いたこの2つの数値的アプローチの原理と限界を整理します。

### 2. 具体例と計算イメージ（Toy Model）

厳密な定義に入る前に、手計算でも仕組みが追える2つの具体例を確認します。

#### 実験A：ダーツ投げによる円周率 $\pi$ の推定（モンテカルロ法）

1辺の長さが $1$ の正方形 $[0, 1] \times [0, 1]$ の中に、原点を中心とする半径 $1$ の四分円（$x^2 + y^2 \le 1$）を描きます。正方形の面積は $1$、四分円の面積は $\pi/4$ です。

この正方形の中に、独立な一様乱数のペア $(U_i, V_i)$（各 $U(0, 1)$）を $N$ 回ランダムに打ち込みます。点 $(U_i, V_i)$ が四分円の内側に入れば $X_i = 4$、外側なら $X_i = 0$ と記録します。すると $X_i$ の期待値は、

$$E[X_i] = 4 \cdot P(U_i^2 + V_i^2 \le 1) + 0 \cdot P(U_i^2 + V_i^2 > 1) = 4 \cdot \frac{\pi}{4} = \pi$$

となり、$N$ 回の標本平均 $\hat{\pi}_N = \frac{1}{N}\sum_{i=1}^N X_i$ は大数の法則によって $\pi$ に収束します（図0-10-1）。

ここで誤差の大きさを確認します。$X_i / 4$ は成功確率 $p = \pi/4 \approx 0.7854$ のベルヌーイ分布なので、$X_i$ の分散は $V[X_i] = 16 p(1 - p) = \pi(4 - \pi) \approx 2.6968$、標準偏差は $\sigma = \sqrt{2.6968} \approx 1.6422$ です。中心極限定理より、$N$ 回試行したときの標準誤差は $\sigma / \sqrt{N}$ となります。

| 試行回数 $N$ | 標準誤差 $\sigma / \sqrt{N}$ | $95\%$ 誤差幅（$\pm 1.96\sigma / \sqrt{N}$） | 精度の目安 |
| :---: | :---: | :---: | :--- |
| $100$ 回 | $0.1642$ | $\pm 0.3219$ | 小数第1位も安定しない |
| $10{,}000$ 回 | $0.0164$ | $\pm 0.0322$ | 誤差を1/10にするのに試行は100倍 |
| $1{,}000{,}000$ 回 | $0.0016$ | $\pm 0.0032$ | 100万回投げてようやく小数第2位付近 |

どんな複雑な図形の面積や積分であっても、「ランダムに点を打って平均をとる」だけで計算できるのがモンテカルロ法の強みです。同時に、精度を1桁（$10$ 倍）良くするには試行回数が **$100$ 倍** 必要になるという収束の遅さ（$O(1/\sqrt{N})$）もこの表から読み取れます。

#### 実験B：5個のデータから中央値のぶれを測る（ブートストラップ法）

ある作業の所要時間（分）を5回測定したところ、次のデータが得られたとします。

$$\{12,\; 15,\; 18,\; 20,\; 45\}$$

$45$ 分という外れ値が含まれているため、代表値として平均（$22$ 分）ではなく**中央値（$18$ 分）**を採用しました。ここで、「もしもう一度5回の測定をやり直したら、中央値 $18$ 分はどれくらいぶれるのか（標準誤差）」を知りたいとします。

母集団の分布は分かりませんが、手元の5個のデータから**同じものを何度選んでもよい（引いたら箱へ戻す：復元抽出）**ルールで5個ずつランダムに引き直し、疑似標本（ブートストラップ標本）を作ってみます。

* 1回目の引き直し：$\{15,\; 15,\; 18,\; 20,\; 45\}$ $\implies$ 中央値 **$18$**
* 2回目の引き直し：$\{12,\; 12,\; 15,\; 18,\; 20\}$ $\implies$ 中央値 **$15$**
* 3回目の引き直し：$\{18,\; 20,\; 20,\; 45,\; 45\}$ $\implies$ 中央値 **$20$**

これを $B = 1{,}000$ 回や $10{,}000$ 回繰り返し、得られた $B$ 個の中央値の標準偏差を計算すれば、それが中央値の標準誤差の推定値になります。

ここで、**「なぜ非復元抽出（一度引いた値を戻さない引き方）ではダメなのか」**は明らかです。5個のデータから非復元で5個引き直すと、順番が違うだけで毎回まったく同じ集合 $\{12, 15, 18, 20, 45\}$ しか得られず、中央値が毎回 $18$ になってばらつきが $0$ になってしまうからです。重複を許す復元抽出だからこそ、手元の標本から生じ得るぶれを再現できます（図0-10-2右）。

import math
import random
import statistics

# 実験A：モンテカルロ法による円周率 pi の推定（N = 10,000）
random.seed(42)
N = 10_000
hits = sum(1 for _ in range(N) if random.random() ** 2 + random.random() ** 2 <= 1.0)
pi_hat = 4.0 * hits / N
se_theory = math.sqrt(math.pi * (4.0 - math.pi) / N)
print(f"pi_hat (N={N}) = {pi_hat:.4f}  (理論SE = {se_theory:.4f})")

# 実験B：元データ {12, 15, 18, 20, 45} の中央値ブートストラップ（B = 10,000）
data = [12, 15, 18, 20, 45]
B = 10_000
boot_meds = sorted(statistics.median(random.choices(data, k=len(data))) for _ in range(B))
se_boot = statistics.stdev(boot_meds)
ci_low, ci_high = boot_meds[int(0.025 * B)], boot_meds[int(0.975 * B) - 1]
print(f"中央値 = {statistics.median(data)}, ブートストラップSE = {se_boot:.2f}, 95%CI = [{ci_low}, {ci_high}]")

### 3. 定義・導出・構造（What）

#### (1) 逆関数法による乱数生成の証明

コンピュータの基本機能で生成できるのは区間 $[0, 1]$ の一様乱数 $U \sim U(0, 1)$ です。そこから任意の確率分布（累積分布関数 $F$）に従う乱数 $X$ を作り出す最も基本的な方法が**逆関数法（Inverse Transform Sampling）**です。

> **【定理1：逆関数法】**
> 累積分布関数 $F(x)$ が連続かつ狭義単調増加であるとする。一様乱数 $U \sim U(0, 1)$ に対して $X := F^{-1}(U)$ と定義すると、$X$ は累積分布関数 $F$ に従う。

**【証明】**
$F$ は狭義単調増加なので、任意の実数 $x$ に対して $F^{-1}(u) \le x \iff u \le F(x)$ が成り立ちます。また $U \sim U(0, 1)$ より任意の $p \in [0, 1]$ に対して $P(U \le p) = p$ です。したがって、

$$P(X \le x) = P\bigl(F^{-1}(U) \le x\bigr) = P\bigl(U \le F(x)\bigr) = F(x)$$

となり、$X$ の累積分布関数は $F(x)$ に厳密に一致します。（証明終）

* **具体例（指数分布 $\mathrm{Exp}(\lambda)$ の乱数生成）：**
    累積分布関数は $F(x) = 1 - e^{-\lambda x}$（$x \ge 0$）です。$u = 1 - e^{-\lambda x}$ を $x$ について解くと $e^{-\lambda x} = 1 - u \implies x = -\frac{1}{\lambda}\ln(1 - u)$ となります。よって一様乱数 $U$ から $X = -\frac{1}{\lambda}\ln(1 - U)$ を計算すれば厳密な指数乱数が得られます（さらに $1 - U$ も同じ $U(0, 1)$ に従うため、実務では $-\frac{1}{\lambda}\ln U$ でも同じ分布になります）。

* **離散分布や不連続点がある場合：**
    一般化逆関数 $F^{-1}(u) := \inf\{x \mid F(x) \ge u\}$（記号 $\inf$ は条件を満たす最小の値［下限］を表します）を用います。たとえば離散分布で $P(X = x_1) = p_1,\; P(X = x_2) = p_2, \dots$ のときは、区間 $[0, 1]$ を長さ $p_1, p_2, \dots$ の小区間に分割し、$U$ が落ちた小区間に対応する $x_k$ を出力します。

* **逆関数が初等関数で書けない場合（ボックス＝ミュラー法）：**
    標準正規分布 $N(0, 1)$ の累積分布関数 $\Phi(x)$ の逆関数は初等関数で表せません。そこで0-4節のガウス積分で用いた2次元の極座標変換 $(Z_1, Z_2) = (R\cos\Theta, R\sin\Theta)$ を逆に使います。独立な標準正規変数のペア $(Z_1, Z_2)$ の同時密度 $\frac{1}{2\pi}e^{-(z_1^2+z_2^2)/2}$ を極座標で書くと（$s = r^2$ とおくと $r\,dr = \frac{1}{2}\,ds$ より同時密度が $\frac{1}{2}e^{-s/2}\,ds \cdot \frac{1}{2\pi}\,d\theta$ に分離するため）、半径の2乗 $R^2 = Z_1^2 + Z_2^2$ は指数分布 $\mathrm{Exp}(1/2)$ に従い、角度 $\Theta$ は一様分布 $U(0, 2\pi)$ に独立に従います。したがって2つの独立な一様乱数 $U_1, U_2 \sim U(0, 1)$ から逆関数法で $R = \sqrt{-2\ln U_1}$、$\Theta = 2\pi U_2$ を作れば、独立な標準正規乱数のペア

    $$Z_1 = \sqrt{-2\ln U_1}\cos(2\pi U_2), \qquad Z_2 = \sqrt{-2\ln U_1}\sin(2\pi U_2)$$

    が厳密に生成できます（**ボックス＝ミュラー法**）。

#### (2) モンテカルロ法の収束速度と必要試行回数の見積り

目的の期待値を $\theta := E[g(X)]$ とし、$X_1, X_2, \dots, X_N$ を独立に生成して計算したモンテカルロ推定量を

$$\hat{\theta}_N := \frac{1}{N} \sum_{i=1}^N g(X_i)$$

と定義します。$\sigma_g^2 := V[g(X)] < \infty$ とすると、0-5節の2つの極限定理から次の性質が直ちに従います。

1. **不偏性と一致性：** $E[\hat{\theta}_N] = \theta$ であり、大数の弱法則より $N \to \infty$ で $\hat{\theta}_N \to \theta$（確率収束）。
2. **誤差の分布と収束速度：** $V[\hat{\theta}_N] = \frac{\sigma_g^2}{N}$ より、標準誤差は $\mathrm{SE}(\hat{\theta}_N) = \frac{\sigma_g}{\sqrt{N}} = O(N^{-1/2})$。さらに中心極限定理より、$N$ が十分大きいとき $\hat{\theta}_N \approx N(\theta,\; \sigma_g^2 / N)$ となります。

したがって、**「信頼度 $95\%$（$z_{0.025} \approx 1.96$）のもとで推定誤差を許容幅 $\varepsilon$ 以内に抑えたい」**ときに必要な試行回数 $N$ は、

$$1.96 \cdot \frac{\sigma_g}{\sqrt{N}} \le \varepsilon \quad \Longleftrightarrow \quad N \ge \left(\frac{1.96\,\sigma_g}{\varepsilon}\right)^2$$

と見積もることができます（実際には未知の $\sigma_g$ の代わりに、少数の予備シミュレーションで求めた標本標準偏差 $s_g$ を代入して必要回数を見積もります）。

#### (3) ブートストラップ法（Bootstrap Method）の手順

母集団の分布 $F$ が未知で、手元にサイズ $n$ の観測標本 $\mathcal{D} = \{x_1, x_2, \dots, x_n\}$ だけがある状況を考えます。データから計算したい任意の統計量（中央値、分位点、相関係数、回帰係数など）を $\hat{\theta} = T(x_1, \dots, x_n)$ とします。

ブートストラップ法では、手元の標本 $\mathcal{D}$ に各点 $1/n$ の確率を置いた離散分布（**経験分布** $\hat{F}_n$）を真の分布 $F$ の近似とみなし、次の手順を実行します。

1. 元の標本 $\mathcal{D}$ から**復元抽出**でサイズ $n$ の疑似標本 $\mathcal{D}^{*(b)} = \{x_1^{*(b)}, \dots, x_n^{*(b)}\}$ を作ります。
2. その疑似標本から同じ統計量 $\hat{\theta}^{*(b)} = T(\mathcal{D}^{*(b)})$ を計算します。
3. ステップ1〜2を $B$ 回（通常 $B = 1{,}000 \sim 10{,}000$ 回）独立に繰り返し、$\hat{\theta}^{*(1)}, \dots, \hat{\theta}^{*(B)}$ を得ます。
4. 得られた $B$ 個の値の標本標準偏差を $\hat{\theta}$ の**ブートストラップ標準誤差**とし、下位 $2.5\%$ 点と上位 $2.5\%$ 点の区間を **$95\%$ ブートストラップ信頼区間（パーセンタイル法）** とします。

*（注：ブートストラップ法は手元の標本 $\mathcal{D}$ が母集団をよく代表していることを前提とします。標本サイズ $n$ が極端に小さい場合や、データの最大値のように経験分布の端が真の分布の端を捉えられない統計量、あるいは独立性が成り立たない時系列データにはそのまま適用できず、時系列用のブロック・ブートストラップなどの工夫が必要になります。）*

> **【コラム：高次元積分におけるモンテカルロ法の利点と、疑似乱数の再現性】**
>
> **1. なぜ高次元積分では格子積分よりモンテカルロ法が有利なのか：**
> 1次元の定積分 $\int_0^1 g(x)\,dx$ を台形公式などの格子分割で数値計算する場合、区間を $M$ 分割すると誤差は $O(M^{-2})$ で急速に減ります。1次元ではモンテカルロ法の $O(N^{-1/2})$ よりはるかに高速です。
>
> ところが、$d$ 個の変数が絡む $d$ 次元積分になると事情が一変します。各軸を $M$ 分割すると格子点の総数は $N = M^d$ 個に爆発します（**次元の呪い**）。総計算点数 $N$ を使って格子積分の誤差を書き直すと $M = N^{1/d}$ なので $O(N^{-2/d})$ となり、たとえば $d = 20$ 次元では $O(N^{-0.1})$ とほとんど収束しなくなります。一方、モンテカルロ法の誤差 $O(N^{-1/2})$ は**次元 $d$ に一切依存しません**。そのため、変数が概ね $5$ 次元を超える多重積分では、モンテカルロ法が標準的な数値計算手法になります。
>
> **2. コンピュータの「疑似乱数」と再現性の価値：**
> 通常のプログラムが生成する乱数は、サイコロのような物理現象ではなく、初期値（シード）から漸化式によって決定論的に計算される**疑似乱数**です。同じシードを与えれば何度実行してもまったく同じ乱数列が再現されます。これは科学計算や実務の検証において弱点ではなく、「他の担当者や監査人が同じシードでシミュレーションを再実行し、結果を再現・検証できる」という重要な利点になります。

### 4. 限界と補正（Critique & Adaptation）

モンテカルロ法の最大の弱点は、収束速度が $O(1/\sqrt{N})$ と遅く、精度を1桁上げるごとに計算量が100倍になる点です。そこで、試行回数 $N$ をむやみに増やす代わりに、**同じ計算コストのまま分子の分散 $\sigma_g^2$ を小さくする「分散低減法（Variance Reduction Techniques）」**が広く用いられます。

代表的な2つの手法を、積分 $\theta = \int_0^1 e^x\,dx = E[e^U] = e - 1 \approx 1.7183$（$U \sim U(0, 1)$）の計算例で検証します。通常のモンテカルロ法では、$g(U) = e^U$ の分散は $V[e^U] = E[e^{2U}] - (E[e^U])^2 = \frac{e^2 - 1}{2} - (e - 1)^2 \approx \mathbf{0.2420}$ です。

#### (1) 対称変量法（Antithetic Variates）の分散公式による検証

一様乱数 $U \sim U(0, 1)$ を1つ生成したとき、$1 - U$ も同じ $U(0, 1)$ に従います（標準正規乱数 $Z$ であれば $-Z$ を使います）。そこで、独立に2回引く代わりに、ペア $(U, 1 - U)$ の平均

$$Z := \frac{g(U) + g(1 - U)}{2}$$

を1つの標本とみなします。$E[Z] = \frac{E[g(U)] + E[g(1-U)]}{2} = \theta$ なので不偏性は保たれます。分散公式（0-3節）を展開すると、

$$V[Z] = \frac{1}{4}\Bigl(V[g(U)] + V[g(1 - U)] + 2\operatorname{Cov}\bigl(g(U),\, g(1 - U)\bigr)\Bigr) = \frac{\sigma_g^2}{2}\bigl(1 + \rho\bigr)$$

ここで $\rho := \rho\bigl(g(U), g(1 - U)\bigr)$ です。なお、$Z$ を1回計算するには $g$ を2回評価しているため、関数評価の総回数を同じ $N$ 回（$Z$ を $N/2$ ペア）に揃えて比較すると、推定量の分散は

$$V\bigl[\bar{Z}_{N/2}\bigr] = \frac{V[Z]}{N/2} = \frac{\sigma_g^2}{N}(1 + \rho)$$

となります。通常のモンテカルロ法の分散 $\frac{\sigma_g^2}{N}$ と比べて **$(1 + \rho)$ 倍** になります。したがって、$g$ が単調関数であれば $U$ が大きいほど $g(U)$ は大きく $g(1 - U)$ は小さくなるため負の相関（$\rho < 0$）を持ち、同じ計算コストで分散が減少します（逆に $g(u) = (u - 0.5)^2$ のように $0.5$ を軸に対称な関数では $g(1 - U) = g(U)$ で $\rho = +1$ となり逆効果になるため、単調な問題に適用します）。

上の例 $g(U) = e^U$ で実際に計算すると、$E[e^U e^{1-U}] = E[e] = e$ より $\operatorname{Cov}(e^U, e^{1-U}) = e - (e - 1)^2 \approx -0.2342$、相関係数は **$\rho \approx -0.9677$** となり、分散は $1 + \rho \approx 0.0323$ 倍（**約 $96.8\%$ 削減**、試行回数を約31倍に増やしたのと同じ精度向上）になります。

#### (2) 制御変量法（Control Variates）と0-8節（単回帰）との一致

目的の確率変数 $g(X)$ と強く相関しており、かつ**真の期待値 $\mu_Y = E[Y]$ があらかじめ分かっている**別の確率変数 $Y$（制御変量）を用意します。直感的には、重さを知りたい品物と一緒に「真の重さが正確に $1{,}000$ g と分かっている基準のおもり」を同じ体重計へ載せ、おもりの測定値のブレから体重計の誤差を差し引いて補正するイメージです（実務でも、複雑な条件が付いて解析解がない契約の価値 $g(X)$ を計算したいときに、同じ乱数で動く「条件の単純な類似契約」の価格 $Y$ を使います）。同じ乱数で $g(X)$ と $Y$ を同時に計算し、任意の定数 $c$ を用いて新しい推定量

$$W(c) := g(X) - c(Y - \mu_Y)$$

を作ります。$E[Y - \mu_Y] = 0$ なので、どんな $c$ を選んでも $E[W(c)] = E[g(X)] = \theta$（不偏）です。直感的には、「今回の乱数で $Y$ がたまたま真の平均 $\mu_Y$ より大きく上振れたなら、相関する $g(X)$ も同じ向きに上振れているはずなので、その分だけ差し引いて補正する」という仕組みです。

$W(c)$ の分散を $c$ の2次関数として展開します。

$$V[W(c)] = V[g(X)] - 2c\operatorname{Cov}\bigl(g(X), Y\bigr) + c^2 V[Y]$$

これを $c$ で微分して $0$ とおくと、分散を最小化する最適係数 $c^*$ とそのときの最小分散が求まります。

$$c^* = \frac{\operatorname{Cov}\bigl(g(X), Y\bigr)}{V[Y]}, \qquad V[W(c^*)] = V[g(X)]\bigl(1 - \rho_{g,Y}^2\bigr)$$

ここで注目すべきは、**最適係数 $c^* = \frac{\operatorname{Cov}(g(X), Y)}{V[Y]}$ は0-8節で導出した単回帰分析の傾き $\hat{\beta}_1$ と同じ式であり、分散の削減率 $\rho_{g,Y}^2$ は単回帰の決定係数 $R^2$ と一致する**という点です。$Y$ で説明できる線形変動を取り除き、残差の分散だけを残す操作に他なりません。

上の例 $g(U) = e^U$ に対し、最も単純な制御変量 $Y = U$（$\mu_Y = 1/2,\; V[Y] = 1/12$ が既知）を用いると、部分積分より $E[U e^U] = 1$ なので $\operatorname{Cov}(e^U, U) = 1 - \frac{e - 1}{2} \approx 0.1409$、最適係数は $c^* \approx 1.6903$、相関係数は $\rho \approx 0.9918$（$\rho^2 \approx 0.9837$）となり、分散は $1 - \rho^2 \approx 0.0163$ 倍（**約 $98.4\%$ 削減**）まで大きく縮小します。

### 5. 接続と展望（Bridge）：第0部の総括と第1部以降への接続

これで第0部「数理の基礎（0-1節〜0-10節）」がすべて揃いました。本節および第0部全体で整備した道具は、第1部以降で次のように使われます。

1. **次部（第1部 1-1節：消費者行動と市場均衡［ミクロ経済学］）：**
