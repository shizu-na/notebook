### 前節（8-5）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（支払備金とロスディベロップメント）の導入になります。

1. **ボーナス・マルス制度の定常分布と長期平均料率：**

    無事故確率 $p_0 = 0.60$（事故あり確率 $0.40$）の契約者グループについて、定常分布の均衡式 $\mathbf{\pi} P = \mathbf{\pi}$ を解きます。

    * **(a) 定常分布 $(\pi_1, \pi_2, \pi_3)$：**

        * 第3列より：$\pi_3 = 0.40(\pi_1 + \pi_2 + \pi_3) = \mathbf{0.40}$
        * 第2列より：$\pi_2 = 0.60\,\pi_3 = 0.60 \times 0.40 = \mathbf{0.24}$
        * 第1列より：$\pi_1 = 1 - 0.40 - 0.24 = \mathbf{0.36}$

        （検算：$0.60\,\pi_1 + 0.60\,\pi_2 = 0.60(0.36 + 0.24) = 0.36$ で一致します。）

    * **(b) 長期的な平均料率水準：**

        $$0.36 \times 70\% + 0.24 \times 100\% + 0.40 \times 140\% = 25.2\% + 24.0\% + 56.0\% = \mathbf{105.2\%}$$

2. **Bühlmann 信頼性モデルによる保険料の更新：**

    集団平均 $\mu = 10$ 万円、プロセス分散の期待値 $v = 160$、仮説平均の分散 $a = 40$ より、構造パラメータは $k = \frac{v}{a} = \frac{160}{40} = \mathbf{4}$ です。

    * **(a) 観測年数 $n = 4$ 年間の場合：**

        $$Z = \frac{4}{4 + 4} = \mathbf{0.50}, \qquad \hat{\mu}_{\mathrm{B}} = 0.50 \times 18 + 0.50 \times 10 = \mathbf{14 \text{ 万円}}$$

    * **(b) 観測年数 $n = 12$ 年間の場合：**

        $$Z = \frac{12}{12 + 4} = \mathbf{0.75}, \qquad \hat{\mu}_{\mathrm{B}} = 0.75 \times 18 + 0.25 \times 10 = 13.5 + 2.5 = \mathbf{16 \text{ 万円}}$$

        同じ年平均実績 $18$ 万円でも、観測年数が $4$ 年から $12$ 年へ増えることで信頼性係数 $Z$ が $0.50 \to 0.75$ へ上がり、予測保険料が個人実績側へ近づきます。

3. **決算日時点で「まだ金額が確定していない事故」をどう見積もるか（本節への接続）：**

    損害保険では、事故が発生してから保険金の支払いが完全に終わるまでに数か月から数年の遅れが生じます。そこで決算日時点では、すでに発生した事故に伴う将来の支払見込額を負債として**支払備金**（普通支払備金と IBNR 備金）に積み立てます。過去の支払いの進展パターンを表にまとめた**ランオフ三角形**からこの金額を推計するのが、**チェインラダー法**や**ボーンヒュッター＝ファーガソン法**です。

## 8-6. 支払備金とロスディベロップメント

### 1. 動機（Why）：なぜ損害保険会社は「まだ報告も来ていない事故」の負債を計上するのか

8-4節と8-5節では、将来の事故に備えて「いくら保険料を集めるか（料率算定）」の仕組みを整理しました。本節では視点を決算（財務会計とリスク管理）へ移し、損害保険会社の貸借対照表（BS）で最大の負債項目となる**支払備金（しはらいびきん：Loss Reserve）**の推計数理を扱います。

第2部（2-5節）で学んだ通り、企業会計では現金の出入りではなく経済的事実の発生時点で収益と費用を認識する**発生主義**が原則です。損害保険会社が「今年度の保険料」を収益として計上するなら、その保険期間内に発生した事故の保険金は、現金の支払いが翌年度以降になったとしても「今年度の費用（負債）」として計上しなければなりません。

ところが損害保険の現場では、事故が発生してから保険金支払いが完了するまでに、次の2段階のタイムラグが生じます。

1. **報告の遅れ（事故発生 $\to$ 保険会社への連絡）：** 3月末の決算日直前に起きた事故や、工場の環境汚染・製造物責任（PL）のように時間が経ってから被害が発覚する事故では、決算日時点でまだ保険会社へ報告が届いていません。
2. **解決の遅れ（報告 $\to$ 最終的な支払完了）：** 自動車の人身事故や賠償責任訴訟では、怪我の治療、後遺障害の等級認定、示談交渉や裁判を経て最終的な賠償額が確定するまで、数年にわたって支払いが続きます。

この「時間とともに支払額が膨らみ、最終額へ近づいていく過程」を**ロス・ディベロップメント（損害の進展）**と呼びます。本節では、支払備金の2つの区分（普通支払備金・IBNR備金）を整理したうえで、進展データを表にした**ランオフ三角形**から将来の支払額を推計する**チェインラダー法**と**ボーンヒュッター＝ファーガソン（BF）法**、さらに推定の不確実性を測る**マック（Mack）モデル**の考え方を順に確認します。

### 2. 具体例と計算イメージ（Toy Model）

一般的な数式に入る前に、3年間で支払いが完了する小さな架空のデータを使って、**チェインラダー法**と**ボーンヒュッター＝ファーガソン（BF）法**の計算手順と両者の違いを手計算で確認します。

#### 実験A：3×3のランオフ三角形（チェインラダー法 vs BF法）

ある保険種目について、過去3年間（事故年度 $1, 2, 3$）に発生した事故の**累積支払保険金額**（単位：億円）が、事故発生からの経過年数（**進展年度** $1, 2, 3$）ごとに次のように観測されたとします。3年目の終わりにはすべての支払いが完了するものとします。

| 事故年度 $i$ ＼ 進展年度 $j$ | 進展1年目（$j = 1$） | 進展2年目（$j = 2$） | 進展3年目（$j = 3$：終局） |
| --- | :---: | :---: | :---: |
| **事故年度1** | $100$ | $150$ | $180$ |
| **事故年度2** | $120$ | $180$ | *（未知：$C_{2,3}$）* |
| **事故年度3（当期）** | $150$ | *（未知：$C_{3,2}$）* | *（未知：$C_{3,3}$）* |

決算日時点（現在）で分かっているのは表の左上半分（三角形の部分）だけです。右下の空白（将来の支払分）を埋めて、今後支払うべき**支払備金**を見積もります。

**1. チェインラダー法による推計：**

過去の年度で「1年目から2年目へ何倍に膨らんだか」「2年目から3年目へ何倍に膨らんだか」という倍率（**進展係数**）を、観測済みの全年度の合計比率で計算します。

* 1年目 $\to$ 2年目の進展係数：$\hat{f}_1 = \dfrac{150 + 180}{100 + 120} = \dfrac{330}{220} = \mathbf{1.50}$
* 2年目 $\to$ 3年目の進展係数：$\hat{f}_2 = \dfrac{180}{150} = \mathbf{1.20}$

この倍率を右下の空白へ掛け合わせて、各事故年度の最終的な支払総額（**終局損害額**）を予測します。

* **事故年度2（現在 $180$ 億円支払済）：**

    終局損害額 $\hat{C}_{2,3}^{\mathrm{CL}} = 180 \times 1.20 = \mathbf{216 \text{ 億円}}$ $\implies$ 必要な支払備金 $= 216 - 180 = \mathbf{36 \text{ 億円}}$

* **事故年度3（現在 $150$ 億円支払済）：**

    1年目から3年目までの通算倍率（累積進展係数）は $F_3 = 1.50 \times 1.20 = \mathbf{1.80}$ なので、

    終局損害額 $\hat{C}_{3,3}^{\mathrm{CL}} = 150 \times 1.80 = \mathbf{270 \text{ 億円}}$ $\implies$ 必要な支払備金 $= 270 - 150 = \mathbf{120 \text{ 億円}}$

* **チェインラダー法による支払備金合計：** $36 + 120 = \mathbf{156 \text{ 億円}}$

**2. ボーンヒュッター＝ファーガソン（BF）法による推計（事故年度3の例）：**

ここで、事故年度3（当期）の**既経過保険料**（保険期間のうち決算日までにすでに経過した期間に対応する保険料収入）が $300$ 億円であり、当初の料率算定で想定していた予定損害率が $75\%$（つまり**事前の終局損害見積額 $U_3^{\text{prior}} = 300 \times 75\% = \mathbf{225 \text{ 億円}}$**）だったとします。

チェインラダー法では、事故年度3の1年目の支払いがたまたま $150$ 億円と多めだったため、それに $1.80$ 倍をそのまま掛けて終局損害額を $270$ 億円と大きく見積もりました。これに対し **BF法** では、「1年目の時点で終局額の $\frac{1}{1.80} = \frac{5}{9}$（約 $55.6\%$）が支払済みであり、残りの未払割合は $1 - \frac{5}{9} = \frac{4}{9}$（約 $44.4\%$）である」と解釈します。そのうえで、**今後の未払分を「事前の見積額 $225$ 億円 $\times$ 未払割合 $\frac{4}{9}$」で見積もります**。

* 事故年度3の BF法支払備金：$\hat{R}_3^{\mathrm{BF}} = 225 \times \left(1 - \dfrac{1}{1.80}\right) = 225 \times \dfrac{4}{9} = \mathbf{100 \text{ 億円}}$
* 事故年度3の BF法終局損害額：$\hat{C}_{3,3}^{\mathrm{BF}} = 150 + 100 = \mathbf{250 \text{ 億円}}$

チェインラダー法の $270$ 億円と事前見積 $225$ 億円のちょうど間（$250$ 億円）に落ち着き、直近年度の一時的な支払増に振り回されにくい安定した見積もりになります（図8-6-1右）。

### 3. 定義・導出・構造（What）

#### (1) 支払備金の2区分（普通支払備金と IBNR 備金）

損害保険会社の決算で計上する支払備金は、決算日時点で「事故の報告が届いているかどうか」によって2つに分かれます（図8-6-1右）。

1. **普通支払備金（既報告未払備金：OS［Outstanding Claims］／RBNS）：**

    決算日までにすでに事故の報告を受けているものの、治療中や示談交渉中のためまだ支払いが完了していない案件に対する備金です。通常は損害調査担当者が1件ごとに「この事故は最終的にいくらになりそうか」を個別に見積もって積み上げます（**ケース・リザーブ**）。

2. **IBNR 備金（既発生未報告備金：Incurred But Not Reported）：**

    決算日までに**すでに事故は発生しているものの、まだ保険会社へ報告が届いていない**案件に対する備金です。個別の案件が見えないため、過去の統計データ（ランオフ三角形）から集団全体として数理的に推計します。

    （※実務では、すでに報告されている案件でも将来に症状悪化や訴訟長期化で当初の見積額より膨らむ部分［**IBNER**：既発生既報告だが積立不足分］も含めて、ランオフ三角形の統計モデルで一括して見積もることが一般的です。）

#### (2) ランオフ三角形とチェインラダー法の定式化

事故年度を $i \in \{1, 2, \dots, n\}$、進展年度を $j \in \{1, 2, \dots, n\}$ とし、事故年度 $i$ に発生した事故について進展年度 $j$ までに支払われた**累積支払保険金額**を $C_{i, j}$ とします（各年の増分支払額を $X_{i, j} := C_{i, j} - C_{i, j-1}$ と書きます）。

現在（決算日時点）で観測されているのは、$i + j \le n + 1$ を満たす左上半分（**ランオフ三角形**）であり、対角線 $i + j = n + 1$ 上のセル $C_{i, n+1-i}$ が各事故年度の現在までの最新支払実績です。

**【チェインラダー法（Chain-Ladder Method）】**

進展年度 $j$ から $j + 1$ への進展係数（リンク・レシオ）を、両方の値が観測されているすべての事故年度 $i = 1, \dots, n - j$ の合計比として推定します。

$$\hat{f}_j := \frac{\sum_{i=1}^{n-j} C_{i, j+1}}{\sum_{i=1}^{n-j} C_{i, j}} \qquad (j = 1, 2, \dots, n - 1)$$

これは各年度の個別倍率 $\frac{C_{i, j+1}}{C_{i, j}}$ を、前期累積額 $C_{i, j}$ で加重平均した値に一致します。

事故年度 $i$（現在、進展年度 $k = n + 1 - i$ まで観測済み）について、終局（進展年度 $n$）までの累積進展係数を

$$\hat{F}_i := \prod_{j = n + 1 - i}^{n - 1} \hat{f}_j$$

とおくと、チェインラダー法による終局損害額と支払備金の推定値は次式で与えられます。

$$\hat{C}_{i, n}^{\mathrm{CL}} = C_{i, n+1-i} \cdot \hat{F}_i, \qquad \hat{R}_i^{\mathrm{CL}} = \hat{C}_{i, n}^{\mathrm{CL}} - C_{i, n+1-i} = C_{i, n+1-i}\bigl(\hat{F}_i - 1\bigr)$$

#### (3) ボーンヒュッター＝ファーガソン（BF）法と信頼性理論との一致

チェインラダー法は過去の進展倍率だけで計算できる明快な手法ですが、直近の事故年度（$i = n$）では $C_{n, 1}$ という1年目のわずかな実績値に大きな累積進展係数 $\hat{F}_n$ をそのまま掛け算します。そのため、1年目にたまたま大口事故の早期支払いがあったり、逆に報告が少し遅れたりしただけで、最終的な備金見積額が極端にぶれるという弱点があります。

この弱点を補うのが、1972年に提案された**ボーンヒュッター＝ファーガソン（Bornhuetter-Ferguson：BF）法**です。事故年度 $i$ の既経過保険料 $P_i$ と事前の予定損害率 $\mathrm{ELR}_i$ の積として、実績データとは独立した**先験的終局損害額** $U_i^{\text{prior}} := P_i \cdot \mathrm{ELR}_i$ を用意します。

累積進展係数 $\hat{F}_i$ の逆数 $1/\hat{F}_i$ は「現時点で終局損害額のうち何割がすでに支払済みか（既進展割合）」を表すため、残りの未払割合 $(1 - 1/\hat{F}_i)$ を事前見積 $U_i^{\text{prior}}$ に掛けて今後の支払備金を推計します。

$$\hat{R}_i^{\mathrm{BF}} := U_i^{\text{prior}} \left(1 - \frac{1}{\hat{F}_i}\right), \qquad \hat{C}_{i, n}^{\mathrm{BF}} := C_{i, n+1-i} + \hat{R}_i^{\mathrm{BF}}$$

ここで $C_{i, n+1-i} = \frac{1}{\hat{F}_i}\, \hat{C}_{i, n}^{\mathrm{CL}}$ であることに気づき、$Z_i := \frac{1}{\hat{F}_i} \in (0, 1]$ と置いて上式を書き換えると、明快な関係が現れます。

$$\hat{C}_{i, n}^{\mathrm{BF}} = Z_i\, \hat{C}_{i, n}^{\mathrm{CL}} + (1 - Z_i)\, U_i^{\text{prior}}$$

これは、8-5節で学んだ**信頼性理論の加重平均公式**そのものです。進展が進んでいない直近の事故年度ほど $\hat{F}_i$ が大きく（$Z_i$ が小さく）なるため事前見積 $U_i^{\text{prior}}$ を重視し、年数が経過してデータが出揃うにつれて $Z_i \to 1$ となりチェインラダー法 $\hat{C}_{i, n}^{\mathrm{CL}}$ へ滑らかに移行します。

<details markdown="1">
<summary>動かせる最小 Python コード（標準ライブラリのみ）：実験A のチェインラダー法 & BF 法</summary>

実験Aの $3 \times 3$ ランオフ三角形から、進展係数 $\hat{f}_j$・チェインラダー法の支払備金・事故年度3の BF 法推計値を一括で算出します。

```python
import math

# 実験Aの累積支払額ランオフ三角形（単位：億円）
tri = [
    [100, 150, 180],
    [120, 180],
    [150],
]
n = len(tri)
factors = [
    sum(tri[i][j + 1] for i in range(n - j - 1)) / sum(tri[i][j] for i in range(n - j - 1))
    for j in range(n - 1)
]
print("進展係数 f_hat:", [round(x, 4) for x in factors])

total_cl = 0.0
for i, row in enumerate(tri):
    F_i = math.prod(factors[len(row) - 1 :])
    ult_cl = row[-1] * F_i
    res_cl = ult_cl - row[-1]
    total_cl += res_cl
    print(f"年度{i+1}: F={F_i:.2f}, CL終局={ult_cl:.1f}, CL備金={res_cl:.1f}")
print(f"CL支払備金合計 = {total_cl:.1f}億円")

# 事故年度3の BF 法（既経過保険料 300億円 × 予定損害率 75% = 225億円）
prior_u3 = 300 * 0.75
F_3 = math.prod(factors)
res_bf = prior_u3 * (1.0 - 1.0 / F_3)
print(f"年度3 BF法: U_prior={prior_u3:.1f}, BF備金={res_bf:.1f}, BF終局={tri[2][-1] + res_bf:.1f}")
```

実行すると、進展係数 `[1.5, 1.2]`、CL 支払備金合計 `156.0億円`（年度2：`36.0`、年度3：`120.0`）、年度3の BF 法備金 `100.0億円`（終局 `250.0億円`）となり、実験Aと一致します。

#### (4) 過分散ポアソン GLM との一致およびマック（Mack）モデルの考え方

チェインラダー法は、もともとは経験的な計算アルゴリズムとして実務で使われていましたが、後に2つの重要な統計モデルによって理論的な裏付けと「予測誤差（標準誤差）の評価」が与えられました。

1. **過分散ポアソン GLM との一致（8-4節との接続）：**

    ランオフ三角形の各セルの増分支払額 $X_{i, j}$ に対し、8-4節の**対数リンク・ポアソン回帰モデル** $\ln E[X_{i, j}] = \alpha_i + \beta_j$（事故年度効果 $\alpha_i$ と進展年度効果 $\beta_j$ の乗法モデル）を当てはめて最尤推定を行います。すると、得られる将来の予測支払額の合計は、**チェインラダー法の推定値 $\hat{R}_i^{\mathrm{CL}}$ と1円のズレもなく一致する**ことが証明されています。

2. **マック（Mack）モデルによる推定誤差の評価（1993年）：**

    トーマス・マックは、特定の確率分布を仮定せず、各進展年度の条件付期待値と条件付分散に次の3つの仮定だけを置くノンパラメトリックな確率モデルを提案しました。

    * 異なる事故年度 $i$ は互いに独立です。
    * $E[C_{i, j+1} \mid C_{i, 1}, \dots, C_{i, j}] = f_j\, C_{i, j}$（条件付期待値が前期累積額に比例します）。
    * $V[C_{i, j+1} \mid C_{i, 1}, \dots, C_{i, j}] = \sigma_j^2\, C_{i, j}$（条件付分散も前期累積額に比例します）。

    この3つの仮定のもとで、チェインラダー法の進展係数 $\hat{f}_j$ は不偏推定量となり、さらに支払備金推定値 $\hat{R}_i^{\mathrm{CL}}$ の**平均二乗予測誤差（MSEP）**を「将来の偶然のぶれ（プロセス分散）」と「過去の進展係数 $\hat{f}_j$ の推定誤差（推定分散）」の2つに分解して解析的に計算できます。

> **【コラム：ロングテール種目（賠償責任保険）の怖さと、IBNR 見積誤差が損保経営を揺るがす理由】**
>
> 自動車の物損事故や火災保険の多くは、事故発生から数か月〜1年以内にほとんどの保険金支払いが完了します（**ショートテール種目**）。これに対し、企業向けの賠償責任保険（生産物賠償責任［PL］・役員賠償責任［D&O］・医療過誤・環境汚染賠償など）では、事故や有害物質への曝露から被害が発覚するまでに10年以上かかり、さらに集団訴訟の判決・和解まで何年も続くことがあります（**ロングテール種目**）。
>
> 歴史上もっとも有名な事例が、欧米の保険業界を揺るがした**アスベスト（石綿）訴訟**です。1950〜1970年代に建材として広く使われたアスベストによる健康被害（中皮腫など）は、20年〜40年という長い潜伏期間を経て1980〜2000年代に一斉に訴訟となりました。当時の損害保険会社は、契約から何十年も経ってから巨額の IBNR 備金の積増しを迫られ、世界最古級の保険市場であるロイズ（Lloyd's）が一時深刻な経営危機に陥ったほどです。
>
> 支払備金は損保会社の負債の中で最大の項目であるため、ロングテール種目で IBNR 見積もりがわずか数％過小であっただけでも、数年後に過去の事故年度の備金積増し（**負のランオフ損益**）として決算の利益を一気に吹き飛ばす危険があります。

### 4. 限界と補正（Critique & Adaptation）

チェインラダー法と BF 法は実務の標準手法ですが、いずれも「過去の進展パターン（$\hat{f}_j$）が将来もそのまま繰り返される」という定常性の前提に立っています。現実の損害保険経営では、この前提が崩れる次の2つの場面への補正が欠かせません。

#### (1) クレーム・インフレと支払スピードの変化による歪み

1. **クレーム・インフレ（物価・修理費・医療費の上昇）：**

    近年のように自動車の修理部品代・整備工賃・建築資材価格・弁護士費用が急上昇すると、同じ事故でも将来の支払額がカレンダー年度ごとに押し上げられます。過去のインフレ率が低かった時期の進展係数 $\hat{f}_j$ をそのまま使うと、将来のインフレ分が織り込まれず備金が不足します。

2. **支払処理スピードの変化やテール・ファクター（観測期間外の進展）：**

    保険会社がデジタル査定を導入して支払いを早めると、直近の事故年度だけ1年目の累積支払額 $C_{n,1}$ が大きくなります。この変化を知らずに過去の進展係数 $\hat{f}_1$ を掛けると、逆に備金を過大に見積もってしまいます。また、ロングテール種目では表の右端（進展年度 $n$）以降にも支払いが残るため、**テール・ファクター**（$n$ 年目から終局までの追加倍率）をパレート曲線や指数減衰曲線で外挿して補います。

* **実務上の補正：** 支払額を消費者物価指数や修理費指数で現在価値へ調整してからチェインラダー法を適用し、予測後に将来の予想インフレ率を掛け戻す**インフレ調整チェインラダー法**が用いられます。さらに、既払額ベースだけでなく**発生損害額（Incurred：すでに支払った金額と今後支払う見込みの個別見積額［OS備金］の合計）**の三角形でも同時に推計し、両者を突き合わせる検証が行われます。

#### (2) 点推定の限界と「分布による評価（リスクマージン）」

チェインラダー法や BF 法が算出する金額は、あくまで将来の未払額の**期待値（点推定）**です。しかし、実際の支払額は期待値を中心に上下へぶれる確率変数であり、期待値ちょうどしか備金を積んでいなければ、約半分の確率で備金不足に陥ります。

そのため、現代のソルベンシー規制や国際会計基準（IFRS 17）では、3(4)で触れた**マック（Mack）モデル**や**ブートストラップ法**（過分散ポアソン GLM の残差を何度も再抽出して数千通りの疑似ランオフ三角形を生成するシミュレーション手法）を用いて、支払備金の**確率分布全体と標準誤差**を評価します。そして、期待値（最良推計：Best Estimate）に不確実性への備えである**リスクマージン**を上乗せして負債を評価する補正が行われます（8-9節で詳述）。
