### 前節（8-2）の確認問題の解答

前節の最後に提示した3つの問いの解答を確認します。問3の視点が、そのまま本節（複合ポアソン分布と免責額・支払限度額の数理）の導入になります。

1. **ポアソン＝ガンマ混合による負の二項分布の計算：**

    年間事故ペース $\Lambda \sim \mathrm{Ga}(r = 4,\; \beta = 2)$ より、$E[\Lambda] = \frac{4}{2} = 2$、$V[\Lambda] = \frac{4}{2^2} = 1$ です。

    * **(a) 平均 $E[N]$ と分散 $V[N]$：**

        全分散の法則より、

        $$E[N] = E[\Lambda] = \mathbf{2.0}, \qquad V[N] = E[\Lambda] + V[\Lambda] = 2 + 1 = \mathbf{3.0}$$

    * **(b) 1年間無事故（$N = 0$）である確率 $P(N = 0)$：**

        負の二項分布のパラメータ $p = \frac{\beta}{\beta + 1} = \frac{2}{3}$ より、

        $$P(N = 0) = p^r = \left(\frac{2}{3}\right)^4 = \mathbf{\frac{16}{81} \approx 0.1975 \quad (19.8\%)}$$

2. **パレート分布のモーメントと裾確率：**

    生存関数 $S(x) = \left(\frac{\theta}{x + \theta}\right)^\alpha$ について計算します。

    * **(a) $\alpha = 4,\; \theta = 60$ 万円のとき：**

        $$E[X] = \frac{\theta}{\alpha - 1} = \frac{60}{3} = \mathbf{20 \text{ 万円}}$$

        $$V[X] = \frac{\alpha \theta^2}{(\alpha - 1)^2(\alpha - 2)} = \frac{4 \times 3{,}600}{9 \times 2} = \mathbf{800} \qquad (\text{標準偏差 } \approx 28.28 \text{ 万円})$$

        $$P(X > 60) = \left(\frac{60}{60 + 60}\right)^4 = \left(\frac{1}{2}\right)^4 = \mathbf{\frac{1}{16} = 0.0625 \quad (6.25\%)}$$

    * **(b) $\alpha = 1.8$ の場合の平均と分散：**

        パレート分布の $k$ 次モーメントは $\alpha > k$ のときに限り有限となります。$1 < 1.8 \le 2$ であるため、**平均 $E[X]$ は有限の値として存在します**が、**分散 $V[X]$ は無限大へ発散**します。

3. **「回数 $N$」と「1回あたり損害額 $X_i$」を掛け合わせた総損害額 $S$（本節への接続）：**

    1年間の総損害額は、ランダムな事故件数 $N$ 個の損害額を足し合わせたランダム和 $S = \sum_{i=1}^N X_i$ として表されます。$N$ がポアソン分布に従うとき、この $S$ の分布を**複合ポアソン分布**と呼び、繰り返し期待値の法則・全分散の法則・積率母関数を用いることで、平均・分散・歪度と再生性を簡潔に導出できます。

## 8-3. 複合ポアソン分布と免責額・支払限度額の数理

### 1. 動機（Why）：なぜ「ランダムな個数の足し算」と「契約条件による切断」を数式で扱うのか

前節（8-2節）では、損害保険における「事故の発生回数 $N$（頻度）」と「1回あたりの損害額 $X_i$（強度）」を別々にモデル化しました。しかし、保険会社が1年間の保険料（純保険料）や必要な準備金を算定するうえで最終的に知りたいのは、**1年間に発生する損害額の合計（総クレーム額）**

$$S = X_1 + X_2 + \dots + X_N = \sum_{i=1}^N X_i \qquad (N = 0 \text{ のときは } S = 0)$$

の確率分布です（この構造を**集合リスクモデル：Collective Risk Model**と呼びます）。

通常の確率変数の和（0-5節）では足し合わせる個数 $n$ が定数でしたが、ここでは個数 $N$ 自体が確率変数であるため、「件数のぶれ」と「1件あたり金額のぶれ」の両方が絡み合います。

さらに実際の損害保険契約では、発生した損害額 $X$ をそのまま全額支払うとは限りません。モラルハザード（1-2節）や事務コストを抑えるための**免責額（自己負担額）**や、巨大事故から保険会社を守るための**支払限度額（上限）**が設定されています。本節では、複合ポアソン分布のモーメント・積率母関数・再生性を導出したうえで、免責額と支払限度額が支払額分布に与える影響を解析します。

---

### 2. 具体例と計算イメージ（Toy Model）

一般的な定理に入る前に、①小さな離散モデルでの複合ポアソン分布の計算、②指数分布における免責額・支払限度額の支払削減効果、の2つを手計算で確認します。

#### 実験A：年間事故件数 $N \sim \mathrm{Po}(2)$ と2段階の損害額（総損害額 $S$ の平均・分散・確率）

ある保険集団で、1年間の事故件数 $N$ が平均 $\lambda = 2$ のポアソン分布 $\mathrm{Po}(2)$ に従い、1回あたりの損害額 $X_i$ が独立に次の2通りをとるとします。

* 軽微な事故：**$10$ 万円**（確率 $0.7$）
* 大きな事故：**$50$ 万円**（確率 $0.3$）

まず1回あたり損害額 $X$ の原点周りのモーメント（1乗・2乗・3乗の期待値）を求めます。

* $m_1 = E[X] = 10 \times 0.7 + 50 \times 0.3 = 7 + 15 = \mathbf{22 \text{ 万円}}$
* $m_2 = E[X^2] = 10^2 \times 0.7 + 50^2 \times 0.3 = 70 + 750 = \mathbf{820}$
* $m_3 = E[X^3] = 10^3 \times 0.7 + 50^3 \times 0.3 = 700 + 37{,}500 = \mathbf{38{,}200}$

後述する複合ポアソン分布の公式（3(1)で証明）を使うと、総損害額 $S$ の平均・分散・3次中心モーメントは、それぞれ $\lambda = 2$ を掛けるだけで直ちに求まります。

* **期待総損害額：** $E[S] = \lambda m_1 = 2 \times 22 = \mathbf{44 \text{ 万円}}$
* **総損害額の分散：** $V[S] = \lambda m_2 = 2 \times 820 = \mathbf{1{,}640}$（標準偏差 $\sigma_S = \sqrt{1{,}640} \approx \mathbf{40.50 \text{ 万円}}$）
* **歪度（右への歪み具合）：** $\gamma_S = \dfrac{\lambda m_3}{(\lambda m_2)^{3/2}} = \dfrac{76{,}400}{1{,}640 \times 40.50} \approx \mathbf{1.15}$（強い右歪み）

また、小さな金額の正確な発生確率も、件数ごとに場合分けすれば直接求められます（$e^{-2} \approx 0.1353$）。

* $P(S = 0) = P(N = 0) = e^{-2} \approx \mathbf{13.53\%}$
* $P(S = 10) = P(N = 1) P(X_1 = 10) = 2 e^{-2} \times 0.7 = 1.4 e^{-2} \approx \mathbf{18.95\%}$
* $P(S = 20) = P(N = 2) P(X_1 = 10, X_2 = 10) = \dfrac{2^2}{2!} e^{-2} \times 0.7^2 = 0.98 e^{-2} \approx \mathbf{13.26\%}$

#### 実験B：免責額と支払限度額による期待支払額の変化（指数分布の例）

1回の事故の損害額 $X$ が平均 $100$ 万円の指数分布 $\mathrm{Exp}(0.01)$（生存関数 $S_X(x) = e^{-0.01 x}$）に従うとき、契約条件の違いで保険会社の期待支払額 $E[Y]$ がどう変わるかを比べます（$e^{-0.2} \approx 0.8187,\; e^{-2} \approx 0.1353$）。

1. **条件なし（全額支払）：** $E[X] = \mathbf{100.00 \text{ 万円}}$
2. **エクセス免責 $d = 20$ 万円（超過分のみ支払：$Y = \max(X - 20, 0)$）：**

    損害額が $20$ 万円以下なら $0$ 円、$20$ 万円を超えたら「$20$ 万円を引いた超過分」だけを支払います。後述の積分公式（生存曲線の下の面積）より、

    $$E[Y] = \int_{20}^\infty e^{-0.01x}\,dx = 100 e^{-0.2} \approx \mathbf{81.87 \text{ 万円}} \qquad (\text{削減率 } 18.13\%)$$

3. **フランチャイズ免責 $d = 20$ 万円（超えたら全額支払）：**

    損害額が $20$ 万円以下なら $0$ 円ですが、**$20$ 万円を超えた場合は最初の $20$ 万円も含めて全額 $X$ を支払います**。したがってエクセス免責より $20 \times P(X > 20) = 20 e^{-0.2} \approx 16.37$ 万円だけ多くなり、

    $$E[Y_{\text{fran}}] = 100 e^{-0.2} + 20 e^{-0.2} = 120 e^{-0.2} \approx \mathbf{98.25 \text{ 万円}} \qquad (\text{削減率わずか } 1.75\%)$$

4. **支払限度額 $u = 200$ 万円（上限あり：$Y = \min(X, 200)$）：**

    $$E[Y] = \int_0^{200} e^{-0.01x}\,dx = 100(1 - e^{-2}) \approx \mathbf{86.47 \text{ 万円}}$$

5. **エクセス免責 $d = 20$ 万円＋上限 $u = 200$ 万円（損害額 $20 \sim 200$ 万円の層を補償）：**

    $$E[Y] = \int_{20}^{200} e^{-0.01x}\,dx = 100(e^{-0.2} - e^{-2}) \approx \mathbf{68.34 \text{ 万円}}$$

このように、免責額と支払限度額のもとでの期待支払額は、**生存関数 $S_X(x)$ のグラフの下の面積をどの区間で切り取るか**として視覚的に一望できます（図8-3-1右）。

### 3. 定義・導出・構造（What）

#### (1) 複合ポアソン分布の定義・モーメント・積率母関数・再生性

1年間の事故件数 $N$ がポアソン分布 $\mathrm{Po}(\lambda)$ に従い、個別損害額 $X_1, X_2, \dots$ が互いに独立に同一の分布 $F_X$（i.i.d.）に従い、かつ $N$ と $\{X_i\}$ が互いに独立であるとき、総損害額

$$S := \sum_{i=1}^N X_i \qquad (N = 0 \text{ のときは } S = 0)$$

が従う分布を**複合ポアソン分布（Compound Poisson Distribution）** $\mathrm{CP}(\lambda, F_X)$ と呼びます。

**【定理1：複合ポアソン分布の平均・分散・積率母関数・歪度】**

$X$ の $k$ 次モーメントを $m_k := E[X^k]$、積率母関数を $M_X(t) = E[e^{tX}]$（存在する場合）とするとき、以下が成り立ちます。

$$E[S] = \lambda m_1, \qquad V[S] = \lambda m_2, \qquad E\bigl[(S - E[S])^3\bigr] = \lambda m_3, \qquad M_S(t) = \exp\Bigl(\lambda\bigl(M_X(t) - 1\bigr)\Bigr)$$

**【証明】**

1. **平均と分散（0-3節の繰り返し期待値の法則・全分散の法則による導出）：**

    $N = n$ が与えられたもとで $X_1, \dots, X_n$ は i.i.d. なので、$E[S \mid N] = N E[X]$、$V[S \mid N] = N V[X]$ です。ポアソン分布では $E[N] = V[N] = \lambda$ なので、

    $$E[S] = E\bigl[E[S \mid N]\bigr] = E[N]\, E[X] = \lambda m_1$$

    $$V[S] = E\bigl[V[S \mid N]\bigr] + V\bigl[E[S \mid N]\bigr] = E[N]\, V[X] + V[N]\, (E[X])^2 = \lambda\bigl(m_2 - m_1^2\bigr) + \lambda m_1^2 = \lambda m_2$$

    （※一般のカウント分布 $N$ では $V[S] = E[N]V[X] + V[N](E[X])^2$ となりますが、ポアソン分布に限り $E[N] = V[N] = \lambda$ のため $-m_1^2$ と $+m_1^2$ がきれいに相殺し、$\lambda m_2$ という簡潔な式になります。）

2. **積率母関数とキュムラント母関数（0-5節の応用）：**

    繰り返し期待値の法則より、$N$ で条件付けを行うと $e^{tS} = \prod_{i=1}^N e^{tX_i}$ の条件付期待値は $(M_X(t))^N$ になります。

    $$M_S(t) = E\bigl[E[e^{tS} \mid N]\bigr] = E\bigl[(M_X(t))^N\bigr] = \sum_{n=0}^\infty \bigl(M_X(t)\bigr)^n \frac{\lambda^n e^{-\lambda}}{n!} = e^{-\lambda} e^{\lambda M_X(t)} = \exp\Bigl(\lambda\bigl(M_X(t) - 1\bigr)\Bigr)$$

    両辺の自然対数をとったキュムラント母関数は $K_S(t) = \lambda(M_X(t) - 1)$ です。これを $t$ で $1, 2, 3$ 回微分して $t = 0$ を代入すれば、$K_S'(0) = \lambda m_1$、$K_S''(0) = \lambda m_2$、および3次中心モーメント $K_S'''(0) = \lambda m_3$ が直ちに得られます。したがって**歪度**は次式となります。

    $$\gamma_S := \frac{E\bigl[(S - E[S])^3\bigr]}{(V[S])^{3/2}} = \frac{\lambda m_3}{(\lambda m_2)^{3/2}} = \frac{m_3}{\sqrt{\lambda}\, m_2^{3/2}}$$

    （$X \ge 0$ のため常に $\gamma_S > 0$ の右歪みになりますが、件数 $\lambda$ が増えるにつれて $1/\sqrt{\lambda}$ の速さで $0$ へ近づき、正規分布へ接近します。）（証明終）

**【定理2：複合ポアソン分布の再生性（ポートフォリオの統合）】**

互いに独立な2つの契約集団の総損害額 $S_1 \sim \mathrm{CP}(\lambda_1, F_1)$ と $S_2 \sim \mathrm{CP}(\lambda_2, F_2)$ を合算した $S = S_1 + S_2$ の積率母関数を計算します。

$$M_S(t) = M_{S_1}(t)\, M_{S_2}(t) = \exp\!\left((\lambda_1 + \lambda_2)\left[\frac{\lambda_1 M_{X_1}(t) + \lambda_2 M_{X_2}(t)}{\lambda_1 + \lambda_2} - 1\right]\right)$$

角括弧内の第1項は、確率 $\frac{\lambda_1}{\lambda_1 + \lambda_2}$ で $F_1$、確率 $\frac{\lambda_2}{\lambda_1 + \lambda_2}$ で $F_2$ に従う混合分布 $F := \frac{\lambda_1 F_1 + \lambda_2 F_2}{\lambda_1 + \lambda_2}$ の積率母関数です。したがって一意性定理より、**独立な複合ポアソン分布の和は再び複合ポアソン分布 $\mathrm{CP}(\lambda_1 + \lambda_2,\; F)$ に従います**。これにより、自動車保険と火災保険のように性質の異なる複数の種目を合算した会社全体のリスクも、1つの複合ポアソン分布として統一的に解析できます。

#### (2) 免責額（フランチャイズ・エクセス）と支払限度額の解析

非負の連続型損害額 $X \ge 0$（生存関数 $S_X(x) = P(X > x)$）に対し、契約条件が保険会社の支払額 $Y$ の期待値へ与える影響を整理します。$f_X(x) = -S_X'(x)$ に注意して部分積分を行うと $\int_0^u x f_X(x)\,dx = \bigl[-x S_X(x)\bigr]_0^u + \int_0^u S_X(x)\,dx = -u S_X(u) + \int_0^u S_X(x)\,dx$ となり、$+u S_X(u)$ が相殺されて、任意の非負の切断上限 $u \ge 0$ に対する**制限期待値（Limited Expected Value）**は生存関数の面積に一致します。

$$E[X \wedge u] := E[\min(X, u)] = \int_0^u x f_X(x)\,dx + u S_X(u) = \int_0^u S_X(x)\,dx$$

この1本の公式から、主要な3つの契約条件の期待支払額がすべて導かれます（図8-3-1右）。

1. **エクセス免責（通常免責：$d$）：** $Y = (X - d)_+ = \max(X - d, 0) = X - (X \wedge d)$。

    $$E[(X - d)_+] = E[X] - E[X \wedge d] = \int_d^\infty S_X(x)\,dx$$

    免責額 $d$ によって削減される期待損害の割合を**損害削減率（LER：Loss Elimination Ratio）**と呼びます。

    $$\mathrm{LER}(d) := \frac{E[X \wedge d]}{E[X]} = \frac{\int_0^d S_X(x)\,dx}{\int_0^\infty S_X(x)\,dx}$$

    また、エクセス免責 $d$ を導入すると、そもそも損害額が $d$ を超えた事故だけが保険会社へ請求されます。ポアソン過程の各事象を確率 $p = S_X(d)$ で独立に残す操作（**ポアソン過程の分解［間引き］**）により、**支払が発生する件数 $N_d$ は再びポアソン分布 $\mathrm{Po}\bigl(\lambda S_X(d)\bigr)$ に従う**という便利な性質が成り立ちます。

2. **フランチャイズ免責（$d$）：** $X \le d$ なら $Y = 0$、$X > d$ なら $Y = X$（全額支払）。

    $$E[Y_{\text{fran}}] = E\bigl[X \cdot \mathbf{1}(X > d)\bigr] = d\, S_X(d) + \int_d^\infty S_X(x)\,dx$$

    フランチャイズ免責は、図8-3-1左の通り $x = d$ で不連続に跳ね上がるため、「損害額が $19$ 万円のときに修理費を水増しして $21$ 万円にすれば $0$ 円が一気に $21$ 万円になる」という強いモラルハザードを生みやすく、現代の個人向け保険ではエクセス免責が標準となっています。

3. **支払限度額（$u$）およびレイヤー補償（免責 $d$・上限 $u$）：**

    損害額のうち $d$ を超え $u$ までの層（最大支払額 $u - d$）を補償する場合、$X \le d$ では $0$、$d < X \le u$ では $X - d$、$X > u$ では $u - d$ となるため、支払額は $Y = \min\bigl((X - d)_+,\; u - d\bigr) = (X \wedge u) - (X \wedge d)$ と書き換えられます。したがって期待支払額は

    $$E[Y] = E[X \wedge u] - E[X \wedge d] = \int_d^u S_X(x)\,dx$$

    と簡潔に表せます。

> **【コラム：支払限度額の導入は、数学的には「重尾分布の裾を切断してモーメントを有限化する操作」である】**
>
> 前節（8-2節）で確認した通り、形状パラメータ $\alpha \le 1$ のパレート分布では期待損害額 $E[X]$ すら無限大へ発散し、保険料を計算することができません。たとえば、$\alpha = 1,\; \theta = 100$ 万円のパレート分布（生存関数 $S_X(x) = \frac{100}{x + 100}$）では、
>
> $$E[X] = \int_0^\infty \frac{100}{x + 100}\,dx = 100 \Bigl[\ln(x + 100)\Bigr]_0^\infty = +\infty$$
>
> となり、無制限の補償を引き受ければ期待支払額は無限大になります。
>
> ところが、この契約に「1事故あたり最大 **$u = 1{,}000$ 万円** まで」という**支払限度額**を1行加えた瞬間に、支払額は $Y = X \wedge 1{,}000$ となり、期待支払額は直ちに有限の値へ収まります。
>
> $$E[X \wedge 1{,}000] = \int_0^{1{,}000} \frac{100}{x + 100}\,dx = 100 \Bigl[\ln(x + 100)\Bigr]_0^{1{,}000} = 100 \ln\!\left(\frac{1{,}100}{100}\right) = 100 \ln 11 \approx \mathbf{239.79 \text{ 万円}}$$
>
> さらに、$0 \le Y \le 1{,}000$ と有界になるため、分散 $V[Y]$ も、あらゆる高次モーメント $E[Y^k]$ も、積率母関数 $M_Y(t) = E[e^{tY}]$ もすべて有限値として確実に存在します。実務の賠償責任保険や企業向け火災保険で「1事故あたり支払限度額 $1$ 億円」「年間通算限度額 $3$ 億円」といった上限が必ず設けられる背景には、単なる営業上の判断だけでなく、**重尾リスクの無限大の裾を切断して統計的・数学的に引き受け可能な範囲へ閉じ込める**という明確な数理的意味があるのです。

### 4. 限界と補正（Critique & Adaptation）

複合ポアソン分布の平均・分散・歪度は3(1)の公式で簡単に求まりますが、**確率分布そのもの（$P(S \le s)$ や $99.5\%$ 分位点）を解析的に閉じた数式で書くことは、ほとんどの場合で不可能**です。実際、定義通りに展開すると

$$F_S(s) = P(S \le s) = \sum_{n=0}^\infty \frac{\lambda^n e^{-\lambda}}{n!} F_X^{*n}(s)$$

と、**$n$ 重たたみ込み** $F_X^{*n}$（独立な確率変数を $n$ 回足し合わせた和の分布の計算）の無限和になってしまいます。この解析的限界を乗り越えるため、実務では目的と精度に応じて次の**4つの数値・近似手法**を使い分けます。

1. **正規近似（Normal Approximation）：**

    期待件数 $\lambda$ が十分に大きいとき、中心極限定理（0-5節）に基づき $S \approx N(\mu_S, \sigma_S^2)$ と近似します。計算が最も手軽ですが、**複合ポアソン分布特有の正の歪度（$\gamma_S > 0$）を無視する**ため、資本要件などで重要になる右裾（$99\%$ 点など）を過小評価しやすい欠点があります。

2. **NP近似（Normal Power Approximation）：**

    正規近似の欠点を補うため、3次中心モーメントから求まる**歪度 $\gamma_S$** を組み込んで右裾を補正する近似式です。標準正規分布の上側分位点 $z_\alpha \ge 1$（例：$95\%$ 点なら $1.645$、$99\%$ 点なら $2.326$）に対し、総損害額 $S$ の $\alpha$-分位点 $s_\alpha$ を次式で近似します。

    $$s_\alpha \approx \mu_S + \sigma_S \left(z_\alpha + \frac{\gamma_S}{6}\bigl(z_\alpha^2 - 1\bigr)\right)$$

    $\gamma_S > 0$ のとき第2項の $\frac{\gamma_S}{6}(z_\alpha^2 - 1)$ が正の値となり、正規近似より右へ膨らんだ現実的な分位点を与えます（ただし $\gamma_S$ が $1$ を大きく超える極端な重尾では精度が落ちます）。

3. **Panjer（パニエ）の再帰公式（Exact Recursion）：**

    個別損害額 $X$ を一定の金額単位（例：$10$ 万円刻み）で離散化し、非負の整数値 $0, 1, 2, \dots$ をとる確率質量関数 $f_k = P(X = k)$ へ置き換えます（$f_0 = 0$ とします）。確率母関数 $G_S(z) := \sum_{k=0}^\infty g_k z^k$ と $G_X(z) := \sum_{j=1}^\infty f_j z^j$ は $G_S(z) = \exp\bigl(\lambda(G_X(z) - 1)\bigr)$ を満たすため、両辺を $z$ で微分した $G_S'(z) = \lambda G_X'(z) G_S(z)$（すなわち $\sum_{k=1}^\infty k g_k z^{k-1} = \lambda \bigl(\sum_{j=1}^\infty j f_j z^{j-1}\bigr)\bigl(\sum_{m=0}^\infty g_m z^m\bigr)$）の $z^{k-1}$ の係数を比較すると $k g_k = \lambda \sum_{j=1}^k j f_j g_{k-j}$ が得られます。これにより、総損害額 $S$ の厳密な確率 $g_k = P(S = k)$ はたたみ込みを一切計算せずに次の再帰式で $g_0 \to g_1 \to g_2 \to \dots$ と順番に計算できます。

    $$g_0 = e^{-\lambda}, \qquad g_k = \frac{\lambda}{k} \sum_{j=1}^k j f_j\, g_{k-j} \qquad (k = 1, 2, \dots)$$

    実験A（$10$ 万円単位で $f_1 = 0.7,\; f_5 = 0.3,\; \lambda = 2$）で検算すると、$g_1 = \frac{2}{1}(1 \cdot 0.7 g_0) = 1.4 g_0$、$g_2 = \frac{2}{2}(1 \cdot 0.7 g_1 + 0) = 0.98 g_0$ となり、手計算と完全に一致します。なお、二項・ポアソン・負の二項の3分布をまとめて扱う **$(a, b, 0)$ クラス**（確率比 $p_n/p_{n-1} = a + b/n$ を満たす頻度分布のクラス。ポアソン分布は $a = 0,\; b = \lambda$ に対応）全般に対しても、$g_k = \sum_{j=1}^k \left(a + \frac{bj}{k}\right) f_j g_{k-j}$ として同じ再帰構造が成り立ちます。

4. **モンテカルロ・シミュレーション（0-10節）：**

    年間通算免責額や複雑な再保険特約が重なり、Panjer の再帰公式でも扱いにくい場合は、乱数で「①$N \sim \mathrm{Po}(\lambda)$ を1回生成 $\to$ ②$X_1, \dots, X_N$ を独立に生成して契約条件を適用し合算」という試行を数万回〜数十万回繰り返して分布を直接数値評価します。

<details markdown="1">
<summary>動かせる最小 Python コード（標準ライブラリのみ）：実験A の Panjer 再帰公式による厳密分布</summary>

実験A（$\lambda = 2$、$10$ 万円単位で $f_1 = 0.7,\; f_5 = 0.3$）について、たたみ込みを使わずに Panjer の再帰公式で総損害額 $S$ の厳密な確率分布と平均・標準偏差を計算します。

```python
import math

lam = 2.0
f = {1: 0.7, 5: 0.3}  # 1単位 = 10万円（10万円: 0.7, 50万円: 0.3）
K = 50
g = [0.0] * (K + 1)
g[0] = math.exp(-lam)

for k in range(1, K + 1):
    g[k] = (lam / k) * sum(j * fj * g[k - j] for j, fj in f.items() if j <= k)

for k in (0, 1, 2, 5, 6):
    print(f"P(S = {10 * k:2d}万円) = {g[k]:.4f}")

mean_s = sum((10 * k) * g[k] for k in range(K + 1))
sd_s = math.sqrt(sum(((10 * k) - mean_s) ** 2 * g[k] for k in range(K + 1)))
print(f"確率合計 = {sum(g):.6f}, E[S] = {mean_s:.2f}万円, SD[S] = {sd_s:.2f}万円")
```

実行すると、`P(S = 0万円) = 0.1353`、`P(S = 10万円) = 0.1895`、`P(S = 20万円) = 0.1326`、および `E[S] = 44.00万円, SD[S] = 40.50万円` となり、実験Aの手計算結果と一致します。
