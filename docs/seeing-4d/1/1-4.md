### 前節（1-3）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

視点 $E = (0, 0, 2)$ から平面 $z = -1$ への透視投影公式 $(x', y') = \left(\frac{3x}{2 - z}, \frac{3y}{2 - z}\right)$ に、立方体 $[-1, 1]^3$ の8頂点を代入します。

1. **底面の4頂点（$z = -1$）：**
    分母が $2 - (-1) = 3$ となり係数が $\frac{3}{3} = 1$ になるため、4頂点はそのまま $(\pm 1, \pm 1)$ に写ります（**1辺の長さ $2$** の内側の正方形）。

2. **上面の4頂点（$z = +1$）：**
    分母が $2 - 1 = 1$ となり係数が $\frac{3}{1} = 3$ になるため、4頂点は $(\pm 3, \pm 3)$ に写ります（**1辺の長さ $6$** の外側の正方形）。

3. **重なり（自己交差）のない接続関係：**
    側面をなす4本の縦辺は、内側の正方形の角 $(\pm 1, \pm 1)$ と外側の正方形の角 $(\pm 3, \pm 3)$ を放射状に結ぶ4本の線分になります。平面上では、**内側の正方形（底面1枚）＋周囲を囲む4つの台形（側面4枚）＋外側の大きな正方形の枠全体（視点に最も近い上面1枚）**という形で、立方体の全8頂点・12辺・6面が1か所も交差・重複せずに2次元平面へ収まっています。

この「1つの面のすぐ外側に視点を置いて1次元低い空間へ透視投影する」手法を、**シュレーゲル図（Schlegel diagram）**と呼びます。本節では、まったく同じ数式を1次元上げて 4D $\to$ 3D へ適用し、4次元立体を3次元空間の模型として組み立てます。

## 1-4. 4次元立体の影（シュレーゲル図）：超立方体と正5胞体を3次元へ透視投影する

### 1. 動機（Why）：なぜ「平行投影」ではなく「シュレーゲル図」を使うのか？

4次元立体を3次元空間へ写すだけなら、[1-1節](1-1.md)の平行投影（単純に第4座標 $w$ を捨てる操作）でも可能です。しかし、4次元超立方体 $[-1, 1]^4$ の $w$ 座標をそのまま捨てると、$w = +1$ にある立方体と $w = -1$ にある立方体が**完全に1つの立方体に重なって潰れてしまい**、4次元構造がまったく見えなくなります。少し斜めから平行投影しても、複数の辺や面が内部で複雑に交差し合ってしまいます。

これに対し、[1-2節](1-2.md)で確立した透視投影を「1つの胞（3次元の面）のすぐ外側」という適切な視点から行う**シュレーゲル図**には、2つの決定的な強みがあります。

**理由①：高次元立体の「頂点・辺・面・胞」の繋がり方（組合せ構造）が、重なりなしで完全に保存されるから**
シュレーゲル図では、視点に最も近い1つの胞 $F_0$ が「外枠」となり、残りのすべての胞が $F_0$ の内部を隙間なく・重なりなく分割する形で収まります。したがって、4次元立体であっても、3次元空間の中に実物の針金模型として組み立ててあらゆる角度から観察できます。

**理由②：任意の次元 $d$ に対して、たった1つの幾何学的原理で存在と「重なりのなさ」が証明できるから**
3D $\to$ 2D（前節の確認問題）も 4D $\to$ 3D（本節）も、さらに 5D $\to$ 4D も、凸多胞体の境界を1つのファセット（最高次元の面）へ中心射影する構造は次元によらず完全に同一です。

### 2. 具体例と幾何学的イメージ（Toy Model）

4次元空間 $\mathbb{R}^4$ の座標を $(x, y, z, w)$ とし、代表的な2つの4次元立体（**4次元超立方体［テッセラクト］**と**正5胞体**）のシュレーゲル図を実際に計算して組み立てます。

#### 実験A：4次元超立方体（テッセラクト）$[-1, 1]^4$ のシュレーゲル図

4次元超立方体 $C_4 = [-1, 1]^4$ の16個の頂点は $(\pm 1, \pm 1, \pm 1, \pm 1)$ です。
[0-4節](../0/0-4.md)の群論で解剖した通り、この立体は **16頂点・32辺・24面（正方形）・8胞（3次元立方体）** から成ります。

8つの胞のうち、$w = +1$ にある立方体 $F_0 = [-1, 1]^3 \times \{1\}$ を外枠として選びます。この胞のすぐ外側にある点

$$E = (0, 0, 0, R) \qquad (R > 1)$$

に目（視点）を置き、すべての点を3次元超平面 $H_0 : w = 1$（スクリーン）へ透視投影します。
点 $P = (x, y, z, w)$（$w < R$）と視点 $E$ を結ぶ直線 $E + t(P - E) = (tx, ty, tz, R + t(w - R))$ がスクリーン $w = 1$ と交わるのは、$R + t(w - R) = 1 \iff t = \frac{R - 1}{R - w}$ のときです。したがって、投影公式は

$$(x', y', z') = \left( \frac{R - 1}{R - w} x, \;\; \frac{R - 1}{R - w} y, \;\; \frac{R - 1}{R - w} z \right)$$

となります。見やすい具体例として **$R = 3$** を選んでみましょう（すると倍率は $\frac{2}{3 - w}$ です）。

1. **手前の立方体胞（$w = +1$ の8頂点）：**
    倍率は $\frac{2}{3 - 1} = 1$。そのまま **外側の大きな立方体 $[-1, 1]^3$**（1辺の長さ $2$）に写ります。

2. **奥の立方体胞（$w = -1$ の8頂点）：**
    倍率は $\frac{2}{3 - (-1)} = \frac{1}{2}$。外側の立方体のど真ん中に浮かぶ **内側の小さな立方体 $\left[-\frac{1}{2}, \frac{1}{2}\right]^3$**（1辺の長さ $1$）に写ります。

3. **残りの6つの胞（$x = \pm 1, \; y = \pm 1, \; z = \pm 1$）：**
    たとえば $x = +1$ の胞は、外側の立方体の右面（$x' = 1$）と内側の立方体の右面（$x' = 1/2$）を4本の斜めの辺で繋いだ**四角錐台（プリン型の立体）**に写ります。これが上下・左右・前後の6方向にぴったり6個並びます。

パーツの個数を数え上げてみましょう。

* **頂点：** 外側 $8$ $+$ 内側 $8$ $=$ **$16$ 個**
* **辺：** 外側 $12$ $+$ 内側 $12$ $+$ 内外を繋ぐ斜め辺 $8$ $=$ **$32$ 本**
* **面：** 外側 $6$ $+$ 内側 $6$ $+$ 内外を繋ぐ台形面 $12$ $=$ **$24$ 枚**
* **胞：** 内側の立方体 $1$ $+$ 周囲の6つの四角錐台 $6$ $+$ 外側の大きな立方体枠全体 $1$ $=$ **$8$ 個**

4次元空間ではこれら8つの胞はすべて**まったく同じ大きさの合同な立方体**ですが、透視投影の遠近効果によって「最も近い1個が大きく外枠になり、最も遠い1個が中央で小さく縮み、間の6個が遠近感で台形柱（四角錐台）に歪んで見えている」のです。

#### 実験B：正5胞体（4次元単体）のシュレーゲル図

4次元で最も頂点数が少ない正多胞体が**正5胞体**です。[0-1節](../0/0-1.md)で見たように、5つの頂点 $P_0, P_1, P_2, P_3, P_4$ のどの異なる2点を選んでも距離がすべて等しい図形であり、**5頂点・10辺・10面（正三角形）・5胞（正四面体）** から成ります。

1つの胞である正四面体 $F_0 = P_1 P_2 P_3 P_4$ の重心のすぐ外側から透視投影すると、次の形が現れます。

* $F_0$ の4頂点 $P_1, P_2, P_3, P_4$ は、そのまま**外側の正四面体**になる。
* 残る1つの頂点 $P_0$ は、外側の正四面体の**ど真ん中（重心）**に写る。
* 頂点 $P_0$ から外側の4頂点 $P_1, P_2, P_3, P_4$ へ4本の辺が伸び、外側の正四面体の内部を**4つの小さな四面体**に隙間なく分割する。

この4つの内部の四面体と、外枠の正四面体 $F_0$ 自身を合わせて、合計 **5つの胞** が3次元空間に重なりなく収まります。

### 3. 厳密な定義と定理（What）：シュレーゲル図の存在と「重なりのなさ」の証明

ここからは、任意の次元 $d$ の凸多胞体に対して、「1つのファセットの外側に適切に視点を置けば、残りの境界全体が重なりなく1対1に投影される」ことを、論理の飛躍を抑えて証明します。

#### (1) 凸多胞体とファセットの最小定義

$\mathbb{R}^d$ において、有限個（$m + 1$ 個）の閉半空間 $H_i^- := \{ \mathbf{x} \in \mathbb{R}^d \mid \langle \mathbf{a}_i, \mathbf{x} \rangle \le b_i \}$（$\mathbf{a}_i \neq \mathbf{0}, \; i = 0, 1, \dots, m$）の共通部分として定義される**有界**な集合

$$P := \bigcap_{i=0}^m \{ \mathbf{x} \in \mathbb{R}^d \mid \langle \mathbf{a}_i, \mathbf{x} \rangle \le b_i \} \subset \mathbb{R}^d$$

が内点を持つ（$d$ 次元の体積を持つ）とき、$P$ を**$d$ 次元凸多胞体（Convex $d$-polytope）**と呼びます（[第4部](../index.md#part-4)でさらに詳しく扱います）。冗長な不等式はあらかじめ取り除き、各境界超平面 $H_i := \{ \mathbf{x} \in \mathbb{R}^d \mid \langle \mathbf{a}_i, \mathbf{x} \rangle = b_i \}$ と $P$ の交わり

$$F_i := P \cap H_i \qquad (i = 0, 1, \dots, m)$$

がすべて $(d-1)$ 次元の多胞体（**ファセット / Facet**；3次元では「面」、4次元では「胞」）になっているとします。

このとき、$P$ の境界 $\partial P$ はすべてのファセットの和集合 $\partial P = \bigcup_{i=0}^m F_i$ です。また、ファセット $F_0$ のうち他のどの超平面 $H_i$（$i \ge 1$）にも触れていない内部の点の集合を $F_0$ の**相対的内部（Relative interior）**と呼び、次で定義します：

$$\operatorname{relint}(F_0) := \{ \mathbf{x} \in \mathbb{R}^d \mid \langle \mathbf{a}_0, \mathbf{x} \rangle = b_0 \text{ かつ すべての } i \ge 1 \text{ に対し } \langle \mathbf{a}_i, \mathbf{x} \rangle < b_i \}$$

#### (2) シュレーゲル図の視点の存在と全単射性（重なりがないことの証明）

> **【定理：シュレーゲル図の存在と全単射性】**
> $P \subset \mathbb{R}^d$ を $d$ 次元凸多胞体とし、$F_0 = P \cap H_0$ をその1つのファセットとする。
>
> 1. **視点の存在：** 次の条件を満たす点（視点）$E \in \mathbb{R}^d$ が必ず存在する。
>
>     $$\langle \mathbf{a}_0, E \rangle > b_0 \quad \text{かつ、すべての } i \in \{1, \dots, m\} \text{ に対して} \quad \langle \mathbf{a}_i, E \rangle < b_i$$
>
> 2. **中心射影の全単射性：** 上の視点 $E$ から超平面 $H_0$ への中心射影を $\pi_E$ とする（点 $\mathbf{x}$ と $E$ を結ぶ直線と $H_0$ の交点）。このとき、$P$ の境界から $F_0$ の相対的内部を除いた集合 $K := \partial P \setminus \operatorname{relint}(F_0)$ への制限写像
>
>     $$\pi_E : \partial P \setminus \operatorname{relint}(F_0) \longrightarrow F_0$$
>
>     は**位相同型（特に1対1・重なりなし・隙間なしの全単射）**になる。

**【証明】**

1. **視点 $E$ の存在：**
    ファセット $F_0$ は $(d-1)$ 次元の凸多胞体なので、相対的内部の点 $\mathbf{p}_0 \in \operatorname{relint}(F_0)$ が存在します。定義より $\langle \mathbf{a}_0, \mathbf{p}_0 \rangle = b_0$、かつすべての $i \ge 1$ に対し $\langle \mathbf{a}_i, \mathbf{p}_0 \rangle < b_i$ です。
    ここで正の数 $\varepsilon > 0$ をとり、$E := \mathbf{p}_0 + \varepsilon \mathbf{a}_0$ とおきます。

    * $i = 0$ のとき：$\langle \mathbf{a}_0, E \rangle = b_0 + \varepsilon \Vert\mathbf{a}_0\Vert^2 > b_0$（任意の $\varepsilon > 0$ で成立）。
    * $i \ge 1$ のとき：$\langle \mathbf{a}_i, E \rangle = \langle \mathbf{a}_i, \mathbf{p}_0 \rangle + \varepsilon \langle \mathbf{a}_i, \mathbf{a}_0 \rangle$。元の値 $\langle \mathbf{a}_i, \mathbf{p}_0 \rangle$ が真に $b_i$ より小さいため、$\varepsilon > 0$ を十分小さく選べば、有限個すべての $i \in \{1, \dots, m\}$ に対して同時に $\langle \mathbf{a}_i, E \rangle < b_i$ となります。

2. **像が $F_0$ に収まること（Well-defined 性）：**
    任意の $\mathbf{x} \in K = \partial P \setminus \operatorname{relint}(F_0)$ をとります。

    * **$\mathbf{x} \in \partial F_0$（$F_0$ の縁）のとき：** $\mathbf{x}$ はすでに $H_0$ 上にあるため、$\pi_E(\mathbf{x}) = \mathbf{x} \in \partial F_0 \subset F_0$ です。
    * **$\mathbf{x} \notin F_0$ のとき：** $\mathbf{x} \in P \setminus F_0$ なので $\langle \mathbf{a}_0, \mathbf{x} \rangle < b_0$ です。一方、視点 $E$ は $\langle \mathbf{a}_0, E \rangle > b_0$ を満たします。したがって線分 $\gamma(t) = (1 - t)E + t\mathbf{x}$（$0 < t < 1$）に対して、$\langle \mathbf{a}_0, \gamma(t) \rangle = b_0$ を満たす $t_0 \in (0, 1)$ がただ1つ存在し、交点 $\mathbf{q} := \gamma(t_0) = \pi_E(\mathbf{x}) \in H_0$ が定まります。
        さらに、すべての $i \ge 1$ に対して $\langle \mathbf{a}_i, E \rangle < b_i$ かつ $\langle \mathbf{a}_i, \mathbf{x} \rangle \le b_i$ なので、$0 < t_0 < 1$ より

        $$\langle \mathbf{a}_i, \mathbf{q} \rangle = (1 - t_0)\langle \mathbf{a}_i, E \rangle + t_0 \langle \mathbf{a}_i, \mathbf{x} \rangle < (1 - t_0)b_i + t_0 b_i = b_i$$

        が成り立ちます。よって $\mathbf{q} \in \operatorname{relint}(F_0) \subset F_0$ となります。

3. **単射性（2点が重ならないこと）：**
    $\pi_E(\mathbf{x}_1) = \pi_E(\mathbf{x}_2) = \mathbf{q}$ となる2点 $\mathbf{x}_1, \mathbf{x}_2 \in K$ をとります。

    * $\mathbf{q} \in \partial F_0$ のとき、上の2.の議論から $K \setminus \partial F_0$ の点はすべて $\operatorname{relint}(F_0)$ に写るため、$\mathbf{x}_1, \mathbf{x}_2$ はともに $\partial F_0$ に属し、$\mathbf{x}_1 = \mathbf{q} = \mathbf{x}_2$ です。
    * $\mathbf{q} \in \operatorname{relint}(F_0)$ のとき、$E, \mathbf{q}, \mathbf{x}_1, \mathbf{x}_2$ は1本の半直線上に並び、$\mathbf{q}$ は $E$ と $\mathbf{x}_1$ の間、かつ $E$ と $\mathbf{x}_2$ の間にあります。もし $\mathbf{x}_1 \neq \mathbf{x}_2$ なら、一方が他方より手前（たとえば $\mathbf{x}_1$ が $\mathbf{q}$ と $\mathbf{x}_2$ の厳密な内分点 $\mathbf{x}_1 = (1-s)\mathbf{q} + s\mathbf{x}_2, \; 0 < s < 1$）になります。ところが $\mathbf{q} \in \operatorname{relint}(F_0)$（$\langle \mathbf{a}_0, \mathbf{q} \rangle = b_0$ かつ $i \ge 1$ で $\langle \mathbf{a}_i, \mathbf{q} \rangle < b_i$）であり、$\mathbf{x}_2 \in P \setminus F_0$（$\langle \mathbf{a}_0, \mathbf{x}_2 \rangle < b_0$ かつ $i \ge 1$ で $\langle \mathbf{a}_i, \mathbf{x}_2 \rangle \le b_i$）なので、内分点 $\mathbf{x}_1$ は**すべての $i \in \{0, 1, \dots, m\}$ に対して厳密な不等式 $\langle \mathbf{a}_i, \mathbf{x}_1 \rangle < b_i$** を満たしてしまいます。これは $\mathbf{x}_1$ が $P$ の内点であることを意味し、$\mathbf{x}_1 \in \partial P$ に矛盾します。よって $\mathbf{x}_1 = \mathbf{x}_2$ です。

4. **全射性（隙間なく埋まること）：**
    $\mathbf{q} \in \partial F_0$ なら $\pi_E(\mathbf{q}) = \mathbf{q}$ です。$\mathbf{q} \in \operatorname{relint}(F_0)$ のとき、半直線 $L(t) := E + t(\mathbf{q} - E)$（$t \ge 1$）を考えます。$t = 1$ では $L(1) = \mathbf{q}$ であり、$\langle \mathbf{a}_0, \mathbf{q} - E \rangle = b_0 - \langle \mathbf{a}_0, E \rangle < 0$ なので、$t$ を $1$ よりわずかに大きくすると $\langle \mathbf{a}_0, L(t) \rangle < b_0$ かつすべての $i \ge 1$ で $\langle \mathbf{a}_i, L(t) \rangle < b_i$ となり、$L(t)$ は $P$ の内部に入ります。$P$ は有界な閉集合なので、$L(t) \in P$ となる最大の $t^* > 1$ が存在し、点 $\mathbf{x} := L(t^*)$ は $\partial P \setminus F_0 \subset K$ に属し、$\pi_E(\mathbf{x}) = \mathbf{q}$ を満たします。

5. **位相同型性：**
    $K = \partial P \setminus \operatorname{relint}(F_0)$ は有界閉集合なのでコンパクト、$F_0 \subset \mathbb{R}^d$ はハウスドルフ空間であり、中心射影 $\pi_E$ は連続な全単射です。したがって **[0-3節](../0/0-3.md)の定理2**より、$\pi_E$ は位相同型写像になります。（証明終）

（※この証明が示す通り、もし視点 $E$ が $F_0$ から遠すぎたり横にズレすぎたりして「他のあるファセット $F_i$ の外側（$\langle \mathbf{a}_i, E \rangle \ge b_i$）」にはみ出してしまうと、影が $F_0$ の外へ飛び出したり重なりが生じたりします。超立方体 $C_4$ の場合は他のすべてのファセットが $x_i = \pm 1$ と $w = -1$ なので、$w$ 軸上の $E = (0, 0, 0, R)$ であれば $R > 1$ をどれだけ大きくとっても条件を満たすという特別な扱いやすさがあります。）

> **【コラム：4次元超立方体を回転させながら透視投影する —— なぜ「中が外へひっくり返る」のか？】**
>
> 4次元超立方体のシュレーゲル図（図1-4左）を動画で見たことがある人は、「内側の小さな立方体がぐんぐん大きくなって外側の立方体になり、外側の立方体が後ろへ回り込んで内側の小さな立方体に縮む」という不思議なループ運動を目にしたことがあるはずです。
> この動きは、**[0-2節](../0/0-2.md)の単回転（$xw$ 平面の回転）**と**本節の 4D $\to$ 3D 透視投影**を組み合わせた $5 \times 5$ 行列の計算で完全に再現できます。
>
> 1. まず、超立方体の各頂点 $\mathbf{p} = (x, y, z, w)^T$ に、$xw$ 平面での角度 $\theta$ の回転（[0-2節](../0/0-2.md)）をかけます：
>
>     $$x_1 = x\cos\theta - w\sin\theta, \quad y_1 = y, \quad z_1 = z, \quad w_1 = x\sin\theta + w\cos\theta$$
>
> 2. 次に、視点 $E = (0, 0, 0, R)$（たとえば $R = 3$）から 3次元空間へ透視投影します：
>
>     $$(x', y', z') = \left( \frac{R - 1}{R - w_1} x_1, \;\; \frac{R - 1}{R - w_1} y_1, \;\; \frac{R - 1}{R - w_1} z_1 \right)$$
>
> $\theta = 0$ のとき、$w = +1$ の胞が視点に最も近いため外側の大きな立方体に見え、$w = -1$ の胞が最も遠いため内側の小さな立方体に見えます。
> ところが $\theta$ を $0$ から $90^\circ$ へ回すと、もともと右側（$x = +1$）にあった四角錐台の胞が $w_1 = +\sin\theta$ 方向へ手前に迫り出して大きく広がり、外側の立方体（$w = +1$）は左側（$x_1 = -\sin\theta$）へ縮んで四角錐台に姿を変えます。さらに $\theta = 180^\circ$ まで回すと、**奥にあった $w = -1$ の胞が手前（$w_1 = +1$）に来て外側の大きな立方体になり、元の外側の立方体が奥（$w_1 = -1$）へ行って内側の小さな立方体に収まります**。
>
> 3次元の立方体が回転するときも、2次元の画面上では「奥にあった小さな正方形が手前に来て大きな正方形になり、手前の正方形が奥へ縮んで入れ替わる」というまったく同じ現象が起きています。4次元超立方体の「裏返り」は、4次元空間で何かがゴムのように変形しているわけではなく、**完全に剛体（硬い立体）のまま4次元回転したときの遠近法の見え方**に過ぎないのです。

### 4. 翻訳と展望（Bridge）：第1部のまとめと第2部への接続

これで[第1部](../index.md#part-1)「影を落とす（射影の幾何）」が完了しました。

1. **アフィン空間と平行投影（[1-1節](1-1.md)）：** 平行性と線分比を保つ影の仕組み。
2. **射影空間 $\mathbb{RP}^n$ と同次座標（[1-2節](1-2.md)）：** 消失点を無限遠点として組み込み、透視投影を行列の積に統一した舞台。
3. **複比と射影双対（[1-3節](1-3.md)）：** 透視投影でも壊れない不変量と、点・超平面の対称性。
4. **シュレーゲル図（1-4節）：** 凸多胞体の境界を重なりなく1次元低い空間へ写す透視投影。

しかし、ここまでの[第1部](../index.md#part-1)で扱ったのは「元の高次元立体をすでに知っている状態から、影を落とす（順問題）」でした。では逆に、**「落とされた影（2次元や3次元の図）だけを見て、元の高次元立体を推測・復元しようとしたとき（逆問題）」**、あるいは**「凸多胞体ではない、滑らかに曲がった曲面や4次元にしか住めない曲面を投影したとき」**には何が起きるでしょうか？

次から始まる[第2部](../index.md#part-2)「次元を落とすと何が壊れるか？」では、射影の避けられない宿命である**錯視（復元自由度とコホモロジー $H^1$）・特異点（折り目・カスプ・ホイットニーの傘）・自己交差（クラインの壺とボーイ曲面）**を数理化します。
