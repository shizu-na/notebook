### 前節（5-2）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **$720^\circ$ 回転をほどくホモトピー $\tilde{H}(\theta, s)$ の検算：**

    $$\tilde{H}(\theta, s) = \left( \cos\alpha\,\sin\frac{\theta}{2}\,\mathbf{u} + \sin\alpha\cos\alpha\left(1 - \cos\frac{\theta}{2}\right)\mathbf{w}, \;\; \cos^2\alpha\cos\frac{\theta}{2} + \sin^2\alpha \right) \qquad \left(\alpha = \frac{\pi}{2}s\right)$$

    * **$s = 0$（$\alpha = 0$）のとき：** $\cos 0 = 1, \; \sin 0 = 0$ より $\tilde{H}(\theta, 0) = \left(\sin\frac{\theta}{2}\,\mathbf{u}, \; \cos\frac{\theta}{2}\right)$ となり、$720^\circ$ 回転ループの $S^3$ への持ち上げそのものになります。
    * **$s = 1$（$\alpha = \frac{\pi}{2}$）のとき：** $\cos\frac{\pi}{2} = 0, \; \sin\frac{\pi}{2} = 1$ より $\tilde{H}(\theta, 1) = (\mathbf{0}, \; 1) = N$ となり、$\theta$ によらず北極1点に収縮します。

2. **単位球面 $S^3$ 上に閉じた積が入るためのノルムの条件：**
    2つの元 $p, q \in \mathbb{R}^4$ の積 $pq$ に対して、長さ（ノルム）の乗法性

    $$\Vert pq \Vert = \Vert p \Vert \Vert q \Vert$$

    が成り立てば、単位球面 $S^3$ 上の元（$\Vert p \Vert = 1, \; \Vert q \Vert = 1$）同士の積は必ず $\Vert pq \Vert = 1 \cdot 1 = 1$ となって再び $S^3$ の上に収まり、$S^3$ 自身が群の構造を持つことができます。

この乗法性 $\Vert pq \Vert = \Vert p \Vert \Vert q \Vert$ を満たす4次元の数体系こそが、1843年にウィリアム・ローワン・ハミルトンが発見した**四元数（クォータニオン）$\mathbb{H}$** です。本節では、四元数によって3次元回転・4次元二重回転・そして第4部の正24胞体と正600胞体を一挙に統合します。

## 5-3. 四元数 $\mathbb{H}$ と2重被覆 $S^3 \to \mathrm{SO}(3)$, $S^3 \times S^3 \to \mathrm{SO}(4)$

### 1. 動機（Why）：なぜ3次元回転を扱うために「4次元の数」が必要なのか？

2次元平面 $\mathbb{R}^2$ の回転は、複素数 $z = \cos\theta + i\sin\theta \in S^1$ を1回掛けるだけで簡潔に計算できました。そこで19世紀の数学者ハミルトンは、「3次元空間 $\mathbb{R}^3$ の回転も、実数1個と虚数単位2個からなる『3元数 $a + bi + cj$』の掛け算で表せるはずだ」と考え、10年以上にわたって試行錯誤を続けました。

しかし、3次元空間にはノルムを保つ掛け算は**数学的に存在しません**（たとえば積 $ij$ の行き先を $a + bi + cj$ と置くと必ず矛盾が生じます）。行き詰まったハミルトンが「思い切って3つ目の虚数単位 $k$ を増やして**4次元空間**へ行き、しかも掛け算の交換法則 $ij = ji$ を捨てて $ij = -ji = k$ とする」という発想に到達した瞬間、すべての歯車が噛み合いました。

四元数 $\mathbb{H}$ を導入することで、本ノートでここまで別々に学んできた4つのテーマが1本の数式に統合されます。

1. **ジンバルロックの完全解消（3次元回転 $\mathrm{SO}(3)$）：** オイラー角のような座標の特異点を持たず、単位四元数 $q \in S^3$ による挟み込み $q\mathbf{v}q^{-1}$ で3次元回転を滑らかに記述できる。
2. **前節（5-2節）の2対1対応の代数化：** 回転空間 $\mathrm{SO}(3) \cong \mathbb{RP}^3 = S^3 / \{\pm 1\}$ が、単位四元数群 $S^3$ から $\mathrm{SO}(3)$ への群準同型の核 $\ker \Phi_3 = \{\pm 1\}$ として自動的に現れる。
3. **第0部（0-2節）の4次元二重回転の回収：** 2つの単位四元数 $(u, v) \in S^3 \times S^3$ の左右からの掛け算 $x \mapsto u x v^{-1}$ が、4次元回転群 $\mathrm{SO}(4)$ のすべての二重回転を漏れなく生成する。
4. **第4部（4-3節）の正24胞体・正600胞体の回収：** 4次元に特有の正24胞体（24頂点）と正600胞体（120頂点）の頂点集合は、単なる幾何学的配置ではなく、**単位四元数群 $S^3$ の有限部分群そのもの**になっている。

### 2. 具体例と幾何学的イメージ（Toy Model）

#### 実験A：なぜ3次元回転は「半角 $\theta/2$ で両側から挟む」のか？

四元数 $\mathbb{H}$ の虚数単位 $i, j, k$ は、ハミルトンの基本関係式

$$i^2 = j^2 = k^2 = ijk = -1$$

（したがって $ij = k, \; jk = i, \; ki = j$、逆順は符号反転 $ji = -k, \; kj = -i, \; ik = -j$）を満たします。実部が $0$ の四元数 $v = xi + yj + zk$（**純虚四元数**）を、3次元空間 $\mathbb{R}^3$ のベクトル $(x, y, z)^T$ と同一視します。

いま、$z$ 軸（単位ベクトル $k$）の周りに角度 $\theta$ だけ回転させる単位四元数 $q := \cos\frac{\theta}{2} + k\sin\frac{\theta}{2}$（共役は $\bar{q} = q^{-1} = \cos\frac{\theta}{2} - k\sin\frac{\theta}{2}$）を用意し、$x$ 軸の単位ベクトル $i$ を**両側から挟んで** $q i q^{-1}$ を計算してみます。

1. まず左から掛ける：$q i = \left(\cos\frac{\theta}{2} + k\sin\frac{\theta}{2}\right)i = i\cos\frac{\theta}{2} + ki\sin\frac{\theta}{2} = i\cos\frac{\theta}{2} + j\sin\frac{\theta}{2}$。
    （$xy$ 平面上で $\frac{\theta}{2}$ だけ回転します。）

2. 次に右から $q^{-1}$ を掛ける（$ik = -j, \; jk = i$ に注意）：

    $$\begin{aligned}
    (q i) q^{-1}
    &= \left(i\cos\frac{\theta}{2} + j\sin\frac{\theta}{2}\right)\left(\cos\frac{\theta}{2} - k\sin\frac{\theta}{2}\right) \\
    &= i\cos^2\frac{\theta}{2} - ik\cos\frac{\theta}{2}\sin\frac{\theta}{2} + j\sin\frac{\theta}{2}\cos\frac{\theta}{2} - jk\sin^2\frac{\theta}{2} \\
    &= i\left(\cos^2\frac{\theta}{2} - \sin^2\frac{\theta}{2}\right) + j\left(2\sin\frac{\theta}{2}\cos\frac{\theta}{2}\right) = i\cos\theta + j\sin\theta
    \end{aligned}$$

一方、回転軸上のベクトル $k$ を挟むと、$q$ と $k$ は可換（$qk = kq$）なので $q k q^{-1} = k q q^{-1} = k$ となって動きません。
つまり、**左からの掛け算 $q$ が $\frac{\theta}{2}$ 回転させ、右からの掛け算 $q^{-1}$ が（$i, j$ との非可換性による符号反転のおかげで）さらに同じ向きに $\frac{\theta}{2}$ 回転させて合計 $\theta$ 回転を生み、軸方向 $k$ では逆に打ち消し合って静止する**――これが半角 $\frac{\theta}{2}$ が現れる代数的な仕掛けです。

#### 実験B：左掛け算だけ・右掛け算だけを行うと「4次元の等角回転」になる

では、挟み込まずに**左からだけ** $u = \cos\alpha + i\sin\alpha$ を任意の4次元ベクトル（四元数）$x = x_0 + x_1 i + x_2 j + x_3 k$ に掛けると何が起きるでしょうか？

$$u x = (\cos\alpha + i\sin\alpha)(x_0 + x_1 i + x_2 j + x_3 k) = (x_0\cos\alpha - x_1\sin\alpha) + (x_0\sin\alpha + x_1\cos\alpha)i + (x_2\cos\alpha - x_3\sin\alpha)j + (x_2\sin\alpha + x_3\cos\alpha)k$$

成分を行列で書けば、$1\text{-}i$ 平面を $+\alpha$、$j\text{-}k$ 平面も $+\alpha$ 回す **0-2節の等角回転 $R(+\alpha, +\alpha)$** そのものです。
一方、**右からだけ** $\bar{v} = \cos\beta - i\sin\beta$ を掛けると（$ji = -k, \; ki = j$ より後ろの2成分の回転向きが逆転し）、$1\text{-}i$ 平面を $-\beta$、$j\text{-}k$ 平面を $+\beta$ 回す**逆向きの等角回転 $R(-\beta, +\beta)$** になります。

この2つを同時に作用させる $x \mapsto u x \bar{v}$ は、2つの平面の回転角が

$$\theta = \alpha - \beta, \qquad \phi = \alpha + \beta$$

となる**任意の4次元二重回転 $R(\theta, \phi)$** を生み出します（特に $\alpha = \beta$ のとき $\theta = 0$ となり、実軸 $1$ を固定する3次元回転 $q x \bar{q}$ に一致します）。

### 3. 厳密な定義と定理（What）：四元数の代数構造・2重被覆定理・正多胞体部分群

ここからは、四元数 $\mathbb{H}$ の基本性質、3次元回転の2重被覆 $\Phi_3$、4次元回転の2重被覆 $\Phi_4$、および正24胞体・正600胞体の部分群構造を、飛躍を抑えて証明します。

#### (1) 四元数 $\mathbb{H}$・共役・ノルムの乗法性

実4次元ベクトル空間 $\mathbb{R}^4$ の標準基底を $\{1, i, j, k\}$ と書き、元を $q = a + bi + cj + dk$（$a, b, c, d \in \mathbb{R}$）と表します。乗法を基底上で

$$i^2 = j^2 = k^2 = -1, \qquad ij = -ji = k, \qquad jk = -kj = i, \qquad ki = -ik = j$$

と定め、分配法則によって双線形に拡張した代数を**ハミルトンの四元数体（斜体）$\mathbb{H}$** と呼びます（乗法は結合法則 $(pq)r = p(qr)$ を満たしますが、非可換です）。

$q = a + bi + cj + dk \in \mathbb{H}$ に対して、実部 $\operatorname{Re}(q) := a$、虚部 $\operatorname{Im}(q) := bi + cj + dk$ と書き、**共役** $\bar{q}$ と**ノルム** $\vert q \vert$ を次で定義します：

$$\bar{q} := a - bi - cj - dk, \qquad \vert q \vert := \sqrt{a^2 + b^2 + c^2 + d^2} = \sqrt{q \bar{q}}$$

ここで2つの基本補題が成り立ちます。

1. **共役の反準同型性 $\overline{pq} = \bar{q}\bar{p}$：**
    双線形性より基底同士の積で確認すれば十分です。$1$ との積は自明、$i^2 = -1$ なら $\overline{i^2} = -1 = (-i)(-i) = \bar{i}\bar{i}$、$ij = k$ なら $\overline{ij} = \bar{k} = -k = (-j)(-i) = \bar{j}\bar{i}$（他の巡回も同様）。よってすべての $p, q \in \mathbb{H}$ で $\overline{pq} = \bar{q}\bar{p}$ が成り立ちます。

2. **ノルムの乗法性 $\vert pq \vert = \vert p \vert \vert q \vert$ と逆元の存在：**
    $q\bar{q} = \vert q \vert^2 \in \mathbb{R}$ は実数なので他の四元数と交換できます。したがって、

    $$\vert pq \vert^2 = (pq)\overline{(pq)} = p(q\bar{q})\bar{p} = \vert q \vert^2 (p\bar{p}) = \vert p \vert^2 \vert q \vert^2$$

    両辺の平方根をとれば $\vert pq \vert = \vert p \vert \vert q \vert$ が得られます。また $q \neq 0$ のとき $q^{-1} := \frac{\bar{q}}{\vert q \vert^2}$ が両側逆元（$q q^{-1} = q^{-1} q = 1$）を与えます。

これにより、**単位3次元球面 $S^3 = \{ q \in \mathbb{H} \mid \vert q \vert = 1 \}$** は、四元数の積に関して閉じ、単位元 $1$ と逆元 $q^{-1} = \bar{q} \in S^3$ を持つ**群（リー群）**になります。

また、実部が $0$ の空間 $\operatorname{Im}\mathbb{H} := \{ xi + yj + zk \mid x, y, z \in \mathbb{R} \} \cong \mathbb{R}^3$ 上の2つの純虚四元数 $\mathbf{u} = u_1 i + u_2 j + u_3 k$ と $\mathbf{v} = v_1 i + v_2 j + v_3 k$ の積を直接展開すると、3次元の内積と外積が同時に現れる簡潔な公式が得られます：

$$\mathbf{u}\mathbf{v} = -\langle \mathbf{u}, \mathbf{v} \rangle + \mathbf{u} \times \mathbf{v}$$

#### (2) 定理1：3次元回転の2重被覆 $\Phi_3 : S^3 \to \mathrm{SO}(3)$ の証明

> **【定理1：単位四元数による3次元回転の2重被覆】**
> 各 $q \in S^3$ に対して、$\operatorname{Im}\mathbb{H} \cong \mathbb{R}^3$ 上の変換 $\Phi_3(q)$ を
>
> $$\Phi_3(q)(\mathbf{v}) := q \mathbf{v} \bar{q} \qquad (\mathbf{v} \in \operatorname{Im}\mathbb{H})$$
>
> と定める。このとき、
>
> 1. 任意の $q = \cos\frac{\theta}{2} + \mathbf{u}\sin\frac{\theta}{2} \in S^3$（$\mathbf{u} \in S^2 \subset \operatorname{Im}\mathbb{H}$）に対して、$\Phi_3(q)$ は**軸 $\mathbf{u}$ の周りの角度 $\theta$ の3次元回転（ロドリゲスの公式）**に完全に一致する。
> 2. 写像 $\Phi_3 : S^3 \to \mathrm{SO}(3)$ は**全射の群準同型**であり、その核は $\ker \Phi_3 = \{+1, -1\}$ である。したがって群の準同型定理より $S^3 / \{\pm 1\} \cong \mathrm{SO}(3)$ が成り立つ。

**【証明】**

1. **ロドリゲスの公式との一致（直接計算）：**
    $\alpha := \frac{\theta}{2}$ とおき、$q = \cos\alpha + \mathbf{u}\sin\alpha$、$\bar{q} = \cos\alpha - \mathbf{u}\sin\alpha$（ただし $\mathbf{u} \in \operatorname{Im}\mathbb{H}, \; \vert\mathbf{u}\vert = 1$）とします。任意の $\mathbf{v} \in \operatorname{Im}\mathbb{H}$ に対して $q \mathbf{v} \bar{q}$ を展開します：

    $$q \mathbf{v} \bar{q} = (\cos\alpha + \mathbf{u}\sin\alpha)\mathbf{v}(\cos\alpha - \mathbf{u}\sin\alpha) = (\cos^2\alpha)\mathbf{v} + (\sin\alpha\cos\alpha)(\mathbf{u}\mathbf{v} - \mathbf{v}\mathbf{u}) - (\sin^2\alpha)\mathbf{u}\mathbf{v}\mathbf{u}$$

    ここで純虚四元数の積公式 $\mathbf{u}\mathbf{v} = -\langle \mathbf{u}, \mathbf{v} \rangle + \mathbf{u} \times \mathbf{v}$ を使います。

    * 第2項の交換子：$\mathbf{u}\mathbf{v} - \mathbf{v}\mathbf{u} = (-\langle \mathbf{u}, \mathbf{v}\rangle + \mathbf{u} \times \mathbf{v}) - (-\langle \mathbf{v}, \mathbf{u}\rangle + \mathbf{v} \times \mathbf{u}) = 2(\mathbf{u} \times \mathbf{v})$。
    * 第3項の3重積：ベクトル3重積の公式 $(\mathbf{u} \times \mathbf{v}) \times \mathbf{u} = \Vert\mathbf{u}\Vert^2 \mathbf{v} - \langle \mathbf{u}, \mathbf{v} \rangle \mathbf{u} = \mathbf{v} - \langle \mathbf{u}, \mathbf{v} \rangle \mathbf{u}$ と $\langle \mathbf{u} \times \mathbf{v}, \mathbf{u} \rangle = 0$ より、

        $$\mathbf{u}\mathbf{v}\mathbf{u} = (-\langle \mathbf{u}, \mathbf{v}\rangle + \mathbf{u} \times \mathbf{v})\mathbf{u} = -\langle \mathbf{u}, \mathbf{v}\rangle \mathbf{u} - \langle \mathbf{u} \times \mathbf{v}, \mathbf{u} \rangle + (\mathbf{u} \times \mathbf{v}) \times \mathbf{u} = \mathbf{v} - 2\langle \mathbf{u}, \mathbf{v}\rangle \mathbf{u}$$

    これらを元の式に代入して倍角公式（$\cos^2\alpha - \sin^2\alpha = \cos 2\alpha, \; 2\sin\alpha\cos\alpha = \sin 2\alpha, \; 2\sin^2\alpha = 1 - \cos 2\alpha$）を適用すると、

    $$q \mathbf{v} \bar{q} = \mathbf{v}\cos 2\alpha + (\mathbf{u} \times \mathbf{v})\sin 2\alpha + \mathbf{u}\langle \mathbf{u}, \mathbf{v} \rangle(1 - \cos 2\alpha)$$

    となります。$\theta = 2\alpha$ を戻せば、これは5-2節で導出した**ロドリゲスの回転公式 $R(\theta\mathbf{u})\mathbf{v}$** そのものです（特に純虚四元数 $\operatorname{Im}\mathbb{H}$ を自分自身へ写し、$\mathrm{SO}(3)$ に属します）。

2. **群準同型性・全射性・核の決定：**

    * **準同型性：** 任意の $p, q \in S^3$ に対し $\Phi_3(pq)(\mathbf{v}) = (pq)\mathbf{v}\overline{(pq)} = p(q\mathbf{v}\bar{q})\bar{p} = \big(\Phi_3(p) \circ \Phi_3(q)\big)(\mathbf{v})$。
    * **全射性：** 0-2節の系1より任意の $A \in \mathrm{SO}(3)$ はある $\mathbf{u} \in S^2, \; \theta \in [0, \pi]$ による回転 $R(\theta\mathbf{u})$ なので、$q := \cos\frac{\theta}{2} + \mathbf{u}\sin\frac{\theta}{2} \in S^3$ をとれば 1. より $\Phi_3(q) = A$ です。
    * **核 $\ker \Phi_3$：** $q = a + bi + cj + dk \in S^3$ が $\Phi_3(q) = I_3$ を満たすことは、すべての $\mathbf{v} \in \operatorname{Im}\mathbb{H}$ で $q\mathbf{v}\bar{q} = \mathbf{v} \iff q\mathbf{v} = \mathbf{v}q$ であることと同値です。$\mathbf{v} = i$ と交換する条件 $qi = iq$ より $cj - dk = -cj + dk \implies c = d = 0$。さらに $\mathbf{v} = j$ と交換する条件より $b = 0$。よって $q = a \in \mathbb{R} \cap S^3 = \{+1, -1\}$ となります。（証明終）

#### (3) 定理2：4次元回転の2重被覆 $\Phi_4 : S^3 \times S^3 \to \mathrm{SO}(4)$ の証明

次に、左と右から別々の単位四元数 $(u, v) \in S^3 \times S^3$ を掛ける変換によって、4次元回転群 $\mathrm{SO}(4)$ 全体が2対1で覆われることを証明します。

> **【定理2：四元数による4次元回転の2重被覆】**
> 各 $(u, v) \in S^3 \times S^3$ に対して、$\mathbb{H} \cong \mathbb{R}^4$ 上の線形変換 $\Phi_4(u, v)$ を
>
> $$\Phi_4(u, v)(x) := u x \bar{v} \qquad (x \in \mathbb{H})$$
>
> と定める。このとき、$\Phi_4 : S^3 \times S^3 \to \mathrm{SO}(4)$ は**全射の群準同型**であり、その核は
>
> $$\ker \Phi_4 = \{ (1, 1), \; (-1, -1) \} \cong \mathbb{Z}/2\mathbb{Z}$$
>
> である。したがって $(S^3 \times S^3) / \{\pm(1, 1)\} \cong \mathrm{SO}(4)$ が成り立つ。

**【証明】**

1. **$\Phi_4(u, v) \in \mathrm{SO}(4)$ であること：**
    ノルムの乗法性より、任意の $x \in \mathbb{H}$ に対して $\vert u x \bar{v} \vert = \vert u \vert \vert x \vert \vert \bar{v} \vert = 1 \cdot \vert x \vert \cdot 1 = \vert x \vert$（長さの保存）。極化恒等式 $\langle x, y \rangle = \frac{1}{2}(\vert x + y \vert^2 - \vert x \vert^2 - \vert y \vert^2)$ より内積も完全に保たれるため、$\Phi_4(u, v) \in \mathrm{O}(4)$ です。
    さらに、行列式 $\det \Phi_4(u, v)$ は $(u, v) \in S^3 \times S^3$ の連続関数であり、値は $+1$ か $-1$ しかとりません。$S^3 \times S^3$ は連結（任意の2点を連続な道で結べる）であり、$(u, v) = (1, 1)$ で $\det \Phi_4(1, 1) = \det I_4 = +1$ なので、すべての $(u, v) \in S^3 \times S^3$ で $\det \Phi_4(u, v) = +1$、すなわち $\Phi_4(u, v) \in \mathrm{SO}(4)$ です。

2. **群準同型性：**
    任意の $(u_1, v_1), (u_2, v_2) \in S^3 \times S^3$ と $x \in \mathbb{H}$ に対して、

    $$\Phi_4(u_1 u_2, \; v_1 v_2)(x) = (u_1 u_2) x \overline{(v_1 v_2)} = u_1 (u_2 x \bar{v}_2) \bar{v}_1 = \big(\Phi_4(u_1, v_1) \circ \Phi_4(u_2, v_2)\big)(x)$$

3. **核 $\ker \Phi_4$ の決定：**
    すべての $x \in \mathbb{H}$ で $u x \bar{v} = x$ が成り立つとします。まず $x = 1$ を代入すると $u \bar{v} = 1 \implies u = v$。するとすべての $x \in \mathbb{H}$ で $u x \bar{u} = x \iff u x = x u$ となります。定理1の核の計算と同じく、$i, j, k$ とすべて交換する単位四元数は $u \in \{+1, -1\}$ のみです。よって $(u, v) = (1, 1)$ または $(-1, -1)$ に限られます。

4. **全射性（任意の4次元回転が $u x \bar{v}$ で書けること）：**
    任意の $A \in \mathrm{SO}(4)$ をとります。単位ベクトル $1 \in S^3 \subset \mathbb{H}$ の像を $y := A(1) \in S^3$ とおきます。
    ここで合成変換 $B := \Phi_4(\bar{y}, 1) \circ A \in \mathrm{SO}(4)$ を作ると、

    $$B(1) = \bar{y} A(1) = \bar{y} y = 1$$

    を満たします。$B$ は内積を保つ直交変換なので、$1$ に直交する3次元部分空間 $1^\perp = \operatorname{Im}\mathbb{H} \cong \mathbb{R}^3$ を自分自身に写します。しかも $\det B = +1$ かつ $B(1) = 1$ なので、$B$ の $\operatorname{Im}\mathbb{H}$ への制限 $B|_{\operatorname{Im}\mathbb{H}}$ は **$\mathrm{SO}(3)$ の元**になります。
    したがって、**定理1（$\Phi_3$ の全射性）**より、ある $w \in S^3$ が存在して、すべての $\mathbf{v} \in \operatorname{Im}\mathbb{H}$ に対して $B(\mathbf{v}) = w \mathbf{v} \bar{w}$ が成り立ちます。一方 $B(1) = 1 = w \cdot 1 \cdot \bar{w}$ も成り立つため、線形性よりすべての $x = a \cdot 1 + \mathbf{v} \in \mathbb{H}$ に対して $B(x) = w x \bar{w} = \Phi_4(w, w)(x)$ となります。
    最後に左から $\Phi_4(y, 1)$ を掛ければ、

    $$A = \Phi_4(y, 1) \circ B = \Phi_4(y, 1) \circ \Phi_4(w, w) = \Phi_4(yw, \; w)$$

    となり、$u := yw \in S^3, \; v := w \in S^3$ によって $A = \Phi_4(u, v)$ と表せることが証明されました。（証明終）

#### (4) 第4部の回収：正24胞体と正600胞体は $S^3$ の有限部分群である

ここで、4-3節で座標構成した2つの4次元正多胞体（**正24胞体**と**正600胞体**）の頂点集合を、半径 $1$ の単位3次元球面 $S^3 \subset \mathbb{H}$ の上の四元数として書き直してみます。

1. **正24胞体の24頂点 ＝ 二項四面体群 $2T \subset S^3$（位数 24）：**
    4-3節の24頂点を $\frac{1}{2}$ 倍して $S^3$ 上に乗せると、次の24個の単位四元数になります：

    $$2T := \big\{ \pm 1, \; \pm i, \; \pm j, \; \pm k \big\} \;\cup\; \left\{ \frac{\pm 1 \pm i \pm j \pm k}{2} \right\}$$

    これが四元数の積で閉じていることを確かめましょう。

    * 前半の8個 $\{\pm 1, \pm i, \pm j, \pm k\}$ はそれ自身で**四元数群 $Q_8$**（位数 $8$）をなします（幾何学的には正16胞体の8頂点）。
    * 後半の16個の元 $h = \frac{\varepsilon_0 + \varepsilon_1 i + \varepsilon_2 j + \varepsilon_3 k}{2}$（$\varepsilon_m \in \{\pm 1\}$）に $i$ を掛けても符号と成分が入れ替わるだけで再び後半の16個に入ります。
    * 後半の元同士の積（例：$\frac{1+i+j+k}{2} \cdot \frac{1+i+j+k}{2} = \frac{-2 + 2i + 2j + 2k}{4} = \frac{-1 + i + j + k}{2}$、あるいは $\frac{1+i+j+k}{2} \cdot \frac{1-i+j-k}{2} = \frac{0 + 0i + 4j + 0k}{4} = j$）を計算すると、分子の4成分が必ず「すべて $\pm 2$」か「1個だけ $\pm 4$ で残り $0$」になり、$4$ で割ると必ず再び $2T$ の24個のいずれかに着地します。
    * 逆元も $\bar{h} \in 2T$ なので、**正24胞体の24頂点は $S^3$ の位数 24 の部分群 $2T$ をなします**。
    * さらに、この部分群 $2T$ を定理1の2重被覆 $\Phi_3: S^3 \to \mathrm{SO}(3)$ で $\mathrm{SO}(3)$ へ写すと、$\ker \Phi_3 = \{\pm 1\} \subset 2T$ で2対1に潰れ、位数 $24/2 = 12$ の部分群 $\Phi_3(2T) \subset \mathrm{SO}(3)$ が得られます。これこそが、0-4節の確認問題で計算した**正四面体の回転対称群 $T \cong A_4$（位数 12）**そのものです（たとえば $q = \frac{1+i+j+k}{2} = \cos\frac{\pi}{3} + \frac{i+j+k}{\sqrt{3}}\sin\frac{\pi}{3}$ は、対角線 $(1,1,1)$ 周りの $120^\circ$ 回転 $i \mapsto j \mapsto k \mapsto i$ を与えます）。

2. **正600胞体の120頂点 ＝ 二項二十面体群 $2I \subset S^3$（位数 120）：**
    同様に、4-3節の正600胞体の120頂点を $\frac{1}{2}$ 倍して $S^3$ 上に乗せた集合

    $$2I := 2T \;\cup\; \left\{ \text{座標 } \left(\pm\frac{\phi}{2}, \; \pm\frac{1}{2}, \; \pm\frac{\phi^{-1}}{2}, \; 0\right) \text{ のすべての偶置換} \right\}$$

    も、四元数の掛け算に関して閉じた**位数 120 の有限部分群**をなします。これを $\Phi_3: S^3 \to \mathrm{SO}(3)$ で写すと、位数 $120/2 = 60$ の**正二十面体（・正十二面体）の回転対称群 $I \cong A_5$** へちょうど2対1に対応します。

4次元空間にだけ現れた「正24胞体」と「正600胞体」という例外的な正多胞体の背後には、**「$S^3$ が群の構造を持ち、3次元正多面体の回転対称群を2重に持ち上げた有限部分群がそのまま4次元の正多胞体の頂点になる」**という、代数と幾何の深い一致が隠されていたのです。

> **【コラム：ジンバルロックの正体と、「球面 $S^n$ が群になれる次元」の制約】**
>
> 航空機・ドローン・3DCGなどで物体の姿勢を表すとき、直感的な方法として「$x$ 軸・$y$ 軸・$z$ 軸の周りに順番に回す3つの角度（**オイラー角**：ロール・ピッチ・ヨー）」が使われます。ところが、ピッチ角がちょうど $\pm 90^\circ$ に達すると、1つ目の回転軸と3つ目の回転軸が空間上で一直線に重なってしまい、1自由度が失われて思い通りの方向へ滑らかに回転できなくなる**ジンバルロック（Gimbal lock）**という問題となる現象が起きます。
>
> 数学的に見れば、これは地球儀の北極・南極で経度が定まらなくなるのと同じ「座標の特異点」です（$\mathrm{SO}(3) \cong \mathbb{RP}^3$ は3次元球面を半分に畳んだ曲がった空間なので、1枚の3次元座標系 $(\psi, \theta, \phi)$ で特異点なしに覆うことが位相的に不可能です）。これに対し、四元数 $q \in S^3 \subset \mathbb{R}^4$ は変数を1つ増やして4次元空間の球面 $S^3$ 上で直接回転を扱うため、**すべての姿勢が完全に平等になり、ジンバルロックが原理的に一切起きません**。さらに、2つの姿勢 $q_1, q_2 \in S^3$ の間を $S^3$ の大円に沿って最短・等速に補間する**球面線形補間（SLERP）**も1本の式で計算できます。
>
> ところで、ここまで見てきた「球面 $S^n$ の上に連続な掛け算（群の構造）が入る」という現象は、どんな次元でも起きるのでしょうか？
> 実は、位相幾何学の深い定理（ボット＝ミルナー・アダムスの定理）によって、**単位球面 $S^n$ がリー群（滑らかな群）の構造を持てるのは、全次元の中で $S^0 = \{\pm 1\}$（実数 $\mathbb{R}$）、$S^1$（複素数 $\mathbb{C}$）、$S^3$（四元数 $\mathbb{H}$）のたった3つだけ**であることが証明されています。
> （※もう1つだけ、8次元空間に**八元数（オクトニオン）$\mathbb{O}$** が存在し、ノルムの乗法性 $\vert pq \vert = \vert p \vert \vert q \vert$ は成り立ちますが［**フルヴィッツの定理**：ノルムを保つ合成代数は $1, 2, 4, 8$ 次元のみ］、八元数では結合法則 $(pq)r = p(qr)$ が壊れるため $S^7$ は群にはなれません。）
>
> 私たちが住む3次元空間の回転群 $\mathrm{SO}(3)$ を2重に覆う $S^3$ が「群になれる最後の球面」であったことこそが、4次元幾何学を他のどの次元とも違う特別な豊かさにしている根本原因なのです。

### 4. 翻訳と展望（Bridge）：次節（ホップ・ファイブレーション）への直結

本節の定理1（$\Phi_3: S^3 \to \mathrm{SO}(3)$）と、5-1節の立体射影 $\sigma: S^3 \setminus \{N\} \to \mathbb{R}^3$ が揃ったことで、いよいよ第5部の最終節である**ホップ・ファイブレーション $S^3 \to S^2$** を1行の数式で定義する準備が完了しました。

本節の定理1の式 $\Phi_3(q)(\mathbf{v}) = q \mathbf{v} \bar{q}$ において、$\mathbf{v}$ として北極 $k$ という1本の単位ベクトルを固定し、$q \in S^3$ を動かす写像

$$\pi : S^3 \longrightarrow S^2, \qquad \pi(q) := q k \bar{q}$$

を考えてみてください。すると、$q \in S^3$ の**右から**位相円 $e^{k\theta} = \cos\theta + k\sin\theta \in S^1$ を掛けても $(q e^{k\theta}) k \overline{(q e^{k\theta})} = q (e^{k\theta} k e^{-k\theta}) \bar{q} = q k \bar{q}$ と値が変わりません。つまり、**$S^2$ の各点の上には、1本の円周 $S^1$ が丸ごとぶら下がっています**。

次節（5-4節）では、この写像 $\pi: S^3 \to S^2$ を5-1節の立体射影で私たちの3次元空間 $\mathbb{R}^3$ 全体へ展開し、**3次元球面 $S^3$ が「入れ子になったクリフォード・トーラス」と「互いに1回ずつ絡み合う円周の束」として $\mathbb{R}^3$ を隙間なく埋め尽くす姿**を可視化します。
