### 前節（5-3）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **単位四元数 $q = \frac{1 + i + j + k}{2}$ による3次元回転（$\bar{q} = \frac{1 - i - j - k}{2}$）：**

    * $q i = \frac{i - 1 - k + j}{2} = \frac{-1 + i + j - k}{2}$ に右から $\bar{q}$ を掛けると、

        $$q i \bar{q} = \frac{1}{4}(-1 + i + j - k)(1 - i - j - k) = \frac{1}{4}(0 + 0i + 4j + 0k) = \mathbf{j}$$

    * 同様に計算すると **$q j \bar{q} = k$**、**$q k \bar{q} = i$** となります。

    すなわち、この四元数は3本の座標軸を $i \mapsto j \mapsto k \mapsto i$ と巡回させる、対角線 $(1, 1, 1)$ 周りの $120^\circ$ 回転（正四面体の回転対称）を与えています。

2. **ホップ写像 $\pi(q) := q k \bar{q}$ の展開計算：**
    $q = a + bi + cj + dk$（$a^2 + b^2 + c^2 + d^2 = 1$）に対して $q k = -d + ci - bj + ak$ であり、右から $\bar{q} = a - bi - cj - dk$ を掛けて成分ごとにまとめます。

    * 実部：$-da + cb - bc + ad = 0$（必ず純虚四元数になる）
    * $i$ 成分：$(-d)(-b) + ca + (-b)(-d) - a(-c) = 2(ac + bd)$
    * $j$ 成分：$(-d)(-c) - ba - ab - c(-d) = 2(cd - ab)$
    * $k$ 成分：$(-d)(-d) + a^2 - c^2 - b^2 = a^2 + d^2 - b^2 - c^2$

    よって、ホップ写像の明示公式は次のようになります：

    $$\pi(a + bi + cj + dk) = 2(ac + bd)\,i + 2(cd - ab)\,j + (a^2 + d^2 - b^2 - c^2)\,k \in S^2$$

この1本の式こそが、第5部の集大成である**ホップ・ファイブレーション $S^3 \to S^2$** そのものです。本節では、5-1節の立体射影とこの公式を合成し、3次元球面 $S^3$ の内部構造を私たちの3次元空間 $\mathbb{R}^3$ 全体に可視化します。

## 5-4. ホップ・ファイブレーション $S^3 \to S^2$：3次元球面を「入れ子トーラスと絡み合う円の束」として見る

### 1. 動機（Why）：3次元球面 $S^3$ を「円の束」で隙間なく埋め尽くすとはどういうことか？

私たちがよく知る2次元トーラス $T^2 = S^1 \times S^1$ は、円周 $S^1$ の各点の上に、もう1本の円周 $S^1$ がぶら下がった「円の束」としてできています（直積空間）。
では、**3次元球面 $S^3$** はどうでしょうか？ $S^3$ は「2次元球面 $S^2$ と円周 $S^1$ の単純な直積 $S^2 \times S^1$」とは位相的にまったく異なる空間です（たとえば $S^2 \times S^1$ には縮まらないループがありますが、$S^3$ のループはすべて1点に縮まります）。

にもかかわらず、1931年にハインツ・ホップが発見した**ホップ・ファイブレーション（Hopf fibration）**は、次の重要な構造を明らかにしました。

**理由①：$S^3$ は「2次元球面 $S^2$ の各点の上に1本ずつ円周 $S^1$ がねじれてぶら下がった束」であるから**
単純な直積 $S^2 \times S^1$ ではないのに、局所的には $U \times S^1$ の形をしており、空間全体としては**$S^3$ が互いに1点も交わらない無数の大円 $S^1$ によって隙間なく分割されます**。しかも、その「ねじれ」の証拠として、**どの異なる2本の円周を選んでも、必ず鎖のように互いに1回だけ絡み合っています（ホップ・リンク）**。

**理由②：これまでのすべての章の伏線が、3次元空間 $\mathbb{R}^3$ の中に1つの視覚的構造として統合されるから**
ホップ写像 $\pi: S^3 \to S^2$ に5-1節の立体射影 $\sigma: S^3 \setminus \{N\} \to \mathbb{R}^3$ を組み合わせると、3次元空間 $\mathbb{R}^3$ 全体が次の構造で埋め尽くされることが数式で証明できます。

* $S^2$ の北極 $+k$ の逆像 $\longrightarrow$ **$z$ 軸全体**（無限遠点で閉じる円）
* $S^2$ の南極 $-k$ の逆像 $\longrightarrow$ **$XY$ 平面上の単位円**（$z$ 軸を取り囲む核の輪）
* $S^2$ の各緯線（$\eta = \text{一定}$）の逆像 $\longrightarrow$ **3-3節のクリフォード・トーラス**が立体射影されてできる**入れ子状の回転トーラスの族**
* 1つのトーラスの表面上 $\longrightarrow$ どの円も斜めに傾きながらトーラスを1周する**ビラルソー円（Villarceau circles）**の束

### 2. 具体例と幾何学的イメージ（Toy Model）

#### 実験A：地球儀 $S^2$ の「緯線」を $S^3$ へ引き戻すと何が生まれるか？

ホップ写像 $\pi: S^3 \to S^2$ の行き先である2次元球面 $S^2$ を、地球儀のように**緯度 $\eta \in [0, \pi]$**（北極 $+k$ が $\eta = 0$、赤道が $\eta = \frac{\pi}{2}$、南極 $-k$ が $\eta = \pi$）と**経度 $\psi \in [0, 2\pi)$** で表します。

1. **南極（$\eta = \pi$）1点の上にあるファイバー：**
    1本の円周 $S^1$。立体射影すると、$XY$ 平面上の**単位円 $X^2 + Y^2 = 1, \; Z = 0$** になります。

2. **南極のすぐ周りの小さな緯線（$\eta$ が $\pi$ に近い）の上にあるファイバーの集まり：**
    緯線（円周 $S^1$）の各点の上に1本ずつファイバー（円周 $S^1$）が乗るため、全体として **$S^1 \times S^1 = T^2$（トーラス）** になります。立体射影すると、単位円を芯にして取り巻く**細いドーナツ（回転トーラス）**が現れます。

3. **緯度 $\eta$ を南極から赤道（$\eta = \frac{\pi}{2}$）、さらに北極側へと上げていく：**
    ドーナツは次々と前のドーナツをすっぽり包み込みながら大きく膨らんでいきます（ロシアのマトリョーシカ人形のように**無限に入れ子になったトーラス**）。ちょうど赤道 $\eta = \frac{\pi}{2}$ に対応するトーラスが、3-3節で扱った**クリフォード・トーラス**です。

4. **北極（$\eta = 0$）に到達する極限：**
    入れ子のドーナツの外側が無限の彼方へ広がり切り、内側の穴がどんどん狭まって、最後に中央を貫く1本の直線（**$z$ 軸**）へと収束します。

こうして、**1本の単位円（南極）＋ 無限個の入れ子トーラス（緯線たち）＋ 中央を貫く $z$ 軸（北極）**によって、私たちが住む3次元空間 $\mathbb{R}^3$ のすべての点が1点の漏れもなく、1点の重なりもなく埋め尽くされます。

### 3. 厳密な定義と定理（What）：ホップ写像・入れ子トーラスの方程式・ホップ・リンクの証明

ここからは、ホップ・ファイブレーションの3つの幾何学的性質（**①大円による分割、②立体射影による入れ子回転トーラスの厳密方程式、③任意の2本のファイバーが互いに1回絡み合うこと**）を、飛躍を抑えて証明します。

#### (1) ホップ写像の定義と「複素座標」との完全な一致

単位3次元球面 $S^3 = \{ q = a + bi + cj + dk \in \mathbb{H} \mid a^2 + b^2 + c^2 + d^2 = 1 \}$ から、純虚単位球面 $S^2 = \{ xi + yj + zk \in \operatorname{Im}\mathbb{H} \mid x^2 + y^2 + z^2 = 1 \}$ への**ホップ写像（Hopf map）** $\pi: S^3 \to S^2$ を、冒頭の確認問題で展開した式

$$\pi(q) := q k \bar{q} = 2(ac + bd)\,i + 2(cd - ab)\,j + (a^2 + d^2 - b^2 - c^2)\,k$$

と定義します。

ここで、$S^3$ の点を2つの複素数の組 $(z_1, z_2) \in \mathbb{C}^2$（$\vert z_1 \vert^2 + \vert z_2 \vert^2 = 1$）として

$$z_1 := a + d\sqrt{-1}, \qquad z_2 := c + b\sqrt{-1}$$

と書き換えてみます（$\sqrt{-1}$ は複素数の虚数単位）。すると、

$$2 z_1 \bar{z}_2 = 2(a + d\sqrt{-1})(c - b\sqrt{-1}) = 2(ac + bd) + 2(cd - ab)\sqrt{-1}, \qquad \vert z_1 \vert^2 - \vert z_2 \vert^2 = (a^2 + d^2) - (b^2 + c^2)$$

となり、ホップ写像 $\pi: S^3 \to S^2 \subset \mathbb{C} \times \mathbb{R}$ は次の極めて簡潔な形に一致します：

$$\pi(z_1, z_2) = \big( 2 z_1 \bar{z}_2, \;\; \vert z_1 \vert^2 - \vert z_2 \vert^2 \big) \in \mathbb{C} \times \mathbb{R}$$

#### (2) 定理1：ホップ・ファイバーは大円 $S^1$ であり、$S^3$ を隙間なく分割する

> **【定理1：ホップ・ファイブレーションのファイバー構造】**
> ホップ写像 $\pi: S^3 \to S^2$ は全射である。任意の点 $p \in S^2$ に対して、逆像（ファイバー）$\pi^{-1}(p) \subset S^3$ は、ある $q_0 \in \pi^{-1}(p)$ を用いて
>
> $$\pi^{-1}(p) = \big\{ q_0 e^{k\phi} \;\big\vert\; \phi \in [0, 2\pi) \big\} \qquad \left(e^{k\phi} := \cos\phi + k\sin\phi\right)$$
>
> と表される **$S^3$ 上の1本の単位大円**（$S^1$ と位相同型）である。したがって、$S^3$ は互いに交わらない大円の族 $\{ \pi^{-1}(p) \}_{p \in S^2}$ によって隙間なく分割される。

**【証明】**

1. **全射性：** 5-3節の定理1より $\Phi_3: S^3 \to \mathrm{SO}(3)$ は全射であり、$\mathrm{SO}(3)$ は $S^2$ 上の北極 $k$ を任意の点 $p \in S^2$ へ移せる（0-4節のコラム）ため、$\pi(q) = \Phi_3(q)(k)$ は全射です。
2. **ファイバーの決定：** 1点 $q_0 \in \pi^{-1}(p)$ を固定します。任意の $q \in S^3$ に対して、$r := \bar{q}_0 q \in S^3$（すなわち $q = q_0 r$）とおきます。すると、

    $$\pi(q) = \pi(q_0) \iff q_0 r k \bar{r} \bar{q}_0 = q_0 k \bar{q}_0 \iff r k \bar{r} = k \iff r k = k r$$

    $r = r_0 + r_1 i + r_2 j + r_3 k \in S^3$ が $k$ と交換する条件を計算すると、

    $$rk - kr = (r_1 i + r_2 j)k - k(r_1 i + r_2 j) = 2(r_2 i - r_1 j) = 0 \iff r_1 = r_2 = 0$$

    となります。よって $r = r_0 + r_3 k$（$r_0^2 + r_3^2 = 1$）、すなわちある $\phi \in [0, 2\pi)$ によって $r = \cos\phi + k\sin\phi = e^{k\phi}$ と書けることが必要十分です。

3. **単位大円であること：** $q_0 \in S^3$ に対し、2つのベクトル $\mathbf{v}_1 := q_0$ と $\mathbf{v}_2 := q_0 k$ はともに単位ベクトル（$\vert q_0 \vert = \vert q_0 k \vert = 1$）であり、内積は $\langle q_0, q_0 k \rangle = \langle 1, k \rangle = 0$（左掛け算 $x \mapsto q_0 x$ は直交変換なので内積を保つ）より互いに直交します。したがって

    $$q_0 e^{k\phi} = (\cos\phi)\mathbf{v}_1 + (\sin\phi)\mathbf{v}_2 \qquad (\phi \in [0, 2\pi))$$

    は、原点を通る2次元平面 $\operatorname{span}\{\mathbf{v}_1, \mathbf{v}_2\}$ と $S^3$ の交わり、すなわち**半径 $1$ の大円**に他なりません。（証明終）

（※さらに、複素座標 $(z_1, z_2)$ で見れば $q \mapsto q e^{k\phi}$ は $(z_1, z_2) \mapsto (z_1 e^{\sqrt{-1}\phi}, \; z_2 e^{\sqrt{-1}\phi})$ に一致するため、ホップ・ファイバーとは**0-2節で発見した4次元空間の等角回転（クリフォード回転）の軌道そのもの**です。）

#### (3) 定理2：立体射影による「入れ子トーラス」の厳密方程式

$S^3$ の座標を $(x, y, z, w) := (c, b, a, d)$ と並べ（つまり $q = z + yi + xj + wk \in S^3$）、5-1節の立体射影 $\sigma(x, y, z, w) = \left(\frac{x}{1-w}, \frac{y}{1-w}, \frac{z}{1-w}\right) = (X, Y, Z) \in \mathbb{R}^3$（北極 $N = (0, 0, 0, 1)$ すなわち $q = k$ を無限遠点 $\infty$ へ送る）を適用します。

底空間 $S^2$ 上で、北極 $+k$ からの角度（緯度パラメータ）$\eta \in [0, \pi]$ にある緯線

$$L_\eta := \big\{ p \in S^2 \;\big\vert\; p \text{ の } k \text{ 成分} = \cos\eta \big\}$$

の逆像 $T_\eta := \pi^{-1}(L_\eta) \subset S^3$ が、立体射影によって $\mathbb{R}^3$ の中にどのような図形を描くかを厳密に計算します。

> **【定理2：ホップ・ファイブレーションの立体射影構造】**
> 立体射影 $\sigma: S^3 \setminus \{k\} \xrightarrow{\sim} \mathbb{R}^3$ のもとで、緯線 $L_\eta$ の逆像 $T_\eta = \pi^{-1}(L_\eta)$ は次のように $\mathbb{R}^3$ 全体を埋め尽くす。
>
> 1. **$\eta = 0$（北極 $+k$）：** $\sigma(T_0 \setminus \{k\})$ は **$Z$ 軸全体** $\{ (0, 0, Z) \mid Z \in \mathbb{R} \}$。
> 2. **$\eta = \pi$（南極 $-k$）：** $\sigma(T_\pi)$ は **$XY$ 平面上の単位円** $\{ (X, Y, 0) \mid X^2 + Y^2 = 1 \}$。
> 3. **$0 < \eta < \pi$（一般の緯線）：** $T_\eta \subset S^3$ は2次元トーラス $S^1 \times S^1$ であり、その立体射影 $\sigma(T_\eta) \subset \mathbb{R}^3$ は、$Z$ 軸を対称軸とする**厳密な回転トーラス**
>
>     $$\left(\sqrt{X^2 + Y^2} - \frac{1}{\sin(\eta/2)}\right)^2 + Z^2 = \cot^2\!\left(\frac{\eta}{2}\right)$$
>
>     （中心円の大半径 $A(\eta) = \frac{1}{\sin(\eta/2)}$、管の小半径 $B(\eta) = \cot\frac{\eta}{2}$）になる。
>
> 4. **各ファイバーの像：** 5-1節の定理2（円円対応）より、北極 $k$ を通る1本（$Z$ 軸）を除く**すべてのホップ・ファイバー $\sigma(\pi^{-1}(p))$ は、$\mathbb{R}^3$ 内の完全な円周**であり、対応するトーラス $\sigma(T_\eta)$ の表面上を斜めに1周する。

**【証明】**
ホップ写像の $k$ 成分は $(a^2 + d^2) - (b^2 + c^2) = (z^2 + w^2) - (x^2 + y^2)$ です。
$x^2 + y^2 + z^2 + w^2 = 1$ と連立して条件 $(z^2 + w^2) - (x^2 + y^2) = \cos\eta$ を解くと、半角公式より

$$x^2 + y^2 = \frac{1 - \cos\eta}{2} = \sin^2\frac{\eta}{2}, \qquad z^2 + w^2 = \frac{1 + \cos\eta}{2} = \cos^2\frac{\eta}{2}$$

が得られます。

1. $\eta = 0$ のとき $x = y = 0, \; z^2 + w^2 = 1$、$\eta = \pi$ のとき $z = w = 0, \; x^2 + y^2 = 1$ であり、これらは5-1節の確認問題で計算した2本の大円 $C_2$（像は $Z$ 軸）と $C_1$（像は単位円）そのものです。
2. $0 < \eta < \pi$ のとき、$r_1 := \sin\frac{\eta}{2} > 0, \; r_2 := \cos\frac{\eta}{2} > 0$（$r_1^2 + r_2^2 = 1$）とおきます。$T_\eta$ は半径 $r_1$ の円周と半径 $r_2$ の円周の直積 $S^1(r_1) \times S^1(r_2)$（特に $\eta = \frac{\pi}{2}$ が 3-3節のクリフォード・トーラス）であり、北極 $N = (0, 0, 0, 1)$ を含みません（$r_1 > 0$ より $x^2 + y^2 > 0$ だから）。
    点 $(X, Y, Z) \in \mathbb{R}^3$ が $\sigma(T_\eta)$ に属するための必要十分条件は、5-1節の逆立体射影

    $$\sigma^{-1}(X, Y, Z) = \left( \frac{2X}{D}, \;\; \frac{2Y}{D}, \;\; \frac{2Z}{D}, \;\; \frac{D - 2}{D} \right) \qquad (D := X^2 + Y^2 + Z^2 + 1)$$

    が $x^2 + y^2 = r_1^2$ を満たすことです（$z^2 + w^2 = 1 - r_1^2 = r_2^2$ は自動的に成り立つ）。円筒半径 $R := \sqrt{X^2 + Y^2} \ge 0$ とおいて代入すると、

    $$\frac{4 R^2}{(R^2 + Z^2 + 1)^2} = r_1^2 \iff \frac{2R}{R^2 + Z^2 + 1} = r_1 \iff R^2 - \frac{2}{r_1}R + 1 + Z^2 = 0$$

    $R$ について平方完成すれば、

    $$\left(R - \frac{1}{r_1}\right)^2 + Z^2 = \frac{1}{r_1^2} - 1 = \frac{1 - r_1^2}{r_1^2} = \frac{r_2^2}{r_1^2} = \cot^2\!\left(\frac{\eta}{2}\right)$$

    が得られます。常に $A(\eta) = \frac{1}{r_1} > \frac{r_2}{r_1} = B(\eta) > 0$ なので、これは穴の開いた歪みのない回転トーラスです。
    また、異なる $\eta_1 < \eta_2$ に対して、断面円板 $\left(R - \frac{1}{\sin(\eta/2)}\right)^2 + Z^2 \le \cot^2\frac{\eta}{2}$ の水平径の区間は $\left[\frac{1 - \cos(\eta/2)}{\sin(\eta/2)}, \; \frac{1 + \cos(\eta/2)}{\sin(\eta/2)}\right] = \left[\tan\frac{\eta}{4}, \; \cot\frac{\eta}{4}\right]$ であり、$\eta$ が増えるにつれて内径 $\tan\frac{\eta}{4}$ は単調増加、外径 $\cot\frac{\eta}{4}$ は単調減少して $(1, 1)$ へ入れ子状に縮んでいきます。

3. 5-1節の定理2の系より、$S^3$ 上のすべての大円は立体射影で完全な円周（北極を通る1本のみ直線）に写ります。（証明終）

#### (4) 定理3：任意の異なる2本のホップ・ファイバーは互いに1回だけ絡み合う（ホップ・リンク）

> **【定理3：すべてのホップ・ファイバー対の絡み合い】**
> $S^2$ 上の任意の異なる2点 $p_1 \neq p_2$ に対して、その逆像である2本のホップ・ファイバー $\pi^{-1}(p_1)$ と $\pi^{-1}(p_2)$ は、$S^3$ 内（および立体射影後の $\mathbb{R}^3$ 内）で**必ず互いに1回だけ絡み合った鎖（ホップ・リンク）**をなす。

**【証明】**

1. **特別な2点 $p_1 = +k, \; p_2 = -k$ の場合：**
    定理2より、$\sigma(\pi^{-1}(+k) \setminus \{k\})$ は $Z$ 軸全体であり、$\sigma(\pi^{-1}(-k))$ は $XY$ 平面上の単位円 $X^2 + Y^2 = 1, \; Z = 0$ です。$Z$ 軸は単位円が張る円板 $X^2 + Y^2 \le 1, \; Z = 0$ のど真ん中（原点）をちょうど1回だけ横断して貫いているため、この2本は互いに1回だけ絡み合うホップ・リンクです。

2. **任意の異なる2点 $p_1, p_2 \in S^2$ への拡張：**
    $S^2$ 上で互いにぶつからずに $(p_1, p_2)$ を $(+k, -k)$ へ連続移動させる道 $(p_1(t), p_2(t))$（$t \in [0, 1], \; p_1(t) \neq p_2(t)$）をとることができます（たとえば、まず $p_1$ と $p_2$ を含む大円上で $p_2$ を $p_1$ の対蹠点 $-p_1$ まで滑らせ、次に球面全体を回転させて $(p_1, -p_1)$ を $(+k, -k)$ へ運ぶ）。
    すべての時刻 $t \in [0, 1]$ で $p_1(t) \neq p_2(t)$ なので、2本のファイバー $\pi^{-1}(p_1(t))$ と $\pi^{-1}(p_2(t))$ は $S^3$ 内で一度も交差せずに連続変形されて $(\pi^{-1}(+k), \pi^{-1}(-k))$ に一致します。したがって、任意の異なる2本のホップ・ファイバーはすべてホップ・リンクをなします。（証明終）

> **【コラム：量子コンピュータの「ブロッホ球」はホップ・ファイブレーションそのもの】**
>
> 量子コンピュータの基本単位である**1量子ビット（qubit）**の状態は、複素2次元空間 $\mathbb{C}^2$ 内の長さ $1$ のベクトル
>
> $$\vert \psi \rangle = z_1 \vert 0 \rangle + z_2 \vert 1 \rangle \qquad \big(z_1, z_2 \in \mathbb{C}, \;\; \vert z_1 \vert^2 + \vert z_2 \vert^2 = 1\big)$$
>
> で表されます。つまり、1量子ビットの波動関数が住んでいる空間はまさに**3次元球面 $S^3 \subset \mathbb{C}^2$** です。
>
> ところが量子力学の基本原理により、状態ベクトル全体に絶対値 $1$ の複素数 $e^{i\phi}$（**大域位相 / Global phase**）を掛けた状態 $e^{i\phi}\vert \psi \rangle = (z_1 e^{i\phi}, z_2 e^{i\phi})$ は、どんな物理測定を行っても元の状態 $\vert \psi \rangle$ とまったく同じ観測確率しか与えず、**物理的に完全に同一の状態**とみなされます。
>
> したがって、「物理的に区別できる1量子ビットの状態全体」とは、3次元球面 $S^3$ を大域位相の円周 $S^1 = \{ e^{i\phi} \}$ の作用で割った商空間 $S^3 / S^1$ であり、本節のホップ写像
>
> $$\pi(z_1, z_2) = \big(2 z_1 \bar{z}_2, \;\; \vert z_1 \vert^2 - \vert z_2 \vert^2\big) \in S^2$$
>
> によって得られる2次元球面 $S^2$ に他なりません。量子情報科学で1量子ビットの状態を可視化するために必ず描かれる**ブロッホ球（Bloch sphere）**とは、まさにホップ・ファイブレーション $S^1 \hookrightarrow S^3 \xrightarrow{\pi} S^2$ の底空間 $S^2$ そのものであり、ブロッホ球上の1点の上に目に見えない大域位相の円周 $S^1$ がホップ・ファイバーとしてぶら下がっているのです。
