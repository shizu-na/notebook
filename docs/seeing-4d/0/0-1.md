## 0-1. 高次元空間の内積・距離・直交性：絵に描けない空間で「長さ」と「角度」を測る

### 1. 動機（Why）：なぜ「絵」ではなく「内積」から幾何学を始めるのか？

2次元平面や3次元空間であれば、図形を紙に描いたり模型を作ったりして、定規で「長さ」を測り、分度器で「角度」を測ることができます。しかし、4次元以上のユークリッド空間 $\mathbb{R}^n$（$n \ge 4$）では、空間そのものを直接眺めることも、分度器を当てることもできません。

それでも私たちが4次元超立方体の対角線の長さや、4次元正多胞体の二面角、あるいは4次元空間での回転や断面を寸分の狂いなく計算できるのは、**「長さ・距離・角度・垂直（直交）」という幾何学的概念をすべて、数の組の計算（内積）だけで再定義しているから**です。

ここで直感に頼らず厳密に確認すべき理由が2つあります。

**理由①：「角度 $\theta$」の定義が本当に破綻しないか保証する必要があるから**
3次元までの高校数学では、内積を「$\mathbf{x} \cdot \mathbf{y} = \Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert \cos\theta$」と定義しました。しかし4次元以上では「絵で測った角度 $\theta$」が先に存在しないため、手順を逆転させます。すなわち、先に成分の積和 $\langle \mathbf{x}, \mathbf{y} \rangle := \sum_{i=1}^n x_i y_i$ を定義し、それを使って

$$\cos\theta := \frac{\langle \mathbf{x}, \mathbf{y} \rangle}{\Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert}$$

によって角度 $\theta$ を定義します。この定義が成立するためには、**どんな次元 $n$ であっても右辺の絶対値が必ず $1$ 以下に収まること（コーシー・シュワルツの不等式）**を、図形に頼らず純粋な代数計算だけで証明しておく必要があります。

**理由②：「射影（影）」と「鏡映（鏡）」を任意の次元で同じ1本の式に書けるから**
本ノート全体を通じて繰り返し使う「超平面への正射影（影を落とす・輪切りにする）」や「超平面に関する鏡映（万華鏡・正多胞体の対称性）」は、内積と直交性さえあれば、3次元でも4次元でも100次元でもまったく同じ数式で記述できます。

---

### 2. 具体例と幾何学的イメージ（Toy Model）

厳密な定義と証明に入る前に、内積の計算だけで「絵に描けない4次元以上の図形の角度や距離」が具体的に見えてくる2つの実験を行います。

#### 実験A：4次元空間の4本目の直交軸と「正単体」の中心角

3次元空間 $\mathbb{R}^3$ では、原点から互いに $90^\circ$ で交わる軸は $x, y, z$ の3本までしか引けません。しかし4次元空間 $\mathbb{R}^4$ の標準基底

$$\mathbf{e}_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \\ 0 \end{pmatrix}, \quad \mathbf{e}_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \\ 0 \end{pmatrix}, \quad \mathbf{e}_3 = \begin{pmatrix} 0 \\ 0 \\ 1 \\ 0 \end{pmatrix}, \quad \mathbf{e}_4 = \begin{pmatrix} 0 \\ 0 \\ 0 \\ 1 \end{pmatrix}$$

は、どの異なる2本を選んでも成分ごとの積の和が $0$（$\langle \mathbf{e}_i, \mathbf{e}_j \rangle = 0$）になり、互いに完全に直交する4本の軸をなします。

では、各次元で最も単純な正多胞体である**$n$ 次元正単体**（2次元＝正三角形、3次元＝正四面体、4次元＝正5胞体）において、**「中心（重心）から2つの頂点へ向かうベクトルのなす角 $\theta_n$」**は何度になるでしょうか？
絵を描かずに、内積だけで任意の次元 $n$ に対して直接計算できます。

$n$ 次元正単体の $n + 1$ 個の頂点を、原点を中心とする単位球面上に配置した単位ベクトル $\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_{n+1} \in \mathbb{R}^n$（すべて $\Vert\mathbf{v}_i\Vert = 1$）とします。

1. 対称性より、$n + 1$ 個の頂点の重心は原点に一致するため、和はゼロベクトルになります：

    $$\mathbf{v}_1 + \mathbf{v}_2 + \dots + \mathbf{v}_{n+1} = \mathbf{0}$$

2. 同様に、どの異なる2頂点を選んでも中心からの角度はすべて同じなので、内積 $\langle \mathbf{v}_i, \mathbf{v}_j \rangle$（$i \neq j$）はすべて同じ定数 $c = \cos\theta_n$ になります。
3. 上の和の自分自身との内積（長さの2乗）をとって展開すると、同じ添字の組（$i = j$）が $n + 1$ 個、異なる添字の組（$i \neq j$）が $(n + 1)n$ 個現れます：

    $$0 = \left\Vert \sum_{i=1}^{n+1} \mathbf{v}_i \right\Vert^2 = \sum_{i=1}^{n+1} \Vert\mathbf{v}_i\Vert^2 + \sum_{i \neq j} \langle \mathbf{v}_i, \mathbf{v}_j \rangle = (n + 1) \cdot 1 + (n + 1)n \cdot c$$

両辺を $n + 1 > 0$ で割れば $1 + nc = 0$、すなわち

$$\cos\theta_n = -\frac{1}{n}$$

が得られます。具体的な値を並べてみると次のようになります。

* **$n = 2$（正三角形）：** $\cos\theta_2 = -\frac{1}{2} \implies \theta_2 = 120^\circ$
* **$n = 3$（正四面体）：** $\cos\theta_3 = -\frac{1}{3} \implies \theta_3 \approx 109.47^\circ$（化学で登場するメタン分子 $\text{CH}_4$ の結合角そのもの）
* **$n = 4$（正5胞体）：** $\cos\theta_4 = -\frac{1}{4} \implies \theta_4 \approx 104.48^\circ$
* **$n \to \infty$：** $\cos\theta_n = -\frac{1}{n} \to 0 \implies \theta_n \to 90^\circ$

次元が上がるにつれて、正単体の頂点同士はどんどん直角（$90^\circ$）に近づいていきます。これは高次元空間ほど「互いにほぼ直交する方向」を大量に確保できることの最初の兆候です。

#### 実験B：超平面への直交射影と鏡映（影と鏡の公式）

3次元空間で、点 $\mathbf{v}$ から原点を通る平面 $H$（単位法線ベクトル $\mathbf{u}$、$\Vert\mathbf{u}\Vert = 1$）へ垂線を下ろす操作を考えます。
ベクトル $\mathbf{v}$ のうち「法線 $\mathbf{u}$ の方向の成分」は $\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}$ です。

* **平面 $H$ への直交射影（真上から光を当てた影）：**
    $\mathbf{v}$ から法線方向の成分をちょうど1回分だけ引き去れば、平面 $H$ 上に落ちる影 $\mathbf{v}_\parallel$ が得られます：

    $$\operatorname{proj}_H(\mathbf{v}) = \mathbf{v} - \langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}$$

* **平面 $H$ を鏡とした鏡映（反転）：**
    法線方向の成分を**2回分**引き去って反対側へ折り返せば、鏡像 $R_{\mathbf{u}}(\mathbf{v})$ が得られます：

    $$R_{\mathbf{u}}(\mathbf{v}) = \mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}$$

この2つの式には「3次元であること」が一切使われていません。4次元空間 $\mathbb{R}^4$ の中の3次元超平面 $H = \{ \mathbf{x} \in \mathbb{R}^4 \mid \langle \mathbf{x}, \mathbf{u} \rangle = 0 \}$ に対しても、まったく同じ式で「4次元物体の3次元への影」と「3次元超平面を鏡とした4次元鏡映」が計算できます。

### 3. 厳密な定義と定理（What）：内積から距離・角度・鏡映を組み立てる

ここからは、$n$ 次元実数ベクトル空間 $\mathbb{R}^n$ の上に幾何学的構造（長さ・距離・角度）を公理的・代数的に定義し、基本定理を飛躍なく証明します。

#### (1) 標準内積（Standard inner product）とユークリッドノルム

$\mathbb{R}^n$ の2つのベクトル $\mathbf{x} = (x_1, \dots, x_n)^T$、$\mathbf{y} = (y_1, \dots, y_n)^T$ に対して、**標準内積** $\langle \mathbf{x}, \mathbf{y} \rangle \in \mathbb{R}$ を次で定義します。

$$\langle \mathbf{x}, \mathbf{y} \rangle := \sum_{i=1}^n x_i y_i = x_1 y_1 + x_2 y_2 + \dots + x_n y_n = \mathbf{x}^T \mathbf{y}$$

この定義から直ちに、任意の $\mathbf{x}, \mathbf{y}, \mathbf{z} \in \mathbb{R}^n$ と $a, b \in \mathbb{R}$ に対して以下の3性質（内積の公理）が成り立ちます。

1. **双線形性（Bilinearity）：** $\langle a\mathbf{x} + b\mathbf{y}, \mathbf{z} \rangle = a\langle \mathbf{x}, \mathbf{z} \rangle + b\langle \mathbf{y}, \mathbf{z} \rangle$（第2成分についても同様）
2. **対称性（Symmetry）：** $\langle \mathbf{x}, \mathbf{y} \rangle = \langle \mathbf{y}, \mathbf{x} \rangle$
3. **正定値性（Positive-definiteness）：** $\langle \mathbf{x}, \mathbf{x} \rangle \ge 0$ であり、$\langle \mathbf{x}, \mathbf{x} \rangle = 0 \iff \mathbf{x} = \mathbf{0}$

正定値性より $\langle \mathbf{x}, \mathbf{x} \rangle = x_1^2 + \dots + x_n^2 \ge 0$ なので、その非負の平方根としてベクトル $\mathbf{x}$ の**ユークリッドノルム（長さ）**を定義できます。

$$\Vert\mathbf{x}\Vert := \sqrt{\langle \mathbf{x}, \mathbf{x} \rangle} = \sqrt{x_1^2 + x_2^2 + \dots + x_n^2}$$

また、$\langle \mathbf{x}, \mathbf{y} \rangle = 0$ であるとき、$\mathbf{x}$ と $\mathbf{y}$ は**直交する（Orthogonal）**といい、$\mathbf{x} \perp \mathbf{y}$ と書きます。$\mathbf{x} \perp \mathbf{y}$ のとき、双線形性と対称性から

$$\Vert\mathbf{x} + \mathbf{y}\Vert^2 = \langle \mathbf{x} + \mathbf{y}, \mathbf{x} + \mathbf{y} \rangle = \Vert\mathbf{x}\Vert^2 + 2\langle \mathbf{x}, \mathbf{y} \rangle + \Vert\mathbf{y}\Vert^2 = \Vert\mathbf{x}\Vert^2 + \Vert\mathbf{y}\Vert^2$$

が成り立ちます（**$n$ 次元のピタゴラスの定理**）。

#### (2) コーシー・シュワルツの不等式と「角度・距離」の正当化

> **【定理1：コーシー・シュワルツの不等式】**
> 任意の $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ に対して、次が成り立つ。
>
> $$\vert\langle \mathbf{x}, \mathbf{y} \rangle\vert \le \Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert$$
>
> 等号が成立するのは、$\mathbf{x}$ と $\mathbf{y}$ が線形従属であるとき（すなわち一方が他方の実数倍であるとき）に限る。

**【証明】**

1. **$\mathbf{y} = \mathbf{0}$ の場合：** 左辺は $\vert\langle \mathbf{x}, \mathbf{0} \rangle\vert = 0$、右辺は $\Vert\mathbf{x}\Vert \cdot 0 = 0$ となり等号が成立します。また $\mathbf{y} = 0 \cdot \mathbf{x}$ なので線形従属です。
2. **$\mathbf{y} \neq \mathbf{0}$ の場合：** 任意の実数 $t \in \mathbb{R}$ に対して、ベクトル $\mathbf{x} + t\mathbf{y}$ の長さの2乗は正定値性から必ず $0$ 以上です。これを $t$ の2次関数として展開します。

    $$f(t) := \Vert\mathbf{x} + t\mathbf{y}\Vert^2 = \langle \mathbf{x} + t\mathbf{y}, \mathbf{x} + t\mathbf{y} \rangle = \Vert\mathbf{y}\Vert^2 t^2 + 2\langle \mathbf{x}, \mathbf{y} \rangle t + \Vert\mathbf{x}\Vert^2 \ge 0$$

    $\mathbf{y} \neq \mathbf{0}$ より2次の係数 $\Vert\mathbf{y}\Vert^2$ は真に正です。下に凸な2次関数 $f(t)$ がすべての実数 $t$ に対して $f(t) \ge 0$ であるための必要十分条件は、判別式 $D/4 \le 0$ です。すなわち、

    $$\langle \mathbf{x}, \mathbf{y} \rangle^2 - \Vert\mathbf{y}\Vert^2 \Vert\mathbf{x}\Vert^2 \le 0 \iff \langle \mathbf{x}, \mathbf{y} \rangle^2 \le \Vert\mathbf{x}\Vert^2 \Vert\mathbf{y}\Vert^2$$

    両辺の平方根をとれば $\vert\langle \mathbf{x}, \mathbf{y} \rangle\vert \le \Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert$ が得られます。
    また、等号が成立するのは判別式 $D/4 = 0$ のとき、すなわち $f(t_0) = \Vert\mathbf{x} + t_0\mathbf{y}\Vert^2 = 0$ となる実数 $t_0$ が存在するときに限ります。正定値性からこれは $\mathbf{x} + t_0\mathbf{y} = \mathbf{0} \iff \mathbf{x} = (-t_0)\mathbf{y}$ と同値であり、等号成立条件が示されました。（証明終）

**【系1：高次元での「角度」の定義】**
ゼロでない2つのベクトル $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ に対して、定理1より

$$-1 \le \frac{\langle \mathbf{x}, \mathbf{y} \rangle}{\Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert} \le 1$$

が常に成り立ちます。関数 $\cos: [0, \pi] \to [-1, 1]$ は全単射なので、$\cos\theta = \frac{\langle \mathbf{x}, \mathbf{y} \rangle}{\Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert}$ を満たす $\theta \in [0, \pi]$ がただ1つ確定します。これを $\mathbf{x}$ と $\mathbf{y}$ の**なす角**と定義します。

> **【定理2：三角不等式とユークリッド距離】**
> 任意の $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ に対して、$\Vert\mathbf{x} + \mathbf{y}\Vert \le \Vert\mathbf{x}\Vert + \Vert\mathbf{y}\Vert$ が成り立つ。

**【証明】**
両辺は非負なので、2乗の差を計算します。定理1より $\langle \mathbf{x}, \mathbf{y} \rangle \le \vert\langle \mathbf{x}, \mathbf{y} \rangle\vert \le \Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert$ なので、

$$\Vert\mathbf{x} + \mathbf{y}\Vert^2 = \Vert\mathbf{x}\Vert^2 + 2\langle \mathbf{x}, \mathbf{y} \rangle + \Vert\mathbf{y}\Vert^2 \le \Vert\mathbf{x}\Vert^2 + 2\Vert\mathbf{x}\Vert \Vert\mathbf{y}\Vert + \Vert\mathbf{y}\Vert^2 = (\Vert\mathbf{x}\Vert + \Vert\mathbf{y}\Vert)^2$$

両辺の平方根をとれば $\Vert\mathbf{x} + \mathbf{y}\Vert \le \Vert\mathbf{x}\Vert + \Vert\mathbf{y}\Vert$ が得られます。（証明終）

これによって、2点 $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ の間の**ユークリッド距離**を $d(\mathbf{x}, \mathbf{y}) := \Vert\mathbf{x} - \mathbf{y}\Vert$ と定義したとき、任意の3点 $\mathbf{x}, \mathbf{y}, \mathbf{z}$ に対して三角不等式 $d(\mathbf{x}, \mathbf{z}) \le d(\mathbf{x}, \mathbf{y}) + d(\mathbf{y}, \mathbf{z})$（寄り道は直行より短くならない）が任意の次元で厳密に成立します。

#### (3) 正規直交基底・直交射影・超平面鏡映

ベクトルの組 $\{\mathbf{u}_1, \dots, \mathbf{u}_k\} \subset \mathbb{R}^n$ が

$$\langle \mathbf{u}_i, \mathbf{u}_j \rangle = \delta_{ij} = \begin{cases} 1 & (i = j) \\ 0 & (i \neq j) \end{cases}$$

を満たすとき、これを**正規直交系**と呼び、部分空間 $W$ の基底になっているとき**正規直交基底（Orthonormal basis）**と呼びます。

> **【定理3：部分空間への直交射影と最短距離】**
> $W \subset \mathbb{R}^n$ を $k$ 次元部分空間とし、$\{\mathbf{u}_1, \dots, \mathbf{u}_k\}$ を $W$ の正規直交基底とする。任意の $\mathbf{v} \in \mathbb{R}^n$ に対して
>
> $$\mathbf{p} := \operatorname{proj}_W(\mathbf{v}) := \sum_{i=1}^k \langle \mathbf{v}, \mathbf{u}_i \rangle \mathbf{u}_i \in W$$
>
> とおくと、次が成り立つ。
>
> 1. 差 $\mathbf{v} - \mathbf{p}$ は $W$ のすべての元と直交する（$\mathbf{v} - \mathbf{p} \in W^\perp$）。
> 2. $\mathbf{p}$ は $W$ の中で $\mathbf{v}$ に最も近いただ1つの点である（任意の $\mathbf{w} \in W$ に対し $\Vert\mathbf{v} - \mathbf{w}\Vert \ge \Vert\mathbf{v} - \mathbf{p}\Vert$、等号は $\mathbf{w} = \mathbf{p}$ のみ）。

**【証明】**

1. 各基底 $\mathbf{u}_j$（$1 \le j \le k$）との内積を計算すると、正規直交性 $\langle \mathbf{u}_i, \mathbf{u}_j \rangle = \delta_{ij}$ より

    $$\langle \mathbf{v} - \mathbf{p}, \mathbf{u}_j \rangle = \langle \mathbf{v}, \mathbf{u}_j \rangle - \sum_{i=1}^k \langle \mathbf{v}, \mathbf{u}_i \rangle \langle \mathbf{u}_i, \mathbf{u}_j \rangle = \langle \mathbf{v}, \mathbf{u}_j \rangle - \langle \mathbf{v}, \mathbf{u}_j \rangle = 0$$

    となります。すべての基底と直交するため、その線形結合である任意の $\mathbf{w} \in W$ とも直交します。

2. 任意の $\mathbf{w} \in W$ に対し、$\mathbf{p} - \mathbf{w} \in W$ であり、1.より $(\mathbf{v} - \mathbf{p}) \perp (\mathbf{p} - \mathbf{w})$ です。よってピタゴラスの定理から

    $$\Vert\mathbf{v} - \mathbf{w}\Vert^2 = \Vert(\mathbf{v} - \mathbf{p}) + (\mathbf{p} - \mathbf{w})\Vert^2 = \Vert\mathbf{v} - \mathbf{p}\Vert^2 + \Vert\mathbf{p} - \mathbf{w}\Vert^2 \ge \Vert\mathbf{v} - \mathbf{p}\Vert^2$$

    等号が成り立つのは $\Vert\mathbf{p} - \mathbf{w}\Vert^2 = 0 \iff \mathbf{w} = \mathbf{p}$ のときに限ります。（証明終）

なお、任意の線形独立な組 $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ が与えられたとき、1本目から順に「すでに作った正規直交系が張る部分空間への射影を引き去って長さを $1$ に正規化する」操作（**グラム・シュミットの直交化法**）：

$$\mathbf{w}_m := \mathbf{v}_m - \sum_{i=1}^{m-1} \langle \mathbf{v}_m, \mathbf{u}_i \rangle \mathbf{u}_i, \qquad \mathbf{u}_m := \frac{\mathbf{w}_m}{\Vert\mathbf{w}_m\Vert}$$

を繰り返せば、必ず同じ部分空間の正規直交基底が得られます（線形独立性より $\mathbf{w}_m \neq \mathbf{0}$ が保証されます）。

最後に、単位ベクトル $\mathbf{u} \in \mathbb{R}^n$（$\Vert\mathbf{u}\Vert = 1$）に対して、超平面 $H = \mathbf{u}^\perp = \{ \mathbf{x} \in \mathbb{R}^n \mid \langle \mathbf{x}, \mathbf{u} \rangle = 0 \}$ に関する**鏡映変換（ハウスホルダー変換）**を

$$R_{\mathbf{u}}(\mathbf{v}) := \mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}$$

と定義します。これは線形写像であり、以下の2つの基本性質を満たします。

1. **内積（したがって長さと角度）を完全に保つ：** 任意の $\mathbf{v}, \mathbf{w} \in \mathbb{R}^n$ に対して、$\langle \mathbf{u}, \mathbf{u} \rangle = 1$ より

    $$\begin{aligned}
    \langle R_{\mathbf{u}}(\mathbf{v}), R_{\mathbf{u}}(\mathbf{w}) \rangle &= \langle \mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}, \; \mathbf{w} - 2\langle \mathbf{w}, \mathbf{u} \rangle \mathbf{u} \rangle \\
    &= \langle \mathbf{v}, \mathbf{w} \rangle - 2\langle \mathbf{v}, \mathbf{u} \rangle \langle \mathbf{u}, \mathbf{w} \rangle - 2\langle \mathbf{w}, \mathbf{u} \rangle \langle \mathbf{v}, \mathbf{u} \rangle + 4\langle \mathbf{v}, \mathbf{u} \rangle \langle \mathbf{w}, \mathbf{u} \rangle \langle \mathbf{u}, \mathbf{u} \rangle \\
    &= \langle \mathbf{v}, \mathbf{w} \rangle
    \end{aligned}$$

2. **2回適用すると元に戻る（対合性 $R_{\mathbf{u}} \circ R_{\mathbf{u}} = I$）：**
    $\langle R_{\mathbf{u}}(\mathbf{v}), \mathbf{u} \rangle = \langle \mathbf{v}, \mathbf{u} \rangle - 2\langle \mathbf{v}, \mathbf{u} \rangle \cdot 1 = -\langle \mathbf{v}, \mathbf{u} \rangle$ なので、

    $$R_{\mathbf{u}}(R_{\mathbf{u}}(\mathbf{v})) = \big(\mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}\big) - 2\big(-\langle \mathbf{v}, \mathbf{u} \rangle\big)\mathbf{u} = \mathbf{v}$$

> **【コラム：距離の公式だけで起きる高次元のパラドックス —— 超立方体の「隙間」が外へはみ出す】**
>
> ここまでに定義したユークリッド距離 $\Vert\mathbf{x}\Vert = \sqrt{x_1^2 + \dots + x_n^2}$ だけで、3次元の直感が完全に破綻する現象を1つ計算できます。
> $n$ 次元の超立方体 $[-1, 1]^n$（1辺の長さ $2$）を考えます。この中には $2^n$ 個の象限（各座標の符号の選び方）があります。それぞれの象限のど真ん中 $\left(\pm \frac{1}{2}, \pm \frac{1}{2}, \dots, \pm \frac{1}{2}\right)$ を中心として、半径 $\frac{1}{2}$ の $n$ 次元球を $2^n$ 個ぎっしり敷き詰めます（各球は座標超平面と超立方体の外側の壁 $x_i = \pm 1$ にぴったり接しています）。
>
> ここで、**「原点 $\mathbf{0}$ を中心として、これら $2^n$ 個の球の真ん中の『隙間』にぴったり収まる球（すべての球に外接する中心球）の半径 $r_n$」**を求めてみましょう。
>
> * 原点 $\mathbf{0}$ から周囲の球の中心 $\left(\pm \frac{1}{2}, \dots, \pm \frac{1}{2}\right)$ までの距離は、距離の公式より
>
>     $$d_n = \sqrt{\underbrace{\left(\frac{1}{2}\right)^2 + \dots + \left(\frac{1}{2}\right)^2}_{n\text{ 個}}} = \frac{\sqrt{n}}{2}$$
>
> * 周囲の球の半径は $\frac{1}{2}$ なので、真ん中の隙間に収まる中心球の半径は
>
>     $$r_n = d_n - \frac{1}{2} = \frac{\sqrt{n} - 1}{2}$$
>
> 具体的な次元で $r_n$ の値を計算すると直感に反する変化が起きます。
>
> * **$n = 2$（正方形と4つの円）：** $r_2 = \frac{\sqrt{2} - 1}{2} \approx 0.207$（小さな隙間）
> * **$n = 3$（立方体と8つの球）：** $r_3 = \frac{\sqrt{3} - 1}{2} \approx 0.366$（まだ周囲の球より小さい）
> * **$n = 4$（超立方体と16個の超球）：** $r_4 = \frac{\sqrt{4} - 1}{2} = 0.5$（**周囲の球とまったく同じ大きさ**になる）
> * **$n = 9$：** $r_9 = \frac{\sqrt{9} - 1}{2} = 1$（中心球が超立方体の外側の壁 $x_i = \pm 1$ にちょうど到達する）
> * **$n \ge 10$：** $r_{10} = \frac{\sqrt{10} - 1}{2} \approx 1.081 > 1$（**「箱の中の球の隙間」に置いたはずの中心球が、箱の外側の壁を突き破って外へはみ出す**）
>
> 超立方体の角（対角線方向）は次元 $n$ とともに $\sqrt{n}$ 倍に遠くへ伸びていくのに対し、壁までの距離（軸方向）は常に $1$ のままだからです。このように、4次元までは具体的な多胞体として把握できる空間も、次元がさらに上がると距離の感覚が大きく変質します（この超高次元の幾何は続編で本格的に扱います）。

### 4. 翻訳と展望（Bridge）：本節の道具がこれからの各部にどう直結するか

1. **次節（[0-2節](0-2.md)：直交行列と4次元空間の二重回転）：**
    本節で定義した内積 $\langle \mathbf{x}, \mathbf{y} \rangle$ を保つ線形変換が**直交変換（直交行列 $\mathrm{O}(n)$）**です。次節では、本節のグラム・シュミットの直交化法と内積を使って、4次元空間の回転群 $\mathrm{SO}(4)$ が「互いに直交する2つの平面での独立な回転（二重回転）」に分解されることを証明します。

2. **[第1部](../index.md#part-1)（射影）と[第3部](../index.md#part-3)（断面スライス）：**
    「高次元立体を1次元低い超平面へ写す平行投影」は本節の直交射影 $\operatorname{proj}_H(\mathbf{v})$ そのものであり、「高次元立体を輪切りにする3次元超平面」は単位法線ベクトル $\mathbf{u}$ を用いた方程式 $\langle \mathbf{x}, \mathbf{u} \rangle = c$ として定式化されます。

3. **[第4部](../index.md#part-4)（鏡映群と正多胞体の完全分類）：**
    本節で定義した超平面鏡映 $R_{\mathbf{u}}(\mathbf{v}) = \mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u}$ を複数組み合わせたものが**鏡映群（コクセター群）**です。法線ベクトル同士の内積を並べた行列（グラム行列）の正定値性を調べることで、4次元正多胞体が全6種、5次元以上が全3種に限られることが証明されます。

### 理解度チェック（次節へ進む前の確認）

次節（[0-2節](0-2.md)：高次元の回転）への橋渡しとして、鏡映を2回合成すると何が起きるかを計算してみましょう。

> **【確認の問い】**
>
> 2次元平面 $\mathbb{R}^2$ において、単位ベクトル $\mathbf{u}_1 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$（鏡 $H_1$ は $x$ 軸）と、そこから角度 $\alpha$ だけ傾いた単位ベクトル $\mathbf{u}_2 = \begin{pmatrix} -\sin\alpha \\ \cos\alpha \end{pmatrix}$（鏡 $H_2$ は $x$ 軸から角度 $\alpha$ 傾いた直線）を考えます。
>
> 1. それぞれの鏡映変換 $R_{\mathbf{u}_1}$ と $R_{\mathbf{u}_2}$ を $2 \times 2$ 行列で表してください（ヒント：$\mathbf{v} - 2\langle \mathbf{v}, \mathbf{u} \rangle \mathbf{u} = (I - 2\mathbf{u}\mathbf{u}^T)\mathbf{v}$ を使います）。
> 2. 2つの鏡映を続けて行う合成変換 $R_{\mathbf{u}_2} \circ R_{\mathbf{u}_1}$ の行列積を計算し、それがどのような幾何学的変換（何度回転か）になっているかを確認してください。
