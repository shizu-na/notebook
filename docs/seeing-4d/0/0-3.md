### 前節（0-2）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **等角回転 $R(\theta, -\theta)$ の内積計算：**
    $\cos(-\theta) = \cos\theta$、$\sin(-\theta) = -\sin\theta$ より、

    $$R(\theta, -\theta)\mathbf{v} = \begin{pmatrix} x\cos\theta - y\sin\theta \\ x\sin\theta + y\cos\theta \\ z\cos\theta + w\sin\theta \\ -z\sin\theta + w\cos\theta \end{pmatrix}$$

    したがって、元の単位ベクトル $\mathbf{v} = (x, y, z, w)^T$（$x^2 + y^2 + z^2 + w^2 = 1$）との内積は、$\sin\theta$ を含む項（$-xy\sin\theta + yx\sin\theta$ と $+zw\sin\theta - wz\sin\theta$）がすべて打ち消し合って

    $$\langle \mathbf{v}, R(\theta, -\theta)\mathbf{v} \rangle = (x^2 + y^2 + z^2 + w^2)\cos\theta = \cos\theta$$

    となり、やはり任意の単位ベクトルに対して一様に角度 $\theta$ だけ回転することが確認できます。

2. **区間 $[0, 2\pi]$ の両端を貼り合わせた図形：**
    線分の左端 $0$ と右端 $2\pi$ を同じ1点とみなして繋ぎ合わせると、幾何学的には**円周 $S^1$** になります。つまり、2次元回転群 $\mathrm{SO}(2)$ は空間の形として円周 $S^1$ と同じです。

この「元の空間の一部の点同士を同じものとみなして糊付けする」操作を、任意の次元で厳密に扱うための仕組みが、本節の主題である**商位相（Quotient topology）**です。

## 0-3. 商位相と空間の貼り合わせ：「端と端を糊付けする」操作を厳密に定義する

### 1. 動機（Why）：なぜ「3次元空間の中で曲げて貼る」だけでは不十分なのか？

折り紙の正方形の左辺と右辺を糊付けすれば、3次元空間の中で「円筒」を作ることができます。片方を半回転ひねってから貼れば「メビウスの帯」になります。さらに円筒の上端と下端を丸めて繋げば「トーラス（ドーナツの表面）」ができます。

ところが、同じ正方形の紙を使って**「クラインの壺」**や**「実射影平面 $\mathbb{RP}^2$」**を作ろうとすると、3次元空間の中ではどう曲げても紙同士がぶつかってしまい、**自己交差なしに糊付けすることができません**。ましてや、第6部で扱う「3次元の立方体の向かい合う面同士を貼り合わせた空間（3次元トーラス $T^3$）」は、私たちの住む3次元空間の中で曲げて貼ること自体が物理的に不可能です。

しかし数学では、**「外側の高い次元の空間（$\mathbb{R}^4$ や $\mathbb{R}^6$）を用意して実際に曲げて貼る」必要はありません**。

**理由①：「どの点とどの点が同じか（同値関係）」と「点の近さ（位相）」だけあれば、空間そのものが厳密に定義できるから**
糊付けの本質は、「紙を3次元空間でどう曲げるか」ではなく、「左端の点 $(0, y)$ から左へ少しはみ出したら、右端の点 $(1, y)$ のすぐ近くに出る」という**近さ（つながり方）のルール**だけです。このルールを抽象化したものが**商位相**です。

**理由②：射影空間 $\mathbb{RP}^n$、回転群 $\mathrm{SO}(3)$、高次元トーラスがすべて同じ1つの操作で作れるから**
本ノートで登場する以下の主要空間は、すべて「既知の空間を同値関係で割る（商位相を入れる）」という単一の構成法で作られます。

* **第1部：** 球面や $\mathbb{R}^{n+1} \setminus \{\mathbf{0}\}$ から作る**実射影空間 $\mathbb{RP}^n$**
* **第2部：** 正方形の辺の貼り合わせで作る**メビウスの帯・クラインの壺・$\mathbb{RP}^2$**
* **第5部：** 半径 $\pi$ の3次元球体の表面の対蹠点を貼り合わせた**回転群 $\mathrm{SO}(3) \cong \mathbb{RP}^3$**
* **第6部：** 立方体や正十二面体の面を貼り合わせて作る**3次元トーラス $T^3$**・**ポアンカレホモロジー球面**

### 2. 具体例と幾何学的イメージ（Toy Model）

商位相の感覚を掴むため、単位正方形 $I^2 = [0, 1] \times [0, 1]$ の4辺に矢印を付けて「同じ矢印の辺同士を向きを揃えて貼り合わせる」5つの基本モデルを比べます（図0-3では円筒を除く4つを示しています）。

1. **円筒（Cylinder）：** 左辺 $(0, y)$ と右辺 $(1, y)$ を同じ向きに同一視する（$(0, y) \sim (1, y)$）。上下の辺は貼らない。
2. **メビウスの帯（Möbius strip）：** 左辺 $(0, y)$ と右辺 $(1, 1 - y)$ を**逆向き**に同一視する（$(0, y) \sim (1, 1 - y)$）。上下の辺は貼らない。
3. **2次元トーラス $T^2 = S^1 \times S^1$：** 左右の辺を同じ向きに貼り（$(0, y) \sim (1, y)$）、さらに上下の辺も同じ向きに貼る（$(x, 0) \sim (x, 1)$）。
4. **クラインの壺（Klein bottle）：** 上下の辺は同じ向きに貼り（$(x, 0) \sim (x, 1)$）、左右の辺は**逆向き**に貼る（$(0, y) \sim (1, 1 - y)$）。
5. **実射影平面 $\mathbb{RP}^2$：** 左右の辺も上下の辺も、**両方とも逆向き**に貼る（$(0, y) \sim (1, 1 - y)$ かつ $(x, 0) \sim (1 - x, 1)$）。これは「円板 $D^2$ の境界（円周 $S^1$）のちょうど反対側の点（対蹠点）同士を貼り合わせる」ことと同じです。

> **【コラム：古い2Dゲームの画面は「平坦なトーラス」——なぜ3次元では歪むのに4次元なら歪まないのか？】**

> レトロな2Dゲーム（画面の右端から出ると左端から現れ、上端から出ると下端から現れる世界）のマップは、まさに上の図の**トーラス $T^2$** です。
> この世界では、どの場所を歩いていても曲率は完全に $0$（紙と同じく平坦）であり、三角形の内角の和は常に $180^\circ$ です。ところが、私たちが3次元空間の中でドーナツの形に紙を丸めてトーラスを作ろうとすると、内側の輪は短く外側の輪は長くなるため、紙を伸ばしたり縮めたりして**歪ませなければ作れません**。
>
> ところが、4次元空間 $\mathbb{R}^4$ なら、長さを一切歪ませずに平坦なトーラスをそのまま埋め込めます。正方形 $[0, 2\pi] \times [0, 2\pi]$ の点 $(\theta, \phi)$ を、$\mathbb{R}^4$ の点
>
> $$(\cos\theta, \; \sin\theta, \; \cos\phi, \; \sin\phi) \in \mathbb{R}^4$$
>
> に写すだけです。
> 実際、この像はすべての点で原点からの距離の2乗が $\cos^2\theta + \sin^2\theta + \cos^2\phi + \sin^2\phi = 2$（半径 $\sqrt{2}$ の3次元球面 $S^3$ 上）に乗っており、微小変化 $(d\theta, d\phi)$ に対する4次元空間での長さの2乗は
>
> $$(-\sin\theta\,d\theta)^2 + (\cos\theta\,d\theta)^2 + (-\sin\phi\,d\phi)^2 + (\cos\phi\,d\phi)^2 = d\theta^2 + d\phi^2$$
>
> となって、**元の平坦な正方形の距離と完全に一致（等長埋め込み）**します。これが第3部・第5部で主役となる**クリフォード・トーラス**です。

### 3. 厳密な定義と定理（What）：位相空間・商位相・位相同型の判定法

ここからは、「貼り合わせた空間が本当に円周 $S^1$ や球面と同じ形（位相同型）であること」を飛躍なく証明するための最小限の位相空間論を整備します。

#### (1) 位相空間・連続写像・位相同型の最小定義

ユークリッド空間 $\mathbb{R}^n$ の部分集合 $U$ が**開集合（Open set）**であるとは、$U$ のどの点 $\mathbf{x}$ をとっても、$\mathbf{x}$ を中心とする十分小さな開球 $B(\mathbf{x}, r) = \{ \mathbf{y} \in \mathbb{R}^n \mid \Vert\mathbf{y} - \mathbf{x}\Vert < r \}$ がすっぽり $U$ に含まれることをいいます。

距離を抽象化し、任意の集合 $X$ に対して部分集合の族 $\mathcal{O}$ が次の3公理を満たすとき、$(X, \mathcal{O})$ を**位相空間（Topological space）**、$\mathcal{O}$ の元を**開集合**と呼びます。

1. $\emptyset \in \mathcal{O}$ かつ $X \in \mathcal{O}$
2. 任意個（無限個でもよい）の開集合の和集合 $\bigcup_{\lambda} U_\lambda$ は再び開集合である。
3. 有限個の開集合の共通部分 $U_1 \cap \dots \cap U_k$ は再び開集合である。

また、開集合の補集合 $X \setminus U$ を**閉集合（Closed set）**と呼びます。ユークリッド空間 $\mathbb{R}^n$ の部分集合 $A \subset \mathbb{R}^n$ には、$\mathbb{R}^n$ の開集合 $U$ との交わり $A \cap U$ を開集合と定める位相（**部分空間位相**）を自然に入れます。

2つの位相空間 $X, Y$ の間の写像 $f: X \to Y$ について：

* **$f$ が連続（Continuous）：** $Y$ の任意の開集合 $V$ に対して、その逆像 $f^{-1}(V) = \{ x \in X \mid f(x) \in V \}$ が $X$ の開集合であること（閉集合の逆像が閉集合であることと同値）。
* **$f$ が位相同型（Homeomorphism）：** $f$ が全単射であり、$f$ も逆写像 $f^{-1}: Y \to X$ もともに連続であること。このとき $X$ と $Y$ は位相空間として同じ形（**位相同型**）であるといい、$X \cong Y$ と書きます。

#### (2) 同値関係・商集合・商位相（Quotient topology）

集合 $X$ の元の間の関係 $\sim$ が以下の3条件を満たすとき、**同値関係**と呼びます。

1. **反射律：** $x \sim x$
2. **対称律：** $x \sim y \implies y \sim x$
3. **推移律：** $x \sim y$ かつ $y \sim z \implies x \sim z$

各元 $x \in X$ に対して、$x$ と同値な元の集まり $[x] := \{ y \in X \mid x \sim y \}$ を**同値類**と呼び、同値類全体の集合を**商集合** $X / {\sim} := \{ [x] \mid x \in X \}$ と書きます。各元をその同値類へ送る自然な全射を $\pi: X \to X / {\sim}, \; \pi(x) := [x]$（**商射影**）とします。

ここで、元の空間 $X$ が位相空間であるとき、商集合 $X / {\sim}$ にどのような開集合（位相）を入れれば「糊付け」を正しく表現できるでしょうか？

> **【定義：商位相（Quotient topology）】**
> 位相空間 $X$ とその上の同値関係 $\sim$ に対して、商集合 $X / {\sim}$ の部分集合 $U \subset X / {\sim}$ が開集合であることを、
>
> $$U \text{ が } X / {\sim} \text{ の開集合} \iff \pi^{-1}(U) \text{ が } X \text{ の開集合}$$
>
> と定める。この位相を**商位相**、これを入れた位相空間 $X / {\sim}$ を**商空間（Quotient space）**と呼ぶ。

逆像は和集合・共通部分・空集合・全体集合をそのまま保つ（$\pi^{-1}(\bigcup U_\lambda) = \bigcup \pi^{-1}(U_\lambda)$ など）ため、この定義が位相空間の3公理を満たすことは直ちに確認できます。また、定義から明らかに商射影 $\pi: X \to X / {\sim}$ は連続であり、商位相は「$\pi$ を連続にする位相の中で最も開集合が多い（最も細かい）位相」です。

**幾何学的な意味の確認（区間 $[0, 1]$ の両端 $0 \sim 1$ の貼り合わせ）：**
貼り合わせた点 $[0] = [1]$ を含む開集合 $U \subset [0, 1]/{\sim}$ の逆像 $\pi^{-1}(U)$ は、元の区間 $[0, 1]$ の中で $0$ と $1$ の**両方**を含む開集合でなければなりません。つまり、$[0, \varepsilon) \cup (1 - \delta, 1]$ のように「左端のすぐ右側」と「右端のすぐ左側」がセットになって初めて、貼り合わせた点の周りの開近傍になります。これによって、$0$ と $1$ が1つの点の左右として滑らかに繋がります。

#### (3) 商位相の普遍性（商空間からの連続写像を作る定理）

商空間 $X / {\sim}$ から別の空間 $Y$ への連続写像を作るとき、わざわざ商位相の開集合を毎回調べる必要はありません。元の空間 $X$ での写像を調べるだけで済むのが次の定理です。

> **【定理1：商位相の普遍性】**
> $X, Y$ を位相空間、$\sim$ を $X$ 上の同値関係、$\pi: X \to X/{\sim}$ を商射影とする。
> 連続写像 $g: X \to Y$ が「$x_1 \sim x_2 \implies g(x_1) = g(x_2)$」（同値な点を同じ点に送る）を満たすならば、
>
> $$\tilde{g}([x]) := g(x)$$
>
> によって写像 $\tilde{g}: X/{\sim} \to Y$ が一意に定まり（Well-defined）、かつ **$\tilde{g}$ は連続写像**になる。

**【証明】**

1. **Well-defined性と一意性：** $[x_1] = [x_2]$ ならば $x_1 \sim x_2$ であり、仮定より $g(x_1) = g(x_2)$ となるため、代表元の選び方によらず $\tilde{g}([x])$ の値がただ1つに確定します（すなわち $\tilde{g} \circ \pi = g$）。
2. **連続性：** $Y$ の任意の開集合 $V$ をとります。$\tilde{g}^{-1}(V)$ が商空間 $X/{\sim}$ の開集合であることを示すには、商位相の定義より $\pi^{-1}(\tilde{g}^{-1}(V))$ が $X$ の開集合であることを示せば十分です。ここで合成写像の逆像の性質より、

    $$\pi^{-1}\big(\tilde{g}^{-1}(V)\big) = (\tilde{g} \circ \pi)^{-1}(V) = g^{-1}(V)$$

    $g$ は連続なので $g^{-1}(V)$ は $X$ の開集合です。よって $\tilde{g}^{-1}(V)$ は $X/{\sim}$ の開集合であり、$\tilde{g}$ の連続性が示されました。（証明終）

#### (4) 「連続全単射 $\implies$ 位相同型」を保証するコンパクト・ハウスドルフの定理

定理1を使えば、商空間から目標の空間への連続全単射 $\tilde{g}: X/{\sim} \to Y$ は簡単に作れます。しかし、位相同型 $X/{\sim} \cong Y$ を言うには、**逆写像 $\tilde{g}^{-1}$ も連続であること**を示さなければなりません。

一般の位相空間では「連続全単射でも逆写像が不連続になる例」が存在します（たとえば半開区間 $[0, 2\pi)$ から円周 $S^1$ への写像 $t \mapsto (\cos t, \sin t)$ は連続全単射ですが、$S^1$ の点 $(1, 0)$ の近くを逆写像で戻すと $0$ の近くと $2\pi$ の近くに千切れてしまうため不連続です）。

この逆写像の連続性を端的に保証するのが、位相空間論で最もよく使われる次の定理です。まず2つの用語を定義します。

* **コンパクト（Compact）：** 位相空間 $X$ を覆うどんな開集合の族 $\{ U_\lambda \}_{\lambda \in \Lambda}$（$X = \bigcup_{\lambda \in \Lambda} U_\lambda$：開被覆）に対しても、その中から**有限個** $U_{\lambda_1}, \dots, U_{\lambda_m}$ を選んで $X = U_{\lambda_1} \cup \dots \cup U_{\lambda_m}$ と覆えること。（※実数空間 $\mathbb{R}^n$ の部分集合がコンパクトであることと「有界かつ閉集合であること」は同値です［**ハイネ・ボレルの定理**］。特に閉区間 $[0, 2\pi]$ や正方形 $[0, 1]^2$、球面 $S^n$ はすべてコンパクトです。）
* **ハウスドルフ（Hausdorff）：** $Y$ の任意の異なる2点 $y_1 \neq y_2$ に対して、$y_1 \in V_1, \; y_2 \in V_2$ かつ $V_1 \cap V_2 = \emptyset$ となる交わらない2つの開集合 $V_1, V_2$ が存在すること。（※ユークリッド空間 $\mathbb{R}^n$ およびその任意の部分空間は、2点間の距離 $r = \Vert y_1 - y_2 \Vert > 0$ に対して半径 $r/2$ の開球をとれば分離できるため、常にハウスドルフです。）

> **【定理2：コンパクト空間からハウスドルフ空間への連続全単射は位相同型】**
> $X$ をコンパクト空間、$Y$ をハウスドルフ空間とする。連続写像 $f: X \to Y$ が全単射であれば、逆写像 $f^{-1}: Y \to X$ も自動的に連続となり、$f$ は位相同型写像になる。

**【証明】**
逆写像 $f^{-1}: Y \to X$ が連続であることは、「$X$ の任意の閉集合 $C$ に対して、$(f^{-1})^{-1}(C) = f(C)$ が $Y$ の閉集合であること」と同値です。これを3ステップで示します。

1. **$C$ はコンパクトである（コンパクト空間の閉部分集合はコンパクト）：**
    $C$ の任意の開被覆 $\{ U_\lambda \}_{\lambda \in \Lambda}$（各 $U_\lambda$ は $X$ の開集合で $C \subset \bigcup_\lambda U_\lambda$）をとります。$C$ は閉集合なので補集合 $X \setminus C$ は開集合であり、$\{ U_\lambda \}_{\lambda \in \Lambda} \cup \{ X \setminus C \}$ は $X$ 全体の開被覆になります。$X$ のコンパクト性より有限個の開集合で $X$ を覆えるため、そこから $X \setminus C$ を除いた有限個の $U_{\lambda_1}, \dots, U_{\lambda_m}$ が $C$ を覆います。

2. **$K := f(C)$ はコンパクトである（コンパクト集合の連続像はコンパクト）：**
    $K = f(C)$ の任意の開被覆 $\{ V_\mu \}_{\mu \in M}$ をとります。$f$ は連続なので $\{ f^{-1}(V_\mu) \}_{\mu \in M}$ は $C$ の開被覆になります。ステップ1より有限個 $f^{-1}(V_{\mu_1}), \dots, f^{-1}(V_{\mu_k})$ で $C$ を覆えるため、その像 $V_{\mu_1}, \dots, V_{\mu_k}$ が $K = f(C)$ を覆います。

3. **$K = f(C)$ は $Y$ の閉集合である（ハウスドルフ空間のコンパクト部分集合は閉集合）：**
    $K = \emptyset$ のときは自明に閉集合なので、$K \neq \emptyset$ とします。補集合 $Y \setminus K$ が開集合であることを示します。任意の点 $y \in Y \setminus K$ を固定します。各 $z \in K$ は $y \neq z$ なので、$Y$ のハウスドルフ性から $y \in V_z, \; z \in W_z, \; V_z \cap W_z = \emptyset$ となる開集合 $V_z, W_z$ が存在します。
    すると $\{ W_z \}_{z \in K}$ は $K$ の開被覆になるため、ステップ2のコンパクト性より有限個の点 $z_1, \dots, z_r \in K$ を選んで $K \subset W_{z_1} \cup \dots \cup W_{z_r}$ とできます。
    ここで有限個の開集合の共通部分 $V := V_{z_1} \cap \dots \cap V_{z_r}$ を作ると、$V$ は $y$ を含む開集合であり、どの $W_{z_i}$ とも交わらないため $V \cap K = \emptyset$、すなわち $V \subset Y \setminus K$ となります。すべての $y \in Y \setminus K$ がこのような開近傍 $V$ を持つため $Y \setminus K$ は開集合、よって $K = f(C)$ は閉集合です。（証明終）

**【応用：区間 $[0, 2\pi]$ の両端を貼った商空間と円周 $S^1$ の位相同型の証明】**
これで前節の確認問題の答えを飛躍なく証明できます。
写像 $g: [0, 2\pi] \to S^1 \subset \mathbb{R}^2$ を $g(t) := (\cos t, \sin t)$ と定めます。

* $g$ は連続であり、$g(0) = g(2\pi) = (1, 0)$ を満たすため、**定理1（普遍性）**より連続写像 $\tilde{g}: [0, 2\pi]/\{0 \sim 2\pi\} \to S^1$ が誘導されます。明らかに $\tilde{g}$ は全単射です。
* 元の区間 $[0, 2\pi]$ は有界閉集合なのでコンパクトであり、連続な商射影 $\pi$ による像 $[0, 2\pi]/\{0 \sim 2\pi\}$ もコンパクトです（定理2のステップ2より）。
* 一方、$S^1$ は $\mathbb{R}^2$ の部分空間なのでハウスドルフです。
* よって**定理2**より、$\tilde{g}$ は位相同型写像となり、$[0, 2\pi]/\{0 \sim 2\pi\} \cong S^1$ が証明されました。

> **【コラム：商位相の落とし穴 —— ハウスドルフ性が壊れる空間】**
>
> 元の空間 $X$ がどれほど素直なハウスドルフ空間であっても、同値関係 $\sim$ の選び方次第では、商空間 $X/{\sim}$ のハウスドルフ性が壊れてしまうことがあります。
>
> 典型的な反例が**「2つの原点を持つ直線」**です。2本の実数直線 $X = \mathbb{R} \times \{1, 2\}$ を用意し、$x \neq 0$ であるすべての点について $(x, 1) \sim (x, 2)$ と同一視します（つまり、原点 $x = 0$ だけを貼り合わせずに2個残します）。
> すると、商空間 $X/{\sim}$ の2つの原点 $O_1 = [(0, 1)]$ と $O_2 = [(0, 2)]$ は異なる点であるにもかかわらず、$O_1$ を含むどんな開集合 $U_1$ も $(-\varepsilon, \varepsilon)$ の $0$ 以外の点を含み、$O_2$ を含むどんな開集合 $U_2$ も $(-\delta, \delta)$ の $0$ 以外の点を含んでしまいます。その結果、**$U_1 \cap U_2$ は必ず空にならず、$O_1$ と $O_2$ を開集合で分離できません**（非ハウスドルフ空間）。
>
> 別の例として、実数直線 $\mathbb{R}$ 上で「差が有理数であるとき同値（$x \sim y \iff x - y \in \mathbb{Q}$）」と定めると、任意の開集合はすべての有理数のズレを含むため、$\mathbb{R}/\mathbb{Q}$ の開集合は $\emptyset$ と全体集合しかなくなってしまいます（密着位相）。
>
> 一方、本ノートで扱う「正方形の辺の貼り合わせ」や「$\mathbb{RP}^n$」「$T^3$」などはすべて良い同値関係（閉集合や有限群・離散群の適切な作用による商）であるため、健全なハウスドルフ空間（多様体）になります。

### 4. 翻訳と展望（Bridge）：本節の道具がこれからの各部にどう直結するか

1. **第1部（実射影空間 $\mathbb{RP}^2, \mathbb{RP}^3$）：**
    $\mathbb{R}^{n+1} \setminus \{\mathbf{0}\}$ を「原点を通る同じ直線上の点（$\mathbf{x} \sim \lambda\mathbf{x}, \; \lambda \neq 0$）」で割った商空間が $\mathbb{RP}^n$ です。長さを $1$ に正規化すれば、これは単位球面 $S^n$ の対蹠点 $\mathbf{x} \sim -\mathbf{x}$ を貼り合わせた商空間 $S^n / \{\mathbf{x} \sim -\mathbf{x}\}$ と位相同型であることが定理1・2から証明できます。

2. **第2部（クラインの壺と $\mathbb{RP}^2$）：**
    図0-3で定義したクラインの壺や $\mathbb{RP}^2$ は、商空間としては2次元多様体として矛盾なく存在します。これらを無理やり3次元空間へ写そうとしたときに初めて自己交差やピンチ点が現れることを第2部で詳しく解析します。

3. **第5部（$\mathrm{SO}(3) \cong \mathbb{RP}^3$）と第6部（3次元多様体の貼り合わせ）：**
    3次元回転群 $\mathrm{SO}(3)$ は、半径 $\pi$ の3次元球体 $D^3$ の表面（球面 $S^2$）の対蹠点同士を貼り合わせた商空間と位相同型になります。また、第6部では正方形の貼り合わせを1次元上げて、立方体 $[0, 1]^3$ の向かい合う面を貼り合わせた**3次元トーラス $T^3$** を構成します。
