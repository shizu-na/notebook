### 前節（6-1）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **2周する単位円周 $\gamma_2(t) = (\cos 2t, \sin 2t)$（$t \in [0, 2\pi]$）の回転数：**
    速度ベクトルは $\gamma_2'(t) = (-2\sin 2t, \; 2\cos 2t)$、速さは $\Vert\gamma_2'(t)\Vert = 2$ なので、単位接ベクトルは $\mathbf{T}(t) = (-\sin 2t, \; \cos 2t)$ です。
    微分すると $T_1'(t) = -2\cos 2t, \; T_2'(t) = -2\sin 2t$ となるため、

    $$T_1(t) T_2'(t) - T_2(t) T_1'(t) = (-\sin 2t)(-2\sin 2t) - (\cos 2t)(-2\cos 2t) = 2(\sin^2 2t + \cos^2 2t) = 2$$

    したがって回転数は $W(\gamma_2) = \frac{1}{2\pi}\int_0^{2\pi} 2\,dt = \mathbf{+2}$ です。1周の円周 $\gamma_+$ の回転数は $+1 \neq +2$ なので、[6-1節](6-1.md)の定理1より**折り目なしで正則ホモトピー変形することはできません**。

2. **2次元平面の円周を3次元空間で脱出する経路：**
    たとえば、$t \in [0, 1]$ に対して

    $$(x(t), \; y(t), \; z(t)) = \big(2t, \;\; 0, \;\; \sin(\pi t)\big)$$

    とすれば、$t = 0$ で内側の $(0, 0, 0)$、$t = 1$ で外側の $(2, 0, 0)$ に一致します。$z(t) = 0$ となるのは両端 $t = 0, 1$ のみであり、そのとき $x^2 + y^2$ は $0$ と $4$（$\neq 1$）なので、単位円周 $x^2 + y^2 = 1, \; z = 0$ に一度も触れずに上空（$z > 0$）を越えて外側へ脱出できます。

2次元の「閉曲線（1次元）による閉じ込め」が3次元空間で簡単に破られたように、**3次元の「結び目（1次元の紐の絡まり）」も、4次元空間 $\mathbb{R}^4$ へ持ち上げた瞬間にすべてほどけてしまいます**。本節では、「3次元でほどけないことの証明」と「4次元ですべてほどけることの明示的構成」を対比して検証します。

## 6-2. 3次元の結び目は、4次元ではすべてほどける：3彩色数と第4座標のすり抜け

### 1. 動機（Why）：なぜ「3次元でほどけない結び目」が4次元ではほどけるのか？

1本の紐を複雑に結んでから両端をくっつけて1つの輪にしたものを**結び目（Knot）**と呼びます。最も単純な非自明な結び目が、3か所の交差を持つ**三葉結び目（Trefoil knot）**です。

私たちが3次元空間の中で三葉結び目をいくら引っ張ったりひねったりしても、紐をハサミで切らない限り、ただの丸い輪（**自明な結び目 / Unknot**）に戻せないことは経験的に明らかです。しかし、数学的に「どんなに複雑な変形を無限回試みてもほどけない」ことを証明するには、[6-1節](6-1.md)の回転数と同じように**「変形しても変わらない不変量」**を見つける必要があります。

本節では、次の2つの問いに飛躍を抑えて答えます。

1. **3次元での不可能証明：** 結び目の図式を変形する3つの基本操作（**ライデマイスター移動**）のもとで保存される不変量「**3彩色数**」を定義し、三葉結び目が3次元空間でほどけないことを証明する。
2. **4次元での可能証明：** 4次元空間 $\mathbb{R}^4$ の第4座標 $w$（直感的には「色」や「時間」として可視化できる余剰次元）を使うと、紐の交差の上下を衝突なしで入れ替えることができる。これを用いて、**どんなに複雑な3次元の結び目であっても、4次元空間では必ず自明な結び目にほどける**ことを明示的な数式で証明する。

---

### 2. 具体例と幾何学的イメージ（Toy Model）

#### 実験A：3色塗り分けゲーム（フォックスの3彩色）

結び目を平面に投影し、交差する場所では「下を通る線」を少し途切れさせて描いた絵を**結び目図式（Knot diagram）**と呼びます。途切れ目から次の途切れ目までの1本の連続した線を**アーク（Arc）**と呼びます（自明な円はアーク1本、三葉結び目はアーク3本です）。

ここで、結び目図式の各アークを**赤・緑・青の3色**（数字で $\{0, 1, 2\}$）で塗り分けるゲームを考えます。ルールはたった1つです。

> **【3彩色のルール】**
> すべての交差点において、そこに集まる3本のアーク（上を通る1本と、下を通る左右の2本）の色は、
> **「3本すべて同じ色」** または **「3本すべて異なる色（赤・緑・青が1本ずつ）」**
> のいずれかでなければならない。

* **自明な結び目（円1本）：** アークが1本しかないので、単色で塗る **3通り**（赤のみ、緑のみ、青のみ）しかありません。
* **三葉結び目（アーク3本）：** 単色で塗る3通りに加えて、**3本のアークを赤・緑・青の3色で別々に塗る**と、3つの交差点すべてで「3本すべて異なる色」というルールが満たされます。色の割り当て方は $3! = 6$ 通りあるので、単色3通りと合わせて合計 **$9$ 通り** の3彩色が存在します。

後半（第3項）で証明する通り、この**「3彩色の総数（3彩色数）」は、結び目を3次元空間内でどう変形しても変わりません**。$9 \neq 3$ である以上、三葉結び目は3次元空間ではただの円にほどけないのです。

#### 実験B：第4座標 $w$ を「色」として見て、交差をすり抜ける

では、なぜ4次元空間 $\mathbb{R}^4$ へ行くとこの壁が消えるのでしょうか？
4次元空間の点 $(x, y, z, w)$ のうち、$(x, y, z)$ を私たちの3次元空間の位置、**第4座標 $w$ を「紐の色（$w = 0$ が青、$w > 0$ が赤）」**としてイメージしてください。3次元空間で2本の紐が同じ位置 $(x, y, z)$ に重なって見えても、**色が違えば（$w$ 座標が異なれば）4次元空間の中ではまったく別の場所にあり、衝突していません**。

三葉結び目の3つの交差点のうち、どこか**1か所だけ**の上下を入れ替えることができれば、三葉結び目はそのままほどけてただの円になります。4次元空間では、次の3ステップで交差の上下をすり抜けられます。

1. 交差点の上側にある紐の一部だけを、$w > 0$ 方向へ持ち上げる（青から**赤色**に変える）。
2. 赤い（$w > 0$ の）状態のまま、3次元空間で下側の青い紐（$w = 0$）をまっすぐ突き抜けて下側へ移動させる（色が違うのでぶつからない）。
3. 下側へ抜け切ったら、$w = 0$ へ戻す（赤から青に戻す）。

たったこれだけで、紐を一切切らずに交差の上下を入れ替えられ、三葉結び目はするりとほどけてしまいます。

### 3. 厳密な定義と定理（What）：3彩色数の不変性証明と4次元結び目解消の証明

#### (1) ライデマイスターの定理と3彩色数 $\operatorname{col}_3(D)$

3次元空間 $\mathbb{R}^3$ 内の2つの結び目（多角形または滑らかな埋め込み $S^1 \hookrightarrow \mathbb{R}^3$）が「紐を切らずに連続変形して一致する（アンビエント・イソトピック）」ことは、平面に投影した結び目図式 $D$ に対して以下の**3種類の局所操作（ライデマイスター移動 / Reidemeister moves）**と平面上の連続変形を有限回繰り返して移り合えることと同値です（**ライデマイスターの定理**、1927年）。

* **R1（ねじりの追加・解消）：** 1本の線に小さな輪（1個の交差）をひねって作る／戻す。
* **R2（2本の重なりの追加・解消）：** 離れた2本の線の一方をもう一方の上へスライドさせて2個の交差を作る／戻す。
* **R3（3本の交差のスライド）：** 2本の線の交差点の上（または下）を、3本目の線が横切って反対側へスライドする。

ここで、3色を有限体 $\mathbb{Z}/3\mathbb{Z} = \{0, 1, 2\}$ の元とみなします。結び目図式 $D$ の各アークに色 $c \in \mathbb{Z}/3\mathbb{Z}$ を割り当てる写像が**3彩色（Fox 3-coloring）**であるとは、すべての交差点（上を通るアークの色を $a$、下を通る2本のアークの色を $b, c$ とする）において、次の線形方程式を満たすことをいいます：

$$2a - b - c \equiv 0 \pmod{3} \qquad \big(\iff b + c \equiv 2a \pmod{3}\big)$$

（※これが実験Aの「3本すべて同じ色、またはすべて異なる色」と完全に同値であることを確認します。もし $b = a$ なら $c \equiv 2a - a = a$ で3本とも同じ色。もし $b \neq a$ なら $b \equiv a + d$（$d \in \{1, 2\}$）と書け、$c \equiv 2a - (a + d) \equiv a + 2d \pmod{3}$ となり、$\{a, a+d, a+2d\}$ は $\{0, 1, 2\}$ の相異なる3色すべてになります。）

図式 $D$ の3彩色の総数を**3彩色数 $\operatorname{col}_3(D)$** と書きます。

#### (2) 定理1：3彩色数の不変性と「三葉結び目は3次元でほどけない」の証明

> **【定理1：3彩色数のライデマイスター不変性】**
> 結び目図式 $D$ の3彩色数 $\operatorname{col}_3(D)$ は、3種類のライデマイスター移動 R1, R2, R3 のいずれを行っても変化しない（結び目不変量である）。
> 特に、自明な結び目の3彩色数は $3$、三葉結び目の3彩色数は $9$ であるため、**三葉結び目は3次元空間内でほどけない**。

**【証明】**
各移動 R1, R2, R3 の局所領域の「外側の境界」にあるアークの色を固定したとき、移動前の3彩色と移動後の3彩色の間に**完全な1対1対応**があることを示します。

1. **R1（ねじりの追加・解消）での不変性：**
    移動前は1本のアーク（色 $a$）。移動後は交差点が1個でき、上を通るアークの色が $a$、下を通る2本のアークの一方も同じアークなので色 $a$、もう一方を色 $c$ とします。交差条件 $a + c \equiv 2a \pmod 3$ を解くと $c \equiv a$ が一意に確定します。よって移動前後の3彩色は1対1に対応します。

2. **R2（2本の重なりの追加・解消）での不変性：**
    移動前は交差しない2本のアーク（色 $a$ と $b$）。移動後は色 $a$ のアークが上を通り、下をくぐるアークが左から色 $b$、2交差点の間の中央部分が色 $x$、右側が色 $c$ に分かれます。

    * 左の交差点の条件：$b + x \equiv 2a \implies x \equiv 2a - b \pmod 3$（中央の色 $x$ が一意に確定）。
    * 右の交差点の条件：$x + c \equiv 2a \implies (2a - b) + c \equiv 2a \implies c \equiv b \pmod 3$（右側の色 $c$ は必ず左側の色 $b$ と一致）。

    したがって、境界の色 $(a, b)$ を与えるごとに移動後の3彩色が一意に定まり、1対1に対応します。

3. **R3（3本の交差のスライド）での不変性：**
    3本の線のうち一番上を通る線の色を $a$、真ん中の線が左から色 $b$ で入り $a$ の下を通って色 $b'$ で出るとします（$a$ との交差条件より移動前後とも $b' \equiv 2a - b \pmod 3$）。一番下の線が左から色 $c$ で入り、2回の交差を経て右側へ出る色を計算します。

    * **移動前：** 一番下の線 $c$ はまず真ん中の線 $b$ の下を通って色 $x \equiv 2b - c$ になり、次に一番上の線 $a$ の下を通って色 $y \equiv 2a - x \equiv 2a - 2b + c \pmod 3$ で出ます。
    * **移動後：** 一番下の線 $c$ はまず一番上の線 $a$ の下を通って色 $x' \equiv 2a - c$ になり、次に真ん中の線の出口側 $b' = 2a - b$ の下を通って色

        $$y' \equiv 2b' - x' \equiv 2(2a - b) - (2a - c) = 2a - 2b + c \pmod 3$$

        で出ます。

    移動前と移動後で出口の色が **$y \equiv y' \pmod 3$ と一致**し、中央の短い線分 $x, x'$ も境界の色 $(a, b, c)$ からそれぞれ一意に定まるため、移動前後の3彩色は1対1に対応します。

4. **三葉結び目と自明な結び目の比較：**

    * 自明な結び目の図式（交差 $0$ 個、アーク $1$ 本）：色は $0, 1, 2$ の $3$ 通りなので $\operatorname{col}_3(\text{Unknot}) = \mathbf{3}$。
    * 三葉結び目の図式（アーク3本 $x_1, x_2, x_3$）：3つの交差条件は $2x_1 - x_2 - x_3 \equiv 0$, $2x_2 - x_3 - x_1 \equiv 0$, $2x_3 - x_1 - x_2 \equiv 0 \pmod 3$ です。$\pmod 3$ では $2 \equiv -1$ なので、3本の方程式はすべて同じ1本の方程式

        $$x_1 + x_2 + x_3 \equiv 0 \pmod{3}$$

        に帰着します。$x_1, x_2 \in \mathbb{Z}/3\mathbb{Z}$ を自由に選べば $x_3 \equiv -x_1 - x_2 \pmod 3$ が一意に決まるため、解の総数は $\operatorname{col}_3(\text{Trefoil}) = 3 \times 3 = \mathbf{9}$ です。

    $9 \neq 3$ なので、三葉結び目はいかなるライデマイスター移動の列によっても自明な結び目へ変形できません。（証明終）

#### (3) 定理2：4次元空間 $\mathbb{R}^4$ では、すべての1次元結び目が必ずほどける

次に、舞台を3次元空間 $\mathbb{R}^3 = \{ (x, y, z, 0) \in \mathbb{R}^4 \}$ から4次元空間 $\mathbb{R}^4$ へ広げます。2つの明確な補題を組み合わせて、**どんな3次元の結び目も4次元空間では紐を切らずに自明な結び目へ連続変形できる**ことを証明します。

> **【補題1（4次元での交差上下入れ替えの明示的構成）】**
> 3次元空間 $\mathbb{R}^3 \times \{0\} \subset \mathbb{R}^4$ 内の結び目について、ある1か所の交差点の近傍における上側の線分 $L_1(u) = (u, 0, +1, 0)$（$u \in [-1, 1]$）と下側の線分 $L_2(v) = (0, v, -1, 0)$（$v \in [-1, 1]$）を考える。
> 時刻 $s \in [0, 1]$ に対する連続変形
>
> $$L_1(u, s) := \Big( u, \;\; 0, \;\; 1 - 3s(1 - u^2), \;\; \sin(\pi s)(1 - u^2) \Big)$$
>
> は、$L_1$ の両端 $u = \pm 1$ を固定し、$L_2$ を動かさないまま、**全時刻 $s \in [0, 1]$ で $L_1$ と $L_2$ が1点も衝突することなく**、$s = 1$ において $L_1$ を $L_2$ の下側（$w = 0$ の $\mathbb{R}^3$ 内）へ移す。

**【証明】**

1. **境界の固定と始点・終点の確認：**

    * $u = \pm 1$ のとき $1 - u^2 = 0$ なので、すべての $s \in [0, 1]$ で $L_1(\pm 1, s) = (\pm 1, 0, 1, 0)$ に固定され、交差点以外の結び目全体と連続に繋がります。
    * $s = 0$ のとき $L_1(u, 0) = (u, 0, 1, 0)$（元のまま上側）。
    * $s = 1$ のとき $\sin\pi = 0$ より $L_1(u, 1) = (u, 0, 1 - 3(1 - u^2), 0) \in \mathbb{R}^3 \times \{0\}$ であり、交差点 $u = 0$ での高さは $z = 1 - 3 = -2 < -1$ となって $L_2$ の下側へ移動完了します。

2. **非衝突性（自己交差ゼロ）：**
    ある $u, v \in [-1, 1]$ と $s \in [0, 1]$ で $L_1(u, s) = L_2(v) = (0, v, -1, 0)$ が起きたと仮定します。

    * 第1・第2成分の比較より $u = 0, \; v = 0$。
    * 第3成分（$u = 0$）の比較より $1 - 3s = -1 \implies s = \frac{2}{3}$。
    * 第4成分（$u = 0$）の比較より $\sin(\pi s) = 0 \implies s \in \{0, 1\}$。

    $s = \frac{2}{3}$ と $s \in \{0, 1\}$ は同時に成り立たないため矛盾です。また、同じ時刻 $s$ の $L_1(u, s)$ 同士も第1成分が $u$ なので自己交差しません。（証明終）

> **【補題2（下降図式は必ず自明な結び目である）】**
> 任意の結び目図式 $D$ は、有限回の「交差の上下入れ替え」によって必ず自明な結び目に変形できる。

**【証明】**
結び目図式 $D$（平面曲線 $(x(t), y(t)), \; t \in [0, 1]$）上で、$x$ 座標が最小となる点 $p_0 = (x_{\min}, y_0)$ を基点に選びます（必要なら微小回転して唯一の最小点かつ非交差点にします）。

1. **下降結び目（Descending knot）の構成：**
    基点 $p_0$ から $t = 0 \to 1$ に沿って図式 $D$ を1周辿り、各交差点について「1回目に通過するときは上、2回目に通過するときは下」となるように、必要なら交差の上下を入れ替えます（交差は有限個なので有限回の入れ替えで終わります）。
    この上下関係は、3次元空間内で「$t \in [0, 1 - \varepsilon]$ の間は高さ $z(t)$ が $1$ から $0$ へ狭義単調減少し、最後の短い区間 $t \in [1 - \varepsilon, 1]$（交差点を含まない $p_0$ のすぐ左側の迂回路 $x < x_{\min}$）で高さを $0$ から $1$ へ戻して $p_0$ に閉じる」という3次元曲線 $K_{\mathrm{desc}}$ として厳密に実現できます。
2. **自明な結び目への連続変形：**
    $K_{\mathrm{desc}}$ の本体部分（$t \in [0, 1 - \varepsilon]$）は、すべての点 $(x(t), y(t), z(t))$ が $x \ge x_{\min}$ の領域にあり、かつ**各時刻 $t$ で高さ $z(t)$ がすべて互いに異なる**という性質を持っています。
    したがって、高さ $z(t)$ を一切変えずに、水平座標 $(x(t), y(t))$ だけを $x \ge x_{\min}$ の領域内で単純な半円弧（例：$(x_{\min} + \sin\frac{\pi t}{1 - \varepsilon}, \; y_0)$）へ線形に連続変形しても、異なる $t_1 \neq t_2$ は高さ $z(t_1) \neq z(t_2)$ が違うため**本体同士は衝突せず**、また常に $x \ge x_{\min}$ に留まるため**左側の戻り線（$x < x_{\min}$）とも衝突しません**。変形後に残るのは平面 $y = y_0$ 内の単純な閉曲線（自明な結び目）です。（証明終）

補題1と補題2を合わせれば、次の主定理が直ちに完成します。

> **【定理2：4次元空間におけるすべての1次元結び目の解消】**
> 3次元空間 $\mathbb{R}^3 \times \{0\} \subset \mathbb{R}^4$ 内に置かれた任意の結び目 $K$ は、4次元空間 $\mathbb{R}^4$ の中での連続変形（アンビエント・イソトピー：紐を切らず、一度も自己交差させない変形）によって、自明な結び目（平面上の単位円周）へほどくことができる。

**【証明】**
補題2より、$K$ は有限回の交差の上下入れ替えによって自明な結び目になります。そして補題1より、その1回1回の交差の上下入れ替えは、4次元空間 $\mathbb{R}^4$ の中での自己交差のない連続変形として実行できます。有限個の連続変形を順に繋ぎ合わせれば、$K$ を自明な結び目へほどく4次元空間内の連続変形が完成します。（証明終）

> **【コラム：では4次元空間で「ほどけない結び目」は作れないのか？ —— 2次元球面の結び目と「余次元2の法則」】**
>
> 2次元平面の点（$0$ 次元）は1次元の円周に閉じ込められますが、3次元では脱出できました。3次元空間の紐（$1$ 次元）はほどけませんが、4次元ではすべてほどけました。
> では、**「4次元空間の中でほどけない結び目」**を作ることはできるのでしょうか？
>
> 答えは **YES** です。1次元の紐（$S^1$）ではなく、次元を1つ上げた**2次元球面 $S^2$（風船の表面）**を4次元空間 $\mathbb{R}^4$ の中に埋め込めば、4次元空間の中で複雑に絡み合って標準球面に戻せない**「2-結び目（Knotted 2-sphere：$S^2 \hookrightarrow \mathbb{R}^4$）」**が無数に存在します。
>
> 最も有名な構成法が1925年にエミール・アルティンが発見した**スピン結び目（Spun knot）**です。
>
> 1. 3次元半空間 $\mathbb{R}^3_+ = \{ (x, y, z) \mid x \ge 0 \}$ の中に、両端を壁 $x = 0$ にくっつけた「三葉結び目の切れ端（1本の弧）」を置きます。
> 2. 4次元空間 $\mathbb{R}^4$ の中で、この半空間 $\mathbb{R}^3_+$ を、壁である2次元平面 $\{ x = 0, w = 0 \}$ を「回転面（不動平面：[0-2節](../0/0-2.md)）」として **$xw$ 平面内で $360^\circ$ ぐるりと1回転**させます。
> 3. すると、結び目の弧が描く回転体の表面は位相的に2次元球面 $S^2$ になり、元の三葉結び目の絡まり方をそのまま引き継いだ「4次元空間内でほどけない球面」が完成します。
>
> 一般に、$k$ 次元球面 $S^k$ を $n$ 次元空間 $\mathbb{R}^n$ に埋め込むとき、**非自明な結び目が存在できるのはちょうど「余次元 $n - k = 2$」（すなわち $S^k \hookrightarrow \mathbb{R}^{k+2}$）のとき**に限られます（$n - k \ge 3$ になると、本節の $S^1 \hookrightarrow \mathbb{R}^4$ と同じく余剰次元でのすり抜けが可能になり、滑らかな結び目はすべてほどけます［※厳密には滑らかな圏では $S^3 \hookrightarrow \mathbb{R}^6$ 等でも余次元2以外でハフリガー結び目が現れる例外がありますが、局所平坦な位相的・PL結び目では余次元3以上ですべてほどけることがゼーマンによって証明されています］）。
>
> また、私たちの体内の細胞にある**DNA**は3次元空間で複雑に絡み合った環状分子ですが、**トポイソメラーゼ**という酵素が「DNAの鎖を一時的に切断し、もう一方の鎖を通過させてから再結合する」という操作を行っています。つまり生命は、酵素による一時的な切断という化学的トリックによって、本節の「交差の上下入れ替え（4次元的なすり抜け）」を3次元空間の中で擬似的に実現し、DNAの結び目をほどいているのです。

### 理解度チェック（最終節 6-3 へ進む前の確認）

本節の3彩色数の計算と、最終節（[6-3節](6-3.md)：3次元多様体の貼り合わせ）への橋渡しとなる問いを2つ置いておきます。

> **【確認の問い】**
>
> 1. **（8の字結び目の3彩色数と限界）** 三葉結び目の次に単純な結び目として、交差が4個ある**8の字結び目（Figure-eight knot）**があります。8の字結び目の4本のアークの色を $x_1, x_2, x_3, x_4 \in \mathbb{Z}/3\mathbb{Z}$ としたとき、4つの交差条件は次のように書けます：
>
>     $$2x_1 - x_2 - x_3 \equiv 0, \quad 2x_2 - x_3 - x_4 \equiv 0, \quad 2x_3 - x_1 - x_4 \equiv 0, \quad 2x_4 - x_1 - x_2 \equiv 0 \pmod{3}$$
>
>     この連立方程式を $\pmod 3$ で解いて、8の字結び目の3彩色数 $\operatorname{col}_3$ を求めてください。（※実は $3$ になります。つまり「3彩色数」だけでは8の字結び目がほどけないことは見抜けず、5彩色数 $\pmod 5$ などのより強い不変量が必要になることが分かります。）
>
> 2. **（最終節 6-3 への伏線：3次元トーラス $T^3$ の中を歩く）** 3次元の立方体 $[0, 1]^3$ の「右面と左面」「前面と背面」「上面と底面」をそれぞれ同じ向きに貼り合わせた空間が**3次元トーラス $T^3 = \mathbb{R}^3 / \mathbb{Z}^3$** です。もし自分がこの立方体の部屋のど真ん中に立ってまっすぐ前（$+x$ 方向）を見ると、自分の目の前には何が見えるでしょうか？ また、真上（$+z$ 方向）を見上げると何が見えるでしょうか？
