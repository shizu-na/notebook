### 前節（6-2）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **8の字結び目の3彩色数：**
    与えられた4つの交差条件

    $$2x_1 - x_2 - x_3 \equiv 0, \quad 2x_2 - x_3 - x_4 \equiv 0, \quad 2x_3 - x_1 - x_4 \equiv 0, \quad 2x_4 - x_1 - x_2 \equiv 0 \pmod{3}$$

    は、$\pmod 3$ で $2 \equiv -1$ より、符号を反転させると

    $$x_1 + x_2 + x_3 \equiv 0, \quad x_2 + x_3 + x_4 \equiv 0, \quad x_3 + x_1 + x_4 \equiv 0, \quad x_4 + x_1 + x_2 \equiv 0 \pmod{3}$$

    となります。第1式と第2式の差をとると $x_1 \equiv x_4$、第2式と第3式の差をとると $x_2 \equiv x_1$、第3式と第4式の差をとると $x_3 \equiv x_2$ となります。
    よってすべてのアークが同じ色（$x_1 \equiv x_2 \equiv x_3 \equiv x_4$）になる単色塗りの **$3$ 通り** しか解が存在しません（$\operatorname{col}_3 = 3$）。
    （※一方で、同じ方程式を $\pmod 5$ で解くと $(x_1, x_2, x_3, x_4) = (0, 1, 4, 3)$ のような非自明解を含めて $25$ 通りの5彩色が存在するため、5彩色数 $\operatorname{col}_5 = 25 \neq 5$ によって8の字結び目が3次元でほどけないことを証明できます。）

2. **3次元トーラス $T^3 = [0, 1]^3 / {\sim}$ の中を歩く景色：**

    * まっすぐ前（$+x$ 方向）を見ると、前方の壁（$x = 1$）が背後の壁（$x = 0$）と直結しているため、**自分の後頭部（背中）**が見えます。さらにその奥にも、周期 $1$ ごとに自分の背中が無限に並んでいるように見えます。
    * 真上（$+z$ 方向）を見上げると、天井（$z = 1$）が床（$z = 0$）と直結しているため、**自分の足の裏**が見えます。

ここから、本ノートの最終節である「6-3. 3次元多様体の貼り合わせと4次元の特異性」に入ります。

## 6-3. 3次元多様体の貼り合わせと4次元の特異性：3次元トーラス・ポアンカレ球面・エキゾチック $\mathbb{R}^4$

### 1. 動機（Why）：「外から眺める」から「空間そのものの中を歩く」へ

ここまで私たちは、4次元空間 $\mathbb{R}^4$ の中に置かれた図形を「外から影を落とす（第1・2部）」「輪切りにする（[第3部](../index.md#part-3)）」「対称性で分類する（[第4部](../index.md#part-4)）」「立体射影で中から見る（[第5部](../index.md#part-5)）」「次元を上げて変形する（[第6部](../index.md#part-6)）」という5つの角度から攻略してきました。

しかし、現代幾何学における「高次元空間を見る」ための最終的な視点は、**「外側の高い次元（$\mathbb{R}^4$ や $\mathbb{R}^6$）に頼らず、多面体の面同士を貼り合わせて『閉じた3次元空間（3次元多様体）』そのものを内側から構築する」**ことです。

本節では、[0-3節](../0/0-3.md)の商位相と[第5部](../index.md#part-5)の $S^3$ の構造を総動員して2つの象徴的な3次元多様体（**3次元トーラス $T^3$** と **ポアンカレホモロジー球面 $S^3 / 2I$**）を構成し、最後に「なぜ全次元の中で**4次元空間 $\mathbb{R}^4$ だけ**が現代トポロジーにおいて他のどの次元とも異なる特有の特異性（**エキゾチック $\mathbb{R}^4$**）を持つのか」を展望して本ノートを締めくくります。

### 2. 具体例と幾何学的イメージ（Toy Model）

#### モデルA：3次元トーラス $T^3$（立方体の対面貼り合わせ）

[0-3節](../0/0-3.md)で、2次元の正方形 $[0, 1]^2$ の左右の辺・上下の辺をそのまま貼り合わせると、平坦な2次元トーラス $T^2 = \mathbb{R}^2 / \mathbb{Z}^2$ ができることを見ました。

まったく同じ操作を1次元上げ、3次元の単位立方体 $[0, 1]^3$ の向かい合う3組の正方形の面を、ひねらずにそのまま貼り合わせます：

$$(0, y, z) \sim (1, y, z), \qquad (x, 0, z) \sim (x, 1, z), \qquad (x, y, 0) \sim (x, y, 1)$$

これが**3次元トーラス $T^3 = S^1 \times S^1 \times S^1 \cong \mathbb{R}^3 / \mathbb{Z}^3$** です。

* 私たちの3次元空間 $\mathbb{R}^3$ の中で立方体を曲げて面同士をくっつけることは不可能です（曲率ゼロのまま埋め込むには6次元空間 $\mathbb{R}^6$ が必要です）。
* しかし、商位相の空間 $T^3$ の**「中」**に入って見渡すと、どの方向へ進んでも壁は存在せず、自分のクローンが前後・左右・上下に無限の3次元格子状に並んでいるように見える、**有限の体積（体積 $1$）を持ちながら果て（境界）がどこにもない平坦な宇宙**として把握できます。

#### モデルB：ポアンカレ十二面体空間（正十二面体の $36^\circ$ ひねり貼り合わせ）

立方体の代わりに、[4-1節](../4/4-1.md)で構成した**正十二面体 $\{5, 3\}$**（12枚の正五角形の面を持つ立体）を用意します。正十二面体には、向かい合う平行な正五角形のペアがちょうど $6$ 組あります。

この向かい合う2枚の正五角形は、互いに $180^\circ$（$\frac{1}{2}$ 回転、あるいは $\frac{1}{10}$ 回転＝$36^\circ$ の奇数倍）だけ向きがズレて向かい合っています。そこで、**6組すべての対面を、右ねじの向きにちょうど $36^\circ$（$\frac{2\pi}{10}$、最小のひねり）だけ回して貼り合わせます**。

こうして得られる3次元空間が、1904年にアンリ・ポアンカレが発見した**ポアンカレホモロジー球面（ポアンカレ十二面体空間）**です。実はこの空間は、後半（第3項）で見る通り、[第5部](../index.md#part-5)（[5-3節](../5/5-3.md)）で正600胞体の120頂点として登場した**二項二十面体群 $2I \subset S^3$ による商空間 $S^3 / 2I$** そのものに一致します。

### 3. 厳密な定義と定理（What）：$T^3$ と $S^3 / 2I$ の厳密計算、およびエキゾチック $\mathbb{R}^4$ の展望

#### (1) 3次元トーラス $T^3$ の位相構造とオイラー標数

3次元ユークリッド空間 $\mathbb{R}^3$ に整数格子群 $\mathbb{Z}^3$ を平行移動 $(\mathbf{x} \mapsto \mathbf{x} + \mathbf{n}, \; \mathbf{n} \in \mathbb{Z}^3)$ で作用させた軌道空間が $T^3 := \mathbb{R}^3 / \mathbb{Z}^3$ です。

* **多様体構造：** 任意の点 $\mathbf{x} \in \mathbb{R}^3$ の半径 $\frac{1}{3}$ の開球 $B(\mathbf{x}, \frac{1}{3})$ は、どの非ゼロの整数平行移動 $\mathbf{n} \in \mathbb{Z}^3 \setminus \{\mathbf{0}\}$ による像とも交わらないため、商射影 $\pi: \mathbb{R}^3 \to T^3$ は局所的に位相同型（しかも距離を保つ局所等長写像）になります。したがって $T^3$ は**至る所曲率が $0$ のコンパクトな3次元多様体**です。
* **胞体分割とオイラー標数 $\chi(T^3)$：** 立方体 $[0, 1]^3$（8頂点・12辺・6面・1胞）の対面を同一視すると、

    * 8個の頂点はすべて $\mathbb{Z}^3$ のズレで一致するため **$V = 1$**。
    * 12本の辺は $x, y, z$ 軸方向の4本ずつが1本にまとまるため **$E = 3$**。
    * 6枚の面は向かい合う2枚ずつが3組にまとまるため **$F = 3$**。
    * 内部の3次元胞はそのまま **$C = 1$**。

    よってオイラー標数は $\chi(T^3) = V - E + F - C = 1 - 3 + 3 - 1 = \mathbf{0}$ です（一般に、任意の奇数次元閉多様体のオイラー標数は必ず $0$ になることがポアンカレ双対性から知られています）。

* **基本群：** $T^3 = S^1 \times S^1 \times S^1$ なので、基本群は3方向の独立な巻き数を数える自由アーベル群 $\pi_1(T^3) \cong \mathbb{Z} \times \mathbb{Z} \times \mathbb{Z} = \mathbb{Z}^3$ になります。

#### (2) ポアンカレホモロジー球面 $S^3 / 2I$ の完全群証明

[5-3節](../5/5-3.md)で構成した**二項二十面体群 $2I \subset S^3$**（位数 $120$、幾何学的には正600胞体の120頂点）を、単位3次元球面 $S^3$ 自身に左掛け算 $(g, x) \mapsto gx$ で作用させます。

* **作用の自由性：** もし $gx = x$ となる $x \in S^3$ が存在すれば、両辺に右から $x^{-1} = \bar{x}$ を掛けて $g = 1$ が確定します。すなわち単位元 $1$ 以外のすべての元は不動点を1つも持ちません。
* したがって、有限群 $2I$ による軌道空間（商空間）

    $$P^3 := S^3 / 2I$$

    は、3次元球面 $S^3$ の正の曲率をそのまま受け継ぐ**コンパクトな3次元多様体**になります（$S^3$ は単連結［$\pi_1(S^3) = \{1\}$］なので、普遍被覆空間の理論より基本群は $\pi_1(P^3) \cong 2I$［位数 $120$ の非可換群］となり、$P^3$ は3次元球面 $S^3$ とは位相同型ではありません）。

* **正十二面体貼り合わせとの一致：** $S^3$ 上に均等に並ぶ120個の点（$2I$ の元＝正600胞体の120頂点）について、「単位元 $1 \in 2I$ に最も近い $S^3$ 上の点の集合（ボロノイ領域／基本領域）」を切り出すと、正600胞体の極双対である**正120胞体 $\{5, 3, 3\}$ の1個の胞＝球面正十二面体**がぴったり現れます。そして隣接する12個の胞へ移す群の生成元が、正十二面体の向かい合う面同士をちょうど $36^\circ$（$\frac{2\pi}{10}$）ひねって貼り合わせる変換に一致します。

ここで、ポアンカレを驚かせた核心的性質――**「基本群 $\pi_1(P^3) \cong 2I$ は非自明（位数 120）なのに、1次ホモロジー群 $H_1(P^3; \mathbb{Z})$ がゼロ（$S^3$ とまったく同じ）になる」**――を、群論だけで飛躍を抑えて証明します。

空間 $X$ の1次ホモロジー群 $H_1(X; \mathbb{Z})$ は、基本群 $\pi_1(X)$ をその交換子部分群 $[\pi_1(X), \pi_1(X)]$（交換子 $[a, b] := aba^{-1}b^{-1}$ たちで生成される正規部分群）で割った**アーベル化** $\pi_1(X) / [\pi_1(X), \pi_1(X)]$ に同型です（フレヴィッツの定理）。したがって、$H_1(P^3; \mathbb{Z}) = \{0\}$ を示すには、**$[2I, 2I] = 2I$（すなわち $2I$ が完全群であること）**を証明すれば十分です。

> **【定理1：二項二十面体群 $2I$ の完全性（$H_1(S^3 / 2I; \mathbb{Z}) = \{0\}$）】**
> 二項二十面体群 $2I \subset S^3$ の交換子部分群は $2I$ 全体に一致する：$[2I, 2I] = 2I$。
> したがって、ポアンカレホモロジー球面 $P^3 = S^3 / 2I$ は $\pi_1(P^3) \cong 2I \neq \{1\}$ であるにもかかわらず、1次ホモロジー群は $H_1(P^3; \mathbb{Z}) \cong 2I / [2I, 2I] = \{0\}$ となる（さらに向き付け可能閉3次元多様体のポアンカレ双対性より $H_2 = \{0\}, \; H_0 \cong H_3 \cong \mathbb{Z}$ となり、すべての次数のホモロジー群が3次元球面 $S^3$ と一致する）。

**【証明】**

1. [5-3節](../5/5-3.md)で示した通り、2重被覆 $\Phi_3: S^3 \to \mathrm{SO}(3)$ を $2I$ に制限すると、正二十面体の回転対称群 $I \cong A_5$（5文字の偶置換全体がなす交代群、位数 $60$）への全射群準同型 $\Phi_3 : 2I \twoheadrightarrow A_5$（核は $\ker \Phi_3 = \{+1, -1\}$）が得られます。
2. 交代群 $A_5$ は非可換単純群（自明な部分群 $\{e\}$ と $A_5$ 自身以外に正規部分群を持たない）です。交換子部分群 $[A_5, A_5]$ は常に正規部分群であり、$A_5$ は非可換なので $[A_5, A_5] \neq \{e\}$、したがって **$[A_5, A_5] = A_5$** です。
3. 群準同型は交換子を交換子へ写す（$\Phi_3(aba^{-1}b^{-1}) = \Phi_3(a)\Phi_3(b)\Phi_3(a)^{-1}\Phi_3(b)^{-1}$）ため、$\Phi_3([2I, 2I]) = [\Phi_3(2I), \Phi_3(2I)] = [A_5, A_5] = A_5$ となります。
    したがって、任意の元 $g \in 2I$ に対して、$\Phi_3(h) = \Phi_3(g)$ を満たす $h \in [2I, 2I]$ が存在します。$\ker \Phi_3 = \{\pm 1\}$ より、これは **$g \in [2I, 2I]$ または $-g \in [2I, 2I]$** を意味します。

4. ここで、四元数群 $Q_8 \subset 2T \subset 2I$ に含まれる2つの元 $i, j \in 2I$ の交換子を直接計算します（$i^{-1} = -i, \; j^{-1} = -j$ に注意）：

    $$[i, j] = i j i^{-1} j^{-1} = (ij)(-i)(-j) = k(ij) = k \cdot k = k^2 = \mathbf{-1}$$

    よって **$-1 \in [2I, 2I]$** です。

5. 上の 3. と 4. を合わせると、$-g \in [2I, 2I]$ の場合でも $-1 \in [2I, 2I]$ を掛けることで $g = (-1)(-g) \in [2I, 2I]$ となるため、すべての $g \in 2I$ が $[2I, 2I]$ に属します。すなわち $[2I, 2I] = 2I$ が証明されました。（証明終）

（※1900年、ポアンカレは当初「ホモロジー群が $S^3$ と同じコンパクト3次元多様体は $S^3$ と位相同型か？」と予想しました。しかし4年後の1904年、まさにこの $P^3 = S^3 / 2I$ を反例として自ら発見し、「では、ホモロジー群ではなく**基本群 $\pi_1$ が自明（単連結）**ならば $S^3$ と位相同型か？」と予想を修正しました。これが、約100年後の2002〜2003年にグリゴリー・ペレルマンによって証明された**ポアンカレ予想**です。）

#### (3) 展望：なぜ4次元空間 $\mathbb{R}^4$ だけに「エキゾチック微分構造」が現れるのか？

本ノートの最後に、現代の4次元トポロジーが明らかにした象徴的な事実を展望として位置づけます。

> **【定理（エキゾチック $\mathbb{R}^4$ の存在：結果の紹介）】**
> ※この定理の厳密な証明には、マイケル・フリードマンによる位相的4次元多様体の分類定理（1982年）と、サイモン・ドナルドソンによるヤン・ミルズ方程式（ゲージ理論）を用いた滑らかな4次元多様体の障害定理（1983年）という現代数学の2大理論を要するため、本ノートでは正確な結果と幾何学的背景のみを紹介します。
>
> 1. **$n \neq 4$（$n = 1, 2, 3, 5, 6, 7, \dots$）のすべての次元：**
>     ユークリッド空間 $\mathbb{R}^n$ と位相同型（連続なゴムの変形として同じ）な滑らかな多様体は、すべて標準的な $\mathbb{R}^n$ と**微分同相（滑らかな座標系まで含めて完全に同じ）**である。すなわち、$\mathbb{R}^n$ の微分構造はただ1つしか存在しない。
>
> 2. **$n = 4$（4次元ユークリッド空間 $\mathbb{R}^4$）のみ：**
>     $\mathbb{R}^4$ と位相同型であるにもかかわらず、標準の $\mathbb{R}^4$ とは**決して微分同相にならない（滑らかな微積分を行う座標系の貼り方が本質的に互換性を持たない）空間**――すなわち**エキゾチック $\mathbb{R}^4$**――が、互いに微分同相でないものだけで**非可算無限個**存在する。

なぜ、1次元でも2次元でも3次元でもなく、5次元でも100次元でもなく、**ちょうど「4次元」だけ**にこのような特異な現象が起きるのでしょうか？ その幾何学的な理由は、前節（[6-2節](6-2.md)）で見た「次元の自由度と交差」の延長線上にあります。

* **低次元（$n \le 3$）：** 空間の自由度が小さすぎるため、位相構造（連続性）を決めると微分構造（滑らかさ）も剛直にただ1つに決まってしまう。
* **高次元（$n \ge 5$）：** 空間が十分広いため、多様体の内部で2次元円板同士が交差してしまっても、余剰次元を使って交差を綺麗に解消する「**ホイットニーのトリック**」が機能する（[6-2節](6-2.md)で4次元以上の空間なら1次元の結び目がすべてほどけたのと本質的に同じメカニズムです）。その結果、高次元の多様体は代数的な不変量によって見通しよく分類でき、$\mathbb{R}^n$ の微分構造も一意に定まる。
* **4次元（$n = 4$）：** 「$2$ 次元 $+ 2$ 次元 $= 4$ 次元」という臨界点にあたり、2次元円板同士の交わりが孤立点になって逃げ場がなく、**ホイットニーのトリックが破綻する唯一の次元**です。連続な位相のレベルでは無限回の操作（カッソン・ハンドル）で交差を押し出して $\mathbb{R}^4$ と同じ形にできても、滑らかな微分のレベルではそれが不可能になるため、「位相的には普通の $\mathbb{R}^4$ なのに、滑らかさの構造が無限通りに分裂する」という4次元固有の現象が起きるのです。

> **【コラム：私たちが住む宇宙の形は $T^3$ か、それともポアンカレ十二面体空間か？】**
>
> 一般相対性理論によれば、私たちの宇宙の空間部分（時間 $t$ を固定した3次元空間）は、必ずしも無限に広がる平坦な $\mathbb{R}^3$ である必要はなく、本節で構成した**3次元トーラス $T^3$**（曲率 $0$）や**ポアンカレ十二面体空間 $S^3 / 2I$**（正の曲率）のように、有限の体積を持ちながら端のない閉じた3次元多様体であっても物理法則とまったく矛盾しません。
>
> もし宇宙が有限の3次元多様体であれば、遠くの銀河から放たれた光が宇宙を何周もして別々の方向から地球に届くため、夜空の反対側に「同じ銀河の過去の姿」が見える可能性があります。また、宇宙最古の光である**宇宙マイクロ波背景放射（CMB）**の温度ゆらぎを全天にわたって精密観測すると、空間が閉じている場合には「宇宙のサイズより長い波長のゆらぎが存在できない（大角度スケールでの温度相関の抑制）」や「全天の反対側に同じ模様の円（マッチド・サークル）が現れる」といった特徴的なサインが刻まれます。
>
> 実際、2003年にWMAP衛星の初期観測データで大角度スケールの揺らぎが予想より小さいことが報告された際、ジャン＝ピエール・ルミネらの宇宙論研究グループが「宇宙の形はポアンカレ十二面体空間 $S^3 / 2I$ ではないか」という仮説をNature誌に発表して大きな話題になりました（その後のプランク衛星などのさらに精密な観測では、現在の観測可能な宇宙の範囲内でマッチド・サークルは見つかっておらず、宇宙は少なくとも観測可能範囲よりはるかに大きいか平坦に近いと考えられています）。それでも、本節で純粋数学として構成した $T^3$ や $S^3 / 2I$ は、現代宇宙論において「宇宙の大域トポロジー」を議論する際の標準モデルであり続けています。

### 4. 全7部の総括と続編への展望

これで、全7部（24節）にわたる「4次元以上を見るための幾何学とトポロジー」の旅が完了しました。私たちは[第0部](../index.md#part-0)の内積と直交変換から出発し、絵に描けない高次元空間を捉えるための5つの「目」を論理の繋がりを保ちながら組み上げました。

1. **射影の目（[第1部](../index.md#part-1)・[第2部](../index.md#part-2)）：** 透視投影・射影空間 $\mathbb{RP}^n$・シュレーゲル図で4次元立体を3次元へ映し、同時に次元を落とすことで生じる復元自由度・離散コホモロジー $H^1$・特異点（折り目・カスプ・ホイットニーの傘）・自己交差（クラインの壺・ボーイ曲面）の正体を突き止めた。
2. **断面の目（[第3部](../index.md#part-3)）：** 射影の重なりを回避し、モース理論の臨界点とヘッセ行列の指数によって、4次元超立方体の「正四面体 $\to$ 切頂四面体 $\to$ 正八面体」変身やクリフォード・トーラスの構造を断面から復元した。
3. **対称性の目（[第4部](../index.md#part-4)）：** オイラー公式と球面幾何から、鏡映群・コクセター図形・グラム行列の正定値性へと進み、正多胞体が3次元で5種、4次元で6種、5次元以上で3種に限られることを証明した。
4. **内部からの目（[第5部](../index.md#part-5)）：** 立体射影によって3次元球面 $S^3$ を私たちの3次元空間 $\mathbb{R}^3$ 全体へ展開し、回転空間 $\mathrm{SO}(3) \cong \mathbb{RP}^3$、四元数による2重被覆 $S^3 \times S^3 \to \mathrm{SO}(4)$、正24胞体・正600胞体の有限群構造、そしてホップ・ファイブレーションの入れ子トーラスと絡み合う円束を1つの風景に統合した。
5. **動的トポロジーと内在的視点の目（[第6部](../index.md#part-6)）：** 次元上昇による制約の解放（球面の裏返し・4次元での結び目解消）と、3次元多様体の貼り合わせ（$T^3$・ポアンカレホモロジー球面）、そして4次元空間 $\mathbb{R}^4$ だけの特異性（エキゾチック $\mathbb{R}^4$）を見渡した。

**【続編への展望：5次元から1000次元へ —— 超高次元ユークリッド空間の幾何】**
本ノートでは、4次元特有の豊かな幾何学とトポロジーを中心に探求しました。ここで視点をさらに **5次元・100次元・1000次元（$n \to \infty$）** へと押し広げると、[0-1節](../0/0-1.md)のコラム（超立方体の隙間の球が $n \ge 10$ で箱の外へはみ出す現象）で垣間見たように、空間の性質は再び大きく姿を変えます。

* $n$ 次元単位球の体積は $n = 5$ で最大になったあと、$n \to \infty$ で **$0$ に収束**する。
* 高次元球の体積のほぼすべてが「表面の極薄の皮」と「赤道付近」に集中する（**測度集中現象**）。
* 第1・2部では「次元を落とす射影は構造を壊す」ことを見たのに対し、超高次元ではランダムな低次元平面へ射影しても点間の距離がほぼそのまま保存される（**ジョンソン・リンデンシュトラウスの補題**）。

4次元幾何学で鍛えた内積・射影・球面の直感をそのまま足場にして、この「形が消えた先の超高次元空間」へ踏み込むのが、本ノートの続編のテーマとなります。

### 本ノートの締めくくり：最終理解度チェック

全7部で学んだ「群の作用」「正多胞体」「立体射影・$S^3$」「貼り合わせ」が1つに繋がったことを確かめる、最後の問いを置いておきます。

> **【最終確認の問い】**
>
> 本節では、正600胞体の120頂点（二項二十面体群 $2I \subset S^3$）で $S^3$ を割った商空間 $S^3 / 2I$ が「正十二面体の対面を $36^\circ$ ひねって貼り合わせた空間（ポアンカレホモロジー球面）」になることを見ました。
> では、同じ仕組みを[5-3節](../5/5-3.md)で扱ったもう1つの有名な部分群――**四元数群 $Q_8 = \{ \pm 1, \pm i, \pm j, \pm k \} \subset S^3$（位数 $8$、正16胞体の8頂点）**――に適用し、商空間 $S^3 / Q_8$ を作ります。
>
> 1. 正16胞体の極双対である**4次元超立方体（正8胞体）**の1個の胞は、3次元の何という立体でしょうか？（これが $S^3 / Q_8$ を作るための基本領域の多面体になります。）
> 2. $Q_8$ の交換子部分群 $[Q_8, Q_8]$ を求めてください（ヒント：本節の定理1の証明で $[i, j] = -1$ を計算しました。また、$Q_8$ の任意の2元の交換子は $+1$ か $-1$ のどちらかしかとりません）。
> 3. 上の 2. の結果から、商空間 $S^3 / Q_8$ の1次ホモロジー群 $H_1(S^3 / Q_8; \mathbb{Z}) \cong Q_8 / [Q_8, Q_8]$ の位数（元の個数）はいくつになるでしょうか？（※これが、立方体の対面を $90^\circ$ ひねって貼り合わせた「四元数空間」のホモロジー群であり、ポアンカレホモロジー球面と違って $H_1 \neq \{0\}$ になることが分かります。）
