### 前節（3-1）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **単位球面 $S^2 : x^2 + y^2 + z^2 = 1$ の高さ関数 $h(x, y, z) = z$ の臨界点：**
    水平な平面 $z = c$ が球面に接する点は、南極 $(0, 0, -1)$（**極小点 $1$ 個**）と北極 $(0, 0, +1)$（**極大点 $1$ 個**）の合計 $2$ 点のみです。鞍点は **$0$ 個** です。

2. **「極小点の個数 $-$ 鞍点の個数 $+$ 極大点の個数」の交代和：**

    * 単位球面 $S^2$：$1 - 0 + 1 = \mathbf{2} = \chi(S^2)$
    * 立てたトーラス $T^2$：$1 - 2 + 1 = \mathbf{0} = \chi(T^2)$

球面を少しへこませて「ハート型」や「ひょうたん型」に変形すると、山頂（極大点）が $2$ つに増えますが、その間には必ず峠（鞍点）が $1$ つ増えるため、交代和は $1 - 1 + 2 = 2$ とまったく変わりません。

このように、「断面を動かしたときに形が変わる瞬間（臨界点）の種類と個数を記録するだけで、元の空間全体のトポロジーを完全に復元できる」という強力な理論が、本節の主題である**モース理論（Morse theory）**です。

## 3-2. 断面の変化点から全体の形を復元する：モース理論

### 1. 動機（Why）：4次元図形の「輪切り」をどう読み解けば全体の形が分かるのか？

前節（[3-1節](3-1.md)）の正則値定理により、高さ $c$ が臨界値でない限り、断面 $h^{-1}(c)$ は滑らかな $(m-1)$ 次元多様体になることが分かりました。さらに、臨界値を1つもまたがない区間 $[a, b]$ の間では、断面 $h^{-1}(c)$ のトポロジー（繋がり方）は一切変化しません。

つまり、空間 $M$ 全体の形（トポロジー）を決定している情報は、**すべて「臨界点を通過する瞬間」だけに凝縮されている**ことになります。

**理由①：高次元空間では「極小・鞍点・極大」以外にも多様な変化点が現れるから**
2次元曲面では、臨界点は「極小（下に凸）」「鞍点（1方向が下に凸・1方向が上に凸）」「極大（上に凸）」の3種類しかありません。しかし、次節（[3-3節](3-3.md)）で扱う3次元球面 $S^3$ や4次元空間内の3次元多様体では、「3方向のうち何方向が下向きに曲がっているか」によって、指数 $0, 1, 2, 3$ の **4種類** の臨界点が現れます。これらを統一的に分類する物差しが**ヘッセ行列**と**モース指数（Morse index）**です。

**理由②：座標系（地図）をどう取り替えても変わらない不変量として臨界点を分類できるから**
曲がった空間（多様体）の上では局所座標の選び方が無数にあります。ある座標系で計算した2階微分（ヘッセ行列）の固有値そのものは座標変換で変わってしまいますが、**「負の固有値の個数（モース指数）」だけは座標系の選び方に一切依存しない不変量**になります（シルベスターの慣性法則）。これにより、空間固有の性質として断面の変化を厳密に分類できます。

### 2. 具体例と幾何学的イメージ（Toy Model）

#### 実験A：2次元曲面の3種類の臨界点と「ハンドル（部品）の取り付け」

高さ関数 $h: M \to \mathbb{R}$ に対して、「高さ $c$ 以下にある空間の部分（劣位集合 / Sublevel set）」を

$$M^{\le c} := \{ \mathbf{p} \in M \mid h(\mathbf{p}) \le c \}$$

と書きます（立体を水槽に沈めたとき、水面 $z = c$ より下に沈んでいる部分全体です）。
2次元曲面を水面 $c$ の下から上へ少しずつ沈めていくとき、3種類の臨界点を通過する前後で $M^{\le c}$ の形がどう変化するかを観察します。

1. **指数 $\lambda = 0$（極小点）：** 局所的に $h(u, v) = c_0 + u^2 + v^2$（お椀の底）。

    * $c < c_0$：空集合 $\emptyset$。
    * $c > c_0$：$u^2 + v^2 \le \varepsilon$ という**2次元円板 $D^2$（0-ハンドル）**が新しく1個誕生する。

2. **指数 $\lambda = 1$（鞍点）：** 局所的に $h(u, v) = c_0 - u^2 + v^2$（馬の鞍・峠）。

    * $c < c_0$：$v^2 - u^2 \le -\varepsilon \iff u^2 - v^2 \ge \varepsilon$。左右に離れた2つの領域（断面は双曲線）。
    * $c > c_0$：$v^2 - u^2 \le +\varepsilon$。左右の領域が中央の細い帯（幅のある橋）で繋がる。すなわち、既存の空間に**1本の帯（1-ハンドル $D^1 \times D^1$）**が貼り付けられる。

3. **指数 $\lambda = 2$（極大点）：** 局所的に $h(u, v) = c_0 - u^2 - v^2$（山の頂上・ドームの天井）。

    * $c < c_0$：$u^2 + v^2 \ge \varepsilon$。中央に丸い穴が開いた状態。
    * $c > c_0$：その丸い穴に**円板の蓋（2-ハンドル $D^2$）**がかぶせられて閉じる。

これを立てたトーラス $T^2$（極小1・鞍点2・極大1）に当てはめると、トーラス全体が次の4ステップの工作だけで完全に組み上がります。

$$\text{①円板(底)が誕生} \;\xrightarrow{\text{1個目の鞍点}}\; \text{②帯を貼って円筒(U字管)に} \;\xrightarrow{\text{2個目の鞍点}}\; \text{③もう1本帯を貼って穴あきトーラスに} \;\xrightarrow{\text{極大点}}\; \text{④蓋をしてトーラス完成}$$

#### 実験B：穴が $g$ 個の曲面（種数 $g$ の閉曲面）のオイラー標数

穴が $g$ 個縦に並んだ浮き輪（種数 $g$ の閉曲面 $\Sigma_g$）をまっすぐ立てて、高さ関数 $h(x, y, z) = z$ の臨界点を数えてみましょう。

* 一番下の底に **極小点（指数 $0$）が $1$ 個**。
* $g$ 個の穴それぞれについて、「穴の下縁」と「穴の上縁」に1個ずつ、合計 **$2g$ 個の鞍点（指数 $1$）**。
* 一番上の頂上に **極大点（指数 $2$）が $1$ 個**。

したがって、臨界点の交代和を計算すると

$$c_0 - c_1 + c_2 = 1 - 2g + 1 = 2 - 2g$$

となり、種数 $g$ の閉曲面のオイラー標数 $\chi(\Sigma_g) = 2 - 2g$ が直接復元されます。

### 3. 厳密な定義と定理（What）：ヘッセ行列・モース指数の不変性・モース理論の基本定理

ここからは、臨界点の2階微分（ヘッセ行列）とモース指数を任意の次元 $m$ で厳密に定義し、**モース指数が座標変換によらないこと**を証明した上で、モース理論の基本定理の骨格と証明範囲の線引きを明確にします。

#### (1) ヘッセ行列・非退化臨界点・モース指数

$m$ 次元の滑らかな多様体 $M$ 上の滑らかな関数 $f: M \to \mathbb{R}$ と、その臨界点 $p \in M$（すなわちある局所座標 $x = (x_1, \dots, x_m)$ において $\frac{\partial f}{\partial x_i}(p) = 0, \; \forall i$ となる点）を考えます。

点 $p$ における $f$ の2階偏導関数を並べた $m \times m$ 実対称行列

$$H_f(p) := \left( \frac{\partial^2 f}{\partial x_i \partial x_j}(p) \right)_{1 \le i, j \le m}$$

を点 $p$ における $f$ の**ヘッセ行列（Hessian matrix）**と呼びます（$f$ が $C^2$ 級以上なのでシュワルツの定理より $\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}$ が成り立ち、必ず対称行列になります）。

実対称行列の固有値はすべて実数です。ここで次を定義します。

* **非退化臨界点（Non-degenerate critical point）：** $\det H_f(p) \neq 0$（すなわち固有値 $0$ を持たない）である臨界点 $p$。
* **モース関数（Morse function）：** すべての臨界点が非退化であるような滑らかな関数 $f: M \to \mathbb{R}$。
* **モース指数（Morse index）$\lambda(p)$：** 非退化臨界点 $p$ におけるヘッセ行列 $H_f(p)$ の**負の固有値の個数**（重複度も込めて数える。$0 \le \lambda(p) \le m$）。

（※退化臨界点の反例：1変数関数 $f(x) = x^3$ の原点 $x = 0$ は $f'(0) = 0$ ですが $f''(0) = 0$ なので退化臨界点です。また、トーラスを縦に立てず**横に寝かせて**置くと、底面全体が1本の円周まるごと極小点［$H_f$ のランクが $1$ で固有値 $0$ を持つ］になり、モース関数になりません。空間をほんのわずか傾けるだけで、すべての臨界点が孤立した非退化臨界点＝モース関数に変わります。）

#### (2) モース指数が座標系の選び方に依存しないことの証明

ヘッセ行列の成分や固有値そのものは、局所座標 $(x_1, \dots, x_m)$ を別の座標 $(y_1, \dots, y_m)$ に取り替えると変化してしまいます。にもかかわらず、**「非退化性」と「モース指数（負の固有値の個数）」だけは座標系に一切依存しない**ことを厳密に証明します。

> **【定理1：臨界点におけるヘッセ行列の変換則とモース指数の不変性】**
> $p \in M$ を関数 $f: M \to \mathbb{R}$ の臨界点とする。$p$ の周りの2つの局所座標系 $x = (x_1, \dots, x_m)$ と $y = (y_1, \dots, y_m)$ について、それぞれの座標でのヘッセ行列を $H_x, H_y$ とし、座標変換のヤコビ行列を $J := \left(\frac{\partial x_k}{\partial y_i}(p)\right)$（正則行列）とおく。このとき、
>
> $$H_y = J^T H_x J$$
>
> が成り立つ。したがって、**$\det H_f(p) \neq 0$（非退化性）および負の固有値の個数 $\lambda(p)$（モース指数）は、局所座標の選び方に一切依存しない**。

**【証明】**

1. **変換則 $H_y = J^T H_x J$ の導出：**
    連鎖律より、1階偏微分は $\frac{\partial f}{\partial y_i} = \sum_{k=1}^m \frac{\partial f}{\partial x_k} \frac{\partial x_k}{\partial y_i}$ です。これをさらに $y_j$ で偏微分すると、積の微分法と連鎖律から

    $$\frac{\partial^2 f}{\partial y_j \partial y_i} = \sum_{k=1}^m \sum_{l=1}^m \frac{\partial^2 f}{\partial x_l \partial x_k} \frac{\partial x_l}{\partial y_j} \frac{\partial x_k}{\partial y_i} + \sum_{k=1}^m \frac{\partial f}{\partial x_k} \frac{\partial^2 x_k}{\partial y_j \partial y_i}$$

    となります。ここで、**点 $p$ が臨界点であること（$\frac{\partial f}{\partial x_k}(p) = 0, \; \forall k$）**が決定的な役割を果たします。右辺第2項がすべて $0$ になって消えるため、点 $p$ では

    $$\frac{\partial^2 f}{\partial y_j \partial y_i}(p) = \sum_{k, l = 1}^m \left(\frac{\partial x_k}{\partial y_i}(p)\right) \frac{\partial^2 f}{\partial x_k \partial x_l}(p) \left(\frac{\partial x_l}{\partial y_j}(p)\right) = (J^T H_x J)_{ij}$$

    すなわち $H_y = J^T H_x J$ が成り立ちます。（※臨界点でない一般の点では第2項が残るため、ヘッセ行列はこのような綺麗な変換則に従いません。）

2. **非退化性の不変性：**
    $J$ は座標変換のヤコビ行列なので $\det J \neq 0$ です。よって $\det H_y = (\det J)^2 \det H_x$ となり、$\det H_y \neq 0 \iff \det H_x \neq 0$ です。

3. **モース指数の不変性（シルベスターの慣性法則の直接証明）：**
    $H_x$ の負の固有値の個数を $\lambda_x$、$H_y$ の負の固有値の個数を $\lambda_y$ とします。
    $H_x$ は実対称行列なので直交行列で対角化でき、負の固有値に対応する固有ベクトルたちが張る $\lambda_x$ 次元部分空間 $V^- \subset \mathbb{R}^m$ と、正の固有値に対応する $(m - \lambda_x)$ 次元部分空間 $V^+ \subset \mathbb{R}^m$ に直和分解されます。このとき、任意の非ゼロベクトル $\mathbf{v} \in V^- \setminus \{\mathbf{0}\}$ に対し $\mathbf{v}^T H_x \mathbf{v} < 0$、任意の非ゼロベクトル $\mathbf{v} \in V^+ \setminus \{\mathbf{0}\}$ に対し $\mathbf{v}^T H_x \mathbf{v} > 0$ です。
    同様に、$H_y$ の正の固有値に対応する $(m - \lambda_y)$ 次元部分空間を $W^+ \subset \mathbb{R}^m$ とおきます。任意の $\mathbf{w} \in W^+ \setminus \{\mathbf{0}\}$ に対し、$(J\mathbf{w})^T H_x (J\mathbf{w}) = \mathbf{w}^T (J^T H_x J)\mathbf{w} = \mathbf{w}^T H_y \mathbf{w} > 0$ です。
    したがって、2つの部分空間 $V^-$ と $J(W^+)$ はゼロベクトル $\mathbf{0}$ 以外を共有できません（$V^- \cap J(W^+) = \{\mathbf{0}\}$）。なぜなら、もし非ゼロベクトル $\mathbf{v} = J\mathbf{w}$ が両方に属すると $\mathbf{v}^T H_x \mathbf{v} < 0$ かつ $> 0$ となり矛盾するためです。
    $J$ は正則なので $\dim J(W^+) = \dim W^+ = m - \lambda_y$ です。よって次元の和は全体空間の次元 $m$ を超えられず、

    $$\dim V^- + \dim J(W^+) = \lambda_x + (m - \lambda_y) \le m \implies \lambda_x \le \lambda_y$$

    が得られます。座標 $x$ と $y$ の役割を逆にして同じ議論を行えば $\lambda_y \le \lambda_x$ も得られるため、$\lambda_x = \lambda_y$ が証明されました。（証明終）

#### (3) モースの補題とモース理論の基本定理

非退化臨界点の周りでは、どんなに複雑な滑らかな関数であっても、うまく局所座標を取り替えれば「2次式の和と差だけ」という極めて単純な標準形に直せます。

> **【定理2（モースの補題 / Morse Lemma）】**
> $p \in M$ を滑らかな関数 $f: M \to \mathbb{R}$ のモース指数 $\lambda$ の非退化臨界点とする。このとき、点 $p$ の周りの局所座標 $(u_1, \dots, u_m)$（点 $p$ が原点 $\mathbf{0}$ に対応する）が存在して、その近傍において $f$ は厳密に次の2次多項式で表される：
>
> $$f(u_1, \dots, u_m) = f(p) - u_1^2 - \dots - u_\lambda^2 + u_{\lambda+1}^2 + \dots + u_m^2$$
>
> 特に、**非退化臨界点は必ず孤立している**（十分小さな近傍の中に他の臨界点は1つも存在しない）。

（※証明の骨格：テイラーの定理の積分剰余形を用いて $f(x) - f(p) = \sum_{i,j} x_i x_j h_{ij}(x)$ と滑らかな対称行列関数 $h_{ij}(x)$［ただし $h_{ij}(0) = \frac{1}{2}\frac{\partial^2 f}{\partial x_i \partial x_j}(p)$］で書き、2次形式の平方完成アルゴリズムを座標の滑らかな変数変換として順に実行することで構成的に証明できます。また、標準形の偏微分は $\frac{\partial f}{\partial u_i} = \pm 2u_i$ なので、近傍内で勾配がゼロになるのは原点 $\mathbf{0}$ のみであり、孤立性が直ちに従います。）

このモースの補題を土台として、劣位集合 $M^{\le c} = \{ \mathbf{p} \in M \mid f(\mathbf{p}) \le c \}$ のトポロジーが高さ $c$ とともにどう変化するかを記述するのが、モース理論の2つの基本定理です。

> **【定理3（モース理論の基本定理とオイラー標数の復元：結果と骨格の紹介）】**
> ※以下の1.・2.の証明には、多様体上のリーマン計量を用いた勾配ベクトル場 $-\nabla f$ の微分方程式（勾配流）による連続変形の構成を要するため、ここでは正確な主張と幾何学的意味のみを提示します。
>
> コンパクトな $m$ 次元多様体 $M$ 上のモース関数 $f: M \to \mathbb{R}$ について、次が成り立つ。
>
> 1. **臨界値のない区間では形が変わらない：** 閉区間 $[a, b]$ に $f$ の臨界値が1つも含まれないならば、$M^{\le a}$ と $M^{\le b}$ は微分同相（同じ形）であり、特に断面 $f^{-1}(a)$ と $f^{-1}(b)$ も微分同相である。
> 2. **臨界点を通過すると $\lambda$-セル（$\lambda$-ハンドル）が1個貼り付く：** 区間 $[c - \varepsilon, c + \varepsilon]$ 内に唯一の臨界値 $c$ があり、その上にモース指数 $\lambda$ の臨界点がただ1つあるならば、$M^{\le c + \varepsilon}$ は位相的（ホモトピー同値の意味）に、$M^{\le c - \varepsilon}$ へ **$\lambda$ 次元の円板 $D^\lambda$（$\lambda$-セル）をその境界 $S^{\lambda-1}$ に沿って1個貼り付けた空間**に等しい。
> 3. **【系：オイラー標数の復元公式】** モース指数 $\lambda$ の臨界点の個数を $c_\lambda$ とおく（コンパクト性＋非退化臨界点の孤立性より、臨界点の総数は必ず有限個になる）。このとき、多様体 $M$ のオイラー標数 $\chi(M)$ は、**モース関数 $f$ の選び方（どの方向から輪切りにするか）に一切よらず**、次の交代和で与えられる：
>
>     $$\chi(M) = \sum_{\lambda = 0}^{m} (-1)^\lambda c_\lambda = c_0 - c_1 + c_2 - \dots + (-1)^m c_m$$

（※なぜ 2. から 3. の交代和公式が出るのか？ 多面体のオイラー標数が「（0次元頂点の数）$-$（1次元辺の数）$+$（2次元面の数）$-\dots$」であったのとまったく同じ理由で、$\lambda$ 次元のセル $D^\lambda$ を1個貼り付けるたびに空間のオイラー標数がちょうど $(-1)^\lambda$ だけ変化するため、底から頂上まで足し合わせると $\sum_{\lambda=0}^m (-1)^\lambda c_\lambda$ になるのです。）

> **【コラム：地形図の「山頂 $-$ 峠 $+$ 窪地 $=$ 2」—— 惑星全体の形を登山道から知る】**
>
> 地球のような球面 $S^2$ の形をした惑星の表面の標高（海抜高度）を、滑らかなモース関数 $h: S^2 \to \mathbb{R}$ とみなしましょう。
>
> * 指数 $0$ の臨界点（$c_0$）：**窪地・湖の底**（周囲がすべて自分より高い点）
> * 指数 $1$ の臨界点（$c_1$）：**峠・鞍部**（尾根道方向には極小、谷方向には極大の点）
> * 指数 $2$ の臨界点（$c_2$）：**山頂**（周囲がすべて自分より低い点）
>
> 定理3の系より、どんなに複雑な山脈や火口やカルデラ湖が地球上に存在していても、地球全体で数え上げれば必ず
>
> $$(\text{窪地の数}) - (\text{峠の数}) + (\text{山頂の数}) = \chi(S^2) = \mathbf{2}$$
>
> が厳密に成り立ちます（たとえば最も単純な「山頂1・窪地1・峠0」なら $1 - 0 + 1 = 2$。そこに新しい山を1つ隆起させると、元の山との間に必ず峠が1つ生まれるため $c_2$ と $c_1$ が同時に $+1$ されて差が保たれます）。
>
> もし宇宙探査機が未知の惑星の地形図を隅々までスキャンし、窪地・峠・山頂の数を数えたところ、$c_0 - c_1 + c_2 = 0$ という結果が出たとしたら、宇宙から惑星全体を外観撮影しなくても、**「この惑星は球体ではなくドーナツ型（トーラス $T^2$）をしている」**と数学的に断言できるのです。これが、外から全体を見ることができない4次元図形を「内部の関数の臨界点」だけで特定するモース理論の威力です。

### 4. 翻訳と展望（Bridge）：本節の理論がこれからの各部にどう直結するか

1. **次節（[3-3節](3-3.md)：3D空間で4D立体を切る）：**
    次節では、いよいよ舞台を4次元空間 $\mathbb{R}^4$ へ上げます。3次元球面 $S^3$（指数 $0$ が1個・指数 $3$ が1個で $\chi(S^3) = 1 - 0 + 0 - 1 = 0$）、4次元超立方体 $C_4$、そして[0-3節](../0/0-3.md)のコラムで登場した平坦なトーラス（クリフォード・トーラス $T^2 \subset S^3 \subset \mathbb{R}^4$）の3次元断面アニメーションを、本節の臨界点解析を使って完全に解読します。

2. **[第4部](../index.md#part-4)（[4-1節](../4/4-1.md)：オイラーの多面体公式 $V - E + F = 2$）：**
    本節のオイラー標数 $\chi = \sum (-1)^\lambda c_\lambda$ は、多面体の頂点・辺・面の交代和 $V - E + F$ と同じ位相不変量です。[第4部](../index.md#part-4)ではこれが3次元正多面体5種の分類証明の出発点になります。

3. **[第6部](../index.md#part-6)（[6-3節](../6/6-3.md)：3次元多様体と4次元多様体）：**
    定理3の「$\lambda$-ハンドルを貼り付けて多様体を作る（ハンドル分解）」という視点は、高次元多様体（特に3次元・4次元多様体）を分類・構成する現代トポロジーの標準手法そのものです。

### 理解度チェック（次節へ進む前の確認）

次節（[3-3節](3-3.md)：3D空間で4D立体を切る）の準備として、3次元球面 $S^3 \subset \mathbb{R}^4$ の高さ関数の臨界点と断面を計算してみましょう。

> **【確認の問い】**
>
> 4次元空間 $\mathbb{R}^4$ 内の単位3次元球面 $S^3 = \{ (x, y, z, w) \in \mathbb{R}^4 \mid x^2 + y^2 + z^2 + w^2 = 1 \}$ を、3次元超平面 $w = c$（$-1 \le c \le 1$）で輪切りにします。
>
> 1. $-1 < c < 1$ のとき、3次元空間 $(x, y, z)$ の中に現れる断面 $S^3 \cap \{w = c\}$ は、どのような3次元図形（半径いくつの何という図形）になるでしょうか？
> 2. 南極 $S = (0, 0, 0, -1)$ の近くでは、$(x, y, z)$ を局所座標として高さ関数 $h(x, y, z) = w = -\sqrt{1 - (x^2 + y^2 + z^2)}$ と表せます。$\sqrt{1 - t} = 1 - \frac{1}{2}t + O(t^2)$ を使って $h(x, y, z)$ を原点 $(0, 0, 0)$ の周りで2次近似し、南極 $S$ における $3 \times 3$ ヘッセ行列とモース指数 $\lambda(S)$ を求めてください。
> 3. 同様に北極 $N = (0, 0, 0, +1)$ でのモース指数 $\lambda(N)$ を求め、定理3の系より3次元球面 $S^3$ のオイラー標数 $\chi(S^3)$ を計算してください。
