# 飯高次元・飯高予想に至る体系的カリキュラム（全7部）

## このノートは何を目指すのか

「複雑な形をした高次元の図形（多項式の方程式で定まる空間＝**代数多様体**）を、本質的な複雑さによってどう分類できるか」という問題に対し、現代の代数幾何学が与えた回答が**小平次元**と**飯高理論**です。

たとえば、複素1次元（実2次元の閉曲面）の図形は、穴の数（種数 $g$）によって次の3種類に分類されます。

* **穴がない（$g = 0$、球面）：** 正の曲率を持ち、最も単純な空間
* **穴が1つ（$g = 1$、トーラス／楕円曲線）：** 平坦な空間
* **穴が2つ以上（$g \ge 2$）：** 負の曲率を持つ複雑な空間

しかし、次元が2、3、4…と高くなると、「穴の数」のような単純な数値だけでは図形を分類できなくなります。そこで、**「空間の上に乗る特別な微分形式（標準束）の『増え方』を測る」**ことで、任意の次元の空間を分類する物差しとして導入されたのが**飯高次元**および**小平次元**です。そして、「空間を低い次元の空間（底空間）と切り口（ファイバー）に分解したとき、全体の複雑さは部品の複雑さの和以上になる」と主張するのが**飯高予想**です。

本ノートは、学部1・2年レベルの線形代数と微積分（第0部）から出発し、論理の飛躍を極力排して、飯高次元・飯高予想の定式化と背景理論（第6部）までを1本の線で繋ぐことを目的としています。

> **最終目標（厳密な定義のプレビュー）**
>
> ※ここでは記号だけを示します。第0部〜第5部を通じて、以下のすべての記号の意味と存在理由を1つずつ構成します。
>
> 滑らかな射影代数多様体 $X$ とその上の因子 $D$ に対し、$m$ 倍の因子 $mD$ に付随する直線束の大域切断の空間を $H^0(X, \mathcal{O}_X(mD))$、その次元を $h^0(X, \mathcal{O}_X(mD)) := \dim_{\mathbb{C}} H^0(X, \mathcal{O}_X(mD))$ と書く。
>
> 1. **飯高次元 $\kappa(X, D)$：**
>     $N(X, D) := \{ m \in \mathbb{Z}_{>0} \mid h^0(X, \mathcal{O}_X(mD)) > 0 \}$ とおく（空集合のときは $\kappa(X, D) := -\infty$）。$N(X, D) \neq \emptyset$ のとき、以下の3つの値は一致し、これを $\kappa(X, D)$ と定義する（値は $-\infty, 0, 1, \dots, \dim X$）。
>
>     * **幾何学的視点：** 基底が定める射影空間への有理写像 $\Phi_{\vert mD \vert}: X \dashrightarrow \mathbb{P}^N$ の像の次元の最大値
>     * **解析的・組合せ的視点：** $m$ を大きくしたときの次元 $h^0(X, \mathcal{O}_X(mD)) \sim c \cdot m^\kappa$ の多項式増大度 $\kappa$
>     * **代数的視点：** 切断環 $R(X, D) := \bigoplus_{m \ge 0} H^0(X, \mathcal{O}_X(mD))$ の商体の超越次数から $1$ を引いた値
>
> 2. **小平次元 $\kappa(X)$：**
>     多様体 $X$ の最高次微分形式の束である標準束 $\omega_X$（標準因子 $K_X$）に対する飯高次元 $\kappa(X) := \kappa(X, K_X)$。双有理同値で不変な基本分類指標となる。
>
> 3. **飯高予想（$C_{n, m}$ 予想）：**
>     滑らかな射影多様体の間の全射な射（代数ファイバー空間）$f: X \to Y$（$\dim X = n, \dim Y = m$）と一般ファイバー $F = f^{-1}(y)$ に対し、次の加法性不等式が成り立つという予想：
>
>     $$\kappa(X) \ge \kappa(Y) + \kappa(F)$$

## 全体の見取り図（第0部〜第6部の繋がり）

このカリキュラムは、**「代数の言語」**と**「幾何の言語」**を別々に鍛えたあと、1次元で実験し、高次元で統合する構造になっています。

```text
【第0部】線形代数・微積分の再構築（商空間・双対・線形近似という共通OSの整備）
    ├──→【第1部】代数学の基礎（方程式を「環・イデアル・超越次数」で扱う）
    └──→【第2部】位相空間と多様体（曲がった空間を「地図帳・微分形式・射影空間」で扱う）
              │
              ▼
        【第3部】複素解析とリーマン面（1次元多様体での完全実験：因子とリーマン・ロッホの定理）
              │
              ▼
        【第4部】代数幾何学の基礎（第1部の代数と第2・3部の幾何を一般次元で統合する）
              │
              ▼
        【第5部】層・直線束・コホモロジー（局所と大域のギャップを測る現代の標準言語）
              │
              ▼
        【第6部】飯高次元・飯高ファイブレーション・飯高予想（すべての道具を統合した分類理論）

```

## 各部の構成と目次

### 第0部：線形代数と微積分の再構築（共通の土台）

* **立ち位置：** 既習の計算手続きを「空間と写像の構造」として捉え直す準備パート。ここで扱う「割って同一視する（商）」「関数側を見る（双対）」「局所的に線形近似する（ヤコビ行列）」の3つは、第1部以降のあらゆる場面で形を変えて再登場します。
* **[0-1. 線形代数の本質](0/0-1.md)**
    行列計算から「ベクトル空間と線形写像」へ視点を移し、核・像・次元定理を空間の潰れ具合として理解する。

* **[0-2. 商空間（Quotient space）](0/0-2.md)**
    「部分空間のズレを無視して同一視する」操作。第1部の剰余環、第2部の射影空間、第5部のコホモロジーすべての原型。

* **[0-3. 双対空間（Dual space）](0/0-3.md)**
    点やベクトルそのものではなく「値を返す関数（測定器）」の空間を考える視点。第2部の微分形式や引き戻し操作の土台。

* **[0-4. 多変数微積分の本質](0/0-4.md)**
    ヤコビ行列と陰関数定理。「曲がった図形を局所的に平坦な空間（接空間）で近似する」仕組みであり、第2部の多様体と第4部の特異点判定に直結する。

### 第1部：代数学の基礎（図形を記述するための「式」の言語）

* **立ち位置：** 多項式の方程式が定める図形を、純粋に数式（可換環）の操作だけで扱うための言語を整備します。ここで作る「イデアル・剰余環・超越次数」は、第4部で幾何学の辞書へとそのまま翻訳されます。
* **[1-1. 群・環・体の基礎](1/1-1.md)**
    四則演算のルールを抽象化した代数構造。割り算ができない環（整域）から分数（商体＝有理関数体）を作る操作を押さえる。

* **[1-2. 多項式環とイデアル](1/1-2.md)**
    連立代数方程式の「式の選び方の違い」を吸収し、方程式系を1つの集合（イデアル）として一括処理する仕組み。

* **[1-3. 剰余環（商環 $R/I$）と準同型定理](1/1-3.md)**
    「方程式 $f = 0$ が成り立つ図形の上の関数環（座標環）」や有限体を、割り算（商環）によって構成する手法。

* **[1-4. 素イデアルと極大イデアル](1/1-4.md)**
    図形が分裂しないこと（既約性）を「素イデアル」、空間の1点を「極大イデアル」として代数的に特定する対応関係。

* **[1-5. 体の拡大と超越次数](1/1-5.md)**
    図形の「次元」を、絵や微積分に頼らず「関数体に含まれる代数的独立な変数の個数（超越次数）」で定義する手法。飯高次元の第3の定義に直結する。

---

### 第2部：位相空間と多様体（曲がった空間と積分要素の定義）

* **立ち位置：** 距離（定規）に依存せず「曲がった空間」と「その上の微分」を厳密に定義します。ここで登場する「最高次微分形式」が小平次元の主役である標準束の正体であり、「射影空間」が代数幾何学の舞台になります。
* **[2-1. 距離空間から位相空間へ](2/2-1.md)**
    距離を捨てて「開集合」だけで連続性や空間の閉じ具合（コンパクト性）を定義する。コンパクト性は「大域的な関数の次元が有限になる」根拠となる。

* **[2-2. 多様体の定義と局所座標系](2/2-2.md)**
    外側の空間を仮定せず、局所的な地図（チャート）を滑らかに貼り合わせて空間を定義する（アトラス）。

* **[2-3. 接空間とベクトル場](2/2-3.md)**
    曲がった空間の上で接ベクトルを「方向微分演算子」として定義する。第1部の極大イデアルの商 $\mathfrak{m}/\mathfrak{m}^2$ とも結びつく。

* **[2-4. 微分形式と外積代数](2/2-4.md)**
    座標変換でヤコビ行列式が自然に現れる外積（$dx \wedge dy$）の仕組み。最高次微分形式の変換則が、後の**標準束 $\omega_X$** そのものになる。

* **[2-5. 射影空間 $\mathbb{P}^n$ の構成](2/2-5.md)**
    商空間の応用として無限遠点を付け加え、空間をコンパクト化する。斉次座標系と、飯高次元で使う射影空間への写像の行き先を定義する。

---

### 第3部：複素解析とリーマン面（1次元多様体での先行実験）

* **立ち位置：** 高次元へ進む前に、最も見通しの良い「複素1次元（曲線）」の世界で、飯高理論のすべての構成要素（正則関数・極・種数・因子・標準因子・小平次元）を手計算レベルで完全に体験します。
* **[3-1. 1変数複素関数と正則性](3/3-1.md)**
    実微分よりはるかに強い複素微分（コーシー・リーマン関係式）。最大値原理により「コンパクト空間上の正則関数は定数しかない」ことが導かれ、直線束や有理型関数が必要な理由が確定する。

* **[3-2. 有理型関数（零点と極）](3/3-2.md)**
    有限次の発散（極）を許す関数と留数定理。コンパクト空間上では「零点の総数＝極の総数」という保存則が成り立つ。

* **[3-3. コンパクト・リーマン面と種数 $g$](3/3-3.md)**
    1次元複素多様体の位相的分類（$g = 0, 1, \ge 2$）とオイラー標数 $\chi = 2 - 2g$。この3分類がそのまま1次元の小平次元（$-\infty, 0, 1$）に対応する。

* **[3-4. 因子（Divisor）と線形系](3/3-4.md)**
    各点での極・零点の許容ルールを整数和（因子 $D$）で表し、条件を満たす関数の有限次元空間 $L(D)$ と射影空間への写像 $\Phi_{\vert D \vert}$ を構成する。

* **[3-5. リーマン・ロッホの定理](3/3-5.md)**
    関数の空間の次元 $\ell(D)$ を、因子の次数と空間の種数 $g$ から計算する基本等式。1次元曲線における小平次元がここで完全に決定される。

### 第4部：代数幾何学の基礎（式と図形の統合・高次元化）

* **立ち位置：** 第1部の代数と第2・3部の幾何を一般の $n$ 次元で統合します。高次元では「同型」よりも緩やかな分類基準である「双有理同値」と、特異点の扱い（ブローアップ・特異点解消）が決定的な役割を果たします。
* **[4-1. アフィン代数多様体とヒルベルトの零点定理](4/4-1.md)**
    代数閉体上で「根基イデアル（式）」と「代数的集合（図形）」が1対1に対応することの証明。代数と幾何の辞書が完成する。

* **[4-2. ザリスキ位相](4/4-2.md)**
    多項式の零点集合を閉集合と定める位相。ハウスドルフ性を持たない代わりに、「空でない開集合はほとんど全体を占める（稠密）」という性質が有理写像や一般ファイバーの定義を支える。

* **[4-3. 射影代数多様体とベズーの定理](4/4-3.md)**
    斉次多項式による射影空間内の多様体と、例外なく交点数が積 $de$ に一致するベズーの定理。高次元における交点理論の原型。

* **[4-4. 射・有理写像・双有理同値](4/4-4.md)**
    一部の例外集合を除いて同型となる「双有理同値（有理関数体の同型）」と、1点を射影空間に膨らませるブローアップ。小平次元が双有理不変量であることの仕組みを見る。

* **[4-5. 特異点と非特異性](4/4-5.md)**
    ザリスキ接空間とヤコビ判定法による滑らかさの代数的定義、および任意の特異点をブローアップで滑らかに直せることを保証する**広中の特異点解消定理**。

### 第5部：層・直線束・コホモロジー（高次元を扱う現代の標準言語）

* **立ち位置：** 第3部で1次元曲線の上に作った「因子 $D$ と空間 $L(D)$」を、任意の次元 $n$ の多様体へ拡張し、局所的なデータを大域へ貼り合わせる際の「障害」を定量化します。ここで飯高次元の定義式に現れるすべての記号が完成します。
* **[5-1. 層と前層の概念](5/5-1.md)**
    空間の各開集合にデータ（関数や微分形式）を割り当て、整合的に貼り合わせる仕組み。局所的には解けても大域的には解けないギャップの存在を確認する。

* **[5-2. ベクトル束と直線束](5/5-2.md)**
    空間の各点に1次元ベクトル空間をねじって貼り付けた構造。非特異多様体上で「因子 $D$」と「直線束 $\mathcal{O}_X(D)$」が1対1に対応し、最高次微分形式の束である**標準束 $\omega_X = \mathcal{O}_X(K_X)$** が統一的に定式化される。

* **[5-3. 層のコホモロジー群 $H^i(X, \mathcal{F})$](5/5-3.md)**
    貼り合わせの障害を測るベクトル空間。長完全列、有限性定理、セール双対性（リーマン・ロッホの定理の背景）、および部分多様体から全体へ切断を延長するための鍵となる**小平消滅定理**を押さえる。

### 第6部：飯高次元・飯高ファイブレーション・飯高予想（本論）

* **立ち位置：** 第0部〜第5部のすべての道具を統合し、高次元代数多様体の分類理論と飯高予想の核心を扱います。
* **[6-1. 飯高次元 $\kappa(X, D)$ の厳密な定義と基本性質](6/6-1.md)**
    多重線形系 $\vert mD \vert$ が定める有理写像 $\Phi_{\vert mD \vert}$、次元の多項式増大度、切断環の超越次数という3つの定義の同値性と基本性質。

* **[6-2. 小平次元 $\kappa(X)$ による多様体の分類](6/6-2.md)**
    標準因子 $K_X$ の飯高次元としての小平次元。$\kappa(X) = -\infty, 0, \text{中間}, \dim X$ の4クラスの幾何学的特徴、具体例、および双有理不変性の確認。

* **[6-3. 飯高ファイブレーションの定理](6/6-3.md)**
    中間的な小平次元（$0 < \kappa(X) < \dim X$）を持つ多様体が、双有理変換を経て「一般ファイバーの小平次元が $0$ になる標準的なファイバー空間」へ分解されることの意味と構成の骨格。

* **[6-4. 飯高予想（$C_{n, m}$ 予想）の定式化と現在地](6/6-4.md)**
    ファイバー空間における加法性 $\kappa(X) \ge \kappa(Y) + \kappa(F)$ の幾何学的意味、解決済みのクラス（低次元・一般型など）、および極小モデル理論（MMP）や消滅定理・拡張定理との関わり。
