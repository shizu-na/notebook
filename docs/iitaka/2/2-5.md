前回の最後に提示した問いの答え合わせから始めます。

1. 外積 $\alpha \wedge \beta = (2dx + 3dy) \wedge (dx - dy + 4dz)$ を分配法則と交代性（$dx \wedge dx = 0, \; dy \wedge dx = -dx \wedge dy$ 等）に従って展開すると、

$$\begin{aligned} \alpha \wedge \beta &= 2(dx \wedge dx) - 2(dx \wedge dy) + 8(dx \wedge dz) + 3(dy \wedge dx) - 3(dy \wedge dy) + 12(dy \wedge dz) \\ &= -5\,dx \wedge dy + 12\,dy \wedge dz - 8\,dz \wedge dx \end{aligned}$$



となります。
2. 座標変換 $w = z + c$（$c$ は定数）の両辺の微分をとると、定数の微分は $0$ なので

$$dw = dz$$



となります。変換係数が常に $1$ であるため、大域的に定義された1次微分形式 $dz$（およびその $m$ 乗である $(dz)^m$）は、どのチャートで見ても発散せず、零点も持ちません。
コンパクトな空間上では、これに掛けられる正則関数は定数関数のみ（2-1節の展望）であるため、正則な $m$ 重微分形式の空間 $H^0(E, mK_E)$ はすべての $m \ge 1$ に対して定数倍の $\{ c(dz)^m \mid c \in \mathbb{C} \}$ すなわち **1次元**（$h^0(E, mK_E) = 1$）となります。1次元の空間から射影空間への写像の像は1点（0次元）になるため、楕円曲線 $E$ の小平次元は $\kappa(E) = 0$ となります。

それでは、第2部の最終節である「2-5. 射影空間 $\mathbb{P}^n$ の構成：商空間の応用。無限遠点を加えて空間をコンパクト化（完備化）する操作と、斉次座標系」に進みます。

## 2-5. 射影空間 $\mathbb{P}^n$ の構成：無限遠点の導入と空間のコンパクト化

### 1. 動機（Why）：なぜアフィン空間 $K^n$ ではなく射影空間 $\mathbb{P}^n$ を考えるのか？

通常の座標空間 $K^n$（アフィン空間）で代数幾何学や多様体論を展開しようとすると、主に2つの問題が生じます。

**理由①：コンパクトではないため、平行線などの「無限遠に逃げる例外」が発生する**
2-1節で確認した通り、ユークリッド空間 $\mathbb{R}^n$ や複素空間 $\mathbb{C}^n$ は有界ではないためコンパクトではありません。
たとえば平面上で「2本の異なる直線 $ax + by + c = 0$ と $a'x + b'y + c' = 0$ は何点で交わるか？」と問うと、通常は1点で交わりますが、「平行である場合」のみ交点が $0$ 個になります。代数方程式の係数を連続的に動かして2直線を平行に近づけていくと、交点が無限のかなたへ飛び去って空間から消えてしまうため、場合分けのない統一的な定理（ベズーの定理など）が記述できません。

**理由②：飯高次元の定義における有理写像 $\Phi_{\vert{}mD\vert{}}$ の行き先として必要不可欠である**
2-4節で見たように、多様体上の微分形式や直線束の切断 $s_0, s_1, \dots, s_N \in H^0(X, \mathcal{O}_X(mD))$ は、局所座標を取り替えると「すべて同じ倍率 $\lambda(x) \neq 0$（たとえばヤコビ行列式の $m$ 乗倍）が掛かる」という変換を受けます：


$$(s_0(x), s_1(x), \dots, s_N(x)) \longmapsto (\lambda(x)s_0(x), \lambda(x)s_1(x), \dots, \lambda(x)s_N(x))$$


したがって、多様体の点 $x \in X$ に対して、座標の選び方に依存しない確定した行き先を割り当てるには、「$(N+1)$ 個の数値の組のうち、0でない共通の定数倍（スカラー倍）の違いをすべて同一視した空間」を行き先に選ぶ必要があります。この空間が **$N$ 次元射影空間 $\mathbb{P}^N$** です。

### 2. 具体例と幾何学的イメージ（Toy Model）

#### 例A：射影平面 $\mathbb{P}^2$ の幾何学的構成と「平行線の交点」

3次元空間 $K^3$（座標 $(X_0, X_1, X_2)$）の原点 $O(0, 0, 0)$ に観測者の目があるとします。
観測者から見て、同じ視線の上にある点 $(X_0, X_1, X_2)$ と $(cX_0, cX_1, cX_2)$（$c \neq 0$）は重なって区別がつきません。そこで、「3次元空間 $K^3$ の原点を通る直線1本1本を、新しい空間の『1つの点』とみなした集合」を2次元射影空間（射影平面）$\mathbb{P}^2$ と定義します。

これが通常の2次元平面 $K^2$（座標 $(x, y)$）とどう対応するかを見るため、高さ $X_0 = 1$ の位置にスクリーン（平面）を置きます。

1. **スクリーンと交わる直線（$X_0 \neq 0$ の場合）：**
原点と点 $(X_0, X_1, X_2)$（ただし $X_0 \neq 0$）を結ぶ直線は、全体を $\frac{1}{X_0}$ 倍することで、スクリーン $X_0 = 1$ 上のただ1つの点

$$\left( 1, \, \frac{X_1}{X_0}, \, \frac{X_2}{X_0} \right) = (1, x, y) \qquad \left(\text{ただし } x = \frac{X_1}{X_0}, \; y = \frac{X_2}{X_0}\right)$$



を通ります。つまり、$X_0 \neq 0$ である直線全体は、通常の2次元平面 $K^2 = \{(x, y)\}$ の点と1対1に対応します。
2. **スクリーンと平行な直線（$X_0 = 0$ の場合 ＝ 無限遠直線）：**
では、$X_0 = 0$ となる水平な直線（$X_1 X_2$ 平面内の原点を通る直線）はどうなるでしょうか？
これはスクリーン $X_0 = 1$ とは交わりませんが、$\mathbb{P}^2$ の定義ではこれも立派な「点」です。
スクリーン上の直線 $y = mx + b$ を $x = \frac{X_1}{X_0}, y = \frac{X_2}{X_0}$ で書き直し、分母を払うと

$$X_2 = m X_1 + b X_0 \iff -b X_0 - m X_1 + X_2 = 0$$



となります。ここで $X_0 = 0$（無限遠）との交点を求めると、切片 $b$ の項が消えて $-m X_1 + X_2 = 0$、すなわち比として

$$[X_0 : X_1 : X_2] = [0 : 1 : m]$$



というただ1つの点が得られます。
この点 $[0 : 1 : m]$ は切片 $b$ に依存せず**傾き $m$ だけで決まる**ため、通常の平面上で傾き $m$ を持つすべての平行線（$y = mx + b_1$ と $y = mx + b_2$）は、無限遠にある同じ点 $[0 : 1 : m]$ において交わることになります。

また、すべての傾き $m$（および垂直方向 $[0 : 0 : 1]$）を集めた無限遠点全体の集合 $\{[0 : X_1 : X_2]\}$ は、それ自身が1次元の射影直線 $\mathbb{P}^1$（**無限遠直線**）をなしており、射影平面は


$$\mathbb{P}^2 = \underbrace{K^2}_{\text{通常の平面 }(X_0 \neq 0)} \sqcup \underbrace{\mathbb{P}^1}_{\text{無限遠直線 }(X_0 = 0)}$$


と分解されます。

### 3. 厳密な定義と定理（What）：斉次座標・標準アフィン被覆・コンパクト性

#### (1) 射影空間 $\mathbb{P}^n(K)$ と斉次座標（Homogeneous coordinates）の定義

体 $K$（主に $K = \mathbb{R}, \mathbb{C}$）上の $(n+1)$ 次元ベクトル空間 $K^{n+1}$ から原点 $\mathbf{0} = (0, \dots, 0)$ を除いた集合 $K^{n+1} \setminus \{\mathbf{0}\}$ を考えます。
この集合の上に、0でないスカラー倍による同値関係 $\sim$ を次のように定義します：


$$(X_0, X_1, \dots, X_n) \sim (Y_0, Y_1, \dots, Y_n) \iff \exists \lambda \in K \setminus \{0\} \text{ s.t. } (Y_0, \dots, Y_n) = (\lambda X_0, \dots, \lambda X_n)$$

この同値関係による商集合を $n$ 次元射影空間（Projective space）と呼び、$\mathbb{P}^n(K)$（または単に $\mathbb{P}^n$）と書きます：


$$\mathbb{P}^n(K) := \big( K^{n+1} \setminus \{\mathbf{0}\} \big) \,/\, \sim$$


点 $(X_0, X_1, \dots, X_n) \in K^{n+1} \setminus \{\mathbf{0}\}$ が定める同値類（$\mathbb{P}^n$ の点）を、比の記号を用いて


$$[X_0 : X_1 : \dots : X_n]$$


と表記し、これを斉次座標（または同次座標 / Homogeneous coordinates）と呼びます。定義より、任意の $\lambda \neq 0$ に対して $[X_0 : \dots : X_n] = [\lambda X_0 : \dots : \lambda X_n]$ であり、すべての成分が同時に $0$ になる $[0 : 0 : \dots : 0]$ という点は存在しません。

* **【注意：斉次座標の成分そのものは「多様体上の関数」ではない】**
点 $P = [1 : 2 : 3]$ は $[2 : 4 : 6]$ とも書けるため、「点 $P$ の第0成分 $X_0$ の値を返す関数」というものは Well-defined には定まりません（代表元によって値が $1$ になったり $2$ になったりするため）。
値を確定させるには、$\frac{X_1}{X_0}$ のように**分母と分子の次数を揃えた比**をとる必要があります。これが1-5節の展望で述べた「切断環 $R(X, D)$ の同じ次数の元の比をとると有理関数になる」という仕組みの原型です。

#### (2) 標準アフィン開被覆による多様体構造（$(n+1)$ 枚のチャート）

2-2節で定義したアトラス（地図帳）を使って、$\mathbb{P}^n(K)$ が確かに $n$ 次元多様体（$K=\mathbb{C}$ なら $n$ 次元複素多様体）になることを示します。

$\mathbb{P}^n$ の点は少なくとも1つの成分 $X_i$ が $0$ ではないため、各 $i = 0, 1, \dots, n$ に対して「第 $i$ 成分が $0$ でない点の集合」


$$U_i := \{ [X_0 : X_1 : \dots : X_n] \in \mathbb{P}^n \mid X_i \neq 0 \}$$


を定めると、この $(n+1)$ 個の開集合で $\mathbb{P}^n$ 全体が漏れなく覆われます：


$$\mathbb{P}^n = U_0 \cup U_1 \cup \dots \cup U_n$$


各 $U_i$ の上では $X_i \neq 0$ なので、すべての成分を $X_i$ で割ることができ、代表元の選び方によらずに $n$ 個の数値（**非斉次座標 / アフィン座標**）が確定します。そこでチャート $\varphi_i : U_i \to K^n$ を


$$\varphi_i([X_0 : \dots : X_n]) := \left( \frac{X_0}{X_i}, \, \dots, \, \frac{X_{i-1}}{X_i}, \, \frac{X_{i+1}}{X_i}, \, \dots, \, \frac{X_n}{X_i} \right) = (x^{(i)}_1, \dots, x^{(i)}_n) \in K^n$$


と定義します。逆写像 $\varphi_i^{-1} : K^n \to U_i$ は、第 $i$ 成分の位置に $1$ を挿入する写像 $(u_1, \dots, u_n) \mapsto [u_1 : \dots : 1 : \dots : u_n]$ で与えられ、全単射（同相）となります。

**【座標変換の計算】**
たとえば $n=2$（射影平面 $\mathbb{P}^2$）において、$U_0 = \{X_0 \neq 0\}$ の局所座標を $(x_1, x_2) = \left(\frac{X_1}{X_0}, \frac{X_2}{X_0}\right)$、$U_1 = \{X_1 \neq 0\}$ の局所座標を $(y_1, y_2) = \left(\frac{X_0}{X_1}, \frac{X_2}{X_1}\right)$ とします。
重なり部分 $U_0 \cap U_1 = \{X_0 \neq 0 \text{ かつ } X_1 \neq 0\}$（すなわち $x_1 \neq 0, y_1 \neq 0$）における座標変換 $\varphi_1 \circ \varphi_0^{-1}$ は、


$$y_1 = \frac{X_0}{X_1} = \frac{1}{x_1}, \qquad y_2 = \frac{X_2}{X_1} = \frac{X_2 / X_0}{X_1 / X_0} = \frac{x_2}{x_1}$$


となります。分母 $x_1$ は $U_0 \cap U_1$ 上で決して $0$ にならないため、この座標変換は滑らか（複素数体上では正則、かつ有理式）です。一般の $n$ と任意の $U_i \cap U_j$ でも全く同じ形になるため、$\mathbb{P}^n(\mathbb{C})$ は **$n$ 次元複素多様体**となります。（特に $n=1$ の $\mathbb{P}^1$ では、座標変換が $y_1 = \frac{1}{x_1}$ となり、2-2節の実験Bで見た立体射影の2枚のチャートと完全に一致します。）

#### (3) 射影空間 $\mathbb{P}^n(\mathbb{C})$ のコンパクト性とハウスドルフ性

> **【定理：射影空間のコンパクト性】**
> 複素射影空間 $\mathbb{P}^n(\mathbb{C})$（および実射影空間 $\mathbb{P}^n(\mathbb{R})$）は、**コンパクトなハウスドルフ空間**である。

**【証明（2-1節の定理1を用いた簡潔な証明）】**

1. $\mathbb{C}^{n+1} \setminus \{\mathbf{0}\}$ の中で、原点からの長さが $1$ である単位球面

$$S^{2n+1} := \left\{ Z = (Z_0, \dots, Z_n) \in \mathbb{C}^{n+1} \;\middle\vert{}\; \vert{}Z_0\vert{}^2 + \vert{}Z_1\vert{}^2 + \dots + \vert{}Z_n\vert{}^2 = 1 \right\}$$



を考えます。$S^{2n+1}$ は $\mathbb{C}^{n+1} \cong \mathbb{R}^{2n+2}$ の**有界閉集合**なので、ハイネ・ボレルの定理（2-1節）により**コンパクト**です。
2. $\mathbb{C}^{n+1} \setminus \{\mathbf{0}\}$ の任意の点 $X = (X_0, \dots, X_n)$ は、自身の長さ $\Vert{}X\Vert{} = \sqrt{\sum \vert{}X_i\vert{}^2} > 0$ で割った $\frac{X}{\Vert{}X\Vert{}}$ をとることで、単位球面 $S^{2n+1}$ 上の点と同値（同じ斉次座標 $[X_0 : \dots : X_n]$）になります。
3. したがって、自然な射影 $\pi: \mathbb{C}^{n+1} \setminus \{\mathbf{0}\} \to \mathbb{P}^n(\mathbb{C})$ を単位球面 $S^{2n+1}$ に制限した連続写像

$$\pi\vert{}_{S^{2n+1}} : S^{2n+1} \longrightarrow \mathbb{P}^n(\mathbb{C})$$



は**全射**になります。
4. 2-1節の定理1「コンパクト空間の連続写像による像はコンパクトである」により、コンパクトな球面 $S^{2n+1}$ の像である $\mathbb{P}^n(\mathbb{C})$ は**コンパクト**です。（また、距離関数 $d([Z], [W]) = \sqrt{1 - \vert{}\langle Z, W \rangle\vert{}^2}$（ただし $\Vert{}Z\Vert{}=\Vert{}W\Vert{}=1$）が Well-defined に定まることから、ハウスドルフ空間であることも直ちに従います。）（証明終）

### 4. 翻訳と展望（Bridge）：第2部の総決算と飯高理論への直結

1. **射影空間 $\mathbb{P}^n$ の標準因子 $K_{\mathbb{P}^n}$ と小平次元 $\kappa(\mathbb{P}^n) = -\infty$：**
2-4節の実験Bで、1次元の射影直線 $\mathbb{P}^1$ 上では $du = -v^{-2} dv$ と変換するため、正則な微分形式が存在せず $\kappa(\mathbb{P}^1) = -\infty$ となることを見ました。
一般の $n$ 次元射影空間 $\mathbb{P}^n$ でも、先ほどの $U_0$ と $U_1$ の座標変換 $y_1 = \frac{1}{x_1}, \; y_2 = \frac{x_2}{x_1}, \dots, y_n = \frac{x_n}{x_1}$ のヤコビ行列式を計算すると、

$$dy_1 \wedge dy_2 \wedge \dots \wedge dy_n = -\frac{1}{x_1^{n+1}} \, dx_1 \wedge dx_2 \wedge \dots \wedge dx_n$$



となり、分母に $x_1^{n+1}$（$(n+1)$ 位の極）が現れます（この指数 $-(n+1)$ が、代数幾何学で有名な公式 **$K_{\mathbb{P}^n} = -(n+1)H$**（$H$ は超平面因子）の正体です）。
指数が負であるため、何乗しても全体で発散しない正則な多重最高次微分形式は $0$ しか存在せず、すべての次元 $n \ge 1$ に対して **$\kappa(\mathbb{P}^n) = -\infty$** となります。
2. **線形系 $\vert{}mD\vert{}$ が定める射影空間への写像 $\Phi_{\vert{}mD\vert{}} : X \dashrightarrow \mathbb{P}^N$（第6部・飯高次元の定義式）：**
第1回目の回答で提示した飯高次元の定義式：

$$\kappa(X, D) = \max_{m \in N(X, D)} \left( \dim \Phi_{\vert{}mD\vert{}}(X) \right)$$



の写像 $\Phi_{\vert{}mD\vert{}}$ の仕組みが、本節の斉次座標によって明確になります。
ベクトル空間 $H^0(X, \mathcal{O}_X(mD))$ の次元を $N + 1$ とし、その基底（1組の独立な切断）を $\{s_0, s_1, \dots, s_N\}$ とします。多様体 $X$ の各点 $x \in X$ に対して、その点での切断の値の比を斉次座標として並べることで、射影空間 $\mathbb{P}^N$ への写像

$$\Phi_{\vert{}mD\vert{}}(x) := [s_0(x) : s_1(x) : \dots : s_N(x)] \in \mathbb{P}^N$$



が作られます（すべての $s_i(x)$ が同時に $0$ になる点では $[0:\dots:0]$ となって定義できないため、破線矢印 $\dashrightarrow$ の「有理写像」となります）。そして、この像 $\Phi_{\vert{}mD\vert{}}(X) \subset \mathbb{P}^N$ が射影空間の中で何次元の図形として広がるかを測ったものが、飯高次元 $\kappa(X, D)$ です。
