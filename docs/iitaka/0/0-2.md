前回の最後に提示した問いの答え合わせから始めます。この答えがそのまま、今回のテーマである「商空間（Quotient space）」の定義に直結します。

$f(\mathbf{x}_1) = f(\mathbf{x}_2) = \mathbf{w}$ であるとき、線形性から $f(\mathbf{x}_1 - \mathbf{x}_2) = f(\mathbf{x}_1) - f(\mathbf{x}_2) = \mathbf{w} - \mathbf{w} = \mathbf{0}_W$ となります。つまり、**2つのベクトルの差 $\mathbf{x}_1 - \mathbf{x}_2$ は核 $\ker f$ に属しています**（$\mathbf{x}_1 - \mathbf{x}_2 \in \ker f$）。
これを書き換えると、$\mathbf{x}_1 = \mathbf{x}_2 + \mathbf{u}$（ただし $\mathbf{u} \in \ker f$）となります。幾何学的には、同じ点 $\mathbf{w}$ に着地する元の集まり（逆像 $f^{-1}(\mathbf{w})$）は、1つの代表点 $\mathbf{x}_2$ を通り、部分空間 $\ker f$ をそのまま平行移動した図形（アフィン部分空間 $\mathbf{x}_2 + \ker f$）になっています。

この「平行移動した部分空間1つ1つを、丸ごと1つの『新しい点』とみなす」という操作が、本節の主題である**商空間**です。

## 0-2. 商空間（Quotient space）：「ある部分空間の差を無視して同一視する」という操作

### 1. 動機（Why）：なぜわざわざ「情報を潰した空間」を作るのか？

商空間は、学部数学で最初の壁になりやすい概念です。直感的には「部分空間 $W$ に属する方向のズレをすべて $0$ とみなして無視する（潰す）」という操作ですが、なぜ既存の空間 $V$ の中に別の部分空間 $U$（直和補空間）を取るだけでは不十分で、わざわざ商空間 $V/W$ という新しい空間を定義する必要があるのでしょうか。理由は2つあります。

**理由①：「潰す方向 $W$」は自然に決まっていても、「残す方向」の選び方は一通りに決まらないから**
平面 $V = \mathbb{R}^2$ において、縦軸（$y$ 軸）を部分空間 $W$ とし、この方向のズレを無視したいとします。
このとき、「残す1次元の直線」として $x$ 軸を選ぶこともできますが、斜めの直線 $y = x$ を選んでも、縦軸方向のズレを無視したときの座標は一意に決まります。空間自体には「どの横軸が特別に正しいか」という基準がありません。
一方、「縦線（$y$ 軸に平行な直線 $x = c$）の集まり」そのものを新しい空間の「点」と定義してしまえば、横軸をどう引くかという恣意的な選択に一切依存せずに、残った1次元の自由度だけを取り出すことができます。これが商空間 $V/W$ です。

**理由②：方程式の解空間、射影空間、コホモロジーがすべて「商」で作られるから**
今後のロードマップにおいて、「商（割り算による同一視）」は以下のすべての場面で土台として使われます。

* **第1部（代数）：** 多項式環 $R$ をイデアル $I$ で割った**剰余環（商環）$R/I$**（方程式 $f=0$ が成り立つ世界を作る操作）
* **第2部（幾何）：** 原点を通る直線全体を1点とみなす**射影空間 $\mathbb{P}^n$**
* **第5部（層とコホモロジー）：** 「条件を満たすもの全体（$\ker$）」を「自明に条件を満たすもの（$\operatorname{Im}$）」で割った商空間 **コホモロジー群 $H^i = \ker / \operatorname{Im}$**

商空間の仕組みをここで完全に理解しておけば、これらすべてが同じ構造の繰り返しに見えるようになります。

### 2. 具体例・情報系との接点（Toy Model）

#### 例A：3次元空間を $z$ 軸で割る（幾何学的イメージ）

3次元空間 $V = \mathbb{R}^3$ と、その部分空間である $z$ 軸 $W = \left\{ \begin{pmatrix} 0 \\ 0 \\ z \end{pmatrix} \;\middle\vert{}\; z \in \mathbb{R} \right\}$ を考えます。
「2つの点 $\mathbf{x}_1, \mathbf{x}_2 \in \mathbb{R}^3$ の差が $W$ に入っている（つまり $x, y$ 座標が同じで、高さ $z$ だけが違う）とき、$\mathbf{x}_1$ と $\mathbf{x}_2$ を同じものとみなす」というルールを入れます。

このとき、1つの点 $\begin{pmatrix} a \\ b \\ c \end{pmatrix}$ と同一視される点の集まりは、


$$\begin{pmatrix} a \\ b \\ c \end{pmatrix} + W = \left\{ \begin{pmatrix} a \\ b \\ c + z \end{pmatrix} \;\middle\vert{}\; z \in \mathbb{R} \right\}$$


となり、**点 $(a, b, 0)$ を通って上下に無限に伸びる鉛直な直線（柱）**そのものになります。
商空間 $\mathbb{R}^3 / W$ とは、**「この鉛直な直線1本1本を、それぞれ1つの『要素（ベクトル）』と呼ぶことにした集合」**です。直線同士の足し算は


$$(\text{点 }(a_1, b_1, 0)\text{ を通る直線}) + (\text{点 }(a_2, b_2, 0)\text{ を通る直線}) = (\text{点 }(a_1+a_2, b_1+b_2, 0)\text{ を通る直線})$$


と定義でき、これは平面 $\mathbb{R}^2$ とまったく同じ2次元ベクトル空間の構造を持ちます。

#### 例B：符号理論における「標準配列（Standard Array）」とシンドローム復号

0-1節の例Cで、長さ $n$ の受信語空間 $V = \mathbb{F}_2^n$ と、パリティ検査行列 $H$ の核として定まる線形符号 $C = \ker H \subset V$（$k$ 次元部分空間）を見ました。
通信路でエラー $\mathbf{e} \in V$ が発生し、送信した符号語 $\mathbf{c} \in C$ に対して受信語 $\mathbf{y} = \mathbf{c} + \mathbf{e}$ が届いたとします。このとき、シンドローム（症状）$\mathbf{s} = H\mathbf{y}$ を計算すると、$\mathbf{c} \in \ker H$ なので


$$\mathbf{s} = H(\mathbf{c} + \mathbf{e}) = H\mathbf{c} + H\mathbf{e} = \mathbf{0} + H\mathbf{e} = H\mathbf{e}$$


となり、シンドロームは送信語 $\mathbf{c}$ には依存せず、エラー $\mathbf{e}$ との差が符号語であるような集合 $\mathbf{e} + C = \{ \mathbf{e} + \mathbf{c} \mid \mathbf{c} \in C \}$ に対してただ1つ決まります。

符号理論ではこの集合 $\mathbf{e} + C$ を**コセット（Coset：剰余類）**と呼びます。そして、すべてのコセットを集めた集合こそが**商空間 $V / C$** です。

* 元の空間 $V = \mathbb{F}_2^n$ の次元は $n$（要素数は $2^n$ 個）
* 符号 $C$ の次元は $k$（要素数は $2^k$ 個）
* 商空間 $V / C$ の次元は $n - k$（コセットの個数は $2^{n-k}$ 個）であり、各コセットがシンドローム $\mathbf{s} \in \mathbb{F}_2^{n-k}$ と1対1に対応します。

「同じシンドロームを持つ受信語を1つのグループ（コセット $\mathbf{e} + C$）にまとめ、その中で最もハミング重みの小さい元（コセットリーダー）をエラーと推定する」というシンドローム復号法は、商空間 $V / C$ と像 $\operatorname{Im} H$ の間の1対1対応（後に述べる**準同型定理**）をそのままアルゴリズムにしたものです。

### 3. 厳密な定義と定理（What）：同値関係から準同型定理まで

ここからは、商空間を厳密に構築します。特に重要なステップである「演算の良定義性（Well-definedness）」について丁寧に確認します。

#### (1) 同値関係と同値類（剰余類）

体 $K$ 上のベクトル空間 $V$ と、その部分空間 $W \subset V$ を固定します。
$V$ の2つの元 $\mathbf{x}, \mathbf{y} \in V$ に対して、関係 $\sim$ を次のように定義します。


$$\mathbf{x} \sim \mathbf{y} \iff \mathbf{x} - \mathbf{y} \in W$$

この関係 $\sim$ は、部分空間 $W$ の性質から以下の3条件（**同値関係**の公理）を満たします。

1. **反射律（$\mathbf{x} \sim \mathbf{x}$）：** $\mathbf{x} - \mathbf{x} = \mathbf{0} \in W$（部分空間はゼロベクトルを含むため）。
2. **対称律（$\mathbf{x} \sim \mathbf{y} \implies \mathbf{y} \sim \mathbf{x}$）：** $\mathbf{x} - \mathbf{y} \in W$ ならば、$-1$ 倍した $\mathbf{y} - \mathbf{x} = -(\mathbf{x} - \mathbf{y}) \in W$（部分空間はスカラー倍で閉じているため）。
3. **推移律（$\mathbf{x} \sim \mathbf{y}$ かつ $\mathbf{y} \sim \mathbf{z} \implies \mathbf{x} \sim \mathbf{z}$）：** $\mathbf{x} - \mathbf{y} \in W$ かつ $\mathbf{y} - \mathbf{z} \in W$ ならば、その和である $\mathbf{x} - \mathbf{z} = (\mathbf{x} - \mathbf{y}) + (\mathbf{y} - \mathbf{z}) \in W$（部分空間は加法で閉じているため）。

ある $\mathbf{x} \in V$ と同値になる元の全体の集合を、$\mathbf{x}$ の同値類（または剰余類 / コセット）といい、$[\mathbf{x}]$ または $\mathbf{x} + W$ と書きます。


$$[\mathbf{x}] = \mathbf{x} + W := \{ \mathbf{x} + \mathbf{w} \mid \mathbf{w} \in W \}$$


このとき、$[\mathbf{x}] = [\mathbf{y}]$（集合として完全に一致する）であることと、$\mathbf{x} - \mathbf{y} \in W$ であることは同値です。この集合 $[\mathbf{x}]$ の中に含まれる個々の元（$\mathbf{x}$ や $\mathbf{x}+\mathbf{w}$）を、このクラスの代表元（Representative）と呼びます。

そして、すべての剰余類を集めてできる集合を $V / W$ と書きます。


$$V / W := \{ \mathbf{x} + W \mid \mathbf{x} \in V \}$$

#### (2) 商空間における演算と「Well-defined（良定義）」の確認

集合 $V / W$ をベクトル空間にするために、剰余類同士の加法とスカラー倍を、代表元を使って次のように定義します。

* **加法：** $(\mathbf{x} + W) + (\mathbf{y} + W) := (\mathbf{x} + \mathbf{y}) + W$
* **スカラー倍：** $c(\mathbf{x} + W) := (c\mathbf{x}) + W \quad (c \in K)$

ここで、現代数学において極めて重要なチェックポイントがあります。
左辺の $\mathbf{x} + W$ というクラスは、別の代表元 $\mathbf{x}'$（ただし $\mathbf{x}' - \mathbf{x} \in W$）を使って $\mathbf{x}' + W$ と書くこともできます。もし、**代表元を $\mathbf{x}$ から $\mathbf{x}'$ に取り替えたときに、右辺の計算結果が違うクラスになってしまったら、この足し算の定義は破綻（矛盾）してしまいます**。
「代表元の選び方に依存せず、演算結果がただ1つに確定すること」を、数学ではWell-defined（良定義である）と言います。実際に確認してみましょう。

* **加法のWell-defined性の証明：**
    $\mathbf{x} + W = \mathbf{x}' + W$ かつ $\mathbf{y} + W = \mathbf{y}' + W$ とします。
    これは、ある $\mathbf{w}_1, \mathbf{w}_2 \in W$ が存在して、$\mathbf{x}' = \mathbf{x} + \mathbf{w}_1$、$\mathbf{y}' = \mathbf{y} + \mathbf{w}_2$ と書けることを意味します。
    このとき、新しい代表元での和 $\mathbf{x}' + \mathbf{y}'$ と元の和 $\mathbf{x} + \mathbf{y}$ の差をとると、

    $$(\mathbf{x}' + \mathbf{y}') - (\mathbf{x} + \mathbf{y}) = (\mathbf{x}' - \mathbf{x}) + (\mathbf{y}' - \mathbf{y}) = \mathbf{w}_1 + \mathbf{w}_2$$

    $W$ は部分空間なので $\mathbf{w}_1 + \mathbf{w}_2 \in W$ です。したがって、

    $$(\mathbf{x}' + \mathbf{y}') + W = (\mathbf{x} + \mathbf{y}) + W$$

    となり、どの代表元を使って足し算しても結果は全く同じクラスになります。
* **スカラー倍のWell-defined性の証明：**
    同様に $\mathbf{x}' - \mathbf{x} = \mathbf{w}_1 \in W$ のとき、$c\mathbf{x}' - c\mathbf{x} = c(\mathbf{x}' - \mathbf{x}) = c\mathbf{w}_1 \in W$ なので、$(c\mathbf{x}') + W = (c\mathbf{x}) + W$ となり確定します。

これにより、$V / W$ は体 $K$ 上のベクトル空間になります。これを $V$ の $W$ による**商空間（Quotient space）**と呼びます。

* **注目点：** 商空間 $V / W$ における「ゼロベクトル」は、$\mathbf{0} + W = W$（すなわち**部分空間 $W$ という集合そのもの**）です。「$W$ の元をすべてゼロに潰した」ということが、数式上でも $\mathbf{w} + W = \mathbf{0} + W$ として表現されています。

また、各元 $\mathbf{x} \in V$ をその属するクラス $\mathbf{x} + W \in V / W$ へ対応させる写像


$$\pi: V \to V / W, \quad \pi(\mathbf{x}) = \mathbf{x} + W$$


は全射の線形写像となり、これを自然な全射（または標準射影 / Canonical projection）と呼びます。明らかに $\ker \pi = W$ です。

#### (3) 商空間の次元公式

有限次元ベクトル空間 $V$ とその部分空間 $W$ に対し、自然な全射 $\pi: V \to V / W$ に前回の**次元定理**を適用すると、$\ker \pi = W$ かつ $\operatorname{Im} \pi = V / W$ なので、直ちに次の公式が得られます。


$$\dim(V / W) = \dim V - \dim W$$


（「元の空間の次元」から「潰した部分空間の次元」を引いたものが、商空間の次元になります。）

#### (4) ベクトル空間の準同型定理（Fundamental Theorem on Homomorphisms）

0-1節と0-2節の集大成となる定理です。任意の線形写像 $f: V \to U$ があるとき、「核 $\ker f$ で割った商空間 $V / \ker f$」と「像 $\operatorname{Im} f$」が、ベクトル空間として完全に同じ構造（同型）になることを主張します。

> **【定理：線形写像の準同型定理】**
> $V, U$ を体 $K$ 上のベクトル空間とし、$f: V \to U$ を線形写像とする。
> このとき、商空間 $V / \ker f$ から像 $\operatorname{Im} f$ への写像 $\tilde{f}$ を
> 
> $$\tilde{f}: V / \ker f \to \operatorname{Im} f, \quad \tilde{f}(\mathbf{x} + \ker f) := f(\mathbf{x})$$
> 
> 
> 
> と定めると、$\tilde{f}$ はWell-definedな同型写像（全単射な線形写像）となる。すなわち、
> 
> $$V / \ker f \cong \operatorname{Im} f$$
> 
> 

**【証明】**

1. **Well-definedであること（代表元の取り方によらないこと）：**
    $\mathbf{x} + \ker f = \mathbf{y} + \ker f$ とすると、$\mathbf{x} - \mathbf{y} \in \ker f$ です。
    核の定義より $f(\mathbf{x} - \mathbf{y}) = \mathbf{0}_U$ であり、$f$ の線形性から $f(\mathbf{x}) - f(\mathbf{y}) = \mathbf{0}_U$、すなわち $f(\mathbf{x}) = f(\mathbf{y})$ となります。よって代表元を取り替えても行先は変わらず、$\tilde{f}$ は写像として正しく定義されています。
2. **線形写像であること：**

    $$\tilde{f}\big(a(\mathbf{x} + \ker f) + b(\mathbf{y} + \ker f)\big) = \tilde{f}\big((a\mathbf{x} + b\mathbf{y}) + \ker f\big) = f(a\mathbf{x} + b\mathbf{y}) = a f(\mathbf{x}) + b f(\mathbf{y}) = a \tilde{f}(\mathbf{x} + \ker f) + b \tilde{f}(\mathbf{y} + \ker f)$$

    より、$\tilde{f}$ は線形写像です。
3. **単射であること：**
    $\tilde{f}(\mathbf{x} + \ker f) = \mathbf{0}_U$ とします。定義より $f(\mathbf{x}) = \mathbf{0}_U$ なので、$\mathbf{x} \in \ker f$ です。
    すると $\mathbf{x} + \ker f = \mathbf{0}_V + \ker f$（商空間のゼロベクトル）となります。核 $\ker \tilde{f}$ がゼロベクトルのみなので、0-1節の性質より $\tilde{f}$ は単射です。（「潰れる原因だった $\ker f$ をあらかじめひとまとめにして1点に潰しておいたのだから、もうこれ以上別の点が同じ点に潰れることはない（単射になる）」という仕組みです。）
4. **全射であること：**
    $\operatorname{Im} f$ の任意の元 $\mathbf{u}$ は、ある $\mathbf{x} \in V$ を用いて $\mathbf{u} = f(\mathbf{x}) = \tilde{f}(\mathbf{x} + \ker f)$ と書けるので、$\tilde{f}$ は全射です。

以上より、$\tilde{f}$ は全単射な線形写像（同型写像）であり、$V / \ker f \cong \operatorname{Im} f$ が示されました。（証明終）

### 4. 翻訳と展望（Bridge）：これが飯高理論のどこに直結するのか？

この「商空間」と「準同型定理」のメカニズムは、今後のステップで以下のように姿を変えて何度も登場します。

1. **射影空間 $\mathbb{P}^n$ の構成（第2部・第4部）：**
飯高次元の定義で多様体の埋め込み先となる射影空間 $\mathbb{P}^n$ は、$(n+1)$ 次元ベクトル空間 $V = \mathbb{C}^{n+1}$ から原点 $\mathbf{0}$ を除き、「原点を通る1次元部分空間（スカラー倍の違い）」で割った商集合として作られます。商空間で学んだ「同値関係で割って新しい空間の点を作る」という思考法そのものです。
2. **層のコホモロジー群 $H^i(X, \mathcal{F})$ の定義（第5部）：**
    第5部で学ぶコホモロジー群は、ベクトル空間の列 $C^{i-1} \xrightarrow{d_{i-1}} C^i \xrightarrow{d_i} C^{i+1}$（ただし $d_i \circ d_{i-1} = 0$、すなわち $\operatorname{Im} d_{i-1} \subset \ker d_i$）に対して、

    $$H^i := \ker d_i \,/\, \operatorname{Im} d_{i-1}$$

    という**商空間**として定義されます。「局所的な貼り合わせ条件を満たすデータ（$\ker d_i$）」の中から、「大域的なデータから自明に作れるズレ（$\operatorname{Im} d_{i-1}$）」を無視して割ることで、空間の穴や大域的な障害を抽出します。
3. **多様体上の部分多様体への制限（第4部・第5部）：**
多様体 $X$ の中に部分多様体 $Y$（たとえば飯高予想におけるファイバー $F$）があるとき、「$X$ 全体の関数（切断）の空間 $V$」から「$Y$ 上に制限した関数の空間 $U$」への制限写像 $f: V \to U$ を考えます。このとき、「$Y$ の上で $0$ になる関数の空間」が $\ker f$ であり、準同型定理 $V / \ker f \cong \operatorname{Im} f$ を使って、全体空間 $X$ の情報からファイバー $F$ 上の情報を引き出します。
