### 前節（6-3）の確認問題の解答

前節の確認問題（[6-3節](6-3.md)）の答え合わせから始めます。

1. $X = S \times C$（$S$ は K3曲面：$\dim S = 2, \; \kappa(S) = 0$、$C$ は種数 $3$ の曲線：$\dim C = 1, \; \kappa(C) = 1$）の小平次元は、直積の加法性より $\kappa(X) = 0 + 1 = \mathbf{1}$ です。
    このとき、$X$ の飯高ファイブレーションは第2射影 $\operatorname{pr}_2 : S \times C \to C$ であり、底空間は $Y_\infty = C$（$\dim Y_\infty = 1, \; \kappa(Y_\infty) = 1$）、一般ファイバーは $F = S$（$\dim F = 2, \; \kappa(F) = 0$）となります。

2. $\kappa(Y) = -\infty, \; \kappa(F) = 0$ より、右辺は $-\infty + 0 = -\infty$ です。左辺は $\kappa(X) = 1$ なので、$1 \ge -\infty$ となり、飯高予想の不等式は（真の不等号で）成り立っています。

---

それでは、本カリキュラムの最終節である「6-4. 飯高予想（$C_{n, m}$ 予想）の定式化と現在地」に進みます。

## 6-4. 飯高予想（$C_{n, m}$ 予想）の定式化と現在地

### 1. 動機（Why）：なぜファイバー空間における加法性 $\kappa(X) \ge \kappa(Y) + \kappa(F)$ が重要なのか？

高次元の非特異射影多様体 $X$ を調べる際、より低い次元の多様体 $Y$ への代数ファイバー空間 $f : X \to Y$（[6-3節](6-3.md)）を構成し、「底空間 $Y$」と「一般ファイバー $F = f^{-1}(y)$」という2つの低次元部品に分解して解析するのが基本手法です（たとえば、飯高ファイブレーションや、アーベル多様体へのアルバネーゼ写像など）。

このとき、「部品である $Y$ と $F$ の複雑さ（小平次元）が分かっているとき、全体空間 $X$ の複雑さはどう制約されるか？」という問いが必然的に生じます。

* もし直積 $X = Y \times F$ であれば、[6-1節](6-1.md)の命題3より $\kappa(X) = \kappa(Y) + \kappa(F)$ が等号で成り立ちます。
* [6-3節](6-3.md)の最後で見たように、一般のファイバー空間では「ファイバーのねじれや特異ファイバーの存在」が正の寄与を生み、$\kappa(X)$ が $\kappa(Y) + \kappa(F)$ より大きくなることがあります。
* では逆に、**ねじれによって小平次元が相殺され、$\kappa(X) < \kappa(Y) + \kappa(F)$ となってしまうようなファイバー空間は存在するのか？**

「そのような相殺は起きない」と主張するのが、飯高茂が1971年に提唱した飯高予想（Iitaka's conjecture $C_{n, m}$）です。もしこの予想が成り立てば、たとえば「底空間 $Y$ も一般ファイバー $F$ も一般型（$\kappa(Y) = m, \; \kappa(F) = n - m$）であれば、全体空間 $X$ も必ず一般型（$\kappa(X) = n$）になる」といった、高次元分類の基本法則が帰納的に保証されます。

---

### 2. 具体例・実験（Toy Model）：自明なケース・真の不等号・逆向きの不等式

#### 実験A：$\kappa(Y) = -\infty$ または $\kappa(F) = -\infty$ の場合（予想が自動的に成り立つケース）

飯高予想の右辺 $\kappa(Y) + \kappa(F)$ は、$-\infty$ との和を常に $-\infty$ と規約しています。
したがって、**$\kappa(Y) = -\infty$ または $\kappa(F) = -\infty$** であれば、右辺は $-\infty$ となり、任意の $\kappa(X) \in \{-\infty, 0, 1, \dots, n\}$ に対して $\kappa(X) \ge -\infty$ が自動的に成立します。

つまり、飯高予想の本質的に非自明な部分は、**$\kappa(Y) \ge 0$ かつ $\kappa(F) \ge 0$** の場合です。
特に、次の「最低限の非消滅」を示すことだけでも強い主張になります：

> 「$\kappa(Y) \ge 0$ かつ $\kappa(F) \ge 0$ ならば、$\kappa(X) \ge 0$（すなわち、ある $m \ge 1$ で $P_m(X) \ge 1$）」

#### 実験B：逆向きの不等式（飯高の容易な不等式 / Easy Addition）

飯高予想の主張とは逆向きの「上界」については、一般のファイバー空間 $f : X \to Y$（$\dim X = n, \; \dim Y = m$）に対して次の不等式が初等的に成り立ちます：


$$\kappa(X) \;\le\; \kappa(F) + \dim Y \qquad (\text{飯高の容易な不等式})$$

* **導出の仕組み：** もし $\kappa(F) = -\infty$ であれば、すべての $m \ge 1$ で $H^0(F, mK_F) = 0$ です。$X$ 上に $0$ でない切断 $s \in H^0(X, mK_X)$ があれば、一般ファイバー $F$ への制限 $s\vert{}_F \in H^0(F, mK_X\vert{}_F) = H^0(F, mK_F)$ も $0$ でなくなるため矛盾します。よって $\kappa(X) = -\infty$ となり成立します。
* $\kappa(F) \ge 0$ の場合も、直感的には、十分大きな $m$ に対して $X$ 上の切断 $H^0(X, mK_X)$ は「底空間 $Y$ 方向の自由度（高々 $O(m^{\dim Y})$）」と「ファイバー $F$ 方向の自由度（$O(m^{\kappa(F)})$）」の積で上から押さえられるため、増大度は高々 $\kappa(F) + \dim Y$ 以下になります（厳密には、底空間 $Y$ の一般超平面切断をとって $\dim Y$ に関する帰納法に帰着させるか、[6-3節](6-3.md)と同様に押し出し層の階数評価を用いることで証明されます）。

この容易な不等式と飯高予想を組み合わせると、


$$\kappa(Y) + \kappa(F) \;\le\; \kappa(X) \;\le\; \dim Y + \kappa(F)$$


という挟み撃ちが得られます。特に、底空間 $Y$ が一般型（$\kappa(Y) = \dim Y$）のときは、両端が一致して等号 $\kappa(X) = \dim Y + \kappa(F)$ が強制されます。

#### 実験C：$\mathbb{P}^1$ 束と楕円曲面での対比

* **$\mathbb{P}^1$ 束 $f : X \to C$（$C$ は種数 $g \ge 2$ の曲線）：**
    $\kappa(C) = 1$、ファイバー $F = \mathbb{P}^1$ は $\kappa(F) = -\infty$。容易な不等式より $\kappa(X) = -\infty$ となり、$-\infty \ge 1 + (-\infty) = -\infty$ で成立。

* **楕円曲面 $f : S \to C$（$C$ は種数 $g \ge 2$ の曲線、$F = E$ は楕円曲線）：**
    $\kappa(C) = 1, \; \kappa(E) = 0$。上の挟み撃ちより $1 + 0 \le \kappa(S) \le 1 + 0$ となり、どのような楕円曲面であっても必ず $\kappa(S) = 1$ に確定します。

### 3. 厳密な定義と定理（What）：飯高予想・証明の基本戦略・現在地

#### (1) 飯高予想（$C_{n, m}$ 予想）と飯高・フィーヴェグ予想（$C_{n, m}^+$ 予想）

> **【予想1：飯高予想（$C_{n, m}$ 予想 / Iitaka, 1971）】**
> 複素数体 $\mathbb{C}$ 上の非特異射影代数多様体の間の代数ファイバー空間 $f : X \to Y$（$\dim X = n, \; \dim Y = m$）と、その一般ファイバー $F = f^{-1}(y)$（$\dim F = n - m$）に対して、次が成り立つ：
> 
> $$\kappa(X) \;\ge\; \kappa(Y) + \kappa(F)$$

さらに、[6-3節](6-3.md)の最後で見た「ファイバーの形状が底空間の上でどれだけ本質的に変化しているか（モジュライの変化の次元）」を数値化したものを $f$ の**変分（Variation）$\operatorname{var}(f) \in \{0, 1, \dots, m\}$** と呼びます（直積や局所自明な束なら $\operatorname{var}(f) = 0$、底空間のすべての方向でファイバーの同型類が変化していれば $\operatorname{var}(f) = m$）。これを用いて飯高予想を精密化したものが次の予想です。

> **【予想2：飯高・フィーヴェグ予想（$C_{n, m}^+$ 予想 / Viehweg, 1983）】**
> $C_{n, m}$ と同じ設定において、$\kappa(Y) \ge 0$ であれば次が成り立つ：
> 
> $$\kappa(X) \;\ge\; \kappa(F) + \max\big\{\kappa(Y), \, \operatorname{var}(f)\big\}$$

---

#### (2) 証明の原理と基本戦略（相対標準束と弱正値性）

飯高予想の証明において、現代の代数幾何学が用いる中心的な仕掛けを、[第5部](../index.md#part-5)までの言語で整理します。

1. **相対標準因子（Relative canonical divisor）$K_{X/Y}$ の導入：**
    $X$ と $Y$ の標準因子の差を

    $$K_{X/Y} := K_X - f^* K_Y \qquad \big(\text{直線束では } \omega_{X/Y} := \omega_X \otimes f^* \omega_Y^{-1}\big)$$

    と定義します。すると、$X$ の標準因子は

    $$K_X = K_{X/Y} + f^* K_Y$$

    と分解されます。また、一般ファイバー $F$ の上では $f^* K_Y\vert{}_F \sim 0$ なので、$K_{X/Y}\vert{}_F \sim K_F$ です。

2. **押し出し層（順像層）$f_* \mathcal{O}_X(mK_{X/Y})$ の「弱正値性（Weak positivity）」：**
    層の押し出し $f_*$ には、「下側の空間 $Y$ から引き戻した直線束 $f^* \mathcal{L}$ は、押し出し $f_*$ の外にくくり出せる」という**射影公式（Projection formula）**

    $$f_*\big(\mathcal{F} \otimes f^* \mathcal{L}\big) \;\cong\; (f_* \mathcal{F}) \otimes \mathcal{L}$$

    が成り立ちます。これに $\mathcal{F} = \mathcal{O}_X(mK_{X/Y}), \; \mathcal{L} = \mathcal{O}_Y(mK_Y)$ を当てはめて両辺の大域切断 $H^0(Y, -)$ をとると、[5-1節](../5/5-1.md)で見た $H^0(Y, f_* \mathcal{G}) = H^0(X, \mathcal{G})$ より、$X$ 上の多重標準空間 $H^0(X, mK_X)$ は、底空間 $Y$ 上の層の大域切断として

    $$H^0\big(X, \, \mathcal{O}_X(mK_X)\big) \;\cong\; H^0\Big(Y, \, f_* \mathcal{O}_X(mK_{X/Y}) \otimes \mathcal{O}_Y(mK_Y)\Big)$$

    と書き換えることができます。

    * ここで $Y$ 上の層 $\mathcal{E}_m := f_* \mathcal{O}_X(mK_{X/Y})$ は、一般の点 $y \in Y$ におけるファイバーが $H^0(F_y, mK_{F_y})$（次元 $P_m(F)$）となるベクトル束（正確には捩れなし連接層）です。
    * もし $\mathcal{E}_m$ が「正の方向を向いている（豊富な直線束を少し足すと大域切断で生成される＝**弱正値 / Weakly positive**）」であれば、$\mathcal{E}_m$ と $\mathcal{O}_Y(mK_Y)$ のテンソル積の切断の次元が $P_m(F)$ と $P_m(Y)$ の積のオーダーを下回らないことが導かれます。
    * フィーヴェグ（1983年）は、**川又・フィーヴェグ消滅定理**（[5-3節](../5/5-3.md)の小平消滅定理の一般化）と**ホッジ理論（ホッジ構造の変分）**、および巡回被覆トリックを組み合わせることで、任意の $m \ge 1$ に対して**押し出し層 $f_* \mathcal{O}_X(mK_{X/Y})$ が弱正値である**という重要な定理を証明しました。
    * この弱正値性から、底空間 $Y$ が一般型（$\kappa(Y) = m$）の場合の $C_{n, m}^+$ が直ちに従います。

#### (3) 解決済みの主な結果と現在地（2026年時点）

飯高予想 $C_{n, m}$ は、**一般の次元 $n \ge 7$ においては現在も未解決**ですが、低次元および多くの重要なクラスにおいて証明が完了しています。主要な到達点は以下の通りです。

| 解決された条件・クラス | 証明者・年 | 概要・使用された主な手法 |

> **【コラム：なぜ「6次元以下は解決済み、7次元以上は未解決」という境界になっているのか？】**
> 上の表を見ると、「なぜちょうど $\dim X = 6$ と $\dim X = 7$ の間に境界があるのか？」と疑問に思われるかもしれません。これには、現在の極小モデル理論の到達点と直結する明確な理由があります。
>
> 1. **底空間が1次元のケース（$\dim Y = 1$）：** 底空間が曲線である $C_{n, 1}$ は、川又（1982）により任意の次元 $n$ で解決済みです。
> 2. **ファイバーが3次元以下のケース（$\dim F \le 3$）：** 川又の定理（1985）により、一般ファイバー $F$ の次元 $\dim F = n - m$ で「極小モデル予想」と「豊富性予想（後述）」が解けていれば $C_{n, m}^+$ が従います。現在、豊富性予想が無条件で証明されているのは **$\dim F \le 3$（3次元以下）** までです。したがって、$\dim F \le 3$ のケースも任意の次元 $n$ で解決済みです。
> 3. **$n \le 5$ と $n = 6$（Birkar の解決）：**
>
>     * 全体次元が $n \le 5$ であれば、どんな分解 $(\dim Y, \dim F)$ も「$\dim Y = 1$」または「$\dim F \le 3$」のどちらかに収まるため、上記の1・2だけで自動的に解決されます。
>     * **$n = 6$** になると、初めてどちらにも収まらない唯一の組み合わせ **$(\dim Y, \dim F) = (2, 4)$**（$C_{6, 2}$）が現れます。Birkar（2009）は、底空間が曲面（$\dim Y = 2$、エンリケス・小平分類が分かっている）であることと、4次元極小モデル理論の進展を組み合わせてこの $C_{6, 2}$ を解決し、$n \le 6$ 全体が証明されました。
>
> 4. **$n = 7$ に残る未解決ケース：**
>     全体次元が **$n = 7$** になると、**$(\dim Y, \dim F) = (2, 5)$** や **$(3, 4)$** といった、4次元以上の豊富性予想や5次元以上の極小モデル予想の未解決部分に直結する組み合わせが現れます（底空間 $Y$ が一般型・アーベル多様体、あるいはファイバー $F$ が一般型といった特殊なクラスを除き、一般には未解決のままです）。これが、現在 $n = 6$ と $n = 7$ の間に境界がある理由です。

### 4. 翻訳と展望（Bridge）：極小モデル理論（MMP）との関係と全7部の総括

#### (1) 極小モデル理論（MMP）との不可分な関係

上記の表にある川又の定理（1985年）が示す通り、飯高予想は現代の高次元代数幾何学の2大予想と直結しています。

1. **極小モデル予想（Minimal Model Conjecture）：** $\kappa(X) \ge 0$ の任意の非特異射影多様体 $X$ に対し、双有理同値な（緩やかな特異点を持つ）モデル $X_{\min}$ であって、標準因子 $K_{X_{\min}}$ が任意の曲線 $C$ と非負に交わる（$K_{X_{\min}} \cdot C \ge 0$、すなわち**ネフ / Nef**である）ものが存在する。
2. **豊富性予想（Abundance Conjecture）：** 極小モデル $X_{\min}$ において、$K_{X_{\min}}$ は単にネフであるだけでなく、十分大きな $m$ に対して $\vert{}mK_{X_{\min}}\vert{}$ が基底点を持たない（**半豊富 / Semi-ample**である。すなわち飯高ファイブレーションが不定点のない正則射として直接実現される）。

これら2つの予想が次元 $n - m$ で成り立てば、一般ファイバー $F$ が「良い極小モデル」を持つため、飯高予想 $C_{n, m}$ が自動的に従います。極小モデル予想は（$\kappa \ge 0$ で）現在も高次元では完全には解決されておらず（一般型については Birkar–Cascini–Hacon–McKernan (BCHM, 2010) によって任意の次元で解決済み）、豊富性予想は3次元までが解決されています。飯高予想の解決は、極小モデル理論の進展と表裏一体の関係にあります。

> **【コラム：極小モデル理論（MMP）は何をしているのか？ —— 2次元の「ブローダウン」と3次元の「フリップ」】**
> 本文で登場した極小モデル理論（Minimal Model Program : MMP）とは、「与えられた非特異射影多様体 $X$ と双有理同値な多様体の中から、余分な曲線や因子を取り除いた最も簡潔な代表元（**極小モデル**）を取り出すアルゴリズム」です。
>
> * **2次元（代数曲面）の極小モデル：$-1$ 曲線を潰す操作**
>     [4-4節](../4/4-4.md)で、曲面上の1点をブローアップすると例外曲線 $E \cong \mathbb{P}^1$（自己交点数 $E^2 = -1$、かつ $K_S \cdot E = -1 < 0$）が生まれることを見ました。
>     逆に、曲面 $S$ の上に $K_S \cdot C < 0$ を満たす $(-1)$-曲線があれば、それを1点に潰す（**ブローダウン**する）ことで、元の非特異な曲面に戻すことができます（カステルヌオーヴォの収縮定理）。2次元では、このブローダウンを有限回繰り返すだけで、必ず「すべての曲線 $C$ に対して $K_{S_{\min}} \cdot C \ge 0$（ネフ）」となる極小モデル（あるいは $\mathbb{P}^2$ や $\mathbb{P}^1$ 束）に到達します。
>
> * **3次元以上での現象と「フリップ（Flip）」：**
>     1980年代、森重文らによって3次元多様体へこのアルゴリズムを拡張しようとしたとき、2次元には存在しなかった新しい現象が現れました。
>
>     1. 曲面を潰して点や曲線にするとき、**端末特異点**と呼ばれる緩やかな特異点が避けられず、非特異多様体の世界だけでは閉じない。
>     2. 3次元空間の中で1本の曲線 $C$ だけ（余次元 $2$）を1点に潰すと、標準因子 $K$ がもはや $\mathbb{Q}$-カルティエ因子にすらならない特異点が生じてしまい、そこでプログラムが停止してしまう。
>
>     これを打開するのが**フリップ（Flip）**と呼ばれる双有理手術です。対象の曲線 $C$（$K_X \cdot C < 0$）を1点に潰したあと、別の方向から新しい曲線 $C^+$（今度は $K_{X^+} \cdot C^+ > 0$ と符号が反転している）を差し込んで空間を貼り替えます。森重文は1988年に3次元フリップの存在を証明し（1990年フィールズ賞受賞）、さらに BCHM（2010年）が任意の次元でのフリップの存在と、一般型・対数一般型多様体の極小モデルの存在を確立しました。
>
> [第0部](../index.md#part-0)から[第6部](../index.md#part-6)まで積み上げてきた「ブローアップ・特異点・標準因子・消滅定理・飯高次元」のすべてが、この極小モデル理論の体系へと繋がっています。

なお、本ノートを通じて前提としてきた「基礎体が複素数体 $\mathbb{C}$（標数 $0$）であること」の役割も、飯高予想の文脈で改めて確認できます。

> **【コラム：複素数体 $\mathbb{C}$ を離れた世界 —— 正標数 $p > 0$ における飯高予想の難しさ】**
> 飯高予想は複素数体 $\mathbb{C}$（標数 $0$）上で定式化されています。では、[1-1節](../1/1-1.md)や[1-3節](../1/1-3.md)で学んだ有限体 $\mathbb{F}_p$ の代数閉包のような**正標数 $p > 0$**（$p = 0$ となる世界）の上で同じ予想を考えると何が起きるでしょうか。
> 正標数では、本ノートで複素数体上の前提として使ってきた基本定理の多くが成り立たなくなります。
>
> 1. **小平消滅定理が成り立たない**（Raynaud による反例が存在する）。
> 2. **4次元以上の特異点解消が未解決**（[4-5節](../4/4-5.md)）。
> 3. **一般ファイバーが滑らかになるとは限らない：** 標数 $0$ では一般ファイバーは必ず非特異になりますが（一般滑らかさの定理）、標数 $p = 2, 3$ では、非特異な全体空間 $X$ から曲線 $Y$ へのファイバー空間であっても、**すべてのファイバーがカスプなどの特異点を持つ**という標数 $0$ にはない現象（準楕円ファイブレーション）が発生します。
>
> そのため、正標数における飯高予想は標数 $0$ とは異なる難しさを持っており、一般ファイバーの滑らかさなどの仮定を置いた上で、低次元（特に3次元以下や一部の高次元ケース）を中心に現在も研究が続けられています。本ノートで複素数体 $\mathbb{C}$ を舞台に選んだ背景には、複素解析の手法（ホッジ理論・消滅定理）と代数の手法を両立して使えるという理論的基盤があります。

#### (2) 全7部（第0部〜第6部）の総括

これで、学部レベルの基礎から飯高予想に至る全7部のカリキュラムが完了しました。最初から最後までの1本の繋がりを振り返ります。

* **[第0部](../index.md#part-0)（線形代数・微積分）：** 商空間・双対空間・ヤコビ行列による線形近似という共通の思考ツールを確立。
* **[第1部](../index.md#part-1)（代数学）：** 方程式をイデアル・剰余環・素イデアル・超越次数で扱う代数の言語を整備。
* **[第2部](../index.md#part-2)（多様体）：** 地図帳（アトラス）と最高次微分形式（標準束の原型）、および射影空間 $\mathbb{P}^n$ を構成。
* **[第3部](../index.md#part-3)（リーマン面）：** 1次元曲線上で正則性・極・種数 $g$・因子・リーマン・ロッホの定理を通じて、小平次元の原型を実験。
* **[第4部](../index.md#part-4)（代数幾何学の基礎）：** ヒルベルトの零点定理とザリスキ位相で代数と幾何を統合し、高次元特有の双有理同値・ブローアップ・特異点解消を導入。
* **[第5部](../index.md#part-5)（層・直線束・コホモロジー）：** 因子 $D$ と直線束 $\mathcal{O}_X(D)$、標準束 $\omega_X$、および大域切断と障害を測るコホモロジー群 $H^i(X, \mathcal{F})$・消滅定理を習得。
* **[第6部](../index.md#part-6)（飯高理論）：** すべての道具を統合し、飯高次元 $\kappa(X, D)$・小平次元 $\kappa(X)$・飯高ファイブレーション・飯高予想 $C_{n, m}$ の定式化と現在地に到達。
