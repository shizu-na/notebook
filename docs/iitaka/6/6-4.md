### 前節（6-3）の確認問題の解答

前回の確認問題（6-3節）の答え合わせから始めます。

1. $X = S \times C$（$S$ は K3曲面：$\dim S = 2, \; \kappa(S) = 0$、$C$ は種数 $3$ の曲線：$\dim C = 1, \; \kappa(C) = 1$）の小平次元は、直積の加法性より $\kappa(X) = 0 + 1 = \mathbf{1}$ です。
    このとき、$X$ の飯高ファイブレーションは第2射影 $\operatorname{pr}_2 : S \times C \to C$ であり、底空間は $Y_\infty = C$（$\dim Y_\infty = 1, \; \kappa(Y_\infty) = 1$）、一般ファイバーは $F = S$（$\dim F = 2, \; \kappa(F) = 0$）となります。

2. $\kappa(Y) = -\infty, \; \kappa(F) = 0$ より、右辺は $-\infty + 0 = -\infty$ です。左辺は $\kappa(X) = 1$ なので、$1 \ge -\infty$ となり、飯高予想の不等式は（真の不等号で）成り立っています。

## 6-4. 飯高予想（$C_{n, m}$ 予想）の定式化と現在地

### 1. 動機（Why）：なぜファイバー空間における加法性 $\kappa(X) \ge \kappa(Y) + \kappa(F)$ が重要なのか？

高次元の非特異射影多様体 $X$ を調べる際、より低い次元の多様体 $Y$ への代数ファイバー空間 $f : X \to Y$（6-3節）を構成し、「底空間 $Y$」と「一般ファイバー $F = f^{-1}(y)$」という2つの低次元部品に分解して解析するのが基本手法です（たとえば、飯高ファイブレーションや、アーベル多様体へのアルバネーゼ写像など）。

このとき、「部品である $Y$ と $F$ の複雑さ（小平次元）が分かっているとき、全体空間 $X$ の複雑さはどう制約されるか？」という問いが必然的に生じます。

* もし直積 $X = Y \times F$ であれば、6-1節の命題3より $\kappa(X) = \kappa(Y) + \kappa(F)$ が等号で成り立ちます。
* 6-3節の最後で見たように、一般のファイバー空間では「ファイバーのねじれや特異ファイバーの存在」が正の寄与を生み、$\kappa(X)$ が $\kappa(Y) + \kappa(F)$ より大きくなることがあります。
* では逆に、**ねじれによって小平次元が相殺され、$\kappa(X) < \kappa(Y) + \kappa(F)$ となってしまうようなファイバー空間は存在するのか？**

「そのような相殺は決して起きない」と主張するのが、飯高茂が1971年に提唱した飯高予想（Iitaka's conjecture $C_{n, m}$）です。もしこの予想が成り立てば、たとえば「底空間 $Y$ も一般ファイバー $F$ も一般型（$\kappa(Y) = m, \; \kappa(F) = n - m$）であれば、全体空間 $X$ も必ず一般型（$\kappa(X) = n$）になる」といった、高次元分類の基本法則が帰納的に保証されます。

---

### 2. 具体例・実験（Toy Model）：自明なケース・真の不等号・逆向きの不等式

#### 実験A：$\kappa(Y) = -\infty$ または $\kappa(F) = -\infty$ の場合（予想が自動的に成り立つケース）

飯高予想の右辺 $\kappa(Y) + \kappa(F)$ は、$-\infty$ との和を常に $-\infty$ と規約しています。
したがって、**$\kappa(Y) = -\infty$ または $\kappa(F) = -\infty$** であれば、右辺は $-\infty$ となり、任意の $\kappa(X) \in \{-\infty, 0, 1, \dots, n\}$ に対して $\kappa(X) \ge -\infty$ が自動的に成立します。

つまり、飯高予想の本質的に非自明な部分は、**$\kappa(Y) \ge 0$ かつ $\kappa(F) \ge 0$** の場合です。
特に、次の「最低限の非消滅」を示すことだけでも極めて強力な主張になります：

> 「$\kappa(Y) \ge 0$ かつ $\kappa(F) \ge 0$ ならば、$\kappa(X) \ge 0$（すなわち、ある $m \ge 1$ で $P_m(X) \ge 1$）」

#### 実験B：逆向きの不等式（飯高の容易な不等式 / Easy Addition）

飯高予想の主張とは逆向きの「上界」については、一般のファイバー空間 $f : X \to Y$（$\dim X = n, \; \dim Y = m$）に対して次の不等式が初等的に成り立ちます：


$$\kappa(X) \;\le\; \kappa(F) + \dim Y \qquad (\text{飯高の容易な不等式})$$

* **導出の仕組み：** もし $\kappa(F) = -\infty$ であれば、すべての $m \ge 1$ で $H^0(F, mK_F) = 0$ です。$X$ 上に $0$ でない切断 $s \in H^0(X, mK_X)$ があれば、一般ファイバー $F$ への制限 $s\vert{}_F \in H^0(F, mK_X\vert{}_F) = H^0(F, mK_F)$ も $0$ でなくなるため矛盾します。よって $\kappa(X) = -\infty$ となり成立します。
* $\kappa(F) \ge 0$ の場合も、十分大きな $m$ に対して $X$ 上の切断 $H^0(X, mK_X)$ は「底空間 $Y$ 方向の自由度（高々 $O(m^{\dim Y})$）」と「ファイバー $F$ 方向の自由度（$O(m^{\kappa(F)})$）」の積で上から押さえられるため、増大度は高々 $\kappa(F) + \dim Y$ 以下になります。

この容易な不等式と飯高予想を組み合わせると、


$$\kappa(Y) + \kappa(F) \;\le\; \kappa(X) \;\le\; \dim Y + \kappa(F)$$


という挟み撃ちが得られます。特に、底空間 $Y$ が一般型（$\kappa(Y) = \dim Y$）のときは、両端が一致して等号 $\kappa(X) = \dim Y + \kappa(F)$ が強制されます。

#### 実験C：$\mathbb{P}^1$ 束と楕円曲面での対比

* **$\mathbb{P}^1$ 束 $f : X \to C$（$C$ は種数 $g \ge 2$ の曲線）：**
    $\kappa(C) = 1$、ファイバー $F = \mathbb{P}^1$ は $\kappa(F) = -\infty$。容易な不等式より $\kappa(X) = -\infty$ となり、$-\infty \ge 1 + (-\infty) = -\infty$ で成立。

* **楕円曲面 $f : S \to C$（$C$ は種数 $g \ge 2$ の曲線、$F = E$ は楕円曲線）：**
    $\kappa(C) = 1, \; \kappa(E) = 0$。上の挟み撃ちより $1 + 0 \le \kappa(S) \le 1 + 0$ となり、どのような楕円曲面であっても必ず $\kappa(S) = 1$ に確定します。

### 3. 厳密な定義と定理（What）：飯高予想・証明の基本戦略・現在地

#### (1) 飯高予想（$C_{n, m}$ 予想）と飯高・フィーヴェグ予想（$C_{n, m}^+$ 予想）

> **【予想1：飯高予想（$C_{n, m}$ 予想 / Iitaka, 1971）】**
> 複素数体 $\mathbb{C}$ 上の非特異射影代数多様体の間の代数ファイバー空間 $f : X \to Y$（$\dim X = n, \; \dim Y = m$）と、その一般ファイバー $F = f^{-1}(y)$（$\dim F = n - m$）に対して、次が成り立つ：
> 
> $$\kappa(X) \;\ge\; \kappa(Y) + \kappa(F)$$

さらに、6-3節の最後で見た「ファイバーの形状が底空間の上でどれだけ本質的に変化しているか（モジュライの変化の次元）」を数値化したものを $f$ の**変分（Variation）$\operatorname{var}(f) \in \{0, 1, \dots, m\}$** と呼びます（直積や局所自明な束なら $\operatorname{var}(f) = 0$、底空間のすべての方向でファイバーの同型類が変化していれば $\operatorname{var}(f) = m$）。これを用いて飯高予想を精密化したものが次の予想です。

> **【予想2：飯高・フィーヴェグ予想（$C_{n, m}^+$ 予想 / Viehweg, 1983）】**
> $C_{n, m}$ と同じ設定において、$\kappa(Y) \ge 0$ であれば次が成り立つ：
> 
> $$\kappa(X) \;\ge\; \kappa(F) + \max\big\{\kappa(Y), \, \operatorname{var}(f)\big\}$$

---

#### (2) 証明の原理と基本戦略（相対標準束と弱正値性）

飯高予想の証明において、現代の代数幾何学が用いる中心的な仕掛けを、第5部までの言語で整理します。

1. **相対標準因子（Relative canonical divisor）$K_{X/Y}$ の導入：**
    $X$ と $Y$ の標準因子の差を

    $$K_{X/Y} := K_X - f^* K_Y \qquad \big(\text{直線束では } \omega_{X/Y} := \omega_X \otimes f^* \omega_Y^{-1}\big)$$

    と定義します。すると、$X$ の標準因子は

    $$K_X = K_{X/Y} + f^* K_Y$$

    と分解されます。また、一般ファイバー $F$ の上では $f^* K_Y\vert{}_F \sim 0$ なので、$K_{X/Y}\vert{}_F \sim K_F$ です。

2. **押し出し層（順像層）$f_* \mathcal{O}_X(mK_{X/Y})$ の「弱正値性（Weak positivity）」：**
    射影公式（層の押し出しの基本公式）を用いると、$X$ 上の多重標準空間 $H^0(X, mK_X)$ は、底空間 $Y$ 上の層の大域切断として

    $$H^0\big(X, \, \mathcal{O}_X(mK_X)\big) \;\cong\; H^0\Big(Y, \, f_* \mathcal{O}_X(mK_{X/Y}) \otimes \mathcal{O}_Y(mK_Y)\Big)$$

    と書き換えることができます。

    * ここで $Y$ 上の層 $\mathcal{E}_m := f_* \mathcal{O}_X(mK_{X/Y})$ は、一般の点 $y \in Y$ におけるファイバーが $H^0(F_y, mK_{F_y})$（次元 $P_m(F)$）となるベクトル束（正確には捩れなし連接層）です。
    * もし $\mathcal{E}_m$ が「正の方向を向いている（豊富な直線束を少し足すと大域切断で生成される＝**弱正値 / Weakly positive**）」であれば、$\mathcal{E}_m$ と $\mathcal{O}_Y(mK_Y)$ のテンソル積の切断の次元が $P_m(F)$ と $P_m(Y)$ の積のオーダーを下回らないことが導かれます。
    * フィーヴェグ（1983年）は、**川又・フィーヴェグ消滅定理**（5-3節の小平消滅定理の一般化）と**ホッジ理論（ホッジ構造の変分）**、および巡回被覆トリックを組み合わせることで、任意の $m \ge 1$ に対して**押し出し層 $f_* \mathcal{O}_X(mK_{X/Y})$ が弱正値である**という画期的な定理を証明しました。
    * この弱正値性から、底空間 $Y$ が一般型（$\kappa(Y) = m$）の場合の $C_{n, m}^+$ が直ちに従います。

---

#### (3) 解決済みの主な結果と現在地（2026年時点）

飯高予想 $C_{n, m}$ は、**一般の次元 $n \ge 7$ においては現在も未解決**ですが、低次元および多くの重要なクラスにおいて証明が完了しています。主要な到達点は以下の通りです。

| 解決された条件・クラス | 証明者・年 | 概要・使用された主な手法 |
| --- | --- | --- |
| **$\dim Y = 1$**（底空間が曲線） | 川又雄二郎（1982） | 押し出し層 $f_* \mathcal{O}_X(mK_{X/Y})$ の半正値性（ホッジ理論）。 |
| **$Y$ が一般型**（$\kappa(Y) = m$） | E. Viehweg（1983） | $f_* \mathcal{O}_X(mK_{X/Y})$ の弱正値性により $C_{n, m}^+$ を証明。 |
| **$F$ が一般型**（$\kappa(F) = n - m$） | J. Kollár（1987） | ホッジ理論・消滅定理により $C_{n, m}^+$ を証明（後に極小モデル理論からも従う）。 |
| **$F$ が良い極小モデルを持つ場合** | 川又雄二郎（1985） | ファイバー $F$ の次元で「極小モデル予想」と「豊富性予想」が成り立てば $C_{n, m}^+$ が成立することを証明。 |
| **$\dim X = n \le 6$**（6次元以下すべて） | C. Birkar（2009） | 5次元以下の極小モデル理論と川又の定理、および $m = 2, \kappa(F) = 0$ の解析を統合して $n \le 6$ の $C_{n, m}$ を完全解決。 |
| **$Y$ がアーベル多様体**<br>（および最大アルバネーゼ次元の多様体） | J. Cao – M. Păun（2017）<br>C. Hacon – M. Popa – C. Schnell（2018） | 特異エルミート計量と $L^2$ 拡張定理による複素解析的証明（曹・パウン）、および一般消滅定理（Generic vanishing）を用いた純代数的証明（ヘイコン・ポパ・シュネル）。 |

（※なお、$\dim X = 7$ についても、追加の仮定のもとでの部分的結果（例：一般化された非消滅予想のもとでの成立や特定の条件付き結果）が近年も研究され続けていますが、無条件での完全解決は $n \le 6$ が現在の到達点です。）

### 4. 翻訳と展望（Bridge）：極小モデル理論（MMP）との関係と全7部の総括

#### (1) 極小モデル理論（MMP）との不可分な関係

上記の表にある川又の定理（1985年）が示す通り、飯高予想は現代の高次元代数幾何学の2大予想と直結しています。

1. **極小モデル予想（Minimal Model Conjecture）：** $\kappa(X) \ge 0$ の任意の非特異射影多様体 $X$ に対し、双有理同値な（緩やかな特異点を持つ）モデル $X_{\min}$ であって、標準因子 $K_{X_{\min}}$ が任意の曲線 $C$ と非負に交わる（$K_{X_{\min}} \cdot C \ge 0$、すなわち**ネフ / Nef**である）ものが存在する。
2. **豊富性予想（Abundance Conjecture）：** 極小モデル $X_{\min}$ において、$K_{X_{\min}}$ は単にネフであるだけでなく、十分大きな $m$ に対して $\vert{}mK_{X_{\min}}\vert{}$ が基底点を持たない（**半豊富 / Semi-ample**である。すなわち飯高ファイブレーションが不定点のない正則射として直接実現される）。

これら2つの予想が次元 $n - m$ で成り立てば、一般ファイバー $F$ が「良い極小モデル」を持つため、飯高予想 $C_{n, m}$ が自動的に従います。極小モデル予想は（$\kappa \ge 0$ で）現在も高次元では完全には解決されておらず（一般型については Birkar–Cascini–Hacon–McKernan (BCHM, 2010) によって任意の次元で解決済み）、豊富性予想は3次元までが完全解決されています。飯高予想の完全解決は、極小モデル理論の完成と表裏一体の関係にあります。

#### (2) 全7部（第0部〜第6部）の総括

これで、学部レベルの基礎から飯高予想に至る全7部のカリキュラムが完了しました。最初から最後までの1本の繋がりを振り返ります。

* **第0部（線形代数・微積分）：** 商空間・双対空間・ヤコビ行列による線形近似という共通の思考ツールを確立。
* **第1部（代数学）：** 方程式をイデアル・剰余環・素イデアル・超越次数で扱う代数の言語を整備。
* **第2部（多様体）：** 地図帳（アトラス）と最高次微分形式（標準束の原型）、および射影空間 $\mathbb{P}^n$ を構成。
* **第3部（リーマン面）：** 1次元曲線上で正則性・極・種数 $g$・因子・リーマン・ロッホの定理を通じて、小平次元の原型を実験。
* **第4部（代数幾何学の基礎）：** ヒルベルトの零点定理とザリスキ位相で代数と幾何を統合し、高次元特有の双有理同値・ブローアップ・特異点解消を導入。
* **第5部（層・直線束・コホモロジー）：** 因子 $D$ と直線束 $\mathcal{O}_X(D)$、標準束 $\omega_X$、および大域切断と障害を測るコホモロジー群 $H^i(X, \mathcal{F})$・消滅定理を習得。
* **第6部（飯高理論）：** すべての道具を統合し、飯高次元 $\kappa(X, D)$・小平次元 $\kappa(X)$・飯高ファイブレーション・飯高予想 $C_{n, m}$ の定式化と現在地に到達。
