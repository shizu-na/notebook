### 前節（6-2）の確認問題の解答

前回の確認問題（6-2節）の答え合わせから始めます。

1. $\mathbb{P}^3$ 内の次数 $d$ の非特異曲面 $S_d \subset \mathbb{P}^3$（$\dim S_d = 2$）の標準因子は $K_{S_d} \sim (d - 4) H\vert{}_{S_d}$ です。

    * $d = 3$：$d - 4 = -1 < 0$ より $\kappa(S_3) = \mathbf{-\infty}$（3次曲面）
    * $d = 4$：$d - 4 = 0$ より $\kappa(S_4) = \mathbf{0}$（K3曲面）
    * $d = 5$：$d - 4 = 1 > 0$ より $\kappa(S_5) = \mathbf{2}$（一般型曲面）

2. $\mathbb{P}^4$ 内の完全交差曲面 $X = V_+(F_1, F_2) \subset \mathbb{P}^4$（$\dim X = 2$）の標準因子は $K_X \sim (d_1 + d_2 - 5) H\vert{}_X$ です。

    * $(d_1, d_2) = (2, 2)$：$2 + 2 - 5 = -1 < 0$ より $\kappa(X) = \mathbf{-\infty}$
    * $(d_1, d_2) = (2, 3)$：$2 + 3 - 5 = 0$ より $\kappa(X) = \mathbf{0}$（K3曲面）
    * $(d_1, d_2) = (2, 4)$：$2 + 4 - 5 = 1 > 0$ より $\kappa(X) = \mathbf{2}$（一般型曲面）



---

それでは、「6-3. 飯高ファイブレーションの定理：中間的な小平次元をもつ多様体が、標準的にファイバー空間構造をもつことの証明の骨格」に進みます。

## 6-3. 飯高ファイブレーションの定理：中間クラス多様体の標準分解

### 1. 動機（Why）：なぜ中間的な小平次元の多様体を「ファイバー空間」に分解するのか？

前節（6-2節）で、$n$ 次元非特異射影多様体 $X$ は小平次元 $\kappa(X)$ によって次の4つのクラスに分かれることを見ました：


$$\kappa(X) = -\infty, \qquad \kappa(X) = 0, \qquad 1 \le \kappa(X) \le n - 1, \qquad \kappa(X) = n$$

このうち、$\kappa(X) = -\infty, \; 0, \; n$ の3つは幾何学的な性格がはっきりした「純粋なクラス」ですが、中間クラス（$0 < \kappa(X) < n$）は「ある方向には一般型のように複雑で、別の方向には平坦（または単純）である」という混成構造を持っています。

ここで、十分大きな $m$ に対する多重標準写像


$$\Phi_{\vert{}mK_X\vert{}} : X \dashrightarrow Y_m \subset \mathbb{P}^{P_m(X) - 1}$$


の像 $Y_m$ の次元が $\dim Y_m = \kappa(X)$ で頭打ちになることに注目します。$n$ 次元の空間 $X$ を $\kappa(X)$ 次元の空間 $Y_m$ へ写すと、各点の逆像（ファイバー）は $n - \kappa(X)$ 次元の部分多様体になります。

しかし、生の多重標準写像 $\Phi_{\vert{}mK_X\vert{}}$ をそのまま使うだけでは、次の3つの技術的な障害が残ります。

1. **不定点の存在：** $\Phi_{\vert{}mK_X\vert{}}$ は有理写像であり、$X$ 全体で定義された通常の射とは限らない。
2. **ファイバーの非連結性：** 像への写像に有限被覆（2重被覆など）が混ざり、一般ファイバーが複数個の連結成分に分かれてしまうことがある。
3. **$m$ への依存性：** $m$ を変えるたびに像 $Y_m$ が変化してしまうと、多様体 $X$ に固有の分解とは言えない。

これらの障害を双有理変換によってすべて整理し、**「$\kappa(X) \ge 0$ の多様体は、双有理同値を除いてただ1つの標準的なファイバー空間 $f_\infty : X_\infty \to Y_\infty$（$\dim Y_\infty = \kappa(X)$）を持ち、その一般ファイバー $F$ は必ず $\kappa(F) = 0$ になる」**ことを保証するのが**飯高ファイブレーションの定理**です。

---

### 2. 具体例・実験（Toy Model）：直積・ねじれた積・非連結ファイバーの解消

#### 実験A：直積多様体 $X = C \times E$ における多重標準写像

$C$ を種数 $g \ge 2$ の曲線（$\kappa(C) = 1$）、$E$ を楕円曲線（$\kappa(E) = 0$）とします。
直積曲面 $X = C \times E$（$\dim X = 2, \; \kappa(X) = 1$）の標準因子は、$K_E \sim 0$ より


$$K_X = \operatorname{pr}_1^* K_C + \operatorname{pr}_2^* K_E \sim \operatorname{pr}_1^* K_C$$


となります。キュネットの公式（6-1節）より、すべての $m \ge 1$ に対して


$$H^0(X, mK_X) \cong H^0(C, mK_C) \otimes_{\mathbb{C}} H^0(E, \mathcal{O}_E) \cong H^0(C, mK_C)$$


です（第2成分 $E$ 上の切断は定数 $1$ のみ）。
3-5節で見た通り、$m \ge 3$ ならば $\Phi_{\vert{}mK_C\vert{}} : C \hookrightarrow \mathbb{P}^{P_m(C) - 1}$ は同型埋め込みになります。したがって、$X$ の多重標準写像 $\Phi_{\vert{}mK_X\vert{}}$ は


$$C \times E \xrightarrow{\;\operatorname{pr}_1\;} C \hookrightarrow \mathbb{P}^{P_m(C) - 1}$$


となり、第1射影 $\operatorname{pr}_1 : C \times E \to C$ そのものを復元します。底空間は $C$（次元 $1 = \kappa(X)$）、すべてのファイバーは楕円曲線 $E$（$\kappa(E) = 0$）です。

#### 実験B：なぜ「十分大きな $m$」が必要か？（ファイバーが非連結になる例）

種数 $g = 2$ の曲線 $C$（$\dim C = 1, \; \kappa(C) = 1$）を考えます。
3-5節の確認問題で計算した通り、$m = 1$ のとき $P_1(C) = h^0(C, K_C) = 2$ なので、標準写像は


$$\Phi_{\vert{}K_C\vert{}} : C \longrightarrow \mathbb{P}^1$$


となります。この時点で既に像の次元は $\dim \mathbb{P}^1 = 1 = \kappa(C)$ に達しています。
しかし、$\deg K_C = 2g - 2 = 2$ であるため、この写像 $\Phi_{\vert{}K_C\vert{}}$ は **2対1の2重被覆** であり、一般の点 $y \in \mathbb{P}^1$ のファイバーは「2点（非連結）」になってしまいます。

ところが、$m = 3$ まで倍数を上げると $P_3(C) = 5$ となり、$\Phi_{\vert{}3K_C\vert{}} : C \hookrightarrow \mathbb{P}^4$ は同型埋め込み（1対1）に変わります。このとき一般ファイバーは「1点（連結、0次元、$\kappa(\text{点}) = 0$）」となり、それ以上 $m$ を大きくしても像は $C$ 自身で完全に安定します。
このように、「像の次元が最大値 $\kappa$ に達した最初の $m$」ではまだ有限被覆が混ざっている可能性があり、**関数体の拡大が完全に止まる十分大きな $m$** をとる必要があります。

### 3. 厳密な定義と定理（What）：代数ファイバー空間と飯高ファイブレーションの定理

#### (1) 代数ファイバー空間の定義

> **【定義：代数ファイバー空間（Algebraic fiber space）】**
> 複素数体 $\mathbb{C}$ 上の非特異射影代数多様体の間の全射な射 $f : X \to Y$ であって、次の互いに同値な条件のいずれか（したがってすべて）を満たすものを**代数ファイバー空間**と呼ぶ。
>
> 1. $f$ のすべてのファイバー $f^{-1}(y)$（$y \in Y$）が連結である（同値条件：一般の点 $y \in Y$ のファイバー $f^{-1}(y)$ が連結である）。
> 2. 層の押し出しについて $f_* \mathcal{O}_X = \mathcal{O}_Y$ が成り立つ。
> 3. 引き戻しによる有理関数体の埋め込み $f^* : K(Y) \hookrightarrow K(X)$ において、$K(Y)$ は $K(X)$ の中で**代数的に閉じている**（$K(X)$ の元が $K(Y)$ 上で代数方程式を満たすならば、最初から $K(Y)$ の元である）。

（※条件1〜3の同値性は、射影射の**シュタイン分解 / Stein factorization**とザリスキの主定理に基づく基本事実です。直感的には、条件3が「$f$ の中に非自明な有限被覆（体の有限次代数拡大）が混ざっていないこと」を代数的に保証しています。）

なお、標数 $0$（複素数体 $\mathbb{C}$ 上）の**一般滑らかさの定理（Generic smoothness / サードの定理の代数版）**により、代数ファイバー空間 $f : X \to Y$ に対して、空でないザリスキ開集合 $U \subset Y$ が存在し、すべての $y \in U$ に対するファイバー $F_y = f^{-1}(y)$ は、次元 $\dim X - \dim Y$ の**連結な非特異射影多様体**になります。

---

#### (2) 飯高ファイブレーションの定理

> **【定理：飯高ファイブレーションの定理（Iitaka, 1971）】**
> $X$ を複素数体 $\mathbb{C}$ 上の非特異射影代数多様体とし、$D$ を $\kappa(X, D) \ge 0$ を満たす因子とする。$e := \gcd N(X, D)$ とおく。
> このとき、以下の4条件を満たす代数ファイバー空間 $f_\infty : X_\infty \to Y_\infty$（**$D$ に付随する飯高ファイブレーション**）が存在し、双有理同値を除いてただ1つに定まる。
>
> 1. $X_\infty, Y_\infty$ は非特異射影多様体であり、双有理射 $\mu : X_\infty \to X$ が存在する。
> 2. 十分大きなすべての $k$（$m = ke$）に対し、多重線形系による有理写像 $\Phi_{\vert{}mD\vert{}} : X \dashrightarrow Y_m$ は $f_\infty : X_\infty \to Y_\infty$ と双有理同値である（すなわち双有理写像 $u_m : Y_\infty \dashrightarrow Y_m$ が存在して $u_m \circ f_\infty = \Phi_{\vert{}mD\vert{}} \circ \mu$ を満たす）。特に、
> 
>     $$\dim Y_\infty = \kappa(X, D)$$
> 
> 3. $Y_\infty$ の**非常に一般的な点** $y \in Y_\infty$（可算個の真のザリスキ閉集合を除いた点）の上のファイバー $F_y = f_\infty^{-1}(y)$ に対し、制限された因子の飯高次元は $0$ である：
> 
>     $$\kappa\big(F_y, \, (\mu^* D)\vert{}_{F_y}\big) = 0$$
> 
> 4. **標準因子 $D = K_X$（$\kappa(X) \ge 0$）の場合：**
>     一般ファイバー $F = f_\infty^{-1}(y)$ の小平次元自身が $0$ になる：
> 
>     $$\kappa(F) = 0$$

* **【補足：「非常に一般的な点」と「一般的な点」の違い】**
    一般の因子 $D$ の場合、各 $m \ge 1$ ごとに $h^0(F_y, m(\mu^* D)\vert{}_{F_y})$ が最小値をとるのは空でないザリスキ開集合 $U_m \subset Y_\infty$ 上であり、すべての $m \ge 1$ で同時に成り立つ領域は可算共通部分 $\bigcap_{m \ge 1} U_m$（非常に一般的な点の集合）となります。
    一方、標準因子 $D = K_X$ の場合は、後のシウの多重種数の変形不変性（Siu, 1998, 2002）により、滑らかなファイバー $F_y$ の多重種数 $P_m(F_y)$ が $y$ によらず完全に一定になることが証明されたため、単に「一般的な点（空でない1つのザリスキ開集合上のすべての点）」に対して $\kappa(F_y) = 0$ が成り立ちます。

---

#### (3) 証明の原理と骨格（3段階）

##### 1. 原理のイメージ（心臓部）

なぜ一般ファイバー $F$ の上で $\kappa(F, (\mu^* D)\vert{}_F) = 0$ にぴったり決まるのか、直感的な仕組みは以下の挟み撃ちです。

* **下界 $\ge 0$ の理由：** 全体空間 $X_\infty$ の上に $0$ でない切断 $s \in H^0(X_\infty, m\mu^* D)$ が存在するなら、$s$ が $0$ になるのは真の閉集合だけなので、一般のファイバー $F$ に制限しても $s\vert{}_F$ は $0$ になりません。よって $F$ の上にも切断が存在し、$\kappa(F, (\mu^* D)\vert{}_F) \ge 0$ です。
* **上界 $\le 0$ の理由：** もし一般ファイバー $F$ の上で $\kappa(F, (\mu^* D)\vert{}_F) \ge 1$ だったとすると、$F$ の上で「$m$ を増やすと定数以外の独立な関数がどんどん増える」ことになります。それらを底空間 $Y_\infty$ 上の関数と組み合わせれば、全体空間 $X_\infty$ の上で $\dim Y_\infty = \kappa(X, D)$ よりも高い次元の増大度が得られてしまい、「$\kappa(X, D)$ が最大次元である」という定義と矛盾します。

##### 2. 本質的ステップ（構成と背理法の骨格）

* **ステップ1：比の体 $K(X, D)$ の安定化と底空間 $Y_\infty$ の構成**
    6-1節で導入した、同じ次数の切断の比が生成する部分体

    $$K(X, D) := \bigcup_{m \in N(X, D)} K_m \;\subset\; K(X)$$

    を考えます（ここで $K_m \cong K(Y_m)$ は $\Phi_{\vert{}mD\vert{}}$ の像の有理関数体）。
    $K(X)$ は $\mathbb{C}$ 上有限生成な体であり、体論の基本事実によりその任意の部分体も $\mathbb{C}$ 上有限生成です。したがって、$K(X, D)$ の有限個の生成元をすべて含むような十分大きな $m_0 \in N(X, D)$ が存在し、その $m_0$ に対して $K_{m_0} = K(X, D)$ となります。
    さらに、$K(X, D)$ の $K(X)$ 内での代数的閉包を $\widetilde{K}$ とおきます。$\widetilde{K}$ も有限生成であり、$K(X, D)$ の有限次代数拡大です（実際、ある十分大きな $m_1$ で $K_{m_1}$ がすでに $\widetilde{K}$ に一致することも示されます）。
    この体 $\widetilde{K}$ を有理関数体とする非特異射影多様体 $Y_\infty$ を1つとります（4-5節の広中の特異点解消）。6-1節の定理1より $\dim Y_\infty = \operatorname{tr.deg}_{\mathbb{C}} \widetilde{K} = \operatorname{tr.deg}_{\mathbb{C}} K(X, D) = \kappa(X, D)$ です。

* **ステップ2：不定点の解消による代数ファイバー空間の完成**
    体の埋め込み $K(Y_\infty) = \widetilde{K} \hookrightarrow K(X)$ は支配的有理写像 $X \dashrightarrow Y_\infty$ を定めます。4-5節の広中の定理（不定点の解消）により、双有理射 $\mu : X_\infty \to X$（$X_\infty$ は非特異射影多様体）をとることで、合成 $f_\infty : X_\infty \to Y_\infty$ が不定点のない通常の射になります。$K(Y_\infty)$ は $K(X_\infty)$ 内で代数的に閉じているため、定義より $f_\infty$ は**代数ファイバー空間**です。

* **ステップ3：一般ファイバー上で $\kappa(F_y, (\mu^* D)\vert{}_{F_y}) = 0$ の導出**
    $\kappa(F_y, (\mu^* D)\vert{}_{F_y}) \ge 0$ は原理で述べた通りです。
    逆に、もし非常に一般的な点 $y \in Y_\infty$ に対して $\kappa(F_y, (\mu^* D)\vert{}_{F_y}) \ge 1$ であると仮定します。
    すると、ある $m_2 \in N(X, D)$ に対して、一般ファイバー上で $h^0(F_y, m_2 (\mu^* D)\vert{}_{F_y}) \ge 2$ となります。
    ここで $Y_\infty$ 上の非常に豊富な因子 $H$ をとります。$Y_\infty$ はもともとある $\vert{}m_1 D\vert{}$ の像（の双有理モデル）であるため、十分大きな整数 $r$ を選べば、$X_\infty$ 上で

    $$r \mu^* D - f_\infty^* H \ge 0 \qquad (\text{すなわち } f_\infty^* H \text{ は } r\mu^* D \text{ の一部で押さえられる})$$

    が成り立ちます。
    一方、$H$ を十分大きくとると、$F_y$ 上で線形独立な2つの切断（$h^0 \ge 2$）を $Y_\infty$ 方向の切断と掛け合わせることで、$X_\infty$ 上の直線束 $\mathcal{O}_{X_\infty}(m_2 \mu^* D + f_\infty^* H)$ の切断が、ファイバー $F_y$ 上の2点をも分離するようになります。つまり、$\Phi_{\vert{}m_2 \mu^* D + f_\infty^* H\vert{}}$ の像の次元は $\dim Y_\infty + 1 = \kappa(X, D) + 1$ 以上になります。
    ところが $r \mu^* D - f_\infty^* H \ge 0$ より、包含

    $$H^0\big(X_\infty, \, m_2 \mu^* D + f_\infty^* H\big) \;\hookrightarrow\; H^0\big(X_\infty, \, (m_2 + r) \mu^* D\big)$$

    が存在するため、$\kappa(X_\infty, (m_2 + r)\mu^* D) \ge \kappa(X, D) + 1$ となります。これは6-1節の命題1（$\kappa(X_\infty, (m_2 + r)\mu^* D) = \kappa(X, D)$）に矛盾します。
    よって $\kappa(F_y, (\mu^* D)\vert{}_{F_y}) = 0$ が示されます。

* **ステップ4：$D = K_X$ の場合に $\kappa(F) = 0$ となる理由（1行の仕上げ）**
    6-2節の定理1（分岐公式 $K_{X_\infty} \sim \mu^* K_X + E$、$E \ge 0$ は $\mu$-例外的）と6-1節の命題2より、すべての $m \ge 1$ に対して $H^0(X_\infty, mK_{X_\infty}) = H^0(X_\infty, m\mu^* K_X)$ が成り立ちます。すなわち、$K_X$ に付随する飯高ファイブレーション $f_\infty : X_\infty \to Y_\infty$ は、**$X_\infty$ 自身の標準因子 $K_{X_\infty}$ に対する飯高ファイブレーションそのもの**です。
    したがって、主張3を $X_\infty$ 上の因子 $K_{X_\infty}$ に直接適用すれば $\kappa(F, K_{X_\infty}\vert{}_F) = 0$ が得られます。
    さらに、一般ファイバー $F = f_\infty^{-1}(y)$ は射のファイバーであるため法束が自明であり、随伴公式より **$K_F \sim K_{X_\infty}\vert{}_F$** です。よって

    $$\kappa(F) = \kappa(F, K_F) = \kappa(F, K_{X_\infty}\vert{}_F) = 0$$

    が完全に導かれます。（証明終）

##### 3. 技術的詳細の切り分け（ここで省略したステップの明示）

* ステップ1において、$\widetilde{K}$（代数的閉包）が実際に「十分大きな1つの $m_1$ に対する $K_{m_1}$ そのものに一致する（つまり有限被覆が $m$ を上げれば自然に解消される）」ことの証明には、切断環 $R(X, D)$ の整閉包の有限性に関する可換環論の議論を用います。
* ステップ3において、一般ファイバー上の $h^0 \ge 2$ から全体空間の切断 $H^0(X_\infty, m_2 \mu^* D + f_\infty^* H)$ がファイバーの点を分離することを厳密に示すには、押し出し層（順像層）$f_{\infty*} \mathcal{O}_{X_\infty}(m_2 \mu^* D)$ が $Y_\infty$ 上の階数 $\ge 2$ の捩れなし連接層であることと、セールの定理（十分豊富な直線束 $\mathcal{O}_{Y_\infty}(H)$ をテンソルすると大域切断で生成されること）を用います。また、6-1節で保留していた飯高の不等式の上界 $h^0(X, mD) \le \beta m^\kappa$ も、まさにこの $\kappa(F_y, (\mu^* D)\vert{}_{F_y}) = 0$（押し出し層の階数が $1$ であること）から直ちに導出されます。

### 4. 翻訳と展望（Bridge）：重要な注意点と次節「飯高予想」への直結

飯高ファイブレーションの定理から、次節の飯高予想（$C_{n, m}$ 予想）へ進む前に、最も誤解しやすいポイントを1つ確認しておきます。

> **【重要な注意点】**
> 飯高ファイブレーション $f_\infty : X_\infty \to Y_\infty$ において、一般ファイバーは必ず $\kappa(F) = 0$ ですが、**底空間 $Y_\infty$ の小平次元 $\kappa(Y_\infty)$ は一般型（$= \dim Y_\infty$）であるとは限りません。** $\kappa(Y_\infty) = -\infty$ になることすら頻繁に起こります。

* **具体例（$\mathbb{P}^1$ 上の楕円曲面）：**
    底空間が射影直線 $Y = \mathbb{P}^1$（$\kappa(\mathbb{P}^1) = -\infty$）、一般ファイバーが楕円曲線 $E$（$\kappa(E) = 0$）であるような非特異射影曲面 $f : S \to \mathbb{P}^1$ を考えます。

    * もし直積 $S = \mathbb{P}^1 \times E$ であれば、$\kappa(S) = -\infty + 0 = -\infty$ です。
    * しかし、底空間 $\mathbb{P}^1$ のいくつかの点の上に「重複ファイバー（多重度 $m_i \ge 2$ の特異ファイバー）」や「$j$-不変量が変化する特異ファイバー」を十分多く持つようにねじって構成した楕円曲面 $S \to \mathbb{P}^1$ では、小平の標準束公式により全体空間の小平次元が **$\kappa(S) = 1$** になります。
    * このとき、この射 $f : S \to \mathbb{P}^1$ 自身が $S$ の飯高ファイブレーションですが、$\kappa(S) = 1$ に対して底空間は $\kappa(\mathbb{P}^1) = -\infty$、ファイバーは $\kappa(E) = 0$ です。

この現象は、次節で扱う**飯高予想（$C_{n, m}$ 予想）**

$$\kappa(X) \ge \kappa(Y) + \kappa(F)$$

が、なぜ等号ではなく**不等号（$\ge$）**でなければならないのかを明確に示しています。ファイバーが底空間の上で非自明に変化（ねじれ）したり特異ファイバーを持ったりすると、その「変化の激しさ（モジュライの変化）」が正の曲率／正の寄与を生み出し、全体空間の小平次元 $\kappa(X)$ を底空間とファイバーの和 $\kappa(Y) + \kappa(F)$ よりも**真に大きく押し上げる**ことがあるのです。

逆に、**「どんなにねじれたファイバー空間であっても、全体空間の小平次元が部品の和 $\kappa(Y) + \kappa(F)$ を下回ることは決してないのか？」**——この根源的な問いが、次節（最終節）の飯高予想そのものです。
