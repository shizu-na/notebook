### 前節（6-1）の確認問題の解答

前節の確認問題（[6-1節](6-1.md)）の答え合わせから始めます。

1. キュネットの公式より、$h^0(X, \mathcal{O}_X(ma, mb)) = h^0(\mathbb{P}^1, \mathcal{O}_{\mathbb{P}^1}(ma)) \cdot h^0(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2}(mb))$ です。

    * **$(a, b) = (0, 1)$ のとき：**

        $$h^0(X, \mathcal{O}_X(0, m)) = 1 \cdot \frac{(m + 2)(m + 1)}{2} = \frac{1}{2}m^2 + \frac{3}{2}m + 1$$

        $m$ の2次式なので、$\kappa(X, D) = \mathbf{2}$ です（直積の加法性からも $0 + 2 = 2$）。

    * **$(a, b) = (1, 1)$ のとき：**

        $$h^0(X, \mathcal{O}_X(m, m)) = (m + 1) \cdot \frac{(m + 2)(m + 1)}{2} = \frac{1}{2}m^3 + 2m^2 + \frac{5}{2}m + 1$$

        $m$ の3次式なので、$\kappa(X, D) = \mathbf{3}$ です（直積の加法性からも $1 + 2 = 3$）。

2. **$(a, b) = (1, -1)$ のとき：**
    すべての $m \ge 1$ に対して $-m < 0$ より $h^0(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2}(-m)) = 0$ となるため、積は常に $0$ です。よって $N(X, D) = \emptyset$ となり、$\kappa(X, D) = \mathbf{-\infty}$ です。

---

それでは、「6-2. 小平次元 $\kappa(X)$ による多様体の分類：$\kappa = -\infty, 0, \text{中間}, \dim X$ の4クラスの幾何学的特徴と具体例」に進みます。

## 6-2. 小平次元 $\kappa(X)$ による多様体の分類

### 1. 動機（Why）：なぜ「標準因子 $K_X$」の飯高次元を分類の主軸にするのか？

[6-1節](6-1.md)で定義した飯高次元 $\kappa(X, D)$ は、空間 $X$ 上にどの因子 $D$ を選ぶかによって値が変わる量でした。
多様体 $X$ そのものを分類するための固有の不変量を得るには、外部から恣意的に因子を選ぶのではなく、**多様体 $X$ が自身の幾何学構造から生まれつき持っている標準的な因子**を1つ固定する必要があります。

その役割を担うのが、[2-4節](../2/2-4.md)・[5-2節](../5/5-2.md)で構成した最高次微分形式の束である**標準束 $\omega_X = \bigwedge^n \Omega^1_X$**（およびそれに対応する**標準因子 $K_X$**）です。
$K_X$ に飯高次元を適用した $\kappa(X) := \kappa(X, K_X)$ が分類の主軸として選ばれる理由は2つあります。

1. **双有理不変性：** [4-4節](../4/4-4.md)で見たように、2次元以上ではブローアップによって同型類が無限に増えますが、$\kappa(X)$ はブローアップなどの双有理変換によって一切変化しない（双有理不変量）。
2. **1次元曲線の種数分類の自然な拡張：** [第3部](../index.md#part-3)（[3-5節](../3/3-5.md)）で確認した通り、1次元曲線では $\kappa(X)$ が $-\infty$（$g=0$）、$0$（$g=1$）、$1$（$g \ge 2$）の3つに分かれ、幾何学的性質（曲率の符号）と完全に一致していました。

---

### 2. 具体例・実験（Toy Model）：超曲面と直積による4クラスの手計算

高次元多様体における小平次元の4つの値（$-\infty, 0, \text{中間}, \dim X$）が、具体的な方程式や構成からどのように現れるかを計算します。

#### 実験A：射影空間 $\mathbb{P}^n$ 内の次数 $d$ の非特異超曲面 $X_d \subset \mathbb{P}^n$（$n \ge 2$）

射影空間 $\mathbb{P}^n$ において、次数 $d \ge 1$ の斉次多項式 $F(X_0, \dots, X_n) = 0$ が定める $(n - 1)$ 次元の非特異射影多様体（超曲面）$X_d$ を考えます。

超平面因子を $H$（対応する直線束は $\mathcal{O}_{\mathbb{P}^n}(1)$）とすると、次の2つの事実が成り立ちます。

* [2-5節](../2/2-5.md)（展望）より、$\mathbb{P}^n$ の標準因子は $K_{\mathbb{P}^n} \sim -(n + 1)H$。
* $X_d$ は $d$ 次斉次多項式の零点なので、因子として $X_d \sim dH$。

ここで、[5-3節](../5/5-3.md)（展望）で導入した**随伴公式** $K_{X_d} \sim (K_{\mathbb{P}^n} + X_d)\vert{}_{X_d}$ を適用すると、$X_d$ の標準因子が1行で求まります：


$$K_{X_d} \sim \big(-(n + 1)H + dH\big)\big\vert{}_{X_d} = (d - n - 1) H\vert{}_{X_d}$$

超平面切断の制限 $H\vert{}_{X_d}$ は $X_d$ を元の $\mathbb{P}^n$ へそのまま埋め込む豊富な因子であるため、$\kappa(X_d, H\vert{}_{X_d}) = \dim X_d = n - 1$ です。したがって、係数 $(d - n - 1)$ の符号によって、小平次元 $\kappa(X_d)$ は次のように3つに完全に分かれます。

1. **$d \le n$ のとき（$d - n - 1 < 0$）：**
    $mK_{X_d}$ は負の豊富な因子 $-L$（$L := m(n + 1 - d)H\vert{}_{X_d}$ は豊富）となるため、すべての $m \ge 1$ で $h^0(X_d, mK_{X_d}) = 0$ となり（もし非零切断 $s \in H^0(X_d, -L)$ があれば、$L$ が豊富であることから十分大きな $k \ge 1$ に対して零点を持つ非零切断 $t \in H^0(X_d, kL)$ が存在し［今の場合 $L$ はすでに非常に豊富なので $k = 1$ でよい］、その積 $s^{\otimes k} \otimes t \in H^0(X_d, \mathcal{O}_{X_d}) = \mathbb{C}$ が零点を持つ非零定数となって矛盾するため）、**$\kappa(X_d) = -\infty$** です。
    （例：$\mathbb{P}^2$ の直線・2次曲線、$\mathbb{P}^3$ の2次曲面・3次曲面。）
    （※反標準因子 $-K_{X_d}$ が豊富である多様体を**ファノ多様体 / Fano variety**と呼びます。）

2. **$d = n + 1$ のとき（$d - n - 1 = 0$）：**
    $K_{X_d} \sim 0$（標準束が自明：$\omega_{X_d} \cong \mathcal{O}_{X_d}$）となるため、すべての $m \ge 1$ で $h^0(X_d, mK_{X_d}) = h^0(X_d, \mathcal{O}_{X_d}) = 1$ となり、**$\kappa(X_d) = 0$** です。
    （例：$\mathbb{P}^2$ の3次曲線＝楕円曲線、$\mathbb{P}^3$ の4次曲面＝**K3曲面**、$\mathbb{P}^4$ の5次3次元多様体＝**カラビ・ヤウ3次元多様体**。特に $\mathbb{P}^4$ 内の5次超曲面 $X_0^5 + X_1^5 + X_2^5 + X_3^5 + X_4^5 = 0$ は、超弦理論において10次元時空の余剰6次元（複素3次元）をコンパクト化する空間の最も標準的なモデルとして研究されています。）

3. **$d \ge n + 2$ のとき（$d - n - 1 > 0$）：**
    [6-1節](6-1.md)の命題1（正の整数倍不変性）より、$\kappa(X_d) = \kappa(X_d, (d - n - 1)H\vert{}_{X_d}) = \kappa(X_d, H\vert{}_{X_d}) = \mathbf{n - 1 = \dim X_d}$（**一般型**）となります。
    （例：$\mathbb{P}^2$ の4次以上の曲線、$\mathbb{P}^3$ の5次以上の曲面。）

> **【コラム：「K3曲面」の名前の由来とカラビ・ヤウ多様体】**
> 実験Aで臨界次数 $d = n + 1$ に現れた $\kappa(X) = 0$ の多様体は、現代数学と理論物理学の両方で活発に研究されている対象です。
>
> * **なぜ「K3曲面」と呼ぶのか？**
>     1958年、アンドレ・ヴェイユは4次曲面 $S_4 \subset \mathbb{P}^3$ を代表とする単連結で $K_S \sim 0$ の曲面群に「K3曲面」という名前を付けました。この名称は、この曲面の研究に重要な貢献をした3人の数学者 **Kummer（クンマー）・Kähler（ケーラー）・Kodaira（小平邦彦）** の頭文字「K」と、当時初登頂されたカラコルム山脈の難峰 **K2** に因んだ命名です。
>
> * **カラビ・ヤウ多様体と超弦理論（10次元時空の余剰6次元）：**
>     次元を1つ上げた $\mathbb{P}^4$ 内の5次超曲面 $X_5$（複素3次元＝実6次元）のような、単連結で標準束が自明（$\omega_X \cong \mathcal{O}_X$）な多様体を**カラビ・ヤウ多様体**と呼びます。
>     1977年、シン＝トゥン・ヤウは「第一チャーン類 $c_1(X) = 0$（特に $\omega_X \cong \mathcal{O}_X$ の場合）を満たすコンパクトなケーラー多様体には、アインシュタイン方程式の真空解に対応する**リッチ平坦計量**（リッチ曲率が $0$ の計量）が必ず存在する」というカラビ予想を証明しました（ヤウはこの業績等でフィールズ賞を受賞）。
>     1980年代には素粒子物理学の**超弦理論**において「10次元時空のうち観測される4次元時空以外の余剰6次元は、超対称性を保つためリッチ平坦な複素3次元多様体＝カラビ・ヤウ多様体として非常に小さなサイズにコンパクト化されている」というモデルが提唱され、代数幾何学と理論物理学が結びつく契機となりました（ミラー対称性の発見）。

#### 実験B：直積による「中間的な小平次元（$0 < \kappa(X) < \dim X$）」の構成

実験Aの超曲面では、$K_{X_d}$ が $H\vert{}_{X_d}$ のスカラー倍になっていたため、中間的な小平次元は現れませんでした。
中間的な小平次元を持つ多様体は、[6-1節](6-1.md)の直積の加法性 $\kappa(X_1 \times X_2) = \kappa(X_1) + \kappa(X_2)$ を用いることで簡単に構成できます。

* $C$ を種数 $g \ge 2$ の曲線（$\dim C = 1, \; \kappa(C) = 1$）、$E$ を楕円曲線（$\dim E = 1, \; \kappa(E) = 0$）とします。
* 直積曲面 $X = C \times E$（$\dim X = 2$）の小平次元は、

    $$\kappa(C \times E) = \kappa(C) + \kappa(E) = 1 + 0 = \mathbf{1}$$

    となり、$0 < \kappa(X) < \dim X$（中間型）になります。

* 同様に、K3曲面 $S$（$\dim = 2, \; \kappa = 0$）と種数 $g \ge 2$ の曲線 $C$ の直積 $S \times C$ は、$\dim = 3$ かつ $\kappa = 1$ の3次元多様体を与えます。

---

### 3. 厳密な定義と定理（What）：小平次元・双有理不変性・4分類の構造

#### (1) 多重種数と小平次元の定義

複素数体 $\mathbb{C}$ 上の $n$ 次元非特異射影代数多様体 $X$ に対し、各正の整数 $m \ge 1$ について


$$P_m(X) := h^0\big(X, \mathcal{O}_X(mK_X)\big) = \dim_{\mathbb{C}} H^0\big(X, \omega_X^{\otimes m}\big)$$


を $X$ の **$m$-種数（または多重種数 / $m$-th plurigenus）**と呼びます（特に $P_1(X) = h^0(X, \omega_X)$ を**幾何種数 / Geometric genus**といい $p_g(X)$ とも書きます）。
そして、標準因子 $K_X$ の飯高次元


$$\kappa(X) := \kappa(X, K_X) \in \{-\infty, \, 0, \, 1, \, \dots, \, n\}$$


を $X$ の小平次元（Kodaira dimension）と定義します。

---

#### (2) 多重種数と小平次元の双有理不変性

> **【定理1：多重種数および小平次元の双有理不変性】**
> $X_1, X_2$ を複素数体 $\mathbb{C}$ 上の非特異射影代数多様体とする。もし $X_1$ と $X_2$ が双有理同値であるならば、すべての $m \ge 1$ に対して
> 
> $$P_m(X_1) = P_m(X_2)$$
> 
> 
> 
> が成り立ち、特に小平次元は一致する：
> 
> $$\kappa(X_1) = \kappa(X_2)$$
> 
> 

**【証明】**

1. 双有理写像 $f : X_1 \dashrightarrow X_2$ に対し、[4-5節](../4/4-5.md)の広中の定理（不定点の解消）を適用すると、非特異射影多様体 $W$ と2つの双有理射 $\pi_1 : W \to X_1, \; \pi_2 : W \to X_2$ が存在して $f \circ \pi_1 = \pi_2$ を満たします。
2. したがって、「任意の非特異射影多様体間の双有理射 $\pi : W \to X$ に対して $P_m(W) = P_m(X)$」を示せば、$P_m(X_1) = P_m(W) = P_m(X_2)$ が得られます。
3. 双有理射 $\pi : W \to X$ における微分形式の引き戻しを考えます。局所座標上で最高次微分形式を引き戻すと、[2-4節](../2/2-4.md)よりヤコビ行列式 $\det J(\pi)$ が係数として掛かります。

    * $\pi$ は正則写像なので、$\det J(\pi)$ は極を持たない正則関数です。
    * $\pi$ は空でない開集合 $U \subset W$ 上で同型なので、$\det J(\pi)$ は恒等的に $0$ ではなく、$\det J(\pi) = 0$ となる零点集合は $\pi$ が同型にならない例外集合の中に含まれます。
    * したがって、$\det J(\pi)$ の零点因子を $E := \operatorname{div}(\det J(\pi))$ とおくと、$E$ は有効因子（$E \ge 0$）かつ $\pi$-例外的（$\operatorname{codim}_X \pi(\operatorname{Supp} E) \ge 2$）であり、標準因子の間に**分岐公式**

        $$K_W \sim \pi^* K_X + E$$

        が成り立ちます。

4. [6-1節](6-1.md)の命題2（の証明で示した各 $m$ ごとの次元の一致）を $D = K_X$ に適用すると、すべての $m \ge 1$ に対して

    $$P_m(W) = h^0(W, mK_W) = h^0(W, m\pi^* K_X + mE) = h^0(X, mK_X) = P_m(X)$$

    が成り立ち、よって $\kappa(W) = \kappa(X)$ となります。（証明終）

（※系：特異点を持つ射影代数多様体 $X_0$ に対しても、広中の特異点解消 $\tilde{X} \to X_0$ を1つとって $\kappa(X_0) := \kappa(\tilde{X})$ と定義すれば、解消の選び方によらず Well-defined に定まります。）

#### (3) 小平次元による4つのクラスの幾何学的特徴

$n$ 次元非特異射影多様体 $X$ は、小平次元 $\kappa(X)$ の値によって次の4つのクラスに大別されます。

| クラス | $\kappa(X)$ の値 | 多重種数 $P_m(X)$ の挙動 | 幾何学的特徴と代表的な具体例 |
| --- | --- | --- | --- |
| **1. 負のクラス** | $-\infty$ | すべての $m \ge 1$ で $P_m(X) = 0$ | 空間が有理曲線 $\mathbb{P}^1$ で覆われている傾向が強い。<br>例：$\mathbb{P}^n$、ファノ多様体、$\mathbb{P}^1$ 束（線織多様体）。 |
| **2. ゼロのクラス** | $0$ | $P_m(X) \in \{0, 1\}$ で有界（ある $m$ で $1$） | 曲率が平坦・中立的。双有理同値な極小モデルで $mK_X \sim 0$ になることが期待される。<br>例：アーベル多様体（複素トーラス）、K3曲面、エンリケス曲面、カラビ・ヤウ多様体。 |
| **3. 中間クラス** | $1 \le \kappa(X) \le n - 1$ | $P_m(X) \sim c \cdot m^\kappa$ | 多重標準写像により、より低い次元の底空間と $\kappa = 0$ のファイバーに分解される（次節：飯高ファイブレーション）。<br>例：楕円曲面、直積 $C \times E$。 |
| **4. 一般型**<br>（General type） | $n = \dim X$ | $P_m(X) \sim c \cdot m^n$（最大増大度） | 十分大きな $m$ に対し、多重標準写像 $\Phi_{\vert mK_X \vert}: X \dashrightarrow \mathbb{P}^N$ が像への**双有理写像**を与える（次節の飯高ファイブレーションの定理より一般ファイバーが連結な $0$ 次元＝$1$ 点となるため；$K_X$ が「巨大 / Big」）。<br>例：種数 $g \ge 2$ の曲線、$\mathbb{P}^{n+1}$ 内の次数 $d \ge n + 3$ の超曲面。 |

**【論理的な注意点（未解決部分との境界の明示）】**

* クラス1（$\kappa(X) = -\infty$）と「$X$ が有理曲線 $\mathbb{P}^1$ の族で覆われる（**単線織 / Uniruled**）」という幾何学的性質の関係について、「単線織 $\implies \kappa(X) = -\infty$」は任意の次元で証明されています（有理曲線 $\mathbb{P}^1$ 上に正則な多重標準形式が乗れないため）。
* 一方、逆の「$\kappa(X) = -\infty \implies X$ は単線織である」は、3次元以下では証明されています（2次元はカステルヌオーヴォの定理、3次元は宮岡・森の定理と森理論による）が、**4次元以上では現在も極小モデル理論の重要な未解決予想の1つ**です。

> **【コラム：小平次元 $\kappa(X)$ と方程式の有理数解の個数】**
> 本ノートでは複素数体 $\mathbb{C}$ 上の幾何学を中心に扱っていますが、多項式方程式の係数が有理数 $\mathbb{Q}$ であるとき、**「その方程式を満たす有理数解（有理点）が何個存在するか」**という整数論（ディオファントス幾何学）の問題は、複素多様体としての**小平次元 $\kappa(X)$** と密接に関係しています。
> 1次元の代数曲線 $C$（種数 $g$）の有理点集合 $C(\mathbb{Q})$ を見ると、3つのクラスで挙動が大きく分かれます。
>
> * **$g = 0$（$\kappa(C) = -\infty$、例：円 $x^2 + y^2 = 1$）：** 有理点が1つでも見つかれば、[4-4節](../4/4-4.md)の有理パラメータ表示（ピタゴラス数の公式）によって**無限個**の有理点が稠密に存在します。
> * **$g = 1$（$\kappa(C) = 0$、楕円曲線 $y^2 = x^3 + ax + b$）：** [4-3節](../4/4-3.md)のコラムで見た「点の足し算」によって有理点全体が有限生成アーベル群をなし（**モーデル・ヴェイユの定理**）、有限個の場合も無限個の場合も起こり得ます（その階数を予測するのがミレニアム懸賞問題の1つである BSD 予想です）。
> * **$g \ge 2$（$\kappa(C) = 1$、一般型曲線、例：フェルマー曲線 $x^n + y^n = 1 \; (n \ge 4)$）：** 1983年、ゲルト・ファルティングスは「種数 $g \ge 2$ の曲線上の有理点は、**必ず有限個しか存在しない**」というモーデル予想（ファルティングスの定理）を証明しました（フィールズ賞受賞業績）。
>
> さらに高次元（$\dim X \ge 2$）においても、「一般型多様体（$\kappa(X) = \dim X$）の有理点は空間全体でザリスキ稠密になることはなく、必ず真の閉部分集合の中に含まれる」という**ボムビエリ・ラング予想**が提唱されています。複素微分形式の増え方を測る幾何学的不変量 $\kappa(X)$ が、有理数解の個数という整数論的な性質とも結びついていることが分かります。

#### (4) 2次元（代数曲面）におけるエンリケス・小平の分類

1次元（曲線）の種数分類の次のステップである2次元（非特異射影曲面）において、小平次元が実際にどのように曲面を分類しきっているかを確認します。

| $\kappa(S)$ | 極小モデル（ブローダウンしきった代表元）の分類 | 代表例と特徴 |
| --- | --- | --- |
| **$-\infty$** | 有理曲面、非有理線織面 | $\mathbb{P}^2$、ヒルツェブルフ曲面、曲線 $C$ 上の $\mathbb{P}^1$ 束。 |
| **$0$** | 次の4タイプのみ：<br>① アーベル曲面 ② K3曲面<br>③ エンリケス曲面 ④ 超楕円曲面 | ① $\mathbb{C}^2 / \Lambda$（$K_S \sim 0$）<br>② $\mathbb{P}^3$ の4次曲面など（単連結、$K_S \sim 0$）<br>③ K3曲面の $\mathbb{Z}/2\mathbb{Z}$ 商（$2K_S \sim 0$、$K_S \not\sim 0$）<br>④ 楕円曲線の直積の有限群商（$12K_S \sim 0$） |
| **$1$** | 固有楕円曲面（Properly elliptic surface） | 曲線 $B$ への射 $f: S \to B$ を持ち、一般ファイバーが楕円曲線（$\kappa = 0$）。 |
| **$2$** | 一般型曲面（Surface of general type） | $\mathbb{P}^3$ の5次以上の曲面など。最も種類が豊富。 |

（※$\kappa(S) = 0$ のクラスにある③エンリケス曲面は、$K_S \not\sim 0$ のため1倍では正則2次微分形式を持たない（$P_1(S) = 0$）にもかかわらず、2倍すると $2K_S \sim 0$ となって切断が現れる（$P_2(S) = 1$）という、[5-2節](../5/5-2.md)で見たメビウスの帯の複素2次元版に相当するねじれを持っています。）

### 4. 翻訳と展望（Bridge）：次節「飯高ファイブレーション」への接続

上の2次元曲面の分類表において、中間クラスである **$\kappa(S) = 1$** の行に注目してください。
$\kappa(S) = 1$ の曲面は、すべて「曲線 $B$ への射 $f: S \to B$ を持ち、一般ファイバー $F$ が楕円曲線（$\kappa(F) = 0$）になっている」というファイバー空間の構造を必然的に持っています。

飯高茂は1971年に、この2次元で見られた現象が**任意の次元 $n$ に対して一般に成り立つ**ことを証明しました。すなわち、中間的な小平次元 $0 < \kappa(X) < \dim X$ を持つ多様体 $X$ は、適切な双有理変換を施すことで、必ず

$$f : \tilde{X} \longrightarrow Y \qquad \big(\dim Y = \kappa(X), \quad \text{一般ファイバー } F \text{ は } \kappa(F) = 0\big)$$

という標準的なファイバー空間（**飯高ファイブレーション**）に分解されます。

これにより、高次元代数多様体の分類理論は、

1. 3つの純粋な構成ブロック（$\kappa = -\infty$、$\kappa = 0$、$\kappa = \dim$（一般型））の理解
2. ファイバー空間 $f: X \to Y$ において、底空間 $Y$ とファイバー $F$ の小平次元から全体空間 $X$ の小平次元を評価する法則（**飯高予想**）

という2本柱に集約されます。次節では、この飯高ファイブレーションの定理を詳しく扱います。
