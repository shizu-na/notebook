### 前節（5-3）の確認問題の解答

第5部の確認問題（5-3節）の答え合わせから始めます。

1. 短完全列 $0 \to \mathcal{O}_{\mathbb{P}^2}(-d) \to \mathcal{O}_{\mathbb{P}^2} \to \mathcal{O}_C \to 0$ から誘導される長完全列において、両端の $H^1(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2})$ と $H^2(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2})$ がともに $0$ であるため、間の写像は同型になります：

    $$H^1(C, \mathcal{O}_C) \cong H^2(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2}(-d))$$

2. $n = 2, \; \omega_{\mathbb{P}^2} = \mathcal{O}_{\mathbb{P}^2}(-3)$ としてセール双対性を適用すると、

    $$H^2(\mathbb{P}^2, \mathcal{O}_{\mathbb{P}^2}(-d)) \cong H^0\big(\mathbb{P}^2, \, \mathcal{O}_{\mathbb{P}^2}(-3) \otimes \mathcal{O}_{\mathbb{P}^2}(d)\big)^* = H^0\big(\mathbb{P}^2, \, \mathcal{O}_{\mathbb{P}^2}(d - 3)\big)^*$$

    となります。

3. 曲線 $C$ 上のセール双対性より種数 $g = h^0(C, \omega_C) = h^1(C, \mathcal{O}_C)$ なので、

    $$g = h^0\big(\mathbb{P}^2, \, \mathcal{O}_{\mathbb{P}^2}(d - 3)\big)$$

    * $d \ge 3$ のとき、$k = d - 3 \ge 0$ なので $g = \binom{(d - 3) + 2}{2} = \binom{d - 1}{2} = \frac{(d - 1)(d - 2)}{2}$。
    * $d = 1, 2$ のとき、$k = d - 3 < 0$ なので $g = 0$（公式 $\frac{(d - 1)(d - 2)}{2}$ に $d = 1, 2$ を代入した値 $0$ と一致）。

    したがって、すべての $d \ge 1$ に対して $g = \frac{(d - 1)(d - 2)}{2}$ が成り立ちます。

## 6-1. 飯高次元 $\kappa(X, D)$ の厳密な定義と基本性質

### 1. 動機（Why）：なぜ「因子 $D$ の $m$ 倍」の漸近挙動を測るのか？

第3部（1次元曲線）では、因子 $D$ の性質は「次数 $\deg(D) \in \mathbb{Z}$」という1つの整数によってほぼ決定されました。$\deg(D) < 0$ なら切断は存在せず、$\deg(D) > 0$ なら十分大きな $m$ に対して $\vert{}mD\vert{}$ が曲線を射影空間へ埋め込みます。

しかし、2次元以上の多様体 $X$ になると、次の2つの理由から「単一の整数（次数）」や「1倍の $D$ の切断の次元 $h^0(X, \mathcal{O}_X(D))$」だけでは因子 $D$ の働きを捉えられなくなります。

1. **方向による偏りがある：**
    たとえば2次元曲面の上では、因子 $D$ は余次元 $1$ の部分多様体（曲線）の和です。ある因子 $D$ が生み出す関数（切断）は、2次元のうち「縦の1方向だけ」を区別できて「横の1方向」を全く区別できない、という中途半端な振る舞いをすることがあります。

2. **1倍では切断がなくても、$m$ 倍すると切断が現れることがある：**
    $D$ 自体には $0$ でない切断が存在しない（$h^0(X, \mathcal{O}_X(D)) = 0$）のに、$2D$ や $3D$ にすると切断が現れる場合があります（たとえば $D \not\sim 0$ だが $2D \sim 0$ となるねじれ因子では $h^0(D) = 0, \; h^0(2D) = 1$ です）。

そこで、「すべての正の整数倍 $mD$（$m = 1, 2, 3, \dots$）を動かしたとき、その切断の組が多様体 $X$ を最大で何次元の図形として射影空間へ写せるか（＝空間を何次元分まで識別できるか）」という漸近的な不変量として導入されたのが、**飯高次元（Iitaka dimension / $D$-dimension）$\kappa(X, D)$**（飯高茂、1971年）です。

---

### 2. 具体例・実験（Toy Model）：$X = \mathbb{P}^1 \times \mathbb{P}^1$ 上の4つの因子

2次元の非特異射影多様体 $X = \mathbb{P}^1 \times \mathbb{P}^1$（第1成分の斉次座標を $[X_0 : X_1]$、第2成分の斉次座標を $[Y_0 : Y_1]$、射影を $\operatorname{pr}_1, \operatorname{pr}_2 : X \to \mathbb{P}^1$ とします）の上で、飯高次元がとり得るすべての値（$-\infty, 0, 1, 2$）を手計算で確認します。

$X$ 上の因子 $D = a F_1 + b F_2$（ただし $F_1 = \{p\} \times \mathbb{P}^1, \; F_2 = \mathbb{P}^1 \times \{q\}$、$a, b \in \mathbb{Z}$）に対応する直線束を $\mathcal{O}_X(a, b) := \operatorname{pr}_1^*\mathcal{O}_{\mathbb{P}^1}(a) \otimes \operatorname{pr}_2^*\mathcal{O}_{\mathbb{P}^1}(b)$ と書きます。
5-2節の実験Bより、大域切断の空間 $H^0(X, \mathcal{O}_X(a, b))$ は「$(X_0, X_1)$ について $a$ 次斉次、かつ $(Y_0, Y_1)$ について $b$ 次斉次である多項式全体」と一致します。したがって、その次元は次のようになります：

$$h^0\big(X, \mathcal{O}_X(a, b)\big) = \begin{cases} (a + 1)(b + 1) & (a \ge 0 \text{ かつ } b \ge 0) \\ 0 & (a < 0 \text{ または } b < 0) \end{cases}$$

これを用いて、$mD$ に対応する直線束 $\mathcal{O}_X(ma, mb)$ の振る舞いを4つの $(a, b)$ で比較します。

1. **$(a, b) = (-1, 2)$ の場合（$\kappa = -\infty$）：**
    すべての $m \ge 1$ に対して $ma = -m < 0$ となるため、常に $h^0(X, \mathcal{O}_X(mD)) = 0$ です。射影空間への写像は1つも作れず、$\kappa(X, D) = \mathbf{-\infty}$ となります。

2. **$(a, b) = (0, 0)$ の場合（$\kappa = 0$）：**
    すべての $m \ge 1$ に対して $h^0(X, \mathcal{O}_X(mD)) = 1$（定数関数のみ）です。写像 $\Phi_{\vert{}mD\vert{}} : X \to \mathbb{P}^0$ の像は常に1点（$0$ 次元）、次元の増大度も $1 = O(m^0)$ なので、$\kappa(X, D) = \mathbf{0}$ です。

3. **$(a, b) = (1, 0)$ の場合（$\kappa = 1$）：**
    $mD$ に対応する直線束は $\mathcal{O}_X(m, 0)$ です。

    * **次元の増大度：** $h^0(X, \mathcal{O}_X(m, 0)) = (m + 1) \cdot 1 = m + 1$（$m$ の **$1$ 次式**）。
    * **写像の像：** 基底は $\{X_0^m, X_0^{m-1}X_1, \dots, X_1^m\}$ であり、写像

        $$\Phi_{\vert{}mD\vert{}}([X_0 : X_1], [Y_0 : Y_1]) = [X_0^m : X_0^{m-1}X_1 : \dots : X_1^m] \in \mathbb{P}^m$$

        は第2成分 $[Y_0 : Y_1]$ を完全に潰してしまいます。そのため、$m$ をどれだけ大きくしても像は1次元曲線（$\mathbb{P}^1$ の同型像）のままであり、$\kappa(X, D) = \mathbf{1}$ となります。

4. **$(a, b) = (1, 1)$ の場合（$\kappa = 2 = \dim X$）：**
    $mD$ に対応する直線束は $\mathcal{O}_X(m, m)$ です。

    * **次元の増大度：** $h^0(X, \mathcal{O}_X(m, m)) = (m + 1)^2 = m^2 + 2m + 1$（$m$ の **$2$ 次式**）。
    * **写像の像：** $m = 1$ の時点で、基底 $\{X_0 Y_0, X_0 Y_1, X_1 Y_0, X_1 Y_1\}$ が定める写像 $\Phi_{\vert{}D\vert{}} : \mathbb{P}^1 \times \mathbb{P}^1 \hookrightarrow \mathbb{P}^3$（セグレ埋め込み）は2次元曲面 $Z_0 Z_3 - Z_1 Z_2 = 0$ への同型埋め込みを与えます。像の次元は $2$ であり、$\kappa(X, D) = \mathbf{2}$ となります。

### 3. 厳密な定義と定理（What）：飯高次元の定義・3つの同値表現・基本性質

以下、$X$ を複素数体 $\mathbb{C}$ 上の $n$ 次元非特異射影代数多様体、$D$ を $X$ 上の因子（カルティエ因子）、対応する直線束を $\mathcal{O}_X(D)$ とします。

#### (1) 半群 $N(X, D)$ と飯高次元の定義

$0$ でない大域切断が存在する正の整数 $m$ の集合を


$$N(X, D) := \big\{ m \in \mathbb{Z}_{>0} \;\big\vert{}\; h^0(X, \mathcal{O}_X(mD)) > 0 \big\}$$


とおきます。
2つの $0$ でない切断 $s \in H^0(X, \mathcal{O}_X(m_1 D))$ と $t \in H^0(X, \mathcal{O}_X(m_2 D))$ のテンソル積 $s \otimes t \in H^0(X, \mathcal{O}_X((m_1 + m_2)D))$ は、$X$ が既約（局所環が整域）であるため $0$ にはなりません。したがって、$N(X, D)$ は足し算で閉じた**加法半群**（$m_1, m_2 \in N(X, D) \implies m_1 + m_2 \in N(X, D)$）です。

$N(X, D) \neq \emptyset$ のとき、$N(X, D)$ のすべての元の最大公約数を $e = e(D) := \gcd N(X, D) \ge 1$ とおきます。初等整数論の基本事実により、十分大きな整数 $k_0$ が存在して、**$k \ge k_0$ を満たす任意の整数 $k$ に対して $k e \in N(X, D)$** が成り立ちます。

各 $m \in N(X, D)$ に対し、$H^0(X, \mathcal{O}_X(mD))$ の基底 $\{s_0, s_1, \dots, s_N\}$（$N = h^0(X, \mathcal{O}_X(mD)) - 1$）を用いて有理写像


$$\Phi_{\vert{}mD\vert{}} : X \dashrightarrow \mathbb{P}^N, \qquad x \longmapsto [s_0(x) : s_1(x) : \dots : s_N(x)]$$


を定めます（基底の取り替えは $\mathbb{P}^N$ の射影変換の違いにしかならないため、像のザリスキ閉包 $\overline{\Phi_{\vert{}mD\vert{}}(X)}$ の次元は基底の選び方に依存しません）。

> **【定義：飯高次元 $\kappa(X, D)$】**
>
> 1. $N(X, D) = \emptyset$ のとき、$\kappa(X, D) := -\infty$ と定義する。
> 2. $N(X, D) \neq \emptyset$ のとき、
> 
>     $$\kappa(X, D) := \max_{m \in N(X, D)} \dim \overline{\Phi_{\vert{}mD\vert{}}(X)}$$
> 
>     と定義する。（像の次元は $0$ 以上かつ $\dim X = n$ 以下なので、$\kappa(X, D) \in \{-\infty, 0, 1, \dots, n\}$ である。）

---

#### (2) 飯高次元の3つの等価な特徴づけ

> **【定理1：飯高次元の漸近挙動と切断環の超越次数（Iitaka, 1971）】**
> $N(X, D) \neq \emptyset$ とし、$\kappa := \kappa(X, D) \in \{0, 1, \dots, n\}$、$e := \gcd N(X, D)$ とおく。このとき以下が成り立つ。
>
> 1. **多項式増大度（飯高の不等式）：** 正の定数 $\alpha, \beta > 0$ と整数 $k_0 > 0$ が存在して、すべての $k \ge k_0$（$m = ke$）に対して次が成り立つ：
> 
>     $$\alpha \cdot m^\kappa \;\le\; h^0\big(X, \mathcal{O}_X(mD)\big) \;\le\; \beta \cdot m^\kappa$$
> 
> 2. **切断環の超越次数：** 次数付き環（**切断環 / Section ring**）
> 
>     $$R(X, D) := \bigoplus_{m=0}^{\infty} H^0\big(X, \mathcal{O}_X(mD)\big)$$
> 
>     は整域であり、その商体の超越次数は $\kappa + 1$ に一致する：
> 
>     $$\kappa(X, D) = \operatorname{tr.deg}_{\mathbb{C}} \operatorname{Frac} R(X, D) - 1$$
> 
> 3. **像の次元の安定化：** 十分大きなすべての $k$（$m = ke$）に対して、$\dim \overline{\Phi_{\vert{}mD\vert{}}(X)} = \kappa(X, D)$ となる。

**【証明の原理と骨格】**

1. **下界 $\alpha m^\kappa \le h^0(X, \mathcal{O}_X(mD))$ の証明：**

    * 最大次元 $\kappa$ を実現する $m_0 \in N(X, D)$ を1つ選び、像の閉包を $Y := \overline{\Phi_{\vert{}m_0 D\vert{}}(X)} \subset \mathbb{P}^N$（$\dim Y = \kappa$）とおきます。
    * 次数 $r \ge 1$ の斉次多項式 $F(Z_0, \dots, Z_N)$ に基底 $(s_0, \dots, s_N)$ を代入すると $F(s_0, \dots, s_N) \in H^0(X, \mathcal{O}_X(r m_0 D))$ が得られます。$F(s_0, \dots, s_N) \equiv 0$ となるのは $F$ が像 $Y$ 上で恒等的に $0$ になる（$F \in I_+(Y)$）ときだけなので、$Y$ の斉次座標環の $r$ 次部分 $S(Y)_r$ から $H^0(X, \mathcal{O}_X(r m_0 D))$ への**単射線形写像**が得られます。
    * $\kappa$ 次元射影多様体 $Y \subset \mathbb{P}^N$ から $\mathbb{P}^\kappa$ への一般射影（$Y$ と交わらない線形部分空間を中心とする射影）をとると、有限全射 $Y \to \mathbb{P}^\kappa$ が得られます。これにより、$(\kappa + 1)$ 変数多項式環 $\mathbb{C}[T_0, \dots, T_\kappa]$ が $S(Y)$ に単射で埋め込まれます。
    * よって各 $r \ge 1$ に対して、重複組合せの公式より

        $$h^0(X, \mathcal{O}_X(r m_0 D)) \;\ge\; \dim_{\mathbb{C}} S(Y)_r \;\ge\; \dim_{\mathbb{C}} \mathbb{C}[T_0, \dots, T_\kappa]_r = \binom{r + \kappa}{\kappa} \;\ge\; \frac{1}{\kappa!} r^\kappa$$

        が得られます。

    * さらに、$e = \gcd N(X, D)$ の各剰余類（$m_0 / e$ 個のクラス）を代表する $c_j \in N(X, D)$ を有限個選び、非零切断 $s_{c_j} \in H^0(X, \mathcal{O}_X(c_j D))$ を掛ける単射 $H^0(r m_0 D) \hookrightarrow H^0((r m_0 + c_j)D)$ を用いれば、十分大きなすべての $m = ke$ に対して下界 $\alpha m^\kappa \le h^0(X, \mathcal{O}_X(mD))$ が示されます。

2. **切断環の超越次数 $\operatorname{tr.deg}_{\mathbb{C}} \operatorname{Frac} R(X, D) = \kappa + 1$ の証明：**

    * 各 $m \in N(X, D)$ に対し、$0$ でない切断 $s_0 \in H^0(X, \mathcal{O}_X(mD))$ を固定して比 $\frac{s_i}{s_0} \in K(X)$ で生成される部分体 $K_m := \mathbb{C}\left(\frac{s_1}{s_0}, \dots, \frac{s_N}{s_0}\right) \subset K(X)$ を考えます。
    * これは有理写像 $\Phi_{\vert{}mD\vert{}} : X \dashrightarrow Y_m$ による像の有理関数体 $K(Y_m)$ の引き戻しそのものなので、1-5節より $\operatorname{tr.deg}_{\mathbb{C}} K_m = \dim Y_m \le \kappa$ です。
    * 同じ次数 $m$ の切断の比全体のなす体 $K(X, D) := \bigcup_{m \in N(X, D)} K_m \subset K(X)$ は、部分体の昇鎖（$K_{m_1}, K_{m_2} \subset K_{m_1 + m_2}$）の和集合です。もし $K(X, D)$ に $\kappa + 1$ 個の代数的独立な元があれば、それらは有限個の比なのである1つの十分大きな $m$ に対する $K_m$ にすべて含まれてしまい、$\dim Y_m \le \kappa$ に矛盾します。よって $\operatorname{tr.deg}_{\mathbb{C}} K(X, D) = \max_m \dim Y_m = \kappa$ です。
    * 一方、切断環 $R(X, D)$ の商体 $\operatorname{Frac} R(X, D)$ は、比の体 $K(X, D)$ に次数 $m_0$ の非零切断 $s_0$ 自身を1つ付け加えた拡大体 $K(X, D)(s_0)$ の有限次拡大になります。$s_0$ は次数を上げる元であるため $K(X, D)$ 上で超越的（もし代数関係式があれば次数ごとの成分に分解して $s_0 = 0$ となる）であり、1-5節の超越次数の加法性より $\operatorname{tr.deg}_{\mathbb{C}} \operatorname{Frac} R(X, D) = \kappa + 1$ が確定します。

3. **上界 $h^0(X, \mathcal{O}_X(mD)) \le \beta m^\kappa$ の証明（技術的詳細の切り分け）：**

    * 下界に比べて、**上界 $h^0(X, \mathcal{O}_X(mD)) \le \beta m^\kappa$ の証明は非自明**です（像の次元 $\dim Y_m$ が $\kappa$ で止まっているからといって、$h^0(mD)$ が $m^{\kappa+1}$ の速さで増えないことは直ちには自明ではありません）。
    * 証明の骨格は、$K(X, D)$ の超越基底を含む十分大きな $m_0$ に対して $\Phi_{\vert{}m_0 D\vert{}} : X \dashrightarrow Y$ の不定点を解消してファイバー空間 $f : \tilde{X} \to Y$（$\dim Y = \kappa$）を作り、一般ファイバー $F$ 上への制限 $D\vert{}_F$ について $\kappa(F, D\vert{}_F) = 0$ を示した上で、$Y$ 上の豊富な因子 $H$ を用いて $h^0(\tilde{X}, m\tilde{D}) \le h^0(Y, mH) = O(m^\kappa)$ と押さえ込むものです。この構造は6-3節（飯高ファイブレーションの定理）で改めて詳しく扱います。

#### (3) 飯高次元の3つの基本性質

> **【命題：飯高次元の基本性質】**
> $X, \tilde{X}, X_1, X_2$ を非特異射影多様体とする。
>
> 1. **正の整数倍不変性：** 任意の正の整数 $a \ge 1$ に対し、
> 
>     $$\kappa(X, aD) = \kappa(X, D)$$
> 
> 2. **双有理射による引き戻しと例外因子の不変性：** $\pi : \tilde{X} \to X$ が双有理射であり、$E$ が $\pi$-例外的な有効因子（すなわち $E \ge 0$ かつ $\operatorname{codim}_X \pi(\operatorname{Supp} E) \ge 2$）であるとき、
> 
>     $$\kappa(\tilde{X}, \, \pi^* D + E) = \kappa(X, D)$$
> 
> 3. **直積での加法性：** $X_1$ 上の因子 $D_1$ と $X_2$ 上の因子 $D_2$ に対し、直積 $X_1 \times X_2$ 上の因子 $\operatorname{pr}_1^* D_1 + \operatorname{pr}_2^* D_2$ の飯高次元は和に一致する：
> 
>     $$\kappa(X_1 \times X_2, \, \operatorname{pr}_1^* D_1 + \operatorname{pr}_2^* D_2) = \kappa(X_1, D_1) + \kappa(X_2, D_2)$$
> 
>     （ただし $-\infty$ との和は常に $-\infty$ と規約する。）

**【各性質の証明の骨格】**

1. **$aD$ の不変性：** $N(X, D) = \emptyset \iff N(X, aD) = \emptyset$ は明らかです（$m \in N(X, D)$ なら $am \in N(X, D)$ なので $m \in N(X, aD)$）。$N(X, D) \neq \emptyset$ のとき、定理1の多項式増大度 $\alpha m^\kappa \le h^0(mD) \le \beta m^\kappa$ に $m = a k$ を代入すれば、$h^0(k(aD))$ も同じ次数 $\kappa$ で増大することが直ちに分かります。
    （※この性質により、有理数係数の因子である **$\mathbb{Q}$-因子** $D \in \operatorname{Div}(X) \otimes \mathbb{Q}$ に対しても、分母を払う正の整数 $a$ を選んで $\kappa(X, D) := \kappa(X, aD)$ と Well-defined に定義できます。）

2. **双有理引き戻しと例外因子の不変性：**
    任意の $m \ge 1$ に対して、自然な包含 $H^0(X, \mathcal{O}_X(mD)) \hookrightarrow H^0(\tilde{X}, \mathcal{O}_{\tilde{X}}(m\pi^* D)) \hookrightarrow H^0(\tilde{X}, \mathcal{O}_{\tilde{X}}(m\pi^* D + mE))$ があります。
    逆に、任意の切断 $s \in H^0(\tilde{X}, \mathcal{O}_{\tilde{X}}(m\pi^* D + mE))$ をとると、$E$ の外側の開集合 $\tilde{X} \setminus \operatorname{Supp} E$ は $X$ の余次元 $2$ 以上の閉集合 $Z := \pi(\operatorname{Supp} E)$ を除いた開集合 $U = X \setminus Z$ と同型です。したがって $s$ は $U = X \setminus Z$ 上の $\mathcal{O}_X(mD)$ の切断を与えます。
    $X$ は非特異（特に正規）であり、$Z$ の余次元は $2$ 以上なので、代数的ハルトークスの拡張定理（余次元 $2$ 以上の閉集合の外で正則な関数は必ず空間全体へ一意に延長できる）により、$s$ は $X$ 全体の切断 $H^0(X, \mathcal{O}_X(mD))$ へ延長されます。
    よってすべての $m \ge 1$ で $h^0(\tilde{X}, m\pi^* D + mE) = h^0(X, mD)$ となり、飯高次元が完全に一致します。

3. **直積での加法性：**
    層のテンソル積に関するキュネットの公式（Künneth formula）より、すべての $m \ge 1$ に対して

    $$H^0\big(X_1 \times X_2, \, \mathcal{O}(m\operatorname{pr}_1^* D_1 + m\operatorname{pr}_2^* D_2)\big) \;\cong\; H^0(X_1, \mathcal{O}_{X_1}(mD_1)) \otimes_{\mathbb{C}} H^0(X_2, \mathcal{O}_{X_2}(mD_2))$$

    が成り立ちます。両辺の次元をとると積 $h^0(X_1, mD_1) \cdot h^0(X_2, mD_2)$ になるため、一方が $0$ なら積も $0$（$-\infty$）、両方正なら多項式増大度が $m^{\kappa_1} \cdot m^{\kappa_2} = m^{\kappa_1 + \kappa_2}$ となり、和 $\kappa_1 + \kappa_2$ に一致します。（証明終）

### 4. 翻訳と展望（Bridge）：次節（小平次元）と飯高予想への直接の接続

1. **次節「6-2. 小平次元 $\kappa(X)$」の双有理不変性の準備完了：**
    本節の命題2で示した等式 $\kappa(\tilde{X}, \pi^* D + E) = \kappa(X, D)$ に対し、$D = K_X$（標準因子）を代入します。
    4-4節で2次元・3次元のブローアップを手計算して確認した通り、非特異射影多様体間の双有理射 $\pi : \tilde{X} \to X$ では、ヤコビ行列式の零点として必ず有効な例外因子 $E \ge 0$ が現れ、$K_{\tilde{X}} \sim \pi^* K_X + E$ が成り立ちます。
    したがって、命題2より直ちに $\kappa(\tilde{X}, K_{\tilde{X}}) = \kappa(X, K_X)$（小平次元の双有理不変性）が確定します。

2. **飯高予想 $\kappa(X) \ge \kappa(Y) + \kappa(F)$ の基準点：**
    命題3（直積での加法性）を標準因子に適用すると、直積 $X = Y \times F$ の標準因子は $K_{Y \times F} = \operatorname{pr}_1^* K_Y + \operatorname{pr}_2^* K_F$（2-4節の外積の分解そのまま）なので、

    $$\kappa(Y \times F) = \kappa(Y) + \kappa(F)$$

    が等号で成り立ちます。飯高予想は、直積ではない一般の「ねじれたファイバー空間（ファイバーの形が底空間の点ごとに連続的に変形する空間）」においても、不等式 $\kappa(X) \ge \kappa(Y) + \kappa(F)$ が保たれることを主張しています。
