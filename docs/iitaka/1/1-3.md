### 前節（1-2）の確認問題の解答

前節の最後に提示した問いの答え合わせから始めます。

1. **イデアル $I_1 = (x, y)$ と $I_2 = (x + y, x - y)$ は集合として完全に一致します（$I_1 = I_2$）。**

    * $x + y \in I_1$ かつ $x - y \in I_1$ なので、それらの結合で作られる $I_2$ は $I_1$ に含まれます（$I_2 \subset I_1$）。
    * 逆に、$\mathbb{R}[x, y]$ の中では $\frac{1}{2}$ を掛けることができるので、

        $$x = \frac{1}{2}(x + y) + \frac{1}{2}(x - y) \in I_2, \qquad y = \frac{1}{2}(x + y) - \frac{1}{2}(x - y) \in I_2$$

        となり、$x$ も $y$ も $I_2$ の元から作れます。よって $I_1 \subset I_2$ も成り立ち、$I_1 = I_2$ です。（※なお、もし係数が整数環 $\mathbb{Z}[x, y]$ や $1 + 1 = 0$ となる2元体 $\mathbb{F}_2[x, y]$ であった場合は、$\frac{1}{2}$ 倍（$2$ での割り算）ができないため、$(x + y, x - y)$ は $(x, y)$ より真に小さいイデアルになります。体 $\mathbb{R}$ 上で $2$ が可逆元であることがここで効いています。）

2. 連立方程式 $\begin{cases} x = 0 \\ y = 0 \end{cases}$ は「$y$ 軸と $x$ 軸の交点」、連立方程式 $\begin{cases} x + y = 0 \\ x - y = 0 \end{cases}$ は「斜め45度の2本の直線の交点」を表しますが、どちらも交点（解集合）は**原点 $(0, 0)$ ただ1点**です。
    「座標軸の向き（式の選び方）を変えても、生成されるイデアル $I$ 自体は全く同じであり、それが同じ幾何学的図形（原点）を表現している」ことがよく分かります。

それでは、「1-3. 剰余環（商環 $R/I$）と準同型定理：方程式が成り立つ世界と『図形上の関数環』の構成」に進みます。

## 1-3. 剰余環（商環 $R/I$）と準同型定理：方程式が成り立つ世界を作る操作

### 1. 動機（Why）：なぜ多項式環 $R$ をイデアル $I$ で割るのか？

[第0部](../index.md#part-0)の「0-2. 商空間」では、ベクトル空間 $V$ を部分空間 $W$ で割ることで、「$W$ の方向のズレをすべて $0$ とみなして潰した空間 $V/W$」を作りました。
これを「環 $R$」と「イデアル $I$」に対して全く同じように実行したものが、**剰余環（または商環 / Quotient ring）$R/I$** です。

なぜ代数幾何学や代数学全般において、この「多項式環 $R$ をイデアル $I$ で割った剰余環 $R/I$」が決定的に重要なのでしょうか？

**理由①：「方程式 $f = 0$ が成り立つ図形の上の世界」を純粋な数式だけで構築できるから**
たとえば平面 $\mathbb{R}^2$ 全体の多項式環 $\mathbb{R}[x, y]$ の中では、多項式 $x^2 + y^2 - 1$ はゼロではありません。
しかし、私たちが調べたいのが「単位円 $C: x^2 + y^2 - 1 = 0$ の上」だけであるとき、円周 $C$ の上では常に $x^2 + y^2 - 1 = 0$（すなわち $y^2 = 1 - x^2$）が成り立っています。
したがって、円周 $C$ 上で2つの関数 $g(x, y) = y^2 + 2x$ と $h(x, y) = 1 - x^2 + 2x$ の値を比べると、その差は


$$g(x, y) - h(x, y) = y^2 - (1 - x^2) = x^2 + y^2 - 1$$


となり、円周 $C$ の上ではどこでも差が $0$（つまり**円周上の関数としてはまったく同じ関数**）になります。

つまり、**「全体の多項式環 $\mathbb{R}[x, y]$ を、図形の上で $0$ になる式のイデアル $I = (x^2 + y^2 - 1)$ で割った剰余環 $\mathbb{R}[x, y] / I$」こそが、「図形 $C$ の上で定義された関数全体のなす環（座標環）」そのものになる**のです。

**理由②：新しい「数（複素数 $\mathbb{C}$ や代数拡大体）」や「微小変化（微分）」を生み出す製造機だから**
実数体 $\mathbb{R}$ の中に $x^2 + 1 = 0$ の解は存在しません。しかし、多項式環 $\mathbb{R}[x]$ をイデアル $(x^2 + 1)$ で割った剰余環 $\mathbb{R}[x]/(x^2 + 1)$ を作ると、その世界の中では強制的に $x^2 + 1 = 0 \iff x^2 = -1$ というルールが成立し、未知数 $x$ のクラス $[x]$ がそのまま虚数単位 $i$ となって**複素数体 $\mathbb{C}$** が誕生します。

### 2. 具体例と幾何学的イメージ（Toy Model）

数式とイメージを直結させるため、3つの具体例で剰余環 $R/I$ を実際に計算してみます。

#### 例A：実数多項式環から複素数体を作る（$\mathbb{R}[x] / (x^2 + 1) \cong \mathbb{C}$）

1変数多項式環 $R = \mathbb{R}[x]$ を、単項イデアル $I = (x^2 + 1)$ で割った剰余環 $\mathbb{R}[x] / (x^2 + 1)$ を考えます。
「差が $x^2 + 1$ の倍数である多項式同士を同じとみなす」ということは、どんな高次の多項式 $f(x)$ を持ってきても、**$x^2 + 1$ で割り算した余り $a + bx$（1次以下の多項式）だけを見ればよい**ということです（なぜなら $f(x) = q(x)(x^2 + 1) + (a + bx)$ より、差 $f(x) - (a + bx) \in (x^2 + 1)$ となるため）。

さらにこの世界では、$[x^2 + 1] = [0]$ すなわち $[x]^2 = [-1]$ という計算ルールが成り立っています。
そこで、剰余類 $[x]$ のことを文字 $i$ と書くことにすると、すべての元 $[a + bx] = a + bi$ の足し算と掛け算は、


$$(a + bi)(c + di) = ac + (ad + bc)i + bd i^2 = (ac - bd) + (ad + bc)i$$


となり、**複素数体 $\mathbb{C}$ の演算と完全に一致します**。（同様に、有理数係数の多項式環 $\mathbb{Q}[x]$ を $(x^2 - 2)$ で割った剰余環 $\mathbb{Q}[x]/(x^2 - 2)$ を作れば、$[x]$ がそのまま $\sqrt{2}$ の役割を果たし、無理数を添加した体 $\mathbb{Q}(\sqrt{2}) = \{a + b\sqrt{2} \mid a, b \in \mathbb{Q}\}$ が純粋に多項式の割り算だけで構成されます。）

> **【コラム：$\mathbb{Z}/4\mathbb{Z}$ は体にならないのに、なぜ「要素が4個の体 $\mathbb{F}_4$」が作れるのか？】**
>
> [1-1節](1-1.md)で、$\mathbb{Z}/n\mathbb{Z}$ が体になるのは $n$ が素数のときだけで、$n = 4$ では $2 \times 2 = 4 \equiv 0$（零因子）があるため $\mathbb{Z}/4\mathbb{Z}$ は体にならないことを見ました。では、要素がちょうど $4$ 個の「体」は存在しないのでしょうか？
> 実は、例Aで $\mathbb{R}[x]$ を $(x^2 + 1)$ で割って複素数体 $\mathbb{C}$ を作ったのとまったく同じ手順を、2元体 $\mathbb{F}_2 = \{0, 1\}$（$1 + 1 = 0$ の世界）の上で行うことで、**要素が4個の体 $\mathbb{F}_4$** が作れます。
>
> 1. $\mathbb{F}_2[x]$ の2次多項式 $p(x) = x^2 + x + 1$ に $x = 0, 1$ を代入すると、$p(0) = 1 \neq 0, \; p(1) = 1 + 1 + 1 = 1 \neq 0$ となり、$\mathbb{F}_2$ の中に根を持ちません（つまり既約多項式です）。
> 2. そこで剰余環 $\mathbb{F}_4 := \mathbb{F}_2[x] / (x^2 + x + 1)$ を作ります。$x^2 + x + 1$ で割った余りは1次以下なので、$\alpha := [x]$ とおくと、元は $\{0, \, 1, \, \alpha, \, \alpha + 1\}$ のちょうど **4個** です。
> 3. この世界では $\alpha^2 + \alpha + 1 = 0$、すなわち $\alpha^2 = \alpha + 1$（$\mathbb{F}_2$ では $-1 = +1$ のため）が成り立ちます。掛け算を確かめると、$\alpha \cdot (\alpha + 1) = \alpha^2 + \alpha = (\alpha + 1) + \alpha = 1$ となり、$0$ 以外のすべての元 $\{1, \, \alpha, \, \alpha + 1\}$ に逆元が存在します。
>
> このように、「既約多項式で割って剰余環を作る」という操作は、複素数体 $\mathbb{C}$ だけでなく、すべての有限体 $\mathbb{F}_{p^r}$ や代数拡大体を生み出す万能の製造機なのです。

#### 例B：「2乗すると $0$ になる無限小」の世界 $\mathbb{R}[x] / (x^2)$（二重数）と極限を使わない自動微分

例Aでは $x^2 + 1 = 0$（2乗すると $-1$）で割りましたが、もし**単項イデアル $I = (x^2)$（2乗すると $0$）**で多項式環 $\mathbb{R}[x]$ を割った剰余環 $\mathbb{R}[x] / (x^2)$ を作ったら何が起きるでしょうか？

$x^2$ で割った余りはやはり1次以下の多項式 $a + bx$ なので、剰余類 $\varepsilon := [x]$ とおくと、この剰余環のすべての元は $a + b\varepsilon$（$a, b \in \mathbb{R}$）と一意に表されます（これを**二重数 / Dual numbers**と呼びます）。
この世界では、$\varepsilon \neq 0$ であるにもかかわらず、

$$\varepsilon^2 = [x^2] = 0$$

というルールが成り立っています（つまり $\varepsilon$ は[1-1節](1-1.md)で学んだ零因子、特に何乗かすると $0$ になる**べき零元**であり、「1次の微小量は残るが、2次以上の微小量 $\varepsilon^2, \varepsilon^3, \dots$ はすべて $0$ に消える理想的な無限小」として振る舞います）。

いま、任意の多項式 $f(x) \in \mathbb{R}[x]$ の変数 $x$ に、点 $a \in \mathbb{R}$ から $\varepsilon$ だけずらした $a + \varepsilon$ を代入してこの剰余環の中で計算してみます。
たとえば単項式 $x^n$ に $a + \varepsilon$ を代入して二項展開すると、$\varepsilon^2 = \varepsilon^3 = \dots = 0$ より

$$(a + \varepsilon)^n = a^n + n a^{n-1}\varepsilon + \binom{n}{2} a^{n-2}\underbrace{\varepsilon^2}_{=\,0} + \dots = a^n + n a^{n-1}\varepsilon$$

となります。したがって、任意の多項式 $f(x) = \sum c_n x^n$ に代入しても（テイラー展開の2次以上の項がすべて自動的に消滅し）、

$$f(a + \varepsilon) = f(a) + f'(a)\varepsilon + \frac{f''(a)}{2!}\underbrace{\varepsilon^2}_{=\,0} + \cdots = f(a) + f'(a)\varepsilon$$

となり、**極限 $\lim_{h \to 0}$ を一切とることなく、剰余環の代数計算だけで1次の係数に導関数 $f'(a)$ が正確に取り出せます**。

* **科学技術計算における「自動微分（Automatic Differentiation）」：**
    コンピュータ上で関数の微分値を求めるとき、微小な数値 $h = 10^{-8}$ を使う「数値微分 $\frac{f(a+h)-f(a)}{h}$」では桁落ちによる丸め誤差が発生し、数式を展開する「数式微分」では式が爆発的に長くなります。これに対し、数の四則演算をすべてこの二重数 $a + b\varepsilon$（$\varepsilon^2 = 0$）の演算 $(a + b\varepsilon)(c + d\varepsilon) = ac + (ad + bc)\varepsilon$ に置き換えてプログラムを1回走らせるだけで、丸め誤差ゼロで関数値 $f(a)$ と導関数値 $f'(a)$ のペアを同時に算出する手法が**自動微分（前進モード）**です。

* **代数幾何学における接空間の原型：**
    この「点 $a$ の周りの2次以上の微小項 $(x - a)^2$ をイデアルで割って $0$ に潰すことで、純粋に代数の操作だけで微分（1次近似・接ベクトル）を取り出す」というアイデアこそが、次節（[1-4節](1-4.md)）や[第2部](../index.md#part-2)・[第4部](../index.md#part-4)で登場する**ザリスキ余接空間 $\mathfrak{m}_P / \mathfrak{m}_P^2$** の核心そのものになります。

* **【2次式で割った3つの剰余環の比較（判別式の符号と環・図形の対応）】：**
    ここで、1変数多項式環 $\mathbb{R}[x]$ を3種類の2次式 $x^2 - 1, \; x^2, \; x^2 + 1$ で割った剰余環を並べてみると、2次方程式の解の配置（幾何）と剰余環の構造（代数）の明確な対応が見えてきます。

    1. **$\mathbb{R}[x] / (x^2 - 1) \cong \mathbb{R} \times \mathbb{R}$（相異なる2実数解 $x = \pm 1$）：**
        $x^2 - 1 = (x - 1)(x + 1)$ と因数分解できるため、剰余環の中では $[x - 1][x + 1] = [0]$ という**零因子**が現れます。各多項式 $f(x)$ を2点 $x = 1, -1$ での値のペア $(f(1), f(-1)) \in \mathbb{R} \times \mathbb{R}$ に写す評価写像により、この剰余環は2つの実数体の直積 $\mathbb{R} \times \mathbb{R}$（2つの独立した点の上の関数環）に分裂します。（実際、任意の $(a, b) \in \mathbb{R} \times \mathbb{R}$ に対して1次多項式 $f(x) = \frac{a-b}{2}x + \frac{a+b}{2}$ をとれば $(f(1), f(-1)) = (a, b)$ となるため評価写像は全射であり、また因数定理より $f(1) = f(-1) = 0 \iff (x - 1)(x + 1) \mid f(x)$ なので核はちょうど $(x^2 - 1)$ になります。よって後述する環の準同型定理から $\mathbb{R}[x]/(x^2 - 1) \cong \mathbb{R} \times \mathbb{R}$ が従います。）

    2. **$\mathbb{R}[x] / (x^2) = \mathbb{R}[\varepsilon]/(\varepsilon^2)$（重解 $x = 0$：二重数）：**
        2つの解 $\pm 1$ が原点 $x = 0$ の1点に合流した極限です。点は $x = 0$ の1点だけになりますが、「2点が合流した痕跡（無限小の厚み・接ベクトル方向）」として2乗すると $0$ になる**べき零元 $\varepsilon$** が生き残り、点での値 $f(0)$ だけでなく傾き $f'(0)$ まで記憶しています。

    3. **$\mathbb{R}[x] / (x^2 + 1) \cong \mathbb{C}$（実数解なし・複素共役解 $x = \pm i$）：**
        実数の範囲では因数分解できない（既約多項式である）ため、零因子が一切現れず、剰余環全体が1つの**体（複素数体 $\mathbb{C}$）**になります。

#### 例C：放物線 $Y: y - x^2 = 0$ 上の関数環（座標環）

幾何学の例を見てみましょう。平面 $\mathbb{R}^2$ 内の放物線 $Y = \{(x, y) \in \mathbb{R}^2 \mid y - x^2 = 0\}$ を考えます。
全体の多項式環 $\mathbb{R}[x, y]$ を、放物線の方程式が生成するイデアル $I = (y - x^2)$ で割った剰余環


$$\mathbb{R}[Y] := \mathbb{R}[x, y] \,/\, (y - x^2)$$


を考えます。この剰余環の中では $[y - x^2] = [0]$、すなわち **$[y] = [x]^2$** です。
したがって、2変数のどんな多項式 $f(x, y)$ を持ってきても、その中の文字 $y$ にすべて $x^2$ を代入して消去したもの $f(x, x^2)$（$x$ だけの1変数多項式）と同じクラスに属します：


$$[f(x, y)] = [f(x, x^2)] \quad \big(\text{なぜなら差 } f(x, y) - f(x, x^2) \text{ は必ず } y - x^2 \text{ で割り切れるから}\big)$$


この結果、放物線上の関数環 $\mathbb{R}[x, y]/(y - x^2)$ は、**1変数多項式環 $\mathbb{R}[x]$（数直線 $\mathbb{R}^1$ 上の関数環）と環として完全に同型**になります。
幾何学的に見れば、「放物線 $y = x^2$ は、曲がっているけれど上からの射影 $(x, x^2) \mapsto x$ によって1次元の数直線 $\mathbb{R}^1$ と1対1に対応している（同じ形をしている）」という事実が、剰余環の計算 $\mathbb{R}[x, y]/(y - x^2) \cong \mathbb{R}[x]$ として的確に捉えられています。

### 3. 厳密な定義と定理（What）：剰余環の構成と環の準同型定理

ここからは、[0-2節](../0/0-2.md)（商空間）との違いに注目しながら、剰余環と環の準同型定理を厳密に定式化します。

#### (1) 剰余環（商環）$R/I$ の定義と「なぜイデアルの吸収律が必要だったのか」

可換環 $R$ とそのイデアル $I \subset R$ に対し、[0-2節](../0/0-2.md)とまったく同じ同値関係


$$f \sim g \iff f - g \in I$$


を入れ、同値類（剰余類）を $[f] = f + I := \{ f + h \mid h \in I \}$、その全体の集合を $R/I := \{ f + I \mid f \in R \}$ とします。
ここに、2つの演算（加法と乗法）を代表元で定義します。

* **加法：** $(f + I) + (g + I) := (f + g) + I$
* **乗法：** $(f + I) \cdot (g + I) := (fg) + I$

**【本質的ステップ：乗法が Well-defined になるカラクリ】**
加法の Well-defined 性は [0-2節](../0/0-2.md)と同じですが、環には乗法（掛け算）があります。
代表元を $f' = f + h_1$、$g' = g + h_2$（ただし $h_1, h_2 \in I$）に取り替えたとき、新しい積 $f'g'$ を展開すると、


$$f'g' = (f + h_1)(g + h_2) = fg + \underbrace{f h_2 + g h_1 + h_1 h_2}_{\text{ここがすべて } I \text{ に入る必要がある}}$$


となります。
ここで、$f$ や $g$ は $I$ の外にある $R$ の一般の元です。にもかかわらず、ズレの項 $f h_2 + g h_1 + h_1 h_2$ が確実に $I$ の中に収まるためには、「$I$ の元 $h_1, h_2$ に、$R$ のどんな元 $f, g$ を掛けても $I$ に吸収される（吸収律）」というイデアルの定義そのものが必要不可欠だったのです。
もし $I$ が単なる部分環（$I$ の中だけで掛け算が閉じている集合）だったら、$f h_2$ が $I$ からはみ出してしまい、剰余環の掛け算は定義できません。「イデアルとは、商環 $R/I$ の掛け算を Well-defined にするために逆算して作られた概念である」と理解すると、イデアルの定義が完全に腑に落ちます。

これにより、$R/I$ は単位元 $1 + I$、零元 $0 + I = I$ を持つ可換環となり、これを剰余環（Quotient ring）と呼びます。

---

#### (2) 環の準同型写像と「環の準同型定理」

2つの可換環 $R, S$ の間の写像 $\varphi: R \to S$ が、任意の $a, b \in R$ に対して


$$\varphi(a + b) = \varphi(a) + \varphi(b), \quad \varphi(ab) = \varphi(a)\varphi(b), \quad \varphi(1_R) = 1_S$$


を満たすとき、$\varphi$ を環の準同型写像（Ring homomorphism）と呼びます（足し算も掛け算も保ち、$1$ を $1$ に写す写像）。

このとき、核 $\ker \varphi$ と像 $\operatorname{Im} \varphi$ を


$$\ker \varphi := \{ a \in R \mid \varphi(a) = 0_S \} \subset R, \qquad \operatorname{Im} \varphi := \{ \varphi(a) \mid a \in R \} \subset S$$


と定めると、次の基本性質が成り立ちます。

1. **核 $\ker \varphi$ は $R$ のイデアルになる：**
    なぜなら、$h \in \ker \varphi$（$\varphi(h) = 0$）に $R$ の任意の元 $a \in R$ を掛けたとき、$\varphi(ah) = \varphi(a)\varphi(h) = \varphi(a) \cdot 0 = 0$ となり、$ah \in \ker \varphi$ と吸収律を満たすからです。

2. **像 $\operatorname{Im} \varphi$ は $S$ の部分環になる。**

そして、[0-2節](../0/0-2.md)のベクトル空間のときとまったく同じ証明で、代数学の大黒柱である次の定理が成り立ちます。

> **【定理：環の準同型定理（Fundamental Theorem on Ring Homomorphisms）】**
> $\varphi: R \to S$ を環の準同型写像とする。このとき、剰余環 $R / \ker \varphi$ から像 $\operatorname{Im} \varphi$ への写像
> 
> $$\tilde{\varphi}: R / \ker \varphi \to \operatorname{Im} \varphi, \quad \tilde{\varphi}(a + \ker \varphi) := \varphi(a)$$
> 
> 
> 
> は Well-defined な環の同型写像（全単射な環準同型）となる。すなわち、
> 
> $$R / \ker \varphi \cong \operatorname{Im} \varphi$$
> 
> 

**【具体例での確認（例Cの放物線を準同型定理で示す）】**
先ほどの例C「$\mathbb{R}[x, y] / (y - x^2) \cong \mathbb{R}[x]$」を、この準同型定理を使って証明してみましょう。

1. 2変数多項式環 $\mathbb{R}[x, y]$ から1変数多項式環 $\mathbb{R}[x]$ へ、「文字 $y$ に $x^2$ を代入する」という写像

    $$\varphi: \mathbb{R}[x, y] \to \mathbb{R}[x], \quad \varphi(f(x, y)) := f(x, x^2)$$

    を考えます。代入操作は和と積を保つので、$\varphi$ は全射の環準同型写像です（$\operatorname{Im} \varphi = \mathbb{R}[x]$）。

2. $\varphi$ の核 $\ker \varphi$（$y = x^2$ を代入すると $0$ になる多項式全体）を求めます。
    任意の $f(x, y) \in \mathbb{R}[x, y]$ を $y$ の多項式と見て $(y - x^2)$ で割ると（※係数が体ではなく環 $\mathbb{R}[x]$ であっても、割る多項式 $y - x^2$ の $y$ に関する最高次係数が $1$［モニック多項式］であるため、筆算の割り算の途中で係数の割り算が一切発生せず、商 $q(x, y) \in \mathbb{R}[x, y]$ と余り $r(x) \in \mathbb{R}[x]$ が一意に定まります）、$f(x, y) = q(x, y)(y - x^2) + r(x)$ と書けます。これに $y = x^2$ を代入すると $f(x, x^2) = r(x)$ となるため、

    $$f(x, x^2) = 0 \iff r(x) = 0 \iff f(x, y) \text{ は } y - x^2 \text{ で割り切れる}$$

    すなわち、**$\ker \varphi = (y - x^2)$** です。

3. よって環の準同型定理より、直ちに

    $$\mathbb{R}[x, y] / (y - x^2) = \mathbb{R}[x, y] / \ker \varphi \cong \operatorname{Im} \varphi = \mathbb{R}[x]$$

    が証明されました。

このように、「剰余環 $R/I$ の正体を知りたければ、核がちょうど $I$ になるような代入写像 $\varphi: R \to S$ を見つけて準同型定理を使えばよい」というのが、代数学および代数幾何学における最も標準的な計算テクニックです。

> **【コラム：中国剰余定理 —— 「離れた2つの図形の上の関数」が直積に分解する仕組み】**
>
> 例Bの比較で見た $\mathbb{R}[x]/(x^2 - 1) \cong \mathbb{R} \times \mathbb{R}$ や、整数での $\mathbb{Z}/6\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/3\mathbb{Z}$（「$2$ で割った余り」と「$3$ で割った余り」を決めれば「$6$ で割った余り」がただ1つ決まる）は、どちらも可換環論の**中国剰余定理**の具体例です。
>
> **【中国剰余定理】** 可換環 $R$ の2つのイデアル $I, J$ が「互いに素（$I + J = R$、すなわち $a + b = 1$ となる $a \in I, \; b \in J$ が存在する）」であるとき、自然な同型
>
> $$R / (I \cap J) \;\cong\; R / I \;\times\; R / J, \qquad [x] \longmapsto ([x]_I, \, [x]_J)$$
>
> が成り立つ。
>
> これを幾何学に翻訳すると自然な意味になります。
>
> * イデアル $I, J$ が表す図形を $X_1 = V(I), \; X_2 = V(J)$ とします。
> * 「$I + J = R$（$1 \in I + J$）」とは、2つの図形に共通の点がない（**$X_1 \cap X_2 = \emptyset$、図形が離れている**）ことを意味します。
> * 一方、$I \cap J$ は**合併 $X_1 \cup X_2$** に対応するイデアルです。
>
> したがって、中国剰余定理 $R/(I \cap J) \cong R/I \times R/J$ は、幾何学的には「互いに離れた2つの図形 $X_1, X_2$ の合併の上で関数を1つ指定することは、$X_1$ 上の関数と $X_2$ 上の関数を別々に1つずつ独立に指定することと完全に同じである」という事実を、純粋に環の言葉で表現したものなのです。

### 4. 翻訳と展望（Bridge）：これが飯高理論のどこに直結するのか？

1. **代数多様体 $X$ の座標環 $k[X] = k[x_1, \dots, x_n] / I(X)$（[第4部](../index.md#part-4)）：**
    アフィン空間 $k^n$ 内の代数多様体 $X$ に対し、「$X$ のすべての点で $0$ になる多項式全体の集合」を $I(X)$ とすると、$I(X)$ は多項式環 $k[x_1, \dots, x_n]$ のイデアルになります。
    そして、多様体 $X$ 上の多項式関数全体のなす環（**座標環 $k[X]$**）は、まさに「多項式を $X$ 上に制限する写像 $\varphi$」に準同型定理を適用することで、

    $$k[X] \cong k[x_1, \dots, x_n] \,/\, I(X)$$

    という剰余環として定義されます。これにより、「図形 $X$ の幾何学的性質」がすべて「剰余環 $k[x_1, \dots, x_n]/I(X)$ の代数的性質」へと翻訳されます。

2. **部分多様体（ファイバー）への制限とイデアル層（[第5部](../index.md#part-5)・[第6部](../index.md#part-6)）：**
    飯高予想などで、多様体 $X$ の中に部分多様体 $F$（ファイバーなど）があるとき、「$X$ 上の関数（層 $\mathcal{O}_X$）」を「$F$ 上の関数（層 $\mathcal{O}_F$）」へ制限する操作は、各局所において「$F$ 上で $0$ になる関数のイデアル $\mathcal{I}_F$ で割る操作」すなわち

    $$\mathcal{O}_F \cong \mathcal{O}_X / \mathcal{I}_F$$

    という剰余環の形で記述されます。全体空間 $X$ の標準束の情報をファイバー $F$ へ引き継がせる（随伴公式や拡張定理）際、この剰余環の完全列が重要な役割を果たします。

> **【確認の問い】**

>

>
> を考えます。これは全射の環準同型写像です（定数関数を代入すれば任意の実数が出せるので $\operatorname{Im}(\operatorname{ev}_3) = \mathbb{R}$）。
>
> 1. この評価写像の核 $\ker(\operatorname{ev}_3) = \{ f(x) \in \mathbb{R}[x] \mid f(3) = 0 \}$ は、高校数学の「因数定理」を使うと、どの1次多項式が生成する単項イデアルになるでしょうか？
> 2. 環の準同型定理を使うと、剰余環 $\mathbb{R}[x] / \ker(\operatorname{ev}_3)$ は何と同型になるでしょうか？（特に、その剰余環は「体」になっているでしょうか？）
