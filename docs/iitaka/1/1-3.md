前回の最後に提示した問いの答え合わせから始めます。

1. **イデアル $I_1 = (x, y)$ と $I_2 = (x + y, x - y)$ は集合として完全に一致します（$I_1 = I_2$）。**
* $x + y \in I_1$ かつ $x - y \in I_1$ なので、それらの結合で作られる $I_2$ は $I_1$ に含まれます（$I_2 \subset I_1$）。
* 逆に、$\mathbb{R}[x, y]$ の中では $\frac{1}{2}$ を掛けることができるので、

$$x = \frac{1}{2}(x + y) + \frac{1}{2}(x - y) \in I_2, \qquad y = \frac{1}{2}(x + y) - \frac{1}{2}(x - y) \in I_2$$



となり、$x$ も $y$ も $I_2$ の元から作れます。よって $I_1 \subset I_2$ も成り立ち、$I_1 = I_2$ です。


2. 連立方程式 $\begin{cases} x = 0 \\ y = 0 \end{cases}$ は「$y$ 軸と $x$ 軸の交点」、連立方程式 $\begin{cases} x + y = 0 \\ x - y = 0 \end{cases}$ は「斜め45度の2本の直線の交点」を表しますが、どちらも交点（解集合）は**原点 $(0, 0)$ ただ1点**です。
「座標軸の向き（式の選び方）を変えても、生成されるイデアル $I$ 自体は全く同じであり、それが同じ幾何学的図形（原点）を表現している」ことがよく分かります。

それでは、「1-3. 剰余環（商環 $R/I$）と準同型定理：リード・ソロモン符号や巡回符号の構成と、『方程式の解空間上の関数環』の共通構造」に進みます。

## 1-3. 剰余環（商環 $R/I$）と準同型定理：方程式が成り立つ世界を作る操作

### 1. 動機（Why）：なぜ多項式環 $R$ をイデアル $I$ で割るのか？

第0部の「0-2. 商空間」では、ベクトル空間 $V$ を部分空間 $W$ で割ることで、「$W$ の方向のズレをすべて $0$ とみなして潰した空間 $V/W$」を作りました。
これを「環 $R$」と「イデアル $I$」に対して全く同じように実行したものが、**剰余環（または商環 / Quotient ring）$R/I$** です。

なぜ代数幾何学や符号理論で、この「多項式環 $R$ をイデアル $I$ で割った剰余環 $R/I$」が決定的に重要なのでしょうか？

**理由①：「方程式 $f = 0$ が成り立つ図形の上の世界」を純粋な数式だけで構築できるから**
たとえば平面 $\mathbb{R}^2$ 全体の多項式環 $\mathbb{R}[x, y]$ の中では、多項式 $x^2 + y^2 - 1$ はゼロではありません。
しかし、私たちが調べたいのが「単位円 $C: x^2 + y^2 - 1 = 0$ の上」だけであるとき、円周 $C$ の上では常に $x^2 + y^2 - 1 = 0$（すなわち $y^2 = 1 - x^2$）が成り立っています。
したがって、円周 $C$ 上で2つの関数 $g(x, y) = y^2 + 2x$ と $h(x, y) = 1 - x^2 + 2x$ の値を比べると、その差は


$$g(x, y) - h(x, y) = y^2 - (1 - x^2) = x^2 + y^2 - 1$$


となり、円周 $C$ の上ではどこでも差が $0$（つまり**円周上の関数としてはまったく同じ関数**）になります。

つまり、**「全体の多項式環 $\mathbb{R}[x, y]$ を、図形の上で $0$ になる式のイデアル $I = (x^2 + y^2 - 1)$ で割った剰余環 $\mathbb{R}[x, y] / I$」こそが、「図形 $C$ の上で定義された関数全体のなす環（座標環）」そのものになる**のです。

**理由②：新しい「数（複素数 $\mathbb{C}$ や有限体 $\mathbb{F}_{p^m}$）」や「符号」を生み出す製造機だから**
実数体 $\mathbb{R}$ の中に $x^2 + 1 = 0$ の解は存在しません。しかし、多項式環 $\mathbb{R}[x]$ をイデアル $(x^2 + 1)$ で割った剰余環 $\mathbb{R}[x]/(x^2 + 1)$ を作ると、その世界の中では強制的に $x^2 + 1 = 0 \iff x^2 = -1$ というルールが成立し、未知数 $x$ のクラス $[x]$ がそのまま虚数単位 $i$ となって**複素数体 $\mathbb{C}$** が誕生します。

### 2. 具体例・情報系との接点（Toy Model）

数式とイメージを直結させるため、3つの具体例で剰余環 $R/I$ を実際に計算してみます。

#### 例A：実数多項式環から複素数体を作る（$\mathbb{R}[x] / (x^2 + 1) \cong \mathbb{C}$）

1変数多項式環 $R = \mathbb{R}[x]$ を、単項イデアル $I = (x^2 + 1)$ で割った剰余環 $\mathbb{R}[x] / (x^2 + 1)$ を考えます。
「差が $x^2 + 1$ の倍数である多項式同士を同じとみなす」ということは、どんな高次の多項式 $f(x)$ を持ってきても、**$x^2 + 1$ で割り算した余り $a + bx$（1次以下の多項式）だけを見ればよい**ということです（なぜなら $f(x) = q(x)(x^2 + 1) + (a + bx)$ より、差 $f(x) - (a + bx) \in (x^2 + 1)$ となるため）。

さらにこの世界では、$[x^2 + 1] = [0]$ すなわち $[x]^2 = [-1]$ という計算ルールが成り立っています。
そこで、剰余類 $[x]$ のことを文字 $i$ と書くことにすると、すべての元 $[a + bx] = a + bi$ の足し算と掛け算は、


$$(a + bi)(c + di) = ac + (ad + bc)i + bd i^2 = (ac - bd) + (ad + bc)i$$


となり、**複素数体 $\mathbb{C}$ の演算と完全に一致します**。

#### 例B：符号理論における巡回符号の舞台 $\mathbb{F}_q[x] / (x^n - 1)$ と拡大体 $\mathbb{F}_{2^m}$

情報系（符号理論や暗号理論）において、剰余環は2つの場面で中心的な役割を果たします。

1. **要素数 $2^m$ 個の有限体 $\mathbb{F}_{2^m}$（AES暗号やリード・ソロモン符号のシンボル）：**
1-1節で、素数 $p$ に対して $\mathbb{Z}/p\mathbb{Z} = \mathbb{F}_p$ が体になることを見ました。しかしコンピュータでは1バイト＝8ビット（$2^8 = 256$ 個の数）で四則演算ができる体 $\mathbb{F}_{2^8}$ が必要です。$256$ は素数ではないので、整数の余り $\mathbb{Z}/256\mathbb{Z}$ では零因子が出て体になりません（$16 \times 16 = 256 \equiv 0$）。
そこで、例Aと全く同じように、$\mathbb{F}_2 = \{0, 1\}$ 上の多項式環 $\mathbb{F}_2[x]$ を、**因数分解できない（既約な）$8$ 次多項式 $p(x)$**（たとえばAESで使われる $p(x) = x^8 + x^4 + x^3 + x + 1$）のイデアル $(p(x))$ で割った剰余環

$$\mathbb{F}_{2^8} := \mathbb{F}_2[x] \,/\, (x^8 + x^4 + x^3 + x + 1)$$



を作ります。余りは7次以下の多項式 $a_0 + a_1 x + \dots + a_7 x^7$（係数 $(a_0, \dots, a_7)$ がちょうど8ビットのデータ！）になり、$p(x)$ が因数分解できないおかげで零因子が一切発生せず、$256$ 個の元を持つ完全な**体**になります。
2. **巡回符号（Cyclic code）の代数構造：**
長さ $n$ の符号語 $(c_0, c_1, \dots, c_{n-1})$ を多項式 $c(x) = c_0 + c_1 x + \dots + c_{n-1} x^{n-1}$ と表したとき、「右に1ビット巡回シフトする操作 $(c_{n-1}, c_0, \dots, c_{n-2})$」は、多項式に $x$ を掛けて

$$x c(x) = c_0 x + c_1 x^2 + \dots + c_{n-1} x^n$$



とし、**$x^n$ を $1$ に置き換える（つまり $x^n - 1 = 0$ とみなす）**操作に一致します。
したがって、巡回符号が住んでいる空間とはまさに**剰余環 $R = \mathbb{F}_q[x] / (x^n - 1)$** であり、「巡回シフトしても符号の中に留まる部分空間」とは「$x$ を掛けても閉じている部分空間」、すなわち前節で学んだ**剰余環 $R$ のイデアル**そのものになります。

#### 例C：放物線 $Y: y - x^2 = 0$ 上の関数環（座標環）

幾何学の例を見てみましょう。平面 $\mathbb{R}^2$ 内の放物線 $Y = \{(x, y) \in \mathbb{R}^2 \mid y - x^2 = 0\}$ を考えます。
全体の多項式環 $\mathbb{R}[x, y]$ を、放物線の方程式が生成するイデアル $I = (y - x^2)$ で割った剰余環


$$\mathbb{R}[Y] := \mathbb{R}[x, y] \,/\, (y - x^2)$$


を考えます。この剰余環の中では $[y - x^2] = [0]$、すなわち **$[y] = [x]^2$** です。
したがって、2変数のどんな多項式 $f(x, y)$ を持ってきても、その中の文字 $y$ にすべて $x^2$ を代入して消去したもの $f(x, x^2)$（$x$ だけの1変数多項式）と同じクラスに属します：


$$[f(x, y)] = [f(x, x^2)] \quad \big(\text{なぜなら差 } f(x, y) - f(x, x^2) \text{ は必ず } y - x^2 \text{ で割り切れるから}\big)$$


この結果、放物線上の関数環 $\mathbb{R}[x, y]/(y - x^2)$ は、**1変数多項式環 $\mathbb{R}[x]$（数直線 $\mathbb{R}^1$ 上の関数環）と環として完全に同型**になります。
幾何学的に見れば、「放物線 $y = x^2$ は、曲がっているけれど上からの射影 $(x, x^2) \mapsto x$ によって1次元の数直線 $\mathbb{R}^1$ と1対1に対応している（同じ形をしている）」という事実が、剰余環の計算 $\mathbb{R}[x, y]/(y - x^2) \cong \mathbb{R}[x]$ として完璧に捉えられています。

### 3. 厳密な定義と定理（What）：剰余環の構成と環の準同型定理

ここからは、0-2節（商空間）との違いに注目しながら、剰余環と環の準同型定理を厳密に定式化します。

#### (1) 剰余環（商環）$R/I$ の定義と「なぜイデアルの吸収律が必要だったのか」

可換環 $R$ とそのイデアル $I \subset R$ に対し、0-2節とまったく同じ同値関係


$$f \sim g \iff f - g \in I$$


を入れ、同値類（剰余類）を $[f] = f + I := \{ f + h \mid h \in I \}$、その全体の集合を $R/I := \{ f + I \mid f \in R \}$ とします。
ここに、2つの演算（加法と乗法）を代表元で定義します。

* **加法：** $(f + I) + (g + I) := (f + g) + I$
* **乗法：** $(f + I) \cdot (g + I) := (fg) + I$

**【本質的ステップ：乗法が Well-defined になるカラクリ】**
加法の Well-defined 性は 0-2節と同じですが、環には乗法（掛け算）があります。
代表元を $f' = f + h_1$、$g' = g + h_2$（ただし $h_1, h_2 \in I$）に取り替えたとき、新しい積 $f'g'$ を展開すると、


$$f'g' = (f + h_1)(g + h_2) = fg + \underbrace{f h_2 + g h_1 + h_1 h_2}_{\text{ここがすべて } I \text{ に入る必要がある！}}$$


となります。
ここで、$f$ や $g$ は $I$ の外にある $R$ の一般の元です。にもかかわらず、ズレの項 $f h_2 + g h_1 + h_1 h_2$ が確実に $I$ の中に収まるためには、「$I$ の元 $h_1, h_2$ に、$R$ のどんな元 $f, g$ を掛けても $I$ に吸収される（吸収律）」というイデアルの定義そのものが必要不可欠だったのです！
もし $I$ が単なる部分環（$I$ の中だけで掛け算が閉じている集合）だったら、$f h_2$ が $I$ からはみ出してしまい、剰余環の掛け算は定義できません。「イデアルとは、商環 $R/I$ の掛け算を Well-defined にするために逆算して作られた概念である」と理解すると、イデアルの定義が完全に腑に落ちます。

これにより、$R/I$ は単位元 $1 + I$、零元 $0 + I = I$ を持つ可換環となり、これを剰余環（Quotient ring）と呼びます。

---

#### (2) 環の準同型写像と「環の準同型定理」

2つの可換環 $R, S$ の間の写像 $\varphi: R \to S$ が、任意の $a, b \in R$ に対して


$$\varphi(a + b) = \varphi(a) + \varphi(b), \quad \varphi(ab) = \varphi(a)\varphi(b), \quad \varphi(1_R) = 1_S$$


を満たすとき、$\varphi$ を環の準同型写像（Ring homomorphism）と呼びます（足し算も掛け算も保ち、$1$ を $1$ に写す写像）。

このとき、核 $\ker \varphi$ と像 $\operatorname{Im} \varphi$ を


$$\ker \varphi := \{ a \in R \mid \varphi(a) = 0_S \} \subset R, \qquad \operatorname{Im} \varphi := \{ \varphi(a) \mid a \in R \} \subset S$$


と定めると、次の基本性質が成り立ちます。

1. **核 $\ker \varphi$ は $R$ のイデアルになる：**
なぜなら、$h \in \ker \varphi$（$\varphi(h) = 0$）に $R$ の任意の元 $a \in R$ を掛けたとき、$\varphi(ah) = \varphi(a)\varphi(h) = \varphi(a) \cdot 0 = 0$ となり、$ah \in \ker \varphi$ と吸収律を満たすからです。
2. **像 $\operatorname{Im} \varphi$ は $S$ の部分環になる。**

そして、0-2節のベクトル空間のときとまったく同じ証明で、代数学の大黒柱である次の定理が成り立ちます。

> **【定理：環の準同型定理（Fundamental Theorem on Ring Homomorphisms）】**
> $\varphi: R \to S$ を環の準同型写像とする。このとき、剰余環 $R / \ker \varphi$ から像 $\operatorname{Im} \varphi$ への写像
> 
> $$\tilde{\varphi}: R / \ker \varphi \to \operatorname{Im} \varphi, \quad \tilde{\varphi}(a + \ker \varphi) := \varphi(a)$$
> 
> 
> 
> は Well-defined な環の同型写像（全単射な環準同型）となる。すなわち、
> 
> $$R / \ker \varphi \cong \operatorname{Im} \varphi$$
> 
> 

**【具体例での威力の確認（例Cの放物線を1行で証明する）】**
先ほどの例C「$\mathbb{R}[x, y] / (y - x^2) \cong \mathbb{R}[x]$」を、この準同型定理を使って鮮やかに証明してみましょう。

1. 2変数多項式環 $\mathbb{R}[x, y]$ から1変数多項式環 $\mathbb{R}[x]$ へ、「文字 $y$ に $x^2$ を代入する」という写像

$$\varphi: \mathbb{R}[x, y] \to \mathbb{R}[x], \quad \varphi(f(x, y)) := f(x, x^2)$$



を考えます。代入操作は和と積を保つので、$\varphi$ は全射の環準同型写像です（$\operatorname{Im} \varphi = \mathbb{R}[x]$）。
2. $\varphi$ の核 $\ker \varphi$（$y = x^2$ を代入すると $0$ になる多項式全体）を求めます。
任意の $f(x, y) \in \mathbb{R}[x, y]$ を $y$ の多項式と見て $(y - x^2)$ で割ると、$f(x, y) = q(x, y)(y - x^2) + r(x)$ と書けます。これに $y = x^2$ を代入すると $f(x, x^2) = r(x)$ となるため、

$$f(x, x^2) = 0 \iff r(x) = 0 \iff f(x, y) \text{ は } y - x^2 \text{ で割り切れる}$$



すなわち、**$\ker \varphi = (y - x^2)$** です。
3. よって環の準同型定理より、直ちに

$$\mathbb{R}[x, y] / (y - x^2) = \mathbb{R}[x, y] / \ker \varphi \cong \operatorname{Im} \varphi = \mathbb{R}[x]$$



が証明されました！
このように、「剰余環 $R/I$ の正体を知りたければ、核がちょうど $I$ になるような代入写像 $\varphi: R \to S$ を見つけて準同型定理を使えばよい」というのが、代数学および代数幾何学における最も標準的な計算テクニックです。

### 4. 翻訳と展望（Bridge）：これが飯高理論のどこに直結するのか？

1. **代数多様体 $X$ の座標環 $k[X] = k[x_1, \dots, x_n] / I(X)$（第4部）：**
アフィン空間 $k^n$ 内の代数多様体 $X$ に対し、「$X$ のすべての点で $0$ になる多項式全体の集合」を $I(X)$ とすると、$I(X)$ は多項式環 $k[x_1, \dots, x_n]$ のイデアルになります。
そして、多様体 $X$ 上の多項式関数全体のなす環（**座標環 $k[X]$**）は、まさに「多項式を $X$ 上に制限する写像 $\varphi$」に準同型定理を適用することで、

$$k[X] \cong k[x_1, \dots, x_n] \,/\, I(X)$$



という剰余環として定義されます。これにより、「図形 $X$ の幾何学的性質」がすべて「剰余環 $k[x_1, \dots, x_n]/I(X)$ の代数的性質」へと完全に翻訳されます。
2. **部分多様体（ファイバー）への制限とイデアル層（第5部・第6部）：**
飯高予想などで、多様体 $X$ の中に部分多様体 $F$（ファイバーなど）があるとき、「$X$ 上の関数（層 $\mathcal{O}_X$）」を「$F$ 上の関数（層 $\mathcal{O}_F$）」へ制限する操作は、各局所において「$F$ 上で $0$ になる関数のイデアル $\mathcal{I}_F$ で割る操作」すなわち

$$\mathcal{O}_F \cong \mathcal{O}_X / \mathcal{I}_F$$



という剰余環の形で記述されます。全体空間 $X$ の標準束の情報をファイバー $F$ へ引き継がせる（随伴公式や拡張定理）際、この剰余環の完全列が決定的な役割を果たします。
